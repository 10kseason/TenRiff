# Lane map

TenRiff applies lane asset arrays from the leftmost lane in order.
Charts with fewer keys use the first N entries.

| Index | Direction | Accent |
|---:|---|---|
| 1 | `left` (90°) | `rgb(255, 76, 92)` |
| 2 | `down` (180°) | `rgb(73, 170, 255)` |
| 3 | `up` (0°) | `rgb(91, 231, 160)` |
| 4 | `right` (-90°) | `rgb(255, 209, 78)` |
| 5 | `down-left` (135°) | `rgb(232, 92, 255)` |
| 6 | `up-left` (45°) | `rgb(64, 232, 255)` |
| 7 | `up-right` (-45°) | `rgb(154, 117, 255)` |
| 8 | `down-right` (-135°) | `rgb(255, 135, 57)` |
| 9 | `center-down` (180°) | `rgb(76, 229, 205)` |
| 10 | `center-up` (0°) | `rgb(244, 244, 255)` |
