# Tencircle

osu!에서 넘어온 사람들을 위한 **로비 전용** TenRiff 스킨.

로비/메뉴 화면만 바꾼다. 게임플레이(기어, 노트, 판정선)는 손대지 않으므로
TenRiff 네이티브 렌더링 그대로 돌아간다. 게임플레이까지 바꾸려면 이 폴더의
`skin.json`에 `gameplay` 섹션을 추가하면 된다. 슬롯 목록은
[`docs/skin-format.md`](../../../docs/skin-format.md)에 있다.

## 무엇이 익숙하게 보이는가

| 요소 | 의도 |
|---|---|
| 마젠타→플럼 그라데이션 | osu! 메뉴 특유의 핑크 톤 |
| 위를 향한 삼각형 필드 | 3단 깊이(먼 것은 블러, 가까운 것은 선명) |
| 히트서클 링 + 어프로치 서클 | 화면 좌우 여백에 배치 — 패널에 가리지 않는 자리 |
| 둥근 워드마크 + 핑크 `!` | Arial Rounded MT Bold |
| 히트서클 안의 `10` | 콤보 숫자 자리에 TenRiff의 "Ten" |

이미지는 전부 `generate.py`에서 직접 그린다. 다른 게임에서 가져온 애셋은 없다.

## 곡 선택 화면 배치

osu!는 곡 목록이 화면 오른쪽에 있다. 그래서 `skin.json`의 `layout`으로 곡 목록과
난이도 패널의 자리를 서로 바꿔 두었다. 폭은 기본값 그대로(곡 목록 756px,
난이도 592px) 두고 위치만 맞바꾼 것이라 패널 안 텍스트는 잘리지 않는다.

```json
"layout": {
  "song_select": {
    "center_panel": [1126, 152, 1882, 922],
    "right_panel": [510, 152, 1102, 922]
  }
}
```

TenRiff 기본 배치(곡 목록 가운데)로 돌리려면 `layout` 블록을 통째로 지우면 된다.
옮길 수 있는 다른 슬롯은 [`docs/skin-format.md`](../../../docs/skin-format.md)의
"레이아웃 슬롯"에 정리돼 있다.

## 설치

1. 게임에서 `Options > Skins > Import Skin`을 누르고 이 폴더를 고른다.
   (Skins 화면에 폴더를 드래그해도 된다.)
2. `Skin Source`를 `TenRiff`로 바꾼다.
3. `TenRiff Skin` 행에서 `Tencircle`을 고른다.

## 수정

PNG를 직접 편집하지 말고 `generate.py`를 고친 뒤 다시 돌린다.

```bash
python generate.py
```

색은 파일 위쪽 팔레트 상수에 모여 있다. 자주 건드릴 만한 것들:

- `PINK` / `MAGENTA` / `PLUM_950` — 전체 색조
- `lobby_background()`의 `triangle_field(...)` 세 줄 — 삼각형 개수, 크기, 진하기
- `bodies` / `rings` — 히트서클 위치와 반지름
- 마지막 `vig` 계수 `0.34` — 비네트 세기

배경이 너무 밝거나 어두우면 `skin.json`의 `background_opacity`(현재 `0.95`)를 조절한다.
엔진은 이 이미지를 어두운 기본 배경 위에 그 투명도로 겹쳐 그린다.

## 알아둘 것

- 메뉴의 강조색(청록 `#6EE7F2`)과 본문 텍스트 색은 엔진이 그리는 값이라 스킨에서 바꿀 수 없다.
  핑크 배경 위에서 보색으로 튀는데, 이게 싫으면 엔진 쪽 테마를 손봐야 한다.
- 상단바 패널은 반투명(`#14141C`, 실효 알파 약 0.63)이라 배경이 비쳐 보인다.
  로고 슬롯은 `48,18`–`388,108` (340×90)이고 비율을 유지한 채 맞춰진다.
