# TenRiff Example Skin

2026-11-09 Modern Common 로컬 후보용 **이미지 없는 Native v1 최소 예제**다.
폴더를 복사한 뒤 이름·색을 바꾸고 가져오면 된다. `lobby.renderer`와
`gameplay.renderer`를 각각 `native`로 지정하므로 메뉴와 게임 모두 기본 구성 요소를 쓴다.

- 로비 배경/로고: `lobby/`
- 화면별 배경: `lobby/screens/<screen-id>.png`
- 노트/롱노트/키/기어/인게임 배경: `gameplay/`
- 1~16키 기본 도형, 4K 팔레트와 16K 판정선 명도 오버라이드가 포함돼 있다.
- 노트·LN 머리·꼬리의 0·1번 레이어는 외곽선, 2번은 불투명 본체다. 테두리를 꺼도 본체가 남는다.
- 판정선 명도는 공통 80%, 16K는 60%다. 사용자 명도 50%를 적용하면 각각 40%, 30%가 된다.
- 공개 final2 클라이언트용으로 만들 때는 `judgement_line_brightness`를 제거한다. 형식 버전은 1을 유지한다.
- 전체 필드와 배열 사용법: [`docs/skin-format.md`](../../../docs/skin-format.md)

빈 이미지 경로 `""`는 해당 표준 파일 자동 탐색을 끈다. 이미지를 넣으려면 해당 필드에
경로를 지정하거나 필드를 생략해 표준 파일명 탐색을 허용한다. 빈 벡터 배열 `[]`는
해당 도형 숨김이므로 혼동하지 않는다. 파일을 바꾼 뒤 스킨 설정에서 `F5`로 다시 읽는다.
