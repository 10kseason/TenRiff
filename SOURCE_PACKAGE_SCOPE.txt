Notes:
- The source bundle is intended to contain code, docs, config, and tests needed to inspect or rebuild the project.
- Internal agent instructions and private working context are intentionally excluded from the public source package.
- Local caches, packaged binaries, user profiles, and private working files are intentionally excluded.
- Local LLM/tooling checkouts such as `external/llama.cpp/` are intentionally excluded from the public source package.
- The repository license is MIT and should be shipped with both source and binary distributions.
- The generic External ONNX Upscaler source and compatibility tools are included, but BGA upscaler models, checkpoints, training data, and model-specific verification metadata are excluded. The only bundled ONNX is the project-owned deterministic NK3 decision graph.
