# Library・Session Mixのボタン修正

フォルダー追加はLibraryタブのコンテンツ見出しにのみ表示します。Songs、Records、Session Mixでは表示しません。

Session Mixの長さ・リミックス・保存・読み込みボタンをコース画面専用の入力処理につなぎました。リミックス後に生成したステージ数を表示します。メニュー音声が動作中でも保存・読み込みダイアログが開き、キャンセル時は下書きと既存のコースパスを保持します。

カスタムコースの作成: 曲一覧で譜面を選び、**C**で順に下書きへ追加し、Session Mixの**下書き保存**を選択します。同じ譜面の繰り返しも可能です。**コース読み込み**で`.lr2crs`を選ぶか、Session Mixへドロップしてください。下書きが空なら作成方法を表示します。

LR2CRS形式、譜面MD5照合、コースの判定・ゲージ・リプレイ動作は変更しません。
