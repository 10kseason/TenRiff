# TenRiff 2.0.1

[한국어](release-2.0.1.ko.md) | [English](release-2.0.1.en.md) | [日本語](release-2.0.1.ja.md) | [简体中文](release-2.0.1.zh-CN.md)

옵션 화면 가독성을 수정했습니다.

- 기본 옵션 은하 배경 밝기를 2.0.0의 40%로 낮췄습니다(원본 RGB 배율 0.392).
- 8개 카드의 가로·세로와 내부 글자·아이콘을 각각 85%로 줄이고 클릭 영역도 맞췄습니다.
- 선택한 옵션의 설명을 카드 아래 한 줄로 표시합니다. 한국어·영어·일본어·중국어를 지원합니다.

판정·점수·리플레이·저장 형식과 final4 호환 기준은 유지합니다. 사용자 지정 배경은 그대로입니다.
