# 選曲背景の星座

[한국어](menu-constellations.ko.md) | [English](menu-constellations.en.md) | [日本語](menu-constellations.ja.md) | [简体中文](menu-constellations.zh-CN.md)

標準の選曲動画の暗い余白に、おひつじ座・てんびん座・かに座をモチーフにした小さな星座を三つ表示します。細い線、青みのある光とまばらな周囲の星で望遠鏡から眺めるような雰囲気を加えます。天体観測用の正確な星図ではありません。

既存レンダラーで動画の上、文字とパネルの下に描画します。動画の再圧縮や追加画像の読み込みはありません。位置は固定し、明るさだけがゆっくり僅かに変化します。システムまたはアプリの動きを減らす設定では静止します。

カスタムスキンの背景・動画、タイトル、リザルト、プレイ画面には適用しません。元の動画、判定と記録は変わりません。参考画像はローカル作業資料としてのみ保管し、ランタイム素材には含めません。
