# 1.9.0 릴리스: 판정 범위와 EX

키 모드 설정의 `판정 범위`에서 **기본 / Hard / EX**를 선택한다. 내부 모드 관리자에 있던 판정 항목을 상위 화면으로 옮기고 나머지 내부 모드의 한국어 이름·값·설명을 정리한다. Easy는 새 플레이 선택지에서 제거하며, 과거 리플레이의 Easy 판정은 그대로 재현한다.

## 수치

아래 숫자는 BMS RANK EASY 기준의 앞뒤 각각의 시간이다. PG/GR/GD에는 기존 BMS RANK 비율(3: 1, 2: 18/21, 1: 15/21, 0: 8/21)을 적용한다. BMS 파일의 RANK EASY와 제거된 플레이 모드 Easy는 서로 다른 값이다.

| 선택 | PG | GREAT | GOOD | BAD 입력 범위 | 점수 배율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 | 21ms | 65ms | 115ms | 210ms, RANK 적용 | 1.00 |
| Hard | 17.5ms | 55.714286ms | 98.571429ms | 모든 RANK 225ms | 1.10 |
| EX | 14ms | 44.571429ms | 78.857143ms | 모든 RANK 250ms | 1.10 |

EX의 좋은 판정 세 범위는 Hard의 80%다. 표의 소수는 표시용 반올림이며 실제 계산에는 비율을 사용한다. EX에 별도의 점수 보너스는 추가하지 않는다. BAD 창은 Hard보다 넓어져 빗나간 입력을 더 넓게 잡는다. 누르지 않은 노트의 자동 미스는 별도 정책으로 기존 340ms 초과를 유지한다. Hard/EX의 자동 미스는 간접 POOR다. 홀드 유예·CN 해제 시간·입력 마스크·음량·게이지는 변경하지 않는다.

## 기록과 호환

- 기본과 Hard의 새 기록은 기존 R5를 유지한다. EX만 `tenriff-native-score-v2-ruleset-6`을 사용하며, 커스텀 EX는 `custom-ruleset-6`이다. 기존 R1–R5의 수치와 재생 규칙은 바꾸지 않는다.
- EX 토큰을 모르는 예전 실행 파일이 정상 R5로 오해하지 않도록 별도 규칙 ID를 사용한다. 기존 리플레이 파일 구조는 유지한다.
- 웹은 R6의 EX와 R5의 기존 판정을 별도 순위로 취급한다. 기존 게시판 ID, 점수, 계정, 기록은 다시 쓰지 않으며 DB 마이그레이션도 추가하지 않는다.
- 판정 선택은 기존처럼 실행 중 설정이다. 프로필에 영구 저장하지 않으며 재시작하면 기본으로 돌아간다. 리플레이 원본과 멀티 공통 규칙이 우선한다.

전체 경계·미스·LN 정책은 [판정 범위](judgement-windows.md)를 참고한다. 빌드·경계·리플레이·웹 검증의 최종 수치는 릴리스의 `evidence/VERIFICATION.ko.md`에 기록한다.
