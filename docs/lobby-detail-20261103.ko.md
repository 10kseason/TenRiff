# 선곡 클리어 배지·곡 정보·배경 영상

2026-11-03 로컬 후속 후보입니다. 리절트 롤백 후보를 이어받으며, 리절트의 복원된 배치를 유지합니다.

- 곡 목록 오른쪽 점수와 미플레이 `--` 대신 기존 EZ CLEAR / NM CLEAR / HD CLEAR / EX CLEAR 배지를 표시합니다. 기존 로고·서체·클리어 색과 EX 프리즘을 재사용합니다. 실패/보조 플레이의 상태를 정식 클리어로 바꾸지 않으며 미플레이 칸은 비웁니다. 폴더의 곡 수는 유지합니다.
- 우측 내 최고 기록의 점수는 유지하고, 그 아래 곡 정보를 BPM / 키 수 / Lv / 노트 수 / 판정 난이도와 NPS 막대로 정리합니다. MIN / AVG / MAX는 막대 패널 안에 표시합니다.
- NPS는 원본 BMS의 시작 시각 0부터 마지막 노트 시작이 들어 있는 1초 구간까지 계산합니다. TAP/LN 시작은 각각 한 개, 꼬리와 지뢰는 제외하며 쉬는 구간은 0으로 포함합니다. MIN/산술 AVG/MAX는 전체 1초 구간 기준이고, 막대만 최대 96개 시간 구간의 최고값으로 축약합니다. 배속 1.0·고정 분기 기준이며 실제 랜덤 분기와 다를 수 있습니다. 계산 중·원본 없음·8MB 초과·6시간 이상 일정은 미표시합니다. 기존 MED 캐시/기록 형식은 유지합니다.
- 상세 정확도는 선곡/로비 표시에서 숨깁니다. 상세 점수·일반 정확도와 리절트의 상세 정확도, 저장 값은 유지합니다.
