# 곡 선택·리절트 시안 적용

2026-11-03

제공한 HTML 시안의 검은 배경, 얇은 구분선, 상단 탭, 좌측 곡 목록/우측 상세, 리절트 공통 요약 띠와 넓은 분석 영역을 네이티브 화면에 적용한 로컬 후보입니다.

사용자가 흰색으로 가린 분포바·중간 난이도 열·점수 아래 클리어/BP 보조문구·우측 클리어 제목은 제외합니다. 기존 지표는 상세/리절트에 유지하며 시안의 예시 숫자·추정 진단·장식 그래프는 데이터로 사용하지 않습니다.

곡 목록은 10행을 표시하며 검색은 목록 위에 있습니다. 실제 표시 기록의 점수에 EX 프리즘·HD 빨강·NM 노랑·EZ 초록을 사용하고, 검증된 FULL COMBO는 기존 라임 글로우와 약한 블룸을 유지합니다. 기존 폰트와 정확도/판정/FAST/SLOW 의미색을 사용합니다.

요약·레인·노트 종류·시간대 탭을 유지합니다. 점수/상세 점수/정확도/콤보/판정 수, 타이밍 분포·평균·절대 오차·표준편차, 레인 및 노트 종류, 시간 구간과 누적 게이지는 기존 계산 결과를 표시합니다. 재도전·리플레이·계속과 기존 NEW RECORD/랭크 상승 연출도 이어집니다.

이전 효과음 5개·음악 선택기·30프레임/1초 전환·실시간 비교기 설정을 이어받습니다. 별도 ui-layout-local 프로필을 사용하며 이전 후보/원본/설치는 보존합니다. 일반 고정 기준선은 1.9.6이고 공개 버전은 승격하지 않습니다.
