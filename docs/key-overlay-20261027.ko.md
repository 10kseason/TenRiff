# 키 오버레이와 로고 · 로컬 후속 작업

기본 위치는 X 0%, Y 25%로, 기본 Classic/Studio HUD의 레인·게이지·점수 영역을 피해 배치합니다.

1.9.9.1에 로컬 단축키/길게 누르기, 세션 믹스 변경을 이어받은 미공개 작업입니다. 일반 고정 기준선 1.9.6과 기존 릴리스는 그대로입니다.

- **설정 → 스킨 → HUD → 키 오버레이 플러그인 (4/5/7/8/10K)**에서 켭니다. 기본 OFF이며 설정 검색에서 `오버레이`로 찾을 수 있습니다.
- **키 오버레이 X/Y**는 화면 안에서 0~100%, 1% 단위로 위치를 조절합니다. 켜짐 상태와 위치는 전역 설정·프로필·휴대용 스킨 프리셋에 저장됩니다. 스킨 미리보기에는 가상 입력과 `미리보기` 표시만 나오며 추정값을 만들지 않습니다.
- 실제 플레이 키 수가 **4·5·7·8·10**일 때만 표시합니다. 다른 키 수에서는 설정을 보존한 채 숨깁니다. 현재 키 바인딩·레인 색·스크래치 표시 순서를 사용합니다.
- 키 입력과 누르는 길이, 최근 1초 NPS, 최근 8초 입력 패턴의 추정 난이도를 표시합니다. [key-note-overlay-cpp](https://github.com/10kseason/key-note-overlay-cpp)의 v2.13 계산 코어와 보정표를 사용합니다. 4K Reform, 5K AERY, 7K Jinjin, 8K Regular, 10K Revive 기준이며 입력 없는 짧은 구간의 보존값에는 `*`가 붙습니다. 위/아래 화살표는 기준 범위 밖입니다.
- 이 값은 **현재 입력 패턴의 부하 추정**입니다. 곡 전체 난이도, 플레이어 실력이나 클리어 가능성을 판정하지 않습니다. 원본 단위·단명은 그대로 사용합니다.
- TenRiff가 받아들인 실제 레인 전환을 관찰합니다. 보조키가 같은 레인의 소유권을 넘겨받는 동안 계속 눌린 레인은 하나의 홀드로 표시합니다. 판정·점수·리플레이·오디오 처리는 바꾸지 않습니다. 일시정지/카운트다운/포커스 이탈/종료 시 수집을 초기화하며 오토·리플레이·고스트 입력을 집계하지 않습니다.

오디오/판정 스레드에서는 고정 크기 큐에 이벤트만 넣고, HUD 스레드가 최대 10Hz로 난이도를 계산합니다. 큐 손실이나 오래된 입력을 발견하면 전체 추정 구간을 비워 잘못된 홀드/수치를 방지합니다. 별도 프로세스, 전역 키보드 훅, 서비스, 통신, 자동 실행은 추가하지 않습니다. 이 기능은 게임 안에 그리는 내장 플러그인입니다.

홈·선곡·설정·결과 화면의 기본 TenRiff 심벌과 워드마크 표시를 키웠습니다. 기존 원본 이미지와 사용자가 지정한 레이아웃 슬롯은 보존합니다.

검증 기록은 후보 폴더의 `evidence/VERIFICATION.ko.md`에 있습니다. 실제 키보드 장치·OBS 캡처·장시간 플레이는 자동 검증과 별개입니다. MIT 원문과 파일별 출처는 `third_party/key_note_overlay/`에 포함합니다. 외부 앱의 트레이, 보고서, osu! 메모리 읽기 기능은 포함하지 않습니다.
