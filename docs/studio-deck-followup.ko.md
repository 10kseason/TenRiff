# 스튜디오 덱: LR2, 리프 맵, BGA 가독성 보완

1.8.6 이후 사용자 요청에 따른 로컬 변경이다. 이전 사양의 LR2 제외 조건을
해제하되, 판정·게이지·점수·노트 배칭과 렌더링 루프는 바꾸지 않는다.

- 스킨 소스 `native` 또는 `lr2`의 단독 플레이에서 HUD 스타일이 `studio`이면
  스튜디오 덱을 표시한다. LR2 가져오기 경로는 `lr2` 소스를 유지하므로 별도
  변환 포맷을 만들지 않는다. 기존 LR2 노트·건반·기어 이미지와 해상도별 비율은
  원래 경로로 렌더링한다. 다른 이미지 스킨(`tenriff`), 고스트 대전과 멀티플레이는
  클래식 배치를 유지한다.
- Options › Skins › **스튜디오 리프 맵**은 왼쪽 노트 밀도 그래프와 경과/전체
  시간을 함께 켜고 끈다. `skin.hud_riff_map_visible` 기본값은 `true`이며, 기존
  프로필에 키가 없어도 표시된다. 프로필과 `.trskin` 프리셋에 저장되고 게임 내
  전체 화면 미리보기에도 전달된다. 클래식 HUD와 다른 HUD 열 위치는 바뀌지 않는다.
- 그래프를 끄면 정적 64개 막대와 동적 진행선·시계가 함께 사라진다. 표시 상태는
  기존 `GameplayStaticCache`의 비교 키로 사용하므로 전환 시 한 번만 다시
  기록한다. 꺼진 동안 밀도 데이터만 바뀌어도 정적 레이어를 다시 만들지 않는다.
- BGA가 밝아도 곡 제목·설정·점수·리프 맵 시계를 읽을 수 있도록 해당 영역에
  `#050608` 92% 불투명도의 받침을 추가한다. 받침은 기존 정적 커맨드 리스트에
  기록한다. 작은 보조 글자와 그래프 시간 눈금도 밝게 조정했다. 영상 프레임이나
  점수 변경 때문에 새 도형/그라데이션/텍스트 레이아웃을 만들지 않는다.

`hud_layout`과 `hud_riff_map_visible`은 플레이어 프로필 설정이다. 스킨 제작용
JSON 스키마나 외부 웹/오프라인 에디터 슬롯에 별도 필드를 추가하지 않는다.
원래 HUD의 필드 극단 이동 시 공간 부족에 따른 그래프/오른쪽 열 숨김은 유지한다.

회귀 검증 대상은 Native/LR2 활성 조건, 다른 이미지 스킨 및 대전 제외, 그래프
표시/숨김 위치 보존, 프로필·프리셋 왕복, 스킨 설정의 키보드/포인터 공통 경로,
게임 내 미리보기 전달이다. `menu_visual_preview`의 `--lr2-skin <폴더>`,
`--riff-map-off`, `--toggle-riff-map-frame <프레임>`으로 실제 렌더러를 확인할 수
있고, benchmark JSON의 `studio_hud_active`와 `riff_map_cached_visible`은 정적
캐시의 실제 상태를 기록한다. 최종 빌드·테스트·캡처 결과는 통합 검증 보고서를 따른다.
