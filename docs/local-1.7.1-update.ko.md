# 1.7.1 로컬 수정본 — 2026-09-10

공식 1.7.1 소스 위에 요청된 기능과 검증 수정을 반영한 로컬 Windows x64 빌드다. 정식 GitHub 릴리스나 서버 배포는 수행하지 않았다.

## 구현과 사용법

- **스킨 프리셋 공유**: Options → Skins → 스킨 프리셋 내보내기에서 `.trskin` 파일을 저장한다. 받는 PC에서는 가져오기 버튼 또는 스킨 화면에 파일 드롭으로 적용한다. 모든 키 모드의 설정과 활성 스킨 자산을 포함하며, 가져오기는 새 이름의 폴더를 사용한다. [프리셋 안내](skin-presets.md).
- **난이도표**: 선곡의 난이도표/선택 카드에서 5키 에리·7키 에리·10키 리바이브를 선택한다. 선택 창의 F1/F2/F3도 지원한다. 기존 URL·로컬 JSON·기본 LV 기능은 유지한다. 동일 표를 다시 선택해도 새로 받은 내용을 재적용한다.
- **곡 소스 관리**: 소스 화면의 폴더 추가/F2, 목록에서 제거/Del을 사용한다. 제거는 저장된 목록만 바꾸고 실제 폴더·곡·캐시는 삭제하지 않는다. 마지막 소스를 제거한 빈 상태도 저장한다. [소스 관리](library-management.md).
- **검증 실패 수정**: NK3 모델을 Windows native 파일 API로 열고, 프로필과 리플레이 검증기 실행·인자를 UTF-8/UTF-16 경계에 맞게 처리한다. 경로 테스트의 잘못된 ANSI 변환도 수정했다.
- **멀티 결과 보존**: 네트워크 worker가 라운드 명단과 완료 점수를 보존한다. 상대가 나가도 순위에서 사라지지 않으며, 아직 안 끝난 상대의 늦은 최종 점수는 반영한다. 새 라운드/새 연결에서 초기화한다. 프로토콜은 변경하지 않았다.

## 게이지

일반 Easy/Normal/Hard는 LR2 재현으로 보기 어렵다. Easy/Normal은 LR2의 TOTAL/노트수 기반 회복, 20% 시작·80% 클리어와 달리 고정 회복·100% 시작·생존 및 병렬 Gauge Shift를 사용한다. 일반 밸런스는 요청대로 비교만 하고 유지했다. [전체 수치 비교와 근거](lr2-gauge-audit.ko.md).

단위인정/코스는 LR2 beta3 동작을 보존한 OpenLR2 역공학 소스를 기준으로 변경했다.

| 판정 | 게이지 변화 |
|---|---:|
| PG / GR | +0.1 |
| GD | +0.04 |
| BAD | -2 |
| 간접미스 POOR | -3 |
| 빈 입력 POOR | -2 |

100%에서 시작해 곡간 실제 값을 이월하고, 직전 값 32% 미만에서는 손실을 0.6배로 줄인다. 2% 미만에서 실패한다. 표준 LN의 게이지는 머리에서 회복하지 않고 완주/해제 때 한 번 적용한다. 간접미스는 유지하며 새 코스 리플레이에는 규칙과 이월값을 저장한다. 일반 점수 산식과 기존 리플레이 해석은 바꾸지 않았다.

원본 실행 파일과 입력별 A/B까지 완료한 것은 아니다. LNMODE 2 차지 노트는 LR2 beta3에 없는 기능이어서 기존 TenRiff의 머리/꼬리 가중치를 유지한다. 따라서 모든 차트·판정 동작의 비트 단위 LR2 동일성을 주장하지 않는다.

## 검증

| 검사 | 결과 |
|---|---|
| MSVC Windows x64 Release | 게임·검증기·테스트·NK3 smoke·판정 benchmark 빌드 성공 |
| Release CTest | 3/3 통과, 단위 738/738, 통합 제외 0 |
| NK3 Unicode 경로 | P64/MLP Vulkan 및 324개 변환 경로 통과 |
| MSVC AddressSanitizer | 2/2 통과, 단위 728개 실행, 기존 통합 검사 10개 제외 |
| 실제 난이도표 가져오기 | 5KEYS AERY / 7KEYS AERY / 10Key Revive Pack 모두 성공, 비어 있지 않은 데이터 로드 |
| 프리셋 | 원본 삭제 후 새 프로필 복원, 충돌 회피, CP932 LR2 경로, 손상·탈출·길이·깊이 방어 통과 |
| 소스 관리 | 파일 보존, 활성/비활성 제거, 빈 목록 저장/복원 통과 |
| 멀티플레이 | 로컬 2·3인 이탈·늦은 점수·재대전 및 기존 4·8인 시작 경로 통과 |

Release와 ASan 모두 설치 경로 및 TEMP/TMP에 한글이 포함된 조건으로 실행했다. 공개 소스에 없는 외부 `10k-calc` Python 참조는 선택적 skip 메시지 하나를 출력한다. 최초 실패 로그도 남겼으며, 테스트 매크로·Unicode assertion·ASan 단독 테스트 자산 준비 문제를 수정한 뒤 통과했다. 새 검사 제외를 추가하지 않았다.

주요 로그는 수정 작업 폴더의 `evidence/ctest-release-final.log`, `ctest-asan-final.log`, 실제 난이도표 확인은 `ctest-release.log`다. 최종 빌드 로그에는 컴파일 오류/경고가 없다. 별도 최소 NK3 compile 실험의 기존 외부 헤더 경고는 원본 로그에 보존했다.

실제 파일 선택창 조작, 원격 인터넷 다인전, 오디오 장치별 플레이와 지속 FPS는 이번 자동 검사 범위에 포함하지 않았다. 시스템 폰트나 LR2 외부 참조처럼 이식 범위 밖인 조건은 프리셋 안내에 명시했다.
