# TenRiff 1.9.0 固定基準

[한국어](baseline-1.9.0.md) | [English](baseline-1.9.0.en.md) | [日本語](baseline-1.9.0.ja.md) | [简体中文](baseline-1.9.0.zh-CN.md)

**固定基準: [1.9.0](baseline-1.9.0.ja.md)**（2026-10-14の明示的な依頼）。Git tag `1.9.0`を使い、`main`や`latest`に合わせて自動更新しません。旧1.8.7基準と既存リリースは履歴として保持します。

## 識別と保持

2026-10-14の明示的依頼で1.8.7から**1.9.0**へ更新します。[旧1.8.7](baseline-1.8.7.ja.md)、タグ・配布物・設定・原譜面を保持します。`git rev-parse 1.9.0^{commit}`で固定タグのコミットを確認してください。最終コミットとZIPのSHA-256は当該リリース本文とチェックサムファイルに記録し、自身を含むZIPのハッシュをソースへ埋め込みません。Windows GUI/BMS専用の範囲を維持します。

## 動作と互換性

- BMS全体とメニュー/結果音楽の音量を分離。BMS100%は相対ゲイン1.0、メニュー音楽基準0.1、マスター既定70%。保存値を保持します。
- 判定は実行中のみ有効な通常/Hard/EX。EXはEASY RANK基準PG14/GR44.571429/GD78.857143msにRANK倍率を適用し、BAD250msは固定。自動ミス340ms、Hardのホールド規則・点数倍率1.10を保持します。
- 通常/Hardの新規記録はR5、EXはR6。旧R1–R5・Easy・変換バージョンのリプレイを保持し、旧クライアントのR6対応は保証しません。
- 生存完走はS++99/S+98/S95/A+93/A90/B85/C80/残りD、死亡F。表示変更で旧スコアを再保存しません。
- キャッシュ17でSUBARTIST/OBJを再読込し、譜面・リプレイは変更しません。新規設定はEXゲージ・高速最小索引・ゴーストOFF。スキン/フォント/表示サイズは判定・入力・バッチ描画の契約を維持します。
- 精密待機とMMCSS/電力方針を保持します。CPU使用率だけで物理遅延の改善を断定しません。Sitesはclient_submittedのR6対応と送信状態表示であり、サーバー側リプレイ再検証を追加していません。認証・同意・マルチプレイの信頼境界を保持します。

## 配布と制限

公開物はクライアント/verifier/ビルド資料と許可されたNK3推論モデル・ランタイムのみ。サーバー・アカウント・個人設定・曲・ログ・秘密・学習資料・BGA拡大モデル・独立変換EXEを除外します。[リリース条件](release-1.9.0-gate.md)、[ソース範囲](../SOURCE_PACKAGE_SCOPE.txt)、[現在状態](current-state.ja.md)を参照してください。候補検査と最終1.9.0ビルド・独立展開・CI・公開readbackを区別します。実アカウント送信、旧記録欠落原因、物理入力/音声遅延、長時間・他PCは未検証。プラグインruntime/API/SDKとGameSession大規模分離は含みません。次の基準変更にも明示的依頼、4言語文書と互換検証が必要です。
