# ウィンドウモードのドロップとスキン設定

2026-10-18の更新は1.9.6に含まれます。以前のローカル候補、公開1.9.5.3、インストール先、元のプロファイルを保持します。現在の公開状態は[リリース案内](release-1.9.6.ja.md)に従います。

- ウィンドウモードへの切り替えで消えていたファイルドロップ許可を保持する。既存の BMS ファイル・フォルダー処理とファイル選択ダイアログの管理は変更しない。
- スキン設定の上に対応キーモードを横一列のタブとして表示し、末尾に検索欄を置く。現在のソースで表示される設定を検索する。モード別の保存方式は維持する。
- タブのクリックまたは Ctrl+Tab / Ctrl+Shift+Tab でモードを切り替える。Ctrl+F で検索欄を選び、Tab / Shift+Tab でタブ・検索欄・設定一覧を移動する。現在の言語の項目名・値・分類を検索する。
- ギア境界線、判定 X、コンボ X、FAST/SLOW X、インジケーター X を非表示にし、保存値を維持する。
- 新規スキン作成・スキンフォルダーを開く・再読み込みは TenRiff のみ、インポート済みスキン選択は TenRiff または LR2 のみ表示する。
- Original モードのスクラッチ位置条件と、非表示の区切り線幅 100% を維持する。
- アルバム画像の判定難易度バッジは既定で 288×36 から 192×28 デザインピクセルへ縮小する。スキンが明示した矩形は優先する。
- コンボと判定カウンターが重なるときはフィールド内に収まる近い側へ避ける。常に下へ押し出す制限をなくし、インジケーターの上へ移動できる。Classic/Studio、プレイヤー/ゴーストで共通とし、保存位置は変更しない。

[固定判定](judgement-baseline-20261018.ja.md)、R1–R8リプレイ互換、対戦プロトコル7を維持します。1.9.6は対応Sitesとともに標準の新規Online R9/R10送信を許可し、旧ボードは読み取り専用で保持します。一般ソース基準1.9.0は変更しません。

最終検証は1.9.6リリースルートの `evidence/VERIFICATION.ko.md` に記録します。以前の候補の `evidence-ui-20261018/VERIFICATION.ko.md` は当時の証拠として保持します。自動HWNDメッセージ・描画キャプチャと、人のExplorerドラッグ・実機IME/入力・長時間プレイは区別します。
