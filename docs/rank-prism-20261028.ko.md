# 프리즘 랭크 텍스트·EX 팔레트 (로컬 후보)

[English](rank-prism-20261028.en.md) · [日本語](rank-prism-20261028.ja.md) · [简体中文](rank-prism-20261028.zh-CN.md)

S+·S++·S+++를 프리즘 효과가 있는 텍스트로 표시하는 1.9.9.3 기반 로컬 후보입니다. Release 빌드, 전체 CTest 3/3(1,445개), 최종 화면 26개와 에디터 37개 검사를 통과했습니다. 공개 버전과 일반 고정 기준선 1.9.6은 유지합니다.

- S+·S++·S+++ 텍스트에 EX 프리즘 그라데이션과 글로우, 입체감을 주는 면·빛 효과를 적용합니다. PNG를 불러오는 대신 기존 글자 비트맵 캐시 경로를 사용합니다. 효과는 글자·글꼴·크기 또는 장치가 바뀔 때 캐시에 반영하므로 매 프레임 블러나 색상 애니메이션을 추가할 필요가 없습니다. 캐시 생성 실패 시 기존 텍스트 표시로 대체합니다.
- 제작한 랭크 이미지는 소스 밖의 콘셉트 산출물로 보존하며 게임에서 읽거나 패키지에 동봉하지 않습니다. 다른 랭크와 EZ/NM/HD·E/F 색은 유지합니다.
- EX는 선택 이미지의 청록→파랑→라벤더→분홍→금색→민트→청록 팔레트를 정적 sRGB RGB 보간으로 사용합니다. 이 선택은 이전 EX 금색 단일 계열 및 보라 제외 지침을 대체합니다.
- 키 오버레이에서는 추정 난이도 표시만 제거하고 KPS와 키/노트 뷰어를 유지합니다. 차트와 선곡 목록의 난이도 정보는 유지합니다.

| EX 색 | `#4AF3F7` | `#6391FC` | `#C75FFB` | `#FC94DE` | `#F4E289` | `#7CF69F` | `#4AF3F7` |

EX 기본·대체 색은 `#4AF3F7`입니다.

[렌더 대기 복구](render-wait-20261028.ko.md), [심플 롱노트·올콤보](skin-finish-20261028.ko.md), [화면공유/Discord 조사와 BGA 복구](share-sync-20261028.ko.md)를 계승합니다. 이전 문서의 EX 색과 오버레이 추정 난이도 설명은 위 범위가 우선합니다. 이번 변경은 판정·입력·오디오·리플레이·등급 경계값과 기존 렌더 대기 동작을 바꾸지 않습니다. Discord 끊김 해결이나 성능 향상을 측정했다는 주장은 하지 않습니다.

위에 언급된 통과 결과는 역사적 후보 검증입니다. 새 버전의 확인 범위는 [1.9.9.5 검증표](release-1.9.9.5-gate.md)를 따릅니다. 실제 입력·장시간 플레이·다른 PC·임의 스킨은 직접 확인한 범위와 구분합니다.
