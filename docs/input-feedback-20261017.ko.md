# 인디케이터·출력 장치·프로필 단축키

사용자가 선택한 1.9.3 커밋 `bf544e17f22879011a04a7fd157e40b57f6598bb`에 이어진 2026-10-17 변경이며 1.9.4에 포함됩니다. 일반 고정 기준선 1.9.0, 공개 자산과 기존 설치는 유지합니다.

- **BMS 마디선 정렬**: 마디선을 노트 중심에서 노트 아래쪽 경계로 옮깁니다. 설정한 노트 높이와 가져온 스킨의 높이 보정을 반영하며, 같은 박자의 노트 바로 밑에 붙습니다. 플레이어·고스트에 함께 적용하고 마디 시각, STOP/BPM, 판정 시점은 바꾸지 않습니다.

- **옵션 → 스킨 → 인디케이터 모양**: 기존 점 또는 바코드(곧은 세로줄)를 고릅니다. 기본값은 점입니다. `항상` 표시에서는 눈금/중앙선이 처음부터 계속 보이며 판정별 점·줄은 각각 0.7초 뒤 사라집니다. FAST/SLOW 글자 유지 정책과 점수·판정·리플레이는 그대로입니다. 솔로·고스트와 스킨 미리보기에도 같은 모양을 사용합니다. 일시정지 중 표시 시간은 게임 시계와 함께 멈춥니다.
- **옵션 → 사운드 → 사운드 출력 장치**: WASAPI 출력 목록에서 장치 또는 시스템 기본 장치를 선택합니다. 새로고침 키(기본 F5)로 목록을 갱신하고, 뒤로 가면 저장·적용합니다. ASIO는 기존 별도 드라이버 행을 사용합니다. 장치를 잃어도 저장된 선택은 유지하며 다른 출력으로 자동 대체하지 않습니다. 실제 장치를 다시 연결하거나 시스템 기본 장치를 선택하세요. 출력 장치 지정은 게임플레이·BMS 미리듣기에 적용됩니다. 별도 MCI 경로의 텐리프 자체 메뉴·결과 음악은 Windows 기본 장치를 사용합니다.
- **옵션 → 프로필**: F1–F11에 해당하던 기능을 다른 키로 지정하거나 Delete로 해제합니다. 한 기능키의 모든 문맥(예: 도움말/판정선, 새로고침/반속, 미리보기/두 배)에 같은 설정을 사용합니다. 화면 도움말·하단 안내에도 현재 키가 표시됩니다. 다른 기능·즉시 재시작·레인·예약된 메뉴 키와 중복되는 입력은 거부합니다. 기존 키 설정은 유지됩니다.
- **노트속도 ×0.5 / ×2**: 기존 −10/+10 단축키(기본 F5/F6)의 동작을 현재 노트속도 절반/두 배로 바꿉니다. 0.5–50 범위 안에서 한 번 누를 때 한 번 적용하며, 길게 누르거나 중복 Press가 와도 반복 배가하지 않습니다. 플레이·카운트다운·일시정지에서 사용하고, 곡 재생 배속(Rate)·소리·판정 시점은 바꾸지 않습니다. 기존 F3/F4의 ±0.25는 유지됩니다.

설정은 `skin.timing_marker_style=dot|barcode`, `audio.device_id`(빈 값=시스템 기본), `ui.function_keys` 객체에 저장합니다. F5/F6는 과거 `hispeed_decrease_key`/`hispeed_increase_key`와 호환하여 저장합니다. 프로필 내보내기에는 단축키를 포함하지만 장치 ID는 제외하며 가져올 때 현재 PC의 장치 선택을 유지합니다. 스킨 프리셋은 인디케이터 모양을 보존합니다.

검증 결과는 작업 폴더의 `evidence/VERIFICATION.ko.md`가 기준입니다. 이 문서는 실제 장치 청취·다른 PC·장시간 플레이 검증이나 공개 배포를 뜻하지 않습니다.
