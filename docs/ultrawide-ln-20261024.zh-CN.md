# 1.9.9 本地修正：21:9 与长音符

本候选版本基于已发布的 1.9.9 (`79433ba`)，尚未发布。固定基线仍为 1.9.6，保留旧版本、配置与谱面。[English](ultrawide-ln-20261024.md) · [한국어](ultrawide-ln-20261024.ko.md) · [日本語](ultrawide-ln-20261024.ja.md)

- 保留 2560×1080、3440×1440，新增 5120×2160 预设。全屏背景、BGA 和遮罩覆盖左右区域；UI、音符比例、鼠标映射及保存的皮肤坐标保持等比居中。背景继续使用保持比例的 cover crop；明确指定的小区域保持不变。
- 中途松开长音符后，剩余主体继续滚动到原尾部通过，不会立刻消失。已判定的头部、激活光效和计分不会恢复。玩家与幽灵一致，判定、血条和连击规则不变。
- 新 LN Mix 在同轨地雷前后至少留出 50ms。空间不足则保留单音符，后方地雷限制尾部长度。其他轨道的地雷不阻止独立长音符，原始音符、长音符、键音和地雷保持不变。无地雷谱面的生成结果与 v2 相同。

新游戏在现有 `long_note_mix_version` 字段记录 **3**。旧 v1/v2 回放仍还原原始布局，版本不同的幽灵不能改变新游戏布局。v3 需要本候选版验证器，已发布的 1.9.9 会拒绝它。回放字段、判定 ruleset 和 peer 协议不变，v2/v3 原有在线与 BEST 排除规则保持不变。不包含网站部署或数据库修改。

自动验证记录位于候选版本的 `evidence` 目录，不代表实际 21:9 显示器、物理输入、长时间游玩或所有外部皮肤已验证。

松开最后一个长音符时，自动结算也会等待尾部通过，并考虑负视觉偏移。明确跳过、中止和游戏结束行为保持不变。
