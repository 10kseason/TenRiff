# 로컬 UI·검색 후속 후보

1.9.5.2에서 이어지는 미공개 후보입니다. 실행 파일의 버전 번호와 고정 기준선 1.9.0은 그대로이며 이전 릴리스와 설치·프로필은 보존합니다.

- 새 프로필: 노트·필드 크기 60%, 키빔 최대 높이 50%, 5K 흰/파/흰/파/흰. 명시적으로 저장한 값과 모드별 값은 유지합니다. 조절 범위 10–140%는 같습니다.
- 기본 미세 노트속도 조절은 F1 +0.25 / F2 −0.25, 판정선은 F3 위로 1% / F4 아래로 1%입니다. 기존 프로필의 지정 키는 유지합니다. F5/F6의 ×0.5/×2도 유지합니다. 이 키들은 기존 공용 동작 슬롯을 사용하므로 메뉴 도움말·보조 동작의 표시도 지정 키를 따릅니다.
- 스킨 설정의 전체화면 미리보기는 물리 F6으로 열고 F6 또는 Esc로 닫습니다. 별도 프로필 단축키와 무관하며 키를 누른 채 유지해도 토글이 반복되지 않습니다.
- 스킨 설정 → 스킨 프리셋 저장 → 새 .trskin 파일을 선택합니다. 가져오기로 다시 적용할 수 있습니다. 외부 스킨 자산과 현재 프로필의 스킨 조절값을 기존 프리셋 형식에 담습니다. 기존 파일은 덮어쓰지 않고 다른 이름으로 저장합니다. 웹의 skin.json/ZIP과 게임의 .trskin은 서로 다른 형식입니다.
- 검색 Backspace는 누르고 있으면 완전한 UTF-8 문자 단위로 반복 삭제합니다. 빈 검색창에서도 검색 상태를 유지합니다. Backspace는 뒤로가기에 사용하지 않으며 Esc로 나갑니다.
- 난이도표 선택 후 곡 목록에 표가 선언한 모든 레벨 폴더를 숫자 오름차순으로 표시합니다. 미보유 레벨도 0곡으로 남습니다. Enter/두 번 클릭으로 해당 레벨의 곡만 열고 Esc로 폴더 목록으로 돌아옵니다. 검색은 선택 레벨을 해제하고 표 전체에서 수행합니다.
- `Lv:16`은 16만, `Lv:16+`는 16+만 찾습니다. `+`를 하한 검색으로 쓰던 동작은 종료합니다. 범위는 `lv:16to20`, 상한은 `lv:20-`를 사용합니다. 일반 텍스트는 곡명과 아티스트만 검색하며 파일 경로·장르·표 이름은 제외합니다.
- 마지막 노트와 LN이 끝난 뒤 남은 오디오를 넘기는 키는 Enter입니다. 레인키와 Esc는 클리어 후주를 넘기지 않습니다. 재생이 자연 종료되면 기존 설정대로 결과로 이동합니다. 멀티플레이·코스 제한과 플레이 중 Esc 일시정지는 유지합니다.
- 웹/오프라인 스킨 에디터는 현재 스키마·기본 색상·키빔 높이·심플 사각형과 350ms FAST/SLOW/700ms 마커를 반영합니다. 필드 크기 미리보기는 10–140%, 기본60%이며 JSON에 저장되지 않습니다. Studio HUD·판정선 유형·점/바코드는 게임 프로필에서 설정합니다. 브라우저 미리보기는 모양 참고용이며 실제 게임 렌더와 완전히 같다고 보장하지 않습니다.

구현 이유: 기존 설정/프리셋 형식과 입력·오디오 경로를 재사용하고, 표 폴더는 별도의 선택 상태로 관리해 빈 레벨을 보존합니다. 판정·점수·게이지·리플레이 규칙은 변경하지 않습니다. Guest 제외, 고정 등급, client_submitted와 BGA 모델 미동봉 정책을 유지합니다.

검증은 후보 폴더의 evidence/VERIFICATION.ko.md를 참조합니다. 웹 에디터는 사용자 승인으로 Sites 버전8에 배포했습니다. 게임 공개 릴리스는 별도 승인 대상입니다. 물리 입력·실제 청음·장시간 플레이·다른 PC·임의 외부 스킨은 미검증입니다.
