# TenRiff 1.9.5 — 音楽の出力先統合と判定インジケーター

メニュー・結果音楽も選択した出力先を使用します。FASTは青、最高判定は緑、LATEは赤。最高判定でもFAST/SLOWを更新します。ロビーはOFF → ミラー → ランダム → Sランダム → スクラッチ固定ランダム → OFFの順です。

- MCI再生を既存AudioThread/デコーダーに統合し、選択したWASAPI機器またはASIOドライバーを使用します。メニューは同じWASAPI機器の共有モード、ゲームの排他設定は維持。機器不在時に自動で別出力へ切り替えません。音量・曲の順次選択・フォーカス消音を維持します。
- 非同期デコードをメニュー/音声コールバックの外で実行し、操作のないメニューでも完了を確認。試聴・ゲーム・エディターの前に出力を解放し、古いエディター処理は練習/結果画面で再生しません。設定変更クリック音はWindows既定経路です。
- 青/緑/赤の境界は各プレイヤーとゴーストの実際のサンプル単位判定幅です。最高判定またはその範囲内の点/縦線は最新表示も緑。条件付き表示も最高判定に対応し、0.7秒の個別消去と常時目盛り表示を維持します。
- 最高判定でもFAST/SLOWを更新し、整数msへの丸め結果が0なら古い文字を消去。条件付き文字0.75秒、常時モードは最新値保持。スコア・判定幅・リプレイ計算は変更しません。
- ランダム順序は上記のとおり逆方向にも対応。rrの表示だけをランダムに変更し、内部トークン・アルゴリズム・シードを維持。韓国語の無効値表示はOFFに統一します。
- 1.9.4のキャッシュ保持/メニュー解放、速度キー、キー設定、小節線を維持。基準線1.9.0・過去の配布物/設定・Guest除外・等級・R7/R8/旧リプレイ・BGA重み非同梱・OFF/空/Autoは維持します。
