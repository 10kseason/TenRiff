# 设置界面与每局种子更新

2026-10-19 · [1.9.6](baseline-1.9.6.zh-CN.md)

- 按键设置新增通用按键及原有10种布局标签。编辑立即重试和11项功能，共用个人设置的保存值、冲突校验和即时保存。Tab切换标签与按键设置，左右选择标签。

- 皮肤14个标签高度52→60、文字18→24设计像素，搜索框宽度340→260以保持单行。沿用选曲大厅键数配色，7+1使用8键颜色。

- 皮肤设置FAST为蓝色、SLOW为红色，保持描边、文字适配、翻译及预览。百分比尺寸、位置、透明度和亮度均以1%调整。px/ms单位与已保存的小数值不自动迁移。

- 键数模式设置改为游戏模式设置，默认判定范围在所有语言中显示Normal。判定数值、R9/R10、分数和固定等级保持不变。

- 每次新单人游戏或重试，在OFF、镜像、随机、固定划盘随机、S随机与R随机下均生成新种子。手动种子改为自动的只读提示。BMS RANDOM使用独立种子。不同种子仍可能碰巧产生相同布局。

- 回放和验证使用已记录种子。共用谱面的幽灵在种子影响布局时仍要求一致，原谱面OFF/镜像路径不会仅因未使用种子不同而拒绝。对战随机OFF共享规则及peer v7保持不变。

- 这些更改包含在1.9.7中。保留以往发布、安装和个人设置，通用源码基线仍为1.9.6。实际输入、试听、长时间和其他PC需另行验证。

- TenRiff自身背景音乐（标题、菜单、结果）的基准增益从10%提高至12.5%，衰减减少约1.94dB。保留已保存的主音量、菜单音量以及歌曲试听和游戏增益。
