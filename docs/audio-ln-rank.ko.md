# 오디오 원음 경로·롱노트 해제·BMS RANK

## 오디오

노멀라이즈 OFF에서도 기존 `soft_limit_audio_sample`이 마스터 볼륨 전에 0.92 이상 파형을 압축했습니다.
예를 들어 키음과 배경음 합이 1.7이고 마스터가 35%라면 정상 출력은 0.595로 충분한 여유가 있지만,
기존 경로는 이를 약 0.334까지 줄였습니다. OFF의 실제 콜백 회귀 테스트로 재현했습니다.

OFF에서는 자동 음량 보정과 소프트 리미터를 모두 건너뛰고 마스터 볼륨을 선형 적용합니다.
최종 신호가 기기의 ±1 범위를 넘을 때만 잘라내며 NaN/Inf는 무음 처리합니다. ON의 기존 RMS 및
소프트 리미터는 유지합니다. 디코더·샘플레이트 변환·Rate·메뉴 음악 처리는 변경하지 않습니다.

## 롱노트

기존 일반 LN은 해제 판정을 꼬리 시각까지 미루고 재입력 시 해제 상태를 취소했습니다.
CN도 같은 오디오 콜백 안에서 떼고 다시 누르면 해제 상태가 취소될 수 있었습니다.
이제 해제 순간에 꼬리와의 시간 차를 판정하고 종료하므로, 너무 일찍 놓으면 즉시 BAD·콤보 단절·게이지 감소가
반영됩니다. 재입력으로 이 미스를 취소하거나 꼬리를 중복 득점하지 않습니다.

정상 꼬리 근처의 PG/GR/GD 판정 창, 일반 LN을 계속 누를 때 자동 완료, CN을 끝까지 놓지 않을 때의
타임아웃은 유지합니다. No LN Release는 자동 꼬리 처리 모드이며 중간에 놓아도 되는 모드가 아닙니다.

## BMS 판정

파일의 `#RANK`를 읽어 실제 플레이·리플레이·고스트 판정에 연결합니다. 값이 없거나 지원하지 않는 값이면 EASY입니다.
기본 설정, 판정 MOD OFF일 때의 각 경계는 다음과 같습니다. 숫자는 노트 시각의 앞뒤 각각 허용되는 시간입니다.

| #RANK | 등급 | PG | GR | GD | BAD |
| --- | --- | ---: | ---: | ---: | ---: |
| 3 / 누락 | EASY | 21ms | 65ms | 115ms | 210ms |
| 2 | NORMAL | 18ms | 55.714286ms | 98.571429ms | 180ms |
| 1 | HARD | 15ms | 46.428571ms | 82.142857ms | 150ms |
| 0 | VERYHARD | 8ms | 24.761905ms | 43.809524ms | 80ms |

EASY는 기존 PG20ms를 21ms로만 바꿉니다. 다른 등급은 EASY의 모든 노트 판정 창에 18/21, 15/21, 8/21을 곱합니다.
자동 미스 340ms, 홀드 허용 설정, 입력 마스크는 RANK로 줄이지 않습니다. 기존 `Judge Easy/Hard` MOD는
파일의 판정 창에 추가 적용합니다. Rate에 따라 판정 시간이 이중으로 달라지지 않으며 실제 재생 시간 기준입니다.
수동 커스텀 판정 값은 같은 RANK 비율을 사용하고 비공식 판정으로 구분합니다.

이전 기본 PG20ms 프로필은 21ms로 보정하고 나머지 값은 유지합니다. 판정 변경을 예전 기록에 소급하지 않도록
새 플레이는 `tenriff-native-score-v2-ruleset-3`을 기록합니다. 기존 canonical ruleset-1/2는
PG20ms, RANK 미적용 및 이전 롱노트 해제 동작을 복원해 재생·고스트·로컬 검증합니다.

## 웹 기록 호환

1.8.3 클라이언트의 새 기록은 R3 식별자와 `timing_profile`을 제출하고, BMS 결과에는 원본 `bms_rank`도
내보냅니다. R3 웹 요청은 `timing_profile`이 필수이며 `bms-easy`, `bms-normal`, `bms-hard`,
`bms-veryhard`, `osu-fixed` 중 해당 차트 형식과 맞는 값을 사용합니다. 판정 프로파일별로 R3 기록을
구분하므로 서로 다른 RANK의 판정 창을 같은 기록 그룹으로 섞지 않습니다. `osu-fixed`는 기존 osu
호환 경로의 고정 판정 구분이며 공개 클라이언트의 BMS 전용 차트 입력 범위를 바꾸지 않습니다.

기존 R1/R2 기록의 ID·점수·그룹 식별자는 유지하며 R3로 재계산하거나 재작성하지 않습니다.
웹 데이터베이스 변경은 새 판정 프로파일을 지원하는 스키마·인덱스 변경으로 제한합니다.
누락·잘못된 프로파일 거부, 기존 기록 유지 및 배포 후 확인은 [1.8.3 릴리스 검증](release-1.8.3-gate.md)에
기록합니다. 이 호환 계약 설명만으로 웹 배포나 최종 패키지 검증이 완료되었다는 뜻은 아닙니다.

## 검증 범위

수정 전 오디오 3개·롱노트 2개·RANK 1개 회귀가 실패하는 것을 먼저 확인했습니다.
44.1/48kHz와 Rate0.75/1/1.5에서 PG 경계 및 경계 밖 한 샘플을 검사하고, 현재/기존 규칙의
리플레이 재계산과 정상 저장을 함께 확인합니다. 청감·물리 입력·장시간 장치 플레이는 별도 확인 대상입니다.
