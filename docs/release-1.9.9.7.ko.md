# TenRiff 1.9.9.7 — 일반 롱노트 조기 해제 수정 및 온라인 제출

일반 롱노트를 GOOD 범위만큼 일찍 떼어도 성공하던 동작을 수정합니다. 이제 현재 PG 범위까지만 조기 해제를 허용하며 Normal은 원본 RANK에 따라10/15/19/22ms, Hard19ms, EX10ms입니다. 정확한 경계는 성공이고 더 이른 해제는 즉시 BAD·콤보 단절·게이지 감소·OD8 Miss입니다. 재누름으로 복구되지 않습니다. 끝까지 누르면 자동 PG이며, CN의 별도 해제 판정과 단노트·머리 판정창은 유지합니다.

새 Normal/Hard는 R11, EX는 R12입니다. 온라인 Sites 제출·조회·보드 표시가 이를 지원하며 기존 R9/R10 제출도 별도 순위로 유지합니다. 판정 ID를 그대로 보드 조건에 넣으므로 이전 기록의 점수·해시·순위 조건을 바꾸지 않습니다. 기존 R1–R10과 custom 리플레이·고스트는 원래 정책으로 처리하며 JSON 필드 추가나 데이터 이관은 없습니다. BEST 세대3은 과거 결과 파일을 보존합니다. peer v8은 같은 패킷 구조로 v7을 거부하여 서로 다른 판정으로 대전하지 않게 합니다.

Guest·커스텀·보조 모드·LN Mix v2/v3·일시정지 등 기존 제출 제외를 유지합니다. 웹은 게임이 제출한 점수·해시를 저장하는 `client_submitted` 서비스이며 서버 리플레이 재검증을 제공하지 않습니다. 별도 Ranked 서버의 미지원 판정 차단도 유지합니다. 일반 고정 기준선1.9.6과 이전 릴리즈·설치·프로필·차트는 보존합니다. 물리 입력/키감·장시간·다른PC·실제2PC 및 실계정 업로드는 별도 확인이 필요합니다.
