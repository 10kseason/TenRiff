# 1.8.6 로컬 피드백 시험본

`TenRiff-1.8.6-feedback-test`는 공개 1.8.6에서 출발한 로컬 수정본이다.
프로젝트/게임 표시 버전은 1.8.6이고 패키지 이름으로 시험본을 구별한다.
전체 변경은 [보완 설명](feedback-followup.ko.md)과 CHANGELOG의 Unreleased 항목에 기록했다.

## 사용과 확인

1. 실행용 ZIP을 새 폴더에 풀고 `launch_win.bat`로 실행한다.
2. 비교할 때는 기존 `.trprofile`을 가져와 키·오디오·입력 보정·VSync·FPS 설정을 같게 맞춘다.
3. 같은 차트에서 반복 연주해 노트별 타이밍 흔들림과 로딩 중 음성채팅 끊김이 남는지 확인한다.
   남으면 차트 형식, 입력 보정값, 오디오 공유/독점, VSync·FPS 및 시각/판정/키음 중 어느 부분인지를 기록한다.

Options는 4×2의 여덟 카드다. **키 모드 설정 → 모드**에서 기존 모드 관리자를,
**키 설정 → NKRO Test**에서 기존 입력 테스트를 연다. 키 재할당은 같은 키 모드의
이전 기본·보조 슬롯에서 해당 키를 제거한 뒤 새 슬롯에 넣는다.
비워진 기본 키는 재시작해도 미할당으로 남으며 다른 키 모드의 키는 유지된다.

스킨 설정의 **스튜디오 리프 맵**으로 왼쪽 그래프를 켜고 끈다. LR2 가져오기 스킨의
단독 플레이에서도 스튜디오 덱을 사용할 수 있다. FAST/SLOW는 마지막 유효 비PG 오차를
0.75초 유지하며 PG가 이를 지우거나 시간을 연장하지 않는다. 타이밍 막대는 켜기/끄기와
별도로 비PG 판정 후/항상 표시를 선택한다. 글자·막대 위치는 판정 위치와 독립적이다.

## 검증 범위와 남은 부분

+20ms 보정이 콜백 위치에 따라 +10/+12.5/+15/+20ms로 변한 결함은 실제 콜백 경로로
재현하고 수정했다. WASAPI 재생 위치에 늦은 콜백 시각을 붙이던 경로도 관측 직후 시각을
사용하도록 보완했다. 두 경로 모두 이전 버전에도 있으므로 1.8.6에서 새로 생긴 단일 원인으로
확정하지 않는다. 제보자의 실제 기기·차트·음성채팅과 물리 입력/출력 싱크의 개선은 별도 확인이 필요하다.

일반 로딩은 차트 분석·음원 레이트 선택 뒤 한 번만 오디오를 연다. 독점 모드는 기존 선택을
유지하므로 다른 앱의 동시 출력은 보장하지 않는다. 이는 [Windows 독점 스트림 동작](https://learn.microsoft.com/en-us/windows/win32/coreaudio/exclusive-mode-streams)에 따른 경계다.

R1~R4 리플레이의 판정·자동 연주·고스트 시각은 유지한다. 리플레이에는 보정된 판정 시각만
저장되므로, 입력 보정을 사용하는 새 라이브 연주와 리플레이의 키음 시각까지 동일하다고
보장하지 않는다. [입력 보정 호환 범위](input-offset-timing.ko.md)를 따른다.

자동 검사 결과와 캡처는 작업 폴더 `evidence/VERIFICATION.ko.md`를 기준으로 한다.
이는 다른 PC·긴 실제 연주·온라인 대전이나 모든 LR2 스킨에 대한 물리 검증을 대신하지 않는다.
