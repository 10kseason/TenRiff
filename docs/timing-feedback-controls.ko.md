# 스킨 전체화면 미리보기와 표시 설정

1.8.2 이후 로컬 추가 기능과 스킨 설정 조절 수정입니다.

## 사용

실시간 미리보기 우측 상단의 **전체화면 미리보기 [F6]**를 누르면 현재 스킨으로
전체 인게임 화면을 볼 수 있습니다. Esc/F6 또는 우측 상단 복귀 버튼으로 돌아옵니다.
창 모드에서는 일시적으로 테두리 없는 전체화면을 사용하고, 복귀하면 원래 화면 모드로 돌아옵니다.
실제 게임과 같은 1920×1080 기준 배치와 렌더러를 사용하며, 샘플 노트와 판정만 합성 데이터입니다.
선택 레인에서 키 폭발 모양(prism/ring/spark)을 반복 표시합니다.

스킨의 7K 다음 모드는 **7+1**로 표시됩니다. 해당 모드의 **스크래치 위치**를
왼쪽/오른쪽으로 바꾸면 미리보기와 실제 게임 모두 같은 레인 배치를 사용합니다.

옵션 → 스킨 → HUD에서 다음 항목을 조절합니다.

- FAST/SLOW 인디케이터: 글자와 ms 표시 ON/OFF.
- FAST/SLOW 막대: 타이밍 기록 막대 ON/OFF.
- 인디케이터 X/Y, 막대 X/Y: 각각 10px 단위로 이동. X는 -600~600, Y는 -400~400입니다.

좌표는 1920×1080 기준의 기존 판정 주변 배치에 더해지는 오프셋입니다.
X 양수는 오른쪽, Y 양수는 아래입니다. 해상도에 맞춰 함께 확대·축소됩니다.
스킨 미리보기는 GREAT / FAST 샘플로 두 표시와 위치를 바로 보여줍니다.
Esc/뒤로로 나가면 프로필에 저장하며, 재시작과 `.trskin` 내보내기/가져오기에서도 유지합니다.
PG·중앙 판정·만료된 피드백에서는 둘 다 숨깁니다. 고스트에도 같은 표시 경로를 사용합니다.

스킨 소스를 TenRiff로, 설치 스킨을 `TenRiff_SimpleSquare`로 고르면 심플 네모 스킨을 사용합니다.
검은 필드와 평평한 직사각형 노트·롱노트 끝·키로 구성하며 프로필의 레인 색과 크기를 사용합니다.
기존 기본 스킨과 사용자 스킨은 유지됩니다.

## 구현 이유

기존에는 글자와 막대가 하나의 스위치와 판정 위치에 연결되어 있었습니다.
표시 스위치를 분리하고 기존 위치에 별도 오프셋을 더해 이전 프로필의 배치를 보존했습니다.
오래된 프로필/매니페스트의 단일 스위치는 두 요소에 적용됩니다. 사용자가 표시를 변경하면
그때 화면에 보이는 두 값을 채택한 뒤 프로필 값을 우선해 스킨 재로딩이 선택을 취소하지 않습니다.
렌더링 텍스트 캐시는 표시 설정과 독립적으로 유지해 미리보기 ON/OFF가 즉시 반영됩니다.
네모 스킨은 기존 Native 벡터 스프라이트 형식으로 만들어 새 렌더러나 이미지 의존성을 추가하지 않습니다.

모드별 크기가 없는 상태에서 첫 조절 시 맵에 0을 먼저 넣어 최소값 50%로 떨어지던 문제는
현재 적용 크기를 먼저 읽은 뒤 저장하는 방식으로 수정했습니다. 예를 들어 필드 크기 100%의 첫 +는
105%, 노트 높이 180%의 첫 -는 175%가 됩니다. 기존 모드별 값과 설정 범위는 유지합니다.

마름모·화살표·삼각형·오각형·육각형의 머리와 꼬리에 검은 외곽선을 적용합니다.
기존 테두리 OFF/불투명도 설정은 그대로 사용합니다. 롱노트 몸통을 머리·꼬리 중심까지
겹쳐 다각형 경사면과 짧고 두꺼운 롱노트에서도 연결이 끊기지 않게 했습니다.
미리보기는 같은 그림 함수를 재사용해 별도 모사 코드에 따른 비율·효과 차이를 막습니다.

## 검증 범위

프로필 파일 재로딩, `.trskin` 왕복, 이전 설정 호환, 네 가지 표시 조합, 좌표 경계,
스킨별 설정 우선순위, 4K~16K 스킨 로딩, 실제 렌더러의 합성 장면을 확인합니다.
물리 입력·장시간 실플레이와 웹사이트 배포는 별도입니다.
