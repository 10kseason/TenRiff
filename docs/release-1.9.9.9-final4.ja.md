# TenRiff 1.9.9.9-final4

LR2 スコア DB のクリアランプを表示専用で取り込む `tenriff-lr2-import` を追加しました。LR2 の判定順を最悪ケースで EX-HARD ゲージに通し、生存したプレイのみ EX と表示します。オーディオコールバックと HUD スレッドが共有するロックに予防措置を入れました。固定ベースラインを **1.9.9.9-final4** に上げます。

## 使い方

リリース ZIP を新しいフォルダに展開し、`launch_win.bat` を実行します。

### LR2 クリアランプのインポート

### ゲーム内でインポート

LR2を終了し、**オプション → プロフィール → LR2記録をインポート**でスコアの `.db` を選択します。現在のプロファイルに保存し、登録済み曲フォルダーと現在のフォルダーでEXを確認します。曲がなくても基本ランプは取り込めます。

処理はバックグラウンドで進み、同じボタンを再度選ぶとキャンセルします。完了後は再起動せず選曲ランプを更新します。再インポートは以前のLR2ランプ一覧を置き換えます。キャンセル、読み書きの失敗、ゲーム終了時は以前の一覧を保持します。TenRiff記録、BEST、オンライン送信資格は変わりません。

### コマンドライン

```
tenriff-lr2-import.exe <LR2 スコア .db> <プロフィールフォルダ> [曲フォルダ ...]
```

LR2 の DB は読み取り専用で開き、出力は `<プロフィールフォルダ>\lr2_import.json` のみです。削除すれば取り込んだランプも消えます。取り込んだランプは TenRiff の記録より上位のときだけ選曲画面に表示され、選択曲のランプ表記に `LR2 ` が付きます。リザルト、BEST、オンライン送信の対象にはならず、スコアは取り込みません。リリースにはどのユーザーの LR2 DB も含まれません。規則と制限:[LR2 クリアランプのインポート](lr2-clear-import.ja.md)。

### オーディオコールバックのロック

HUD スレッドは、オーディオコールバックと共有するロックを保持している間だけ優先度を上げます(`TENRIFF_HUD_LOCK_CEILING=0` で無効)。オーディオコールバックはウィンドウマネージャーへの問い合わせとコンソール出力を行いません。変更前の測定でも音切れは観測されなかったため予防措置であり、体感や遅延の改善は主張しません。`TENRIFF_RT_PROBE=1` で実行すると、曲の終了時にロックの待ち時間と保持時間を標準エラーに出力します。

## 互換性

判定・スコア・ゲージ計算、入力、リプレイ形式と R1〜R14、peer プロトコル、ランキング識別子は final3 と同じです。保存済みのプロフィールと設定はそのまま読み込みます。Web リーダーボード(v28)とスキンエディター(v14)は変更していません。

## 固定ベースライン

このリリースから一般ソースのベースラインは **1.9.9.9-final4** です。[ベースライン](baseline-1.9.9.9-final4.ja.md)。

物理入力・試聴、長時間、他の PC、WASAPI 排他・ASIO でのロック測定、他ユーザーの LR2 DB は別途の検証です。[リリースゲート](release-1.9.9.9-final4-gate.md)。
