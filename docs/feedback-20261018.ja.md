# ローカルUI・検索の改善候補

1.9.5.2に続く未公開候補です。実行ファイルのバージョンと固定基準1.9.0は変更せず、旧リリース・インストール・プロファイルを保存します。

- 新規設定はノート・フィールド60%、キービーム最大高さ50%、5Kは白/青/白/青/白です。明示的な保存値とモード別値を維持し、範囲は10–140%です。
- 速度の微調整は既定F1 +0.25 / F2 −0.25、判定線はF3で1%上へ、F4で1%下へ移動します。保存済み割当は維持し、F5/F6は×0.5/×2です。共有アクションに対応するメニュー操作と表示も割当に従います。
- スキン全画面プレビューは物理F6で開き、F6またはEscで閉じます。再割当とは独立し、長押しによる連続切替を防ぎます。
- スキン設定の保存操作から新規.trskinを作り、取り込みで復元できます。既存形式と外部素材を使い、既存ファイルは上書きせず別名保存します。Webのskin.json/ZIPとゲームの.trskinは別形式です。
- 検索のBackspace長押しはUTF-8文字単位で削除し、空でも入力状態を保ちます。戻る操作はEscです。
- 難易度表に宣言された全レベルを数字の昇順のフォルダーで表示し、未所持は0曲です。Enter/ダブルクリックで同じレベルの曲だけを開き、Escで戻ります。検索は選択レベルを解除して表全体を対象にします。
- `Lv:16`は16のみ、`Lv:16+`は16+のみです。+は下限ではありません。範囲は`lv:16to20`、上限は`lv:20-`です。通常語は曲名・アーティストのみを検索します。
- 全ノートとLN終了後の音声を飛ばすキーはEnterのみです。レーンキーとEscでは飛ばしません。自然終了・対戦/コース制約・演奏中のEsc一時停止を維持します。
- Web/オフラインエディターは現在のスキーマ、5K色、高さ、シンプル四角形、350ms FAST/SLOW・700msマーカーを反映します。幅のプレビューは10–140%、既定60%でJSONには保存しません。Studio HUD・判定線タイプ・点/バーコードはゲームで設定します。プレビューは外観参考です。

既存の設定・プリセット形式を再利用し、レベル選択を曲選択と分けて空のレベルを保持します。判定・得点・ゲージ・リプレイ、Guest除外、固定グレード、client_submitted、BGAモデル非同梱を維持します。

検証記録は候補のevidence/VERIFICATION.ko.mdです。Webはユーザー承認によりSitesバージョン8へ配信済みです。ゲーム公開には別途承認が必要です。物理入力・聴音・長時間・他PC・任意外部スキンは未検証です。
