# TenRiff 1.8.41 릴리스 검증

기준일: 2026-10-05. 판정 MOD를 조정하고 과거 리플레이의 규칙을 보존하는 업데이트입니다.

## 판정 변경과 호환성

BMS EASY 기준 Judge Hard PG/GR/GD는 ±17.5/55.714286/98.571429ms입니다.
GR/GD를 일반 판정 BMS NORMAL 수준으로 좁히며, 이 세 경계는 기존 RANK 비율을 적용합니다.
BAD는 모든 RANK에서 Judge Hard ±225ms, Judge Easy ±210ms로 고정합니다.
Judge Easy의 PG/GR/GD·홀드 허용창 1.35배, 일반 판정, 자동 미스 340ms와 mask 30ms는 유지합니다.
전체 표와 샘플 경계 설명은 [판정 범위](judgement-windows.md)에 있습니다.

새 기록은 `tenriff-native-score-v2-ruleset-4`로 구분합니다. R1/R2/R3를 이 정책으로
다시 해석하지 않도록 판정 정책을 버전별로 분리하고, 리플레이·고스트·검증기가 같은 정책을
사용합니다. 과거 검증 메타데이터가 부족한 explicit R3/R4 재생도 각 당시 정책을 유지합니다.
커스텀 판정은 계속 비공식입니다.

웹 랭킹은 클라이언트 공개 전에 R4 수용을 배포했습니다. 웹 검사 14개, 로컬 D1/API 검사
51개, lint·타입 검사·빌드가 통과했습니다. 추가 DB 스키마 마이그레이션 없이 배포 전후
60개 보드·94개 기록과 기존 보드 ID를 보존하고, 배포된 R4 JS를 해시로 대조했습니다.
웹의 `client_submitted` 신뢰 범위는 바꾸지 않았습니다.

- Release CTest 3/3, 내부 977개 케이스, runner 통합 제외 0.
  선택적 외부 10k-calc Python 원본이 없어 해당 참조 비교만 생략했습니다.
- 판정 샘플 경계/경계 다음 샘플, RANK×Judge 모드, 여러 샘플레이트와 Rate,
  R1~R4 및 혼합 버전 player/ghost 동작을 검사했습니다.
- 스킨 에디터 검사 32/32.
- 실제 데스크톱: 창/독점 전체화면 × VSync ON/OFF 네 조건 모두 30/30 성공 Present.
  독점 조건은 전체화면 상태의 성공 Present도 30/30이며 종료 후 원래 표시 모드로 복귀했습니다.
  DXGI 대기열 readback은 1입니다.
- 첫 실행의 독점 전체화면은 `0x887a0022`로 진입하지 못했습니다. 실패 로그를 보존하고

  첫 실행 실패의 Windows 측 원인은 확정하지 않았습니다.
- 솔로/고스트 6개 캡처: 플레이어 LN 폭 5K60%=52px, 8K60%=30px, 8K140%=69px,
  세로 범위 y246~383으로 각각 동일했습니다.
- UI 캡처 10개: 일시정지·옵션·오디오·스킨·전체화면 미리보기·프로필·키맵의
  671개 클릭 영역/이벤트 전달 검사 및 각 30/30 성공 Present를 통과했습니다.
  Mode/Graphics는 옵션 카드까지만 포함하며 내부 설정과 OS 파일 대화상자는 별도입니다.

## 공개 전 배포 게이트

최종 결과와 해시는 릴리스 노트 및 로컬 배포 증거에 기록합니다.

- 새 ZIP에서 독립 추출한 소스의 configure·Release 빌드·CTest 및 에디터 검사.
- ZIP CRC, 추출 파일 SHA-256, 커밋 소스 일치, 비공개 정보 검사.
- PR 및 병합 후 main의 AddressSanitizer/OpenVINO CI.
- 초안 첨부 파일 다운로드·해시 검사 후 공개하고 공개 첨부 파일도 익명으로 다시 검증.

기존 릴리즈·설치본·프로필은 보존합니다. 짧은 합성 화면 검사는 물리 입력→화면/오디오
지연이나 실제 차트 장시간 플레이, 여러 PC에서의 동작을 증명하지 않습니다.
