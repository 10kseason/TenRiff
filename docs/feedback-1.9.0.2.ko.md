# TenRiff 1.9.0.2 릴리스 피드백 · 2026-10-15

공개 1.9.0.1 기반의 **1.9.0.2 릴리스 후보**입니다. 고정 기준은 [1.9.0](baseline-1.9.0.md)이며 이전 공개 버전·설치·프로필·원본 채보를 보존합니다. 실제 공개 여부와 다운로드는 [1.9.0.2 릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.0.2)만을 기준으로 확인하세요. [릴리스 범위·검증](release-1.9.0.2-gate.md)은 로컬 근거와 남은 공개 절차를 구분합니다.

## 로비와 선곡 표시

- Options를 초록색으로 표시합니다.
- 선곡에서 기본 제공 5K Aery 난이도표를 선택했을 때만 초록 ⑤를 표시합니다. 기본 Lv와 다른 표에서는 ⑤를 생략하며, 레벨은 빨강·점수는 흰색을 유지합니다. 원본 채보나 난이도표 데이터는 수정하지 않습니다.

### 등록 난이도표 기호 색상

등록된 표의 주소와 정확한 기호가 일치하고 레벨이 있는 경우 아래 기호 전체에 기존 키 모드 색상을 적용합니다. 숫자 레벨은 계속 빨강입니다. Revive10은 숫자 `10`이 아니라 `Ⓡ` 기호를 사용합니다.

| 표 기호 | 키 모드 | 색상 |
| --- | --- | --- |
| `4UE` | 4K | `#FF9BC5` |
| `6UE` | 6K | `#8FB8FF` |
| `8UE` | 8K | `#FFD479` |
| `Ⓡ` (Revive10) | 10K | `#63E9F2` |

5K Aery의 초록 ⑤와 7K Aery·Stella·Satellite 표시는 유지합니다. 기본 Lv와 식별되지 않은 사용자 표에는 이 색상 규칙을 적용하지 않습니다.


## 레벨 검색

검색창에 다음 문법을 사용합니다. `lv`와 `to`는 대소문자를 구분하지 않으며 범위의 양 끝을 포함합니다.

| 입력 | 포함하는 레벨 |
| --- | --- |
| `lv:16to20` | 16 이상 20 이하 |
| `Lv:16` | 정확히 16 |
| `lv:19-` | 19 이하 |
| `lv:18+` | 18 이상 |

난이도표를 선택했다면 **선택한 표의 레벨**을 사용합니다. 기본 Lv에서는 기본 차트/BMS 레벨을 사용합니다. 표에서 등급이 없거나 숫자로 해석할 수 없는 항목을 BMS 레벨로 대신 매칭하지 않습니다. `artist lv:16to20`처럼 공백으로 일반 검색어와 조합하면 두 조건을 모두 만족하는 곡만 표시합니다. 완성되지 않았거나 잘못된 `lv:` 식은 일반 검색어로 처리합니다. 숫자 레벨 필터와 같은 정수 기준을 사용하므로, 난이도표의 `st18`과 `18+`는 모두 숫자 18로 검색합니다.

## 입력과 음량 설정

- 새 프로필과 누락된 `input.debounce_ms`의 기본값은 8ms에서 **0ms**로 바뀝니다. 저장된 값은 이번 기본값 변경으로 초기화하지 않습니다. 단, 기존의 **5ms → 8ms 마이그레이션은 유지**합니다. 새 기본값과 과거 설정의 호환 처리를 분리한 것입니다.
- 오디오 UI의 마스터·BMS 곡·텐리프 음악·BGM·키음 5개 음량을 모두 **1%p(저장값 0.01)** 단위로 조절합니다. 이전 조절 단위보다 세밀하게 맞출 수 있습니다.

| 설정 | 범위 | 새 기본값 |
| --- | --- | --- |
| 마스터 `audio.volume` | 0–100% | 10% |
| BMS 곡 `audio.gameplay_volume` | 0–100% | 100% |
| 텐리프 음악 `audio.menu_music_volume` | 0–100% | 100% |
| BGM `audio.bgm_volume` | 0–200% | 100% |
| 키음 `audio.keysound_volume` | 0–200% | 100% |

저장된 음량과 미리듣기 ×0.75 등 기존 출력 배율을 유지합니다. 자세한 설정은 [설정 문서](config.md)를 참고하세요.

## 검증과 호환 범위

아래 수치는 최종 Aery ⑤ 복원과 등록 표 기호 색상 보완 전 후보의 검증입니다. 개발 빌드와 ZIP 추출 소스의 독립 빌드 모두 Release 빌드, CTest 3/3(각 1,224개, integration skips 0), 에디터 35/35, native MenuApp/GameSession 307/307을 통과했습니다. native 검사는 검색 키 처리 22개를 포함합니다. 복원 전 렌더는 6개 fixture/360 Presents/86 geometry hit checks를 통과했습니다. 최종 Aery ⑤와 4UE/6UE/8UE/Ⓡ 색상 보완 후 빌드 및 표시 검증은 릴리스 검증 절차에서 별도로 확인합니다. Aery FHD/작은 창, 숫자 레벨의 빨강 유지, 기본 Lv·다른 표·사용자 표의 예외도 포함합니다.

초기 빌드는 지원하지 않는 테스트 진단 `CAPTURE` 때문에 실패해 해당 진단 줄을 제거했습니다. 첫 native 검색 검사는 minus 키의 `SC_0C`를 인식하지 못해 실패했고, 검색 전용 코드 비교로 보완한 뒤 위 최종 검사가 통과했습니다. 초기 실패 기록과 원본·기존 기록은 보존합니다.

첫 패키징에서는 기존 스킨 레인 숫자 단축키 검사가 한 차례 실패했습니다. 코드 변경 없이 같은 테스트 바이너리의 재검사, 전체 CTest 재실행 및 독립 빌드 검사는 통과했지만 **근본 원인은 미확정**입니다. 최초 실패도 보존하며 재실행 통과를 원인 해결로 해석하지 않습니다.

로컬 패키지·독립 빌드 근거와 초기 실패는 별도 evidence에 보존합니다. 최종 공개 패키지 대응·PR/main CI·공개 자산 검사는 [릴리스 검증 절차](release-1.9.0.2-gate.md)를 따르며 이 문서에서 미리 통과로 표시하지 않습니다. 실제 공개 상태는 릴리스 페이지가 기준입니다. 내부 키 dispatch·geometry 검사는 물리 장치 입력을 대신하지 않으며 물리 장치·지연·장시간 플레이·다른 PC는 미검증입니다. 고정 기준은 1.9.0입니다.
