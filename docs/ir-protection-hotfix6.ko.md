# TenRiff hotfix6 IR 보호 로컬 후보

핫픽스5 기반 로컬 실행본입니다. 웹 서버는 개별 플레이 키음 원본이 45초 이상이거나 실제 플레이 노트 중 무키음 비율이 85% 이상인 새 제출을 거절합니다. 합산 키음 길이·곡 전체 길이·BGM 전용 음원은 45초 판정에 사용하지 않습니다.

온라인 제출 작업 스레드가 리플레이와 같은 원본 채보/선택 분기/배속·샘플레이트·노트 모드를 재구성하고, 키음 원본을 분석합니다. 탭과 LN 머리를 각각 한 노트로 세며 꼬리는 제외합니다. 해당 노트에 키음이 없거나 디코딩된 PCM이 전부 0이면 무키음입니다. 길이 계산에는 배속을 적용하지 않습니다. 45초 이상 음원은 분석 메모리를 제한하기 위해 45.0초로 포화하여 보내며 서버는 이를 거절합니다. 무키음 임계치는 85%를 포함합니다.

참조 음원 누락·해독 실패·채보 변경·분석 정보 누락은 등록 불가입니다. 원본 BMS 플레이를 지원하며 키 변환 플레이는 전송에서 제외됩니다. 현재 런타임 로더가 지원하지 않는 역사적 osu 기록에는 값을 추정하지 않습니다. PCM/float WAV, 완전한 단일 Vorbis OGG, 엄격한 Media Foundation 해독 경로의 MP3를 검사합니다. MF 전용 WAV와 Ogg Opus 등 분석이 불가능한 형식은 로컬에 보관합니다. 디지털 0 검사이며 청감상 무음/부정행위 방지를 보증하지 않습니다.

서버는 클라이언트 제출 정보를 사용합니다. 입력·판정·점수·리플레이 파일 형식은 바꾸지 않습니다. 기존 설치에 덮어쓰지 말고 별도 폴더에서 실행하세요. 기존 사이트 연결 정보를 사용할 수 있습니다. 새 규칙 적용 뒤 구버전은 분석 정보가 없어 IR 업로드가 거절됩니다.

곡 목록의 선택된 패턴과 상세 정보, 결과 화면에 등록 제외가 확인되면 `IR 제외`를 표시합니다. Speed of Link와 현재 키 변환·지원하지 않는 플레이 조건은 즉시 표시합니다. 선택 패턴만 별도 작업 스레드에서 검사하며 전체 라이브러리 검사나 주기적인 음원 재해독은 하지 않습니다. 선택 변경·재방문·F5·관련 설정 변경 시 다시 확인합니다. 선택한 채로 음원을 교체했다면 다른 곡을 선택했다 돌아오거나 F5를 누르세요.

검사 중·미확인 상태를 등록 가능으로 표시하지 않습니다. 플레이 전 분기를 알 수 없는 RANDOM 채보는 `IR 확인 필요`로 남습니다. 결과는 계정 연결과 관계없이 실제 완료 리플레이의 분기와 조건을 검사하며 현재 메뉴 설정과 섞지 않습니다. 결과의 검사 불가 표시는 음원 누락·변경·지원 불가 분석을 뜻하며 네트워크 장애를 패턴 제외로 분류하지 않습니다. 배지가 없는 것은 등록 가능 보증이 아니며 실제 제출 시 다시 검사합니다.
