# TenRiff 1.9.8 — スキンのX/Y位置とキー区切り線の明るさ

2026-10-19

[한국어](release-1.9.8.ko.md) | [English](release-1.9.8.en.md) | [日本語](release-1.9.8.ja.md) | [简体中文](release-1.9.8.zh-CN.md)

判定・コンボ・FAST/SLOWインジケーター・FAST/SLOWバーそれぞれのXとYをスキン設定で調整できます。非表示だった既存X設定を再表示するため、既定値0と保存済み座標を維持し、Xを変更してもYは変わりません。各Xは−600～600pxを10px刻みで調整し、対応するYの直前に表示します。Native/TenRiff/LR2で検索、キーボード左右、マウス−/+に対応します。

キー区切り線の明るさは0～100%を1%刻みで調整します。既定100%は元の色、0%は黒です。RGBのみ変更し、表示設定・アルファ・幅・小節線は維持します。任意の `skin.lane_divider_brightness` は `0..1`、既定値 `1` としてプロファイル・携帯用スキンに保存し、プレビュー・Classic/Studio・ゴーストに適用します。

既存のX保存形式と描画経路を再利用し、座標の初期化や移行を避けます。判定線はレーンに固定され、横配置は既存のフィールドドラッグに従います。固定判定・スコア・等級・入力・音声・リプレイ契約、R9/R10と過去のR1–R8、peer v7、Guest/client_submittedの境界を維持します。

1.9.7の共通キーと重複検査、拡大した色付きタブ、青FAST/赤SLOW、1%調整、ゲームモード設定・Normal表示、毎回/Retryの新シードと記録済みリプレイシード、シーン音楽の基準ゲイン12.5%をすべて維持します。一般固定基準は1.9.6で、以前のリリース・候補・インストール先・プロファイルを保持します。Webサイト・データベース・公開スキンエディターの変更は今回の範囲外です。

検証手順は完了結果ではありません。ビルド・テスト・パッケージ・ダウンロードの証拠を別途記録します。物理入力・IME・試聴・長時間プレイ・他のPC・任意の外部スキンは別途検証が必要です。
