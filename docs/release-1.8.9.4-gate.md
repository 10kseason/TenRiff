# TenRiff 1.8.9.4 변경·호환·검증 범위

1.8.9.3을 출발점으로 한 결과·오디오·채보 정보 패치입니다. 고정 문서 기준 1.8.7, 기존 태그·배포 파일·프로필과 원본 차트·음원은 유지합니다. 이 문서는 소스의 동작·호환성과 공개 조건을 설명합니다. 패키지와 최종 공개 검증 기록은 릴리스 노트 및 별도 검증 자료에서 관리합니다.

## 화면과 설정

- 네이티브 결과 화면은 위의 큰 점수 자리에 등급(기본 144)을 놓고 기존 등급 자리에 점수(64)를 옮겨 정확도(68)와 정렬합니다. S+ 색·Bloom은 유지합니다. 아래 통계는 판정 5개와 최대 콤보의 6칸이며, 상세 점수 옆에 상세 정확도를 표시합니다. 네이티브 요약이 없는 예전 이미지 결과 스킨은 정확도가 사라지지 않도록 기존 7칸을 유지합니다.
- Gauge Shift EASY/NORMAL/HARD/EX CLEAR 색은 초록/노랑/주황/빨강입니다. 다른 성공·실패·연습 상태의 색은 유지합니다.
- 오디오 메뉴 첫 두 행은 BGM 음량과 키음 음량입니다. 새 설정은 둘 다 100%이며 저장된 사용자 값은 강제로 변경하지 않습니다.
- 한국어 메뉴·도움말은 `키 빔`, `키 키밤`, `그래프 맵`, `키 구분 선`, `키 표시 위치`, `LN 끝 표시`, `LN 끝 사기롱놋화`, `페이드인 농도`, `페이드아웃 농도`를 사용합니다. 내부 설정 키와 스킨 파일 형식은 유지합니다.
- 선곡·결과에 채보자가 있을 때만 `obj: 이름`을 표시합니다. 빈 값에는 줄을 추가하지 않으며, 긴 값은 해당 텍스트 영역 안에 맞춥니다. 선곡 BPM 라벨의 `BPM! :`는 실제 변속이 있는 경우만 사용합니다.

## 채보 정보와 호환성

채보자는 BMS의 `SUBARTIST`, `ARTIST`, `COMMENT` 순서에서 명시된 `OBJ:` 크레딧만 읽습니다. 대소문자, 주변 공백과 전각 콜론을 허용하며 UTF-8 480바이트로 제한합니다. OBJ가 없는 곡은 작곡가를 임의로 채보자로 추정하지 않습니다. BPM 변속은 진행 시간이 있는 구간에서 채널 03/08의 BPM 값이 실제로 달라질 때만 표시합니다. STOP, 미사용 BPM 정의, 같은 BPM 재지정, 시작 위치의 초기 BPM 교체만으로 변속 표시를 만들지 않습니다.

곡 캐시 v16은 `chart_author`와 `has_bpm_changes`를 함께 저장합니다. v15 이하 캐시는 새 정보를 갖고 있지 않으므로 차트를 다시 인덱싱해 계산합니다. 이는 재생 가능한 원본이나 프로필을 옮기는 작업이 아닌 재생성 가능한 곡 목록 캐시 갱신입니다.

업로드의 `chart_author`는 선택 필드이며 값이 없으면 생략합니다. 모든 BMS가 OBJ를 제공하지 않고 기존 클라이언트·저장 기록도 이를 갖고 있지 않기 때문입니다. 리플레이에는 새 필드를 추가하지 않습니다. 웹의 `chart_metadata(hash PRIMARY KEY, author, updated_at)`는 점수와 분리된 표로 연결하고 첫 유효 메타데이터를 유지합니다. 같은 차트의 표시 정보를 보완하기 위해 기존 board ID·차트 식별 해시·순위 조건·점수를 다시 쓰지 않습니다. 웹 배포와 실제 온라인 제출은 아래 별도 검증 대상입니다.

## 중복 키음 보정

차트의 같은 sample 위치에서 디코딩된 PCM과 실제 적용 음량이 같은 중복 음원만 한 번 재생하도록 보정합니다. WAV ID나 파일 이름이 달라도 PCM을 직접 비교해 같은 음원임을 확인하며, 해시만 같다는 이유로 제거하지 않습니다. 서로 다른 차트 sample 위치·PCM·적용 음량은 유지합니다. 음소거·로딩 실패는 정상 음원을 제거하는 근거가 되지 않습니다. PCM 비교는 로딩 경로에서 수행하고 오디오 콜백에서는 파일 읽기·PCM 비교를 하지 않습니다.

입력과 판정 창, 점수·콤보·게이지 계산, R1–R4, 기존 키 변환 버전 3과 이전 리플레이의 배치는 유지합니다. 같은 차트 위치의 중복 키음이 줄어드는 것은 의도된 오디오 변경이며, 이를 성능 향상이나 물리 입력·오디오 지연 개선으로 설명하지 않습니다.

## 미리보기 재현 옵션

`menu_visual_preview`의 기존 캡처 옵션에 아래를 조합할 수 있습니다. 이 명령 예시는 검사 결과가 아닙니다.

```text
--result-status "GAUGE SHIFT EASY CLEAR" --result-grade S+
--result-status "GAUGE SHIFT NORMAL CLEAR"
--result-status "GAUGE SHIFT HARD CLEAR"
--result-status "GAUGE SHIFT EX CLEAR" --result-perfect
--chart-author "Very long chart author / 긴 채보자 이름" --bpm-change
```

`--chart-author`는 선곡·결과에 함께 적용하고, 인자를 생략하면 빈 채보자 배치를 확인할 수 있습니다. `--bpm-change`는 선곡 변속 표시에만 적용합니다. 실제 파서·캐시 전달은 별도 회귀 검사로 확인해야 합니다.
