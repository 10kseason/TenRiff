# TenRiff 1.9.2 变更与兼容性

2026-10-16 · 基于1.9.1.1发行版 `ea8bdba0fb8aa533f0e684b64fc64515e2eb2e41`。固定基准仍为1.9.0，保留以前的标签、发布文件、安装和配置。发布状态与下载以[1.9.2发布页面](https://github.com/10kseason/TenRiff/releases/tag/1.9.2)为准。本文描述功能范围，不代表验证已完成。

## 访客与在线模式

每次启动都会打开F10账户窗口，提供**访客模式**与**在线模式**。每次启动默认为访客，按Esc关闭启动选择也会保持访客。可用F10重新打开并切换。在线选择仅在当前进程有效，不会保存到下次启动。

只有在在线模式下新开始的游戏，满足现有连接与支持条件后才能提交排行榜。访客记录永久留在本地；之后切换在线或连接账户都不会使其变成可上传记录。没有来源标记的历史记录也禁止上传，但保留本地历史查看与回放。

任何一次切换访客都会永久撤销当前游戏的上传权限。同一局中重新切换在线也不会恢复，只对下一次新游戏生效。Sites与独立Ranked提交路径都检查该权限。访客切换会使待处理上传失效；若POST已开始，则等待它结束后才完成切换。此功能不会撤回或删除服务器已经收到的记录。

不修改服务器、数据库格式或数值排名计算。Sites仍是 `client_submitted` 社区排行榜。这些客户端权限检查不等于服务器回放验证或反作弊认证。LN Mix v2、自动演奏和不支持规则等原有限制继续保留。

## 图形、皮肤与菜单

- 删除V-Sync选项行，保留刷新率选择与旧 `graphics.vsync` 保存值。
- BGA亮度为0–100%，步长1%，默认100%，在背景合成后、音符和HUD绘制前应用。
- LR2/TenRiff皮肤导入、歌曲加载与索引、难度表加载使用共同进度条。
- 主页右下角语言按钮按英语 → 韩语 → 日语 → 中文循环并保存选择。
- 删除皮肤页面的**导出皮肤预设**。保留导入、文件拖放、完整配置导出及其内部皮肤打包功能。

评级固定使用未经四舍五入的普通准确率：99% S+++ / 98% S++ / 97% S+ / 95% S / 93% A+ / 90% A / 85% B / 80% C / 70% D / 低于70%且生存 E / 血条失败 F。无记录或中止为 `--`，自动演奏为 `AUTO`。分数、判定、血条及数值排名算法不变。网站Stable表示正式运营状态与相同的固定评级规则。

## 外部AI放大

处理顺序为**原图 → FFmpeg去块 → AI x2修复与残差合成 → 适配显示区域 → 必要时裁剪**。内置weak/block-8滤镜仅对完整原始RGB应用一次并保留透明度。AI输入与bilinear x2底图使用相同的去块结果。

动态空间轴模型一次接收完整原始H/W。固定960×540输入继续通过原像素填充与32像素上下文分块支持，不进行推理前缩放或16:9裁剪。实际残差输出必须恰好为x2。保留原图每轴4096像素上限和每实例3张/96 MiB缓存上限。仅用于静态BGA和选曲图片，视频AI仍禁用。

**公开运行包和源码包均不包含BGA放大模型。** 模型路径默认为空，功能默认为OFF。在Graphics选择或拖入外部ONNX后，再单独开启。保留已有路径、设置及原有NK3键位转换模型。FFmpeg先从游戏旁的 `tools/ffmpeg-deblock/ffmpeg.exe` 查找，再查PATH。执行文件缺失、滤镜或模型失败时保留原生显示。
