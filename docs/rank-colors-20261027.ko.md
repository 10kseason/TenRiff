# 랭크·시프트 시작 색과 EX 무지개 수정

1.9.9.1의 로컬 후속 후보이며 앞선 모든 로컬 변경을 포함합니다. 정확도별 랭크 기준·판정·게이지 증감량·점수·리플레이는 그대로입니다.

- **S+·S++·S+++ → EX 무지개**, **S → HD #FF3838**, **A+·A → NM #FFF000**, **B·C·D → EZ #00ED57**, **E·F → 연보라 #C2A0FF**. AUTO/--는 기존 중립색 #B6C0D0입니다.
- 선곡 로비·기록·결과 랭크가 공통 색을 사용합니다. 무지개는 EX 클리어의 같은 일곱 색을 실제 글자 폭에 적용합니다. 기존 글자/광택 캐시를 사용하므로 매 프레임 그라데이션이나 블러를 만들지 않습니다.
- 선곡 클리어 배지의 네 단계는 EX가 쓰던 동일한 글꼴·굵기·크기, 동일한 로고 모양을 공유합니다. 스킨의 글꼴 지정은 유지합니다. 시프트 시작 값도 해당 클리어 색을 사용하고 EX-HARD는 무지개입니다.
- **EX 게이지는 저장된 단색 스킨 값이 있어도 무지개**입니다. Classic/Studio와 고스트에 적용합니다. 앞선 후보의 “명시적 EX 색 우선” 예외를 이번 요청으로 대체합니다. 다른 게이지의 사용자 지정 색은 유지합니다.
- EX CLEAR 배지는 구형 로비 렌더러에서도 표시합니다. 가져온 로고 이미지도 배지 안에서는 알파/모양을 유지하고 클리어 색으로 칠합니다. 상단 로고 등 배지 밖 이미지는 원래 색입니다. 원본 이미지와 저장된 스킨 파일은 수정하지 않습니다.

기본/명시적 EX 단색/가져온 알파 로고/구형 로비를 포함한 렌더 검사를 수행합니다. 실제 사용자 스킨 전체, 실제 입력 및 장시간 플레이는 별도 검증 범위입니다. 이전 후보와 ZIP, 일반 기준선1.9.6은 보존합니다.
