# TenRiff 1.8.42 릴리스 검증

기준일: 2026-10-05. 고밀도 노트 구간에서 프레임 간격을 불필요하게 늘리던 제한기를 수정하는 클라이언트 업데이트입니다.

## 변경과 호환성

프레임 예산을 조금 초과해도 기존 시간 격자의 다음 칸까지 기다리던 경로를 수정했습니다.
이제 실제 프레임 시작 시각을 기준으로 제한을 적용하고, 그리기가 이미 예산을 넘으면
추가로 쉬지 않습니다. 늦게 깨어나거나 긴 정지가 발생해도 밀린 프레임을 몰아서 그리지 않습니다.
성능 오버레이가 꺼졌을 때는 이력 수집·주기적 정렬도 생략하고, 다시 켤 때 새 이력을 시작합니다.

노트/롱노트 모양과 표시량, FPS 설정, VSync/tearing 정책, 입력·음악/스크롤 속도는 유지합니다.
판정과 R1/R2/R3/R4 리플레이·고스트·검증 규칙은 변경하지 않습니다. 기존 R4 제출 계약을
사용하므로 웹 랭킹 재배포나 DB 마이그레이션은 필요하지 않습니다.

## 수정본에서 확인한 근거

- 신규 회귀 두 건이 수정 전 실패하고 수정 후 통과했습니다.
- 1050 FPS, 프레임당 980µs의 합성 CPU 부하를 실제 RenderThread에 주었을 때,
  프레임 간격 p50은 1.9049→0.9803ms, p99는 2.5570→0.9813ms였습니다.
  이는 GPU FPS나 물리 입력 지연이 아닌 렌더 스레드 시작 간격입니다.
- 자동 회귀는 60/144/240/300/600/1050/1500 FPS에서 경계·예산 초과·긴 정지와
  성능 오버레이 OFF/ON을 확인합니다. Release CTest 3/3, 내부 980개 케이스,
  runner 통합 제외 0입니다. 선택적 외부 10k-calc Python 참조만 부재로 생략했습니다.
- RTX 4060 Ti의 FHD 합성 화면: 노트 12/128개, LN, tapered LN, 고스트 등 6조건에서
  수정 전/후 각각 600/600 성공 Present를 확인했습니다. 고스트 LN의 창/독점 전체화면
  × VSync OFF/ON은 각각 180/180 성공 Present와 원래 화면 모드 복귀를 확인했습니다.
- 동기 렌더 측정에는 여전히 순간 지연이 남았으며 그리기 자체의 속도 개선은 주장하지 않습니다.
  제보된 RTX 4070의 실제 곡에서 체감 문제가 완전히 해결됐다는 증거는 아닙니다.

옵션과 측정 범위는 [고밀도 렌더 검증](dense-note-performance.ko.md)에 설명합니다.

## 1.8.42 공개 전 게이트

최종 통과 결과와 해시는 릴리스 노트 및 로컬 배포 증거에 기록합니다.

- 1.8.42 Release 재빌드·CTest, 소스/압축 해제 소스의 에디터 검사.
- 새 ZIP에서 독립 추출한 소스 configure·Release 빌드·CTest.
- 1.8.42 실행본의 FHD 창/독점 전체화면 × VSync OFF/ON 확인.
- ZIP CRC, 추출 파일 SHA-256, 정확한 병합 커밋 소스 일치 및 비공개 정보 검사.
- PR 및 병합 후 main의 AddressSanitizer/OpenVINO CI.
- 초안 첨부 파일 다운로드·해시 확인 후 공개하고, 공개 파일도 익명으로 재다운로드하여 검증.

CI의 OpenVINO CPU 검사는 `ONEDNN_MAX_CPU_ISA=AVX2`로 동일한 전체 변환 검사를 수행합니다.
초기 두 실행의 Xeon 8573C 호스트에서 Illegal-instruction 종료를 확인했고,
[동일 호스트의 가상 AMX 기능 불일치 보고](https://github.com/uxlfoundation/oneDNN/issues/5689)와
[공식 dispatcher 설정](https://uxlfoundation.github.io/oneDNN/dev_guide_cpu_dispatcher_control.html)을 근거로
CI에서만 공통 AVX2 경로를 지정합니다. 이 검사는 AMX 실행을 검증하지 않으며,
패키지와 일반 로컬 실행의 CPU 기능 선택은 바꾸지 않습니다. 실패 로그를 보존합니다.

이전 릴리즈·설치·프로필을 보존합니다. 물리 입력→화면/오디오 지연, 제보 PC의 실제 차트,
장시간 플레이와 다중 PC 검증은 별도이며 합성 화면 검사로 대체하지 않습니다.
