# NK2 E ローカル移植候補

TenRiff 1.9.8.5にKeyWeaver 1.3.0のE Source LNを移植した未公開候補です。一般固定ベースラインは変更しません。ゲームモード設定でNK2と`E - Source LN`を選択します。新規設定のNK2プリセットはEですが、保存済みNative/Transform/Remasterは保持します。

対象は既存メニューの**4・5・6・7・8・9・10・12・14・16K**のみです。原本と同じキー数は原本配置を保持します。減少変換は区間探索と必要なノート除外を行い、追加や時刻移動は行いません。増加変換の新規LN全体は原本LN一個の区間内に収めます。Fの追加予算は使用しません。DPはフィールド全体を探索します。原本のサンプル時刻・LN・キー音を保持し、生成ノートは別IDと無音にしてキー音の重複を防ぎます。独立安全検査とサンプル区間検査の失敗時は警告付きで原本を保持します。内部はミリ秒精度のためミリ秒への丸めで長さが0になるLNは拒否し、探索区間には基準BPMを使用します。

既存リプレイ項目に`source_ln_e_v1`を保存し、過去プリセットの旧エンジンは分離して保持します。Eには候補付属の検証器を使用してください。形式・R9/R10判定・等級は変更しません。Sitesの条件は`nk2:source_ln_e_v1`で、`client_submitted`境界を維持します。Krrcream/NK3の記録識別は変更しません。検証結果と未検証範囲は候補の`evidence/VERIFICATION.ko.md`を参照してください。

Sitesの既存方針は最大14Kです。16Kの変換とリプレイ検証はローカルで対応しますが、記録は送信しません。
