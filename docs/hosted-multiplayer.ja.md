# 中央サーバー対戦

TenRiff 2.0.0の中央サーバー対戦の案内です。互換基準final4、判定、リプレイ、従来のPeerProtocol v9は維持し、新しいオンラインルームにはhosted protocol v2と`score_version="ex-v1"`を使います。点数・順位は[EX Score](ex-score.ja.md)に統一し、旧hosted v1・直接IP版とは接続できません。

F10でOnlineを選び、既存ランキングの接続情報を取り込みます。対戦画面で公式ルームを作成または選択して参加します。サーバーがアカウントを認証し、ランキング記録は要求しません。Guest、期限切れ・失効した接続は参加不可です。画面にはIP・ポート入力やLAN接続はありません。

別のTenRiff Multiplayer SiteがHTTPSとD1で最大8人のルームを管理します。リーダー退出時は他の参加者に選曲権を渡します。リーダーがローカルBMSを選び、各PCで同一ファイルを照合します。全員の一致と準備が必要です。曲一覧全体・譜面・音源は転送しません。従来の共通曲一覧に代わり、選択した曲を照合します。

音声と入力判定は各PCが処理します。全員がサーバーの未来開始時刻を使い、遅れた開始通知や遅すぎる応答は拒否します。状態と相手スコアは500ms間隔で交換するため表示が遅れる場合があります。インターネット遅延、8人負荷、長時間プレイ、D1使用量は別途検証が必要です。サーバー配備だけではリプレイ検証や不正対策になりません。

F11はルームチャットです。Guestへの変更・アカウント切断や変更は対戦接続も終了します。接続キーは公式対戦SiteからランキングへHTTPSで照合するためだけに使い、保存しません。以後はハッシュのみ保存される短期セッションを使い、20秒ごとに再認証します。失効反映には最長30秒の猶予があります。
