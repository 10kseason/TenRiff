# 오디오 장치 안내 수정

오디오 출력 장치가 없거나 선택한 장치를 사용할 수 없어 플레이 초기화가 실패하면 선곡 화면 하단에 황색 안내를 표시합니다. **옵션 → 오디오 → 사운드 출력 장치**에서 연결된 장치를 선택한 뒤 다시 시작하세요. ASIO는 설치된 ASIO 드라이버를 선택합니다.

기존에는 오류가 난이도표 URL 편집창 안에서만 표시되어 일반 선곡 화면에서는 원인이 보이지 않았습니다. 이제 항상 보이는 하단 안내 두 줄을 사용하며 정상 세션 초기화 후 안내가 사라집니다.

오디오 장치가 없어도 플레이하는 기능, 임의 장치 자동 변경, 오디오 백엔드·판정·점수·리플레이 변경은 포함하지 않습니다. 저장된 장치 선택을 유지합니다.

Included in 1.9.9.8 hot fix 1 (tag: 1.9.9.8-hotfix1). Fixed baseline: 1.9.6.
