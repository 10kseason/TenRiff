# TenRiff 1.9.9.7 — Standard LN early-release fix and online submission

Standard holds previously accepted early release throughout the GOOD window. Early release now succeeds only within the current PG window: Normal10/15/19/22ms by authored RANK, Hard19ms, EX10ms. The exact boundary succeeds; earlier drops immediately commit BAD, combo break, gauge loss and OD8 Miss. Regrabbing cannot refund the failure. Held-through tails still complete automatically; authored CN release timing and tap/head windows remain.

New Normal/Hard runs use R11 and EX uses R12. Sites accepts, lists and labels these identities while preserving R9/R10 submissions on separate boards. Existing board conditions, score hashes and history are never relabeled. R1–R10/custom replays and ghosts retain their original policies, without new JSON fields or migration. BEST generation3 preserves historical result files. Same-layout peer v8 rejects v7 to prevent mixed-policy matches.

Existing Guest, custom, assisted, LN Mix v2/v3 and paused-play exclusions remain. Sites stores game-submitted scores and hashes as client_submitted; it does not reverify replay files on the server. The separate Ranked server-support gate remains. Preserve the pinned1.9.6 baseline and all earlier releases/installations/profiles/charts. Physical input/feel, long sessions, other PCs, real two-PC play and real-account uploads remain unverified.
