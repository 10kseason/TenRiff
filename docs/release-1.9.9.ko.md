# TenRiff 1.9.9

1.9.8.5에 KeyWeaver 1.3.0 NK2 프리셋 E와 웹 리더보드 16K 제출을 더한다. 일반 고정 기준선은 1.9.6이며 이전 릴리스·프로필·설치본을 보존한다.

게임 모드 설정에서 키 컨버터 **NK2**, 프리셋 **E - Source LN**을 선택한다. 출력은 기존 메뉴의 **4/5/6/7/8/9/10/12/14/16K**다. 새 설정의 NK2 프리셋은 E이며 저장된 Native/Transform/Remaster 선택과 기본 변환 알고리즘 Krrcream은 유지한다. 키 수 증가는 E의 구간 탐색과 추가 탭/LN을 사용한다. 생성 LN은 원본 LN 한 개의 전체 구간 안에 들어간다. 감소는 배치와 필요한 노트 제외만 수행하며 F의 추가 예산은 사용하지 않는다.

원본 샘플 시각·LN 길이·키음·릴리스 판정을 보존하고 생성 노트는 키음을 중복 재생하지 않는다. 독립 안전 검사와 정확한 샘플 구간 검사가 실패하면 경고와 함께 원본을 유지한다. 내부 엔진은 밀리초 단위와 런타임 기준 BPM을 사용한다. 과거 NK2 프리셋은 원래 엔진으로 분리해 과거 리플레이 해석을 유지한다.

E 리플레이는 기존 프리셋 필드의 `source_ln_e_v1`을 사용하므로 **1.9.9 검증기**가 필요하다. 기존 1.9.8.5의 보조키 소유권 리플레이 검증도 포함한다. NK2 E의 OFF/미러 고스트는 사용하지 않는 플레이 seed가 달라도 허용하며, 랜덤·노트 추가·LN 혼합·BMS 분기 검사는 유지한다. 판정·등급·R9/R10·리플레이 형식·peer v7은 바꾸지 않는다.

클라이언트와 웹 서버가 함께 **16K** 제출을 허용하고 웹 필터에도 16K를 표시한다. 기존 웹 4–14K와 역사적 11/13K 읽기를 유지하며 15/17K는 거부한다. E는 `nk2:source_ln_e_v1`로 다른 프리셋과 구분한다. Online 정식 R9/R10만 새 제출이 가능하며 Guest·커스텀·LNMix v2 제외와 `client_submitted` 경계는 유지한다. DB 구조·기존 기록·보드 ID는 변경하지 않는다. 이 릴리스는 스킨 형식을 바꾸지 않으며 공개 스킨 에디터 v11을 유지한다.

검증 절차와 한계는 [릴리스 게이트](release-1.9.9-gate.md)를 따른다. 합성·로컬 API 검사는 물리 입력, 장시간 플레이, 다른 PC, 실제 계정의 운영 서버 업로드를 증명하지 않는다. 공개 여부와 다운로드는 [1.9.9 릴리스](https://github.com/10kseason/TenRiff/releases/tag/1.9.9)가 기준이다.
