# TenRiff 1.9.4 — 메모리 정리 시점과 플레이 설정

사용자가 선택한 1.9.3(`bf544e17f22879011a04a7fd157e40b57f6598bb`) 기반의 1.9.4입니다. 일반 고정 기준선 1.9.0, 이전 공개 파일·설치·프로필은 보존합니다.

- 플레이 중 디코딩한 채보 음원을 캐시 한도에 따라 버리지 않습니다. 일시정지 중에도 보관하고, 세션 종료 시 오디오·디코딩 작업이 멈춘 뒤 해제합니다. 초반 음원 우선 로딩과 이후 미리 읽기는 유지합니다.
- 정적 BGA 비트맵의 256장/192MiB LRU 퇴출을 없애고 메뉴 복귀 때 캐시를 비웁니다. 곡 검색 작업의 강제 힙/작업 집합 정리는 로딩·플레이·일시정지 동안 보류하고, 메뉴의 수집 지점 또는 세션 종료 이후 검색 요청에서 처리합니다.
- TenRiff는 C++ 프로그램으로 별도의 관리형 GC가 없습니다. 이 변경은 위의 명시적 캐시 퇴출과 강제 메모리 정리에 적용됩니다. 일반 객체 수명, 영상 프레임 재사용, 비동기 작업 취소와 장치 손실 복구는 유지합니다. 모든 할당·해제나 운영체제 페이징을 막는 기능은 아닙니다.
- 음원은 세션 종료까지, 정적 BGA는 메뉴 복귀까지 메모리 사용량이 누적됩니다. 메뉴 없이 이어지는 코스에서는 여러 곡의 BGA가 함께 남을 수 있으며, 매우 큰 채보는 메모리 압박을 높일 수 있습니다. 끊김 감소나 물리적 입력 지연 개선을 수치로 보장하지 않습니다.
- 스킨에서 인디케이터를 점/바코드로 선택합니다. 항상 표시는 눈금과 중심을 유지하며, 각 판정 표시는 게임 시간 기준 0.7초 후 사라집니다. FAST/SLOW 문구 유지 정책은 그대로입니다.
- 사운드의 출력 장치 선택은 WASAPI 연주/미리듣기에 적용합니다. ASIO는 기존 드라이버 선택을 쓰고, 메뉴/결과 음악은 Windows 기본 출력의 MCI 경로를 유지합니다. 연결이 끊긴 지정 장치에서 다른 출력으로 몰래 전환하지 않습니다.
- 프로필에서 F1–F11 기능 키를 지정/해제하며 안내도 바뀐 키를 표시합니다. 기존 F5/F6의 −10/+10은 ×0.5/×2로 바뀝니다. 1회 누름당 1회 적용하며 기존 0.5–50 범위와 F3/F4 ±0.25를 유지합니다. 곡 재생속도와 판정은 바뀌지 않습니다.
- BMS 마디선은 노트의 아래쪽 가장자리에 맞춥니다. 플레이어/고스트, 노트 높이 설정에 같이 적용하며 채보 시간은 유지합니다.

설정·프로필 호환성의 자세한 설명은 [입력/인디케이터 안내](input-feedback-20261017.ko.md)를 참고하세요. BGA 가중치 미동봉, OFF/빈 경로/Auto 기본값, Guest 업로드 제외, R7/R8와 이전 리플레이, 고정 등급 정책을 유지합니다. 웹/DB 변경은 없습니다.

검증 계획과 한계는 [릴리스 검증 절차](release-1.9.4-gate.md)에 있습니다. 공개 상태와 다운로드는 [1.9.4 릴리스](https://github.com/10kseason/TenRiff/releases/tag/1.9.4)를 기준으로 합니다.
