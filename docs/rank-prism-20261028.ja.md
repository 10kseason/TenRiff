# プリズムのランク文字・EXパレット（ローカル候補）

[한국어](rank-prism-20261028.ko.md) · [English](rank-prism-20261028.en.md) · [简体中文](rank-prism-20261028.zh-CN.md)

S+・S++・S+++の文字にプリズム効果を適用する、1.9.9.3ベースのローカル候補です。Releaseビルド、CTest 3/3（1,445件）、最終描画26件、エディター37件の検証に合格しました。公開版と一般固定基準1.9.6は維持します。

- S+・S++・S+++の文字にEXプリズムのグラデーション、グロー、立体感を出す面と光の効果を適用します。PNG読込ではなく既存の文字ビットマップキャッシュを使います。文字・フォント・サイズ・デバイスが変わる時に効果をキャッシュするため、毎フレームのぼかし処理や色相アニメーションは不要です。キャッシュ生成に失敗した場合は従来の文字表示に戻ります。
- 制作済みのランク画像はソース外のコンセプト成果物として保存し、ゲームでの読込やパッケージへの同梱は行いません。他のランクとEZ/NM/HD・E/Fの色は維持します。
- EXには選択画像のシアン→青→ラベンダー→ピンク→金→ミント→シアンを、静的なsRGB RGB補間で使います。この選択は、従来のEX金色系統および紫色を除外する指示に優先します。
- キーオーバーレイでは推定難易度の表示だけを削除し、KPSとキー/ノートビューアは維持します。譜面と選曲一覧の難易度情報も維持します。
