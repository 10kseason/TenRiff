# スキン HUD の X/Y 位置調整

2026-10-19のユーザー依頼により、公開1.9.7 (`948518d`)を基に1.9.8へ含める変更です。1.9.7の共通キー、色付きタブ、毎回の新シード、シーン音楽の基準ゲインを維持します。一般固定基準1.9.6と以前のリリース・候補・インストール先・プロファイルは保持します。

- キー区切り線の明るさ: 0～100%、1%刻みのスライダーと−/+。既定100%は元の色、0%は黒です。RGBのみ変更し、アルファ・表示設定・幅・小節線を保持します。プレビュー・ゲーム・ゴーストのキャッシュを即時更新します。任意項目 `skin.lane_divider_brightness` をプロファイルと携帯用スキンに保存し、旧ファイルは100%で読み込みます。

| 設定 | X | Y |
| --- | --- | --- |
| 判定 | −600～600px、10px刻み | 既存の縦位置比率 |
| コンボ | −600～600px、10px刻み | 既存の縦位置比率 |
| FAST/SLOW インジケーター | −600～600px、10px刻み | 既存の−400～400px、10px刻み |
| FAST/SLOW バー | −600～600px、10px刻み | 既存の−400～400px、10px刻み |

- X/Yを隣接表示します。Native/TenRiff/LR2で検索、キーボード左右、マウス−/+に対応します。
- Xは既存位置からのオフセットです。負は左、正は右へ移動します。各項目は独立し、X操作はY保存値を変更しません。
- 既存のX設定を再表示し、既定値0、保存値、プロファイル・携帯用スキン形式、プレビュー・Classic/Studio・ゴーストの描画処理を保持します。移行や初期化はありません。
- [2026-10-18の方針](skin-ui-followup-20261018.ja.md)の4つのX設定非表示を置き換えます。ギア境界線などは非表示を維持します。
- 判定線はレーンに固定され、横位置は既存のプレビューフィールドドラッグで一緒に動かします。
- 判定・入力・スコア・リプレイ・音声処理は変更しません。自動検証と実機入力・長時間プレイは区別します。

[1.9.8の変更](release-1.9.8.ja.md)と[検証手順](release-1.9.8-gate.md)を参照してください。この動作説明は検証完了を示すものではなく、公開状態とダウンロードは[1.9.8リリースページ](https://github.com/10kseason/TenRiff/releases/tag/1.9.8)を基準とします。
