# NK2 E 本地移植候选版

本候选版基于TenRiff 1.9.8.5，移植KeyWeaver 1.3.0的E Source LN，尚未发布，也不改变通用固定基线。在游戏模式设置中选择NK2和`E - Source LN`。新设置默认使用E，但保留已有Native/Transform/Remaster选择。

仅支持现有菜单的**4/5/6/7/8/9/10/12/14/16K**。原始模式和相同键数保持原谱。减少键数时进行片段搜索和必要的删减，不添加音符或移动时间。增加键数时，新增长条必须完整位于一个原始长条区间内，不启用F的额外预算。DP采用全场搜索。保留原始采样时间、长条语义和键音；新增音符使用独立ID且不重复播放键音。独立安全检查或采样区间检查失败时，显示警告并保留原始布局。内部精度为毫秒，拒绝毫秒舍入后长度变为0的长条；搜索区间使用运行时基准BPM。

现有回放字段保存`source_ln_e_v1`，旧预设继续使用独立保留的旧引擎。E回放须使用本候选版附带的验证器。回放格式、R9/R10判定和等级不变。Sites条件为`nk2:source_ln_e_v1`，维持`client_submitted`边界，不改变Krrcream/NK3记录标识。验证结果及未验证范围见候选目录的`evidence/VERIFICATION.ko.md`。

Sites现有规则最多接受14K。16K转换和回放验证可在本地使用，16K成绩保留在本地。
