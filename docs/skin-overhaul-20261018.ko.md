# 스킨 설정 개편 (로컬 후보)

직전 1.9.5.2 피드백 후보의 12개 수정을 모두 포함한다. 공개 릴리스와 설치·프로필은 변경하지 않았다.

- 대상 레인 행을 제거했다. 미리보기의 번호 버튼을 클릭하면 편집할 레인이 바뀐다. 현재 선택한 설정 행은 유지되며 색상·너비·오른쪽 간격 편집에 적용된다. 마지막 레인은 왼쪽 간격을 선택한다. 7+1 스크래치 위치와 기존 숫자 단축키도 지원한다.
- 단일 색상, 노트 테두리, 이미지 비율, 전체 투명도, 외곽선 투명도, 레인 색상 농도, 16K 중앙 간격, 구분선 너비를 스킨 설정에서 숨겼다. 기존 저장값은 보존한다. 명시적으로 고정한 구분선은 실제 표시에서 항상 100%를 사용한다.
- 새 설정의 노트 모양은 사각형 심플이다. 16K 중앙 간격 기본값은 100%이며 저장된 간격은 유지한다.
- 이미지 비율은 원본 이미지가 아니라 **설정으로 결정된 실제 노트 영역의 너비·높이**로 판단한다. 1:1이면 원본 비율을 유지해 영역 안에 맞추고, 직사각형이면 늘인다. 이전 비율 토큰은 저장 호환성을 위해 읽고 쓰지만 현재 표시에는 자동 규칙을 적용한다. 플레이어·고스트·스킨 미리보기가 같은 처리를 사용한다.
- UI 폰트와 폰트 파일 선택은 프로필의 언어·글자 크기 다음으로 이동했다. 기존 저장 위치와 TTF/OTF 파일 선택·유효성 검사를 재사용하고 즉시 저장한다.
- 판정선 위치는 1~100%이다. 기존 0%는 로드 시 1%로 제한된다. 게임·미리보기·스킨 파일 파서와 웹 에디터 검증 범위를 맞췄다.

메뉴 삭제는 저장 형식 변경이 아니다. 숨긴 단일 색상이 기존 프로필에서 켜져 있으면 이전 색상 효과도 유지된다. 판정 시점·점수·리플레이·오디오 계약은 변경하지 않았다. 웹 에디터는 사용자 승인 후 [기존 공개 주소](https://tenriff-skin-editor.lastestarcorp.chatgpt.site)에 Sites 버전8로 배포했다. 게임 후보는 로컬 상태다.
