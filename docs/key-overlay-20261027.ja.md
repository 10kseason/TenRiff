# キーオーバーレイとロゴ拡大 · ローカル更新

初期位置はX 0%、Y 25%で、標準Classic/Studioのレーン・ゲージ・スコア領域を避けます。

1.9.9.1とローカル操作・Session Mixの変更を引き継ぐ未公開候補です。固定基準は1.9.6のまま、過去のリリースを保存します。

**設定 → スキン → HUD → キーオーバーレイ プラグイン (4/5/7/8/10K)**で有効にします。初期値OFF。X/Yは画面内の0～100%を1%刻みで調整し、有効状態と位置を設定・プロファイル・携帯用スキンプリセットに保存します。プレビューは仮想入力とPreview表示のみで、推定値を生成しません。

実行時の**4/5/7/8/10K**のみ表示し、ほかのキー数では設定を保存して非表示にします。現在のキーバインド・レーン色・スクラッチ表示順を使います。入力とホールド、直近1秒NPS、8秒入力パターンの推定難易度を表示します。[key-note-overlay-cpp](https://github.com/10kseason/key-note-overlay-cpp) v2.13の計算・校正を使用し、4K Reform、5K AERY、7K Jinjin、8K Regular、10K Reviveの単位と段名を維持します。保持値は`*`、校正範囲外は矢印です。入力負荷の推定であり、全譜面の難易度・実力・クリア予測ではありません。

受理した実入力の論理レーン変化を観察します。押したままのレーンで補助キーへ所有権が移る場合は一つのホールドです。ポーズ・カウントダウン・フォーカス喪失・終了で初期化し、オート・リプレイ・ゴーストは数えません。判定・スコア・音声・リプレイ仕様は変更しません。固定長キューからHUD側で最大10Hz解析し、欠落・古い入力では履歴を消去します。

ホーム・選曲・設定・結果の標準ロゴ表示を拡大し、原画像と指定済み配置枠を保存します。ゲーム内プラグインであり、別プロセス・全体キーフック・常駐サービス・通信を追加しません。外部アプリのトレイ・レポート・osu!メモリ読取は対象外です。MIT原文と出典は`third_party/key_note_overlay/`、検証記録は候補の`evidence/VERIFICATION.ko.md`です。実機入力・OBS・長時間プレイは別途確認が必要です。
