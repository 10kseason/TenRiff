# TenRiff 2.0.0

[한국어](release-2.0.0.ko.md) | [English](release-2.0.0.en.md) | [日本語](release-2.0.0.ja.md) | [简体中文](release-2.0.0.zh-CN.md)

EX Score(2×PG + GR), 계정 연동 중앙 서버 멀티플레이, 별자리 홈·곡 선택·옵션, 검증된 ALL COMBO 표시와 방 채팅·라이브러리·Session Mix 수정을 통합합니다.

- **점수:** EX Score는 P-Great×2 + Great이며 Good·Bad·Poor는 0점입니다. 표시·개인 최고·고스트·Session Mix·멀티플레이·웹 순위를 통일하고 모드/Rate 점수 배율은 적용하지 않습니다. 정확도·등급·게이지·판정 규칙은 별개로 유지합니다. 과거 리플레이 검증용 점수는 보존하고 판정수가 없는 기록은 EX로 추정하지 않습니다. 웹에서는 해당 기록을 보존하되 EX 순위에서 제외합니다.
- **온라인 방:** F10에서 기존 리더보드 계정을 연결한 사용자가 공식 서버 방을 만들고 참가합니다. 순위에 점수를 올린 적은 없어도 됩니다. 최대 8명이 선곡·준비·예약 시작·점수·방 채팅을 공유하고 리더가 나가면 권한을 넘깁니다. 각 PC가 같은 차트를 직접 준비하며 곡 파일과 전체 라이브러리를 전송하지 않습니다.
- **화면:** 별자리 홈·곡 선택·설정 화면과 정적 은하 배경을 통합합니다. 홈 문구는 정확히 **Tenriff BMS Rhythm Game Client**이며 히어로 아래 부제만 제거하고 사용 안내는 유지합니다. 옵션은 기존 8개 카테고리의 4×2 카드와 기존 조작을 유지합니다. 옵션 은하 배경 원본은 수정하지 않고 표시 시 채도 0.92·밝기 0.98을 적용하며 알파를 보존합니다.
- **기록 표현:** 검증된 풀콤보만 **ALL COMBO**로 표시합니다. 선택곡의 최고 클리어 램프와 최고 EX 기록을 분리하고, 긴 제목·작곡가 표시, 정적 썸네일, 포인터 조명과 동작 줄이기 경로를 정리합니다. EX 은하 배지와 클리어 그라데이션은 옵션 배경과 별도 자산입니다.
- **수정:** 방 채팅 입력은 미설정 전역 채팅 서비스 대신 연결된 PeerSession을 확인합니다. F11·Enter·256바이트 제한은 유지합니다. 폴더 추가 버튼은 Library에서만 보이며 Session Mix의 생성·재편성·저장·가져오기와 취소 동작을 수정합니다.

새 온라인 방은 hosted protocol 2와 `ex-v1`, 웹 업로드는 schema 2를 요구합니다. 과거 룰셋/리플레이와 직접 TCP PeerProtocol v9의 구현은 보존하지만 새 방과 구 클라이언트를 혼합하지 않습니다. 기록은 계속 **client_submitted**이며 서버 리플레이 검증이나 부정행위 방지를 보장하지 않습니다. 게스트·출처 없는 과거 기록을 온라인 적격 기록으로 바꾸지 않습니다.

최종 2.0.0 빌드·소스 ZIP 독립 빌드·패키지·CI·공개 자산의 실제 검증 결과는 검증 게이트에 기록합니다. 이전 후보의 통과 횟수를 이 릴리스 결과로 재사용하지 않습니다. 실제 IME·물리 입력·청음·실계정 인터넷 대전·장시간·다른 PC와 성능/비용은 별도 확인이 필요합니다.

호환 기준은 **1.9.9.9-final4**를 유지합니다. **2.0.0 이후에는 버그 수정만 진행하며 새 기능은 추가하지 않습니다.** 릴리스 검증·게시 상태는 [검증 게이트](release-2.0.0-gate.md)를 따릅니다. 아래 이전 버전 안내는 당시 이력입니다.
