# TenRiff 1.9.5.1 — 判定ライン・FAST/SLOW・ファイル選択

スキン設定で判定ラインのタイプ1/2を選択できます。既定はタイプ1です。タイプ2は正確なタイミングのノーツが緑の領域内に入るよう表示だけを調整します。画像比率・回転・形状、ロングノーツ、ゴーストと小節線を反映します。判定時間・得点・ゲージ・リプレイ規則は変わりません。

FAST/SLOWは最大判定範囲外の最後の入力から0.35秒残ります。最大判定でも即座に消えず、最大判定の連打で表示時間が延長されることもありません。新しい範囲外判定が出れば即座に更新します。常時表示の目盛りと点/バーの0.7秒寿命は維持します。

画像・フォルダー・モデル・設定ファイルの選択は毎回新しいダイアログを作成します。重なった明示的要求はアプリ自身の前の選択窓を閉じ、入れ子の置換は一度に制限して再表示ループを防ぎます。所有者はゲーム窓に限定し、終了時に操作可能な状態へ戻します。COM終了前に関連オブジェクトを解放し、古い入力を破棄します。他のエクスプローラー窓やプロセスは終了しません。

新規マスター音量は30%、保存済み音量は維持します。標準曲ライブラリを広げ、中央の最高記録文字を約79%に調整しました。ジャケットの判定表示に判定難易度の接頭辞を追加します。カスタムロビーの明示座標は維持します。

1.9.5の出力先・ランダム順・プロフィールキー・解放延期・ONNX/Safetensors・Guest除外と過去リプレイ互換を含みます。BGA重みは同梱せず、OFF/空/Autoと既存NK3モデルを維持します。固定基準は1.9.0、Web/DB変更はありません。
