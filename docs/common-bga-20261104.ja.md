# 共通BGA

グラフィック設定で **共通BGA動画** にローカル動画を選び、**共通BGA** を有効にします。全譜面の背景・重ね合わせを無音のループ動画に置き換えます。一時停止・再開は既存の表示時計に従います。

初期値はOFF・空のパスです。選択だけでは有効にならず、キャンセルは前の選択を保ちます。BGA OFFが優先されます。未選択なら譜面BGA、削除済み・デコード不可なら標準背景を表示します。ファイル変更・次のゲーム開始時に再試行します。戻るで保存します。

明るさ・ノート背面・アップスケーラー設定は共通です。選曲プレビュー、メニュー・リザルト背景、判定・音声・リプレイ・オンライン記録は変わりません。
