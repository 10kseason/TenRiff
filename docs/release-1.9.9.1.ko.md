# TenRiff 1.9.9.1

[한국어](release-1.9.9.1.ko.md) · [English](release-1.9.9.1.en.md) · [日本語](release-1.9.9.1.ja.md) · [简体中文](release-1.9.9.1.zh-CN.md)

1.9.9에 21:9 화면, 롱노트 해제 표시와 지뢰 회피 LN Mix 수정을 더한다. 일반 고정 기준선은 **1.9.6**이며 이전 릴리스·설치·프로필·차트는 보존한다. 이 문서는 릴리스 범위를 설명하며 공개 완료를 뜻하지 않는다. 공개 여부와 다운로드는 [1.9.9.1 릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.9.1)가 기준이다.

- **21:9 화면:** 2560×1080·3440×1440에 5120×2160 프리셋을 더한다. 전체 화면 배경·BGA·어두운 덮개는 좌우 공간까지 채우고 기존 cover crop으로 비율을 보존한다. UI·노트·마우스 좌표는 1920×1080 설계 기준으로 중앙에 균일 확대하며, 저장된 위치와 명시된 작은 스킨 영역은 유지한다.
- **롱노트 해제:** 처리 중 손을 떼도 남은 몸통이 원래 꼬리가 지나갈 때까지 스크롤한다. 이미 처리한 머리·활성 발광·판정을 되살리지 않으며 플레이어와 고스트에 함께 적용한다. 마지막 LN을 놓쳤을 때도 자동 결과 전환은 꼬리가 화면을 벗어날 때까지 기다리고 음수 시각 오프셋을 반영한다. 명시적 건너뛰기·중단·게임 오버는 유지한다.
- **지뢰 회피 LN Mix v3:** 새 LN은 같은 레인 지뢰 앞뒤 최소 50ms를 비운다. 공간이 부족하면 단타로 남고 뒤 지뢰는 꼬리 길이를 제한한다. 다른 레인의 지뢰는 독립된 LN을 막지 않는다. 원본 LN·노트·키음·지뢰와 기존 seed·음악적 길이 선택을 보존하며, 지뢰가 없는 차트는 v2와 같은 결과를 낸다.

새 LN Mix 플레이는 기존 `long_note_mix_version` 필드에 **3**을 기록한다. 과거 v1/v2는 당시 배치를 재현하고 다른 버전 고스트는 새 플레이의 배치를 바꾸지 못한다. **v3 리플레이는 1.9.9.1 검증기가 필요하며 1.9.9 검증기는 거부한다.** 리플레이 필드·판정 ruleset ID·peer v7은 바꾸지 않는다. 해제 판정·고정 타이밍·점수·게이지·콤보·등급과 기존 NK2 E 동작을 유지한다.

LN Mix v2/v3는 계속 로컬 기록·리플레이 전용이며 기존 BEST와 Sites 제출에서 제외한다. Guest·커스텀 제외와 `client_submitted` 경계, 기존 16K 제출 지원을 유지한다. 웹·DB·스킨 에디터 배포나 기존 설치 덮어쓰기는 포함하지 않는다.

[2026-10-24 후보 기록](ultrawide-ln-20261024.ko.md)은 개발 당시 이력이다. 후보 검증과 새 릴리스 검증을 분리하며 [릴리스 게이트](release-1.9.9.1-gate.md)에 절차와 상태를 기록한다. 자동 화면·입력 처리 검사는 실제 21:9 모니터, 물리 입력·IME·청취, 장시간 플레이, 다른 PC와 모든 외부 스킨의 검증을 뜻하지 않는다.

동봉 오프라인 스킨 에디터 카탈로그는 배경 처리 함수 변경에 맞춰 소스 참조 위치를 동기화하며 편집 항목 ID·값을 유지한다. 공개 웹 스킨 에디터 배포는 포함하지 않는다.
