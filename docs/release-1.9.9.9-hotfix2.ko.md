# TenRiff 1.9.9.9-hotfix2 — 8K·10K NK2 E+ 프리셋

옵션 > 모드에서 키 모드를 **8K 또는 10K**, 변환 알고리즘을 **NK2**로 고른 뒤 프리셋에서 **E+ - Full-field + taps**를 선택하세요. 기존 E 다음에 나타납니다. 다른 키 모드로 바꾸면 E로 돌아갑니다. 같은 키 수의 곡에도 E+ 재배치를 적용합니다.

KeyWeaver 1.4.0의 E+를 별도 엔진으로 이식했습니다. 전체 레인을 활용하고 남아 있는 원본 노트 시점에 탭을 추가합니다. 원본 샘플 시점·LN 의미·키음을 보존하고 추가 노트에는 키음을 복제하지 않습니다. 원본 키음이 빠지는 경우 기존 자동재생 큐로 보존합니다. 안전 검사 실패 시 원본 패턴을 유지합니다. 기존 E 및 Native/Transform/Remaster와 기본 설정은 그대로입니다.

저장 식별자 `fullfield_taps_eplus_v1`로 리플레이·BEST·고스트·온라인 제출의 변환 종류를 구분합니다. 기존 R13/R14 규칙과 파일 형식은 유지합니다. 이 프리셋을 모르는 이전 클라이언트에서 E+ 리플레이를 재생하지 마세요. 변환 완성도와 실제 연주감은 모든 곡에서 보장되지 않습니다.

hotfix1의 OGG 보안 수정과 범용 BGA를 포함합니다. 고정 기준선은 **1.9.6**입니다. Windows ZIP을 새 폴더에 풀고 `launch_win.bat`으로 실행하세요. 기존 설치·프로필·기록을 보존하세요. 이번 변경은 클라이언트 릴리스이며 웹/DB를 재배포하지 않습니다.
