# インジケーター・出力・プロファイルキー

2026-10-17、ユーザー指定1.9.3 (`bf544e17f22879011a04a7fd157e40b57f6598bb`)に続く変更で、1.9.4に含まれます。固定基準1.9.0・公開物・既存インストールを保持します。

- BMS小節線をノート中心から下端へ移動し、設定・取込スキンの高さを反映します。プレイヤー・ゴーストとも同拍のノート直下に表示し、小節時刻・STOP/BPM・判定は変更しません。

- スキン設定で点（既定）/縦線バーコードを選択。常時表示は最初から目盛りと中央線を表示し、各判定マーカーは0.7秒で消えます。FAST/SLOW文字の保持、判定・点数・リプレイは維持。ゴースト・プレビューにも反映し、一時停止中は表示時間も停止します。
- サウンド出力で有効なWASAPI機器またはシステム既定を選択。更新キー（既定F5）で一覧更新、戻るで保存・適用。ASIOは専用ドライバー選択を維持。失われた機器は保存したまま自動代替せず、再接続または既定への切替で復帰します。 出力指定はプレイ・BMS試聴に適用します。TenRiff内蔵メニュー・結果音楽は別MCI経路でWindows既定出力を使用します。
- プロファイルで旧F1～F11の機能を変更・Deleteで解除できます。ヘルプ/判定線、更新/半速、プレビュー/倍速など各キーの全場面に同じ設定が適用され、案内も更新されます。重複・再開始・レーン・予約操作キーとの衝突は拒否します。
- 旧-10/+10（既定F5/F6）はノート速度×0.5/×2へ変更。0.5～50の範囲で押下ごとに1回、長押し・重複押下で累乗しません。プレイ・カウントダウン・一時停止に対応。曲Rate、音声、判定時刻、F3/F4の±0.25は維持。

保存値は`skin.timing_marker_style=dot|barcode`、`audio.device_id`（空=既定）、`ui.function_keys`。F5/F6は既存`hispeed_decrease_key`/`hispeed_increase_key`も保存。プロファイル書出しにキーを含め、機器IDは除外し、取込み時は現在PCの出力を保持します。スキンプリセットは形状を保持。

検証結果は候補の`evidence/VERIFICATION.ko.md`。実機試聴・他PC・長時間・公開を確認したという意味ではありません。
