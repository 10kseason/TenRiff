# EX Score 전환

[한국어](ex-score.ko.md) | [English](ex-score.en.md) | [日本語](ex-score.ja.md) | [简体中文](ex-score.zh-CN.md)

표시 점수와 최고 기록·순위 비교 기준은 **EX Score = P-Great × 2 + Great**입니다. Good, Bad, Poor는 0점입니다. 실제 판정 이벤트 개수를 사용하며 롱노트의 머리·꼬리 판정은 기존 규칙을 따릅니다. 정확도·등급·게이지·판정 시간은 별개의 기존 지표로 유지합니다.

최고 클리어 램프와 최고 EX 기록은 독립적으로 보존합니다. 곡 화면의 점수·정확도·등급·판정 상세와 결과 열기는 최고 EX 기록을 사용하며, 낮은 클리어 등급에서 EX가 올라가도 기존 최고 램프를 낮추지 않습니다. 기록 탭은 선택한 개별 플레이의 정보를 표시합니다.

예전 정규화 점수와 5·3·1 상세점수는 새 점수로 사용하지 않습니다. 이전 리플레이의 검증·파일 호환을 위해 과거 필드와 계산은 보존합니다. 로컬 기록은 저장된 판정 개수로 EX Score를 계산하며 정보가 없으면 `--`로 표시하고 EX 최고 기록 비교에서 제외합니다. 기존 파일을 추정 값으로 덮어쓰지 않습니다.

웹 DB에는 nullable EX Score 및 판정 개수 열을 추가합니다. 판정 개수가 없는 과거 행은 보존하며 EX 순위에서 제외합니다. 같은 계정이 같은 리플레이와 메타데이터를 새 형식으로 다시 제출하면 아직 미산정인 그 행만 계산할 수 있습니다. 이는 서버 리플레이 검증을 뜻하지 않으며 웹 기록은 계속 `client_submitted`입니다. 서버는 판정수의 정수·범위·합계와 EX 산식을 검증합니다.

웹 제출은 `schema_version=2`, `score_version="ex-v1"`; 멀티플레이는 `protocol=2`, 같은 score_version을 사용합니다. 구버전은 업데이트가 필요합니다. 전환 전 방은 EX 방과 섞이지 않으며 기존 짧은 유효기간에 따라 정리됩니다. 기존 TCP 프로토콜과 리플레이 규칙은 재해석하지 않습니다.

클리어 그라데이션은 공통 시작선 x=800과 오른쪽 끝 x=1034를 유지합니다. 원본 전체를 짧은 행에 맞춰 가로로 길쭉하게 표시하고 런타임 채도를 1.2배 적용합니다. EX는 제공된 은하 PNG를 사용합니다. 원본 이미지와 기존 설치·프로필은 보존합니다.
