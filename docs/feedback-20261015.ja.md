# TenRiff 1.9.0.1 フィードバック修正 · 2026-10-15

1.9.0を基にした1.9.0.1の変更です。固定基準は1.9.0のまま、以前のインストール・プロフィール・譜面・公開資産を保持します。配布・公開の検証は[リリース検証範囲](release-1.9.0.1-gate.md)とバージョン別リリース記録を参照してください。

- 曲プレビューの最終音量に0.75を掛けます。音量変更・フォーカス復帰にも適用し、ゲーム中の音声とTenRiff独自音楽の倍率は維持します。
- プロフィールでHi-Speed -10/+10のキーを指定できます。既定F5/F6は半分/2倍から-10/+10へ変更。F3/F4の±0.25と範囲0.50–50.00は維持します。長押しは1回のみ。Enter/クリックで入力開始、Escで取消、Deleteで解除。レーン・再開・予約済み・別の操作キーとの競合を拒否します。`ui.hispeed_decrease_key` / `ui.hispeed_increase_key`はプロフィールと.trprofileに保存します。
- ファイル選択は親ウィンドウ付きモーダルに統一し、重複呼出しを拒否します。終了時に待機中の入力を破棄し、押したままのキーは一度離すまでメニューを操作しません。

## Xbox/XInputゲームパッド

WindowsのシステムXInput 1.4を使い、利用できなければ9.1.0を試します。追加DLLは同梱しません。XInputのシステム呼出しは専用ワーカースレッドで行い、キーボード収集を待たせないようにします。既存InputThreadが内部キューを受け取り、RawInput・Polling共通の入力キューへ渡します。ワーカーは入力の開始・終了に合わせて生成・終了し、常駐サービスはインストールしません。Keymapでボタンを押してレーンに、プロフィールで再試行・Hi-Speed操作に割り当てます。保存名は`PadUp`, `PadDown`, `PadLeft`, `PadRight`, `PadStart`, `PadBack`, `PadLS`, `PadRS`, `PadLB`, `PadRB`, `PadA`, `PadB`, `PadX`, `PadY`, `PadLT`, `PadRT`です。LS/RSはスティック押込みで、軸ではありません。LT/RTは30/255を超えると押下です。

最大4台の同じボタンを1つの論理入力として扱い、すべて離すと解除します。切断時にはそのパッドの押下を解除します。接続時・フォーカス復帰時に押したままのボタンは、一度離してから押し直します。未接続スロットは2秒ごとに確認します。メニューは方向パッドで移動、Aで選択、Bで戻ります。他の操作に未割当のStartはゲームの一時停止です。既存キーボード設定は維持し、スティック軸と振動は含みません。

実装・模擬入力の検証と、実際のXboxパッドの接続・ボタン・物理遅延の検証は別です。実機パッドと別PCは追加確認が必要です。

## DEATH_SENTENCEと互換性

対象譜面にはD1–D5地雷が32個あり、透明ノートの3x/4xチャンネルはありません。同じ位置のBPM 186とSTOP 48で、従来は格納順により直前のBPM 65,535.9999を使い、322.580645msの停止が0.915527msになっていました。48kHzでは後続が15,440サンプル早まり、2番レーンのノートと地雷の間隔が15.5625msでした。修正後は337.229167msとなります。

同位置のBPMをすべて適用してからSTOPを計算します。その位置のノート・音声時刻、原作の急変速と地雷は維持します。Rateは譜面・音声全体の時間を変え、Hi-Speedは表示倍率を変えます。[処理順序の仕様](https://bmson-spec.readthedocs.io/en/master/doc/index.html#order-of-processing)。

リプレイの`mode.bms_timing_version`と結果の`bms_timing_version`を任意項目として追加。省略/1は旧計算、2は修正計算、他の値は拒否します。形式3とR1–R6判定は維持し、影響のある新規プレイのみ2を保存。旧リプレイは当時の時間で再生・検証できます。時間の異なる旧ゴーストは併用せず、修正後初の検証済み記録からBESTを開始します。過去の記録は履歴に残します。

既存Webランキングは両時間を区別できないため、影響のあるv2記録はWeb対応までローカル保存と表示します。影響のない曲の登録は維持。Web/API/DBの配備は含みません。旧クライアントでv2の再生は非対応です。キャッシュ18で長さ・難易度を再計算し、原譜面と旧記録は書き換えません。

ビルド・テスト・実行結果と物理入力・可聴音・長時間プレイの未確認範囲は、バージョン別リリース記録と別の検証資料に記録します。途中段階の合格数は最終1.9.0.1検証の代わりにはなりません。
