# 音乐、切换与纪录反馈 · 2026-11-03 本地候选

基于已发布的1.9.9.8 hot fix 1，使用独立目录。保留旧发布、安装、配置与固定基准1.9.6，不上传或部署。

- 音频设置新增主菜单/通关/失败BGM、按钮点击、滑块拖动和文件拖入提示音独立选择器，支持MP3/OGG/WAV/FLAC。Enter/点击文件名打开，左右选择默认/无，取消保留原值。自选文件保留在外部，请勿移动。主菜单文件用于默认标题音乐模式。
- Main Menu 5改为Clear，Options使用原Main Menu 3音乐（保留Main Menu 3本身），候选排除Main Menu 4。旧文件保存在包外`original-assets`。选项界面播放替换后的Options.mp3。
- 生成的棱镜图在进入单人和歌曲加载时以30个时间帧/1秒显示。与加载并行，快速加载等待切换结束后才开始倒计时/音频时钟，慢加载不增加额外1秒。保留即时重开与对战同步，减少动态效果时使用静态图。
- NEW RECORD仅在兼容最高分至少提高1分时显示，同时播放1.2秒数字扰动。首次与0分比较；仅通关等级提升不触发。正式BEST仍先比较通关等级，同等级再比较分数。独立最高分/评级从旧历史重建，无文件迁移。
- 评级提升时旧字逐渐变亮并碎裂，再显示柔和发光的新评级，支持跳过与减少动态效果。
- 等级内歌曲列表也能用左右键返回等级文件夹，保留快捷设置/纪录列表左右操作。
- Gauge Shift结果图采用EASY 0%到EX 100%的固定四段坐标；EX 0%与HARD 100%处于同一高度，补充不再看似回血。实际血条与原始记录不变。
- 皮肤HUD新增默认关闭的分数比较器及X/Y位置保存。BEST显示与兼容回放同一歌曲时刻的有符号分差，不可用为`--`。S/S+/S++/S+++显示与准确率95/97/98/99%的差(%p)。总分和评级采用不同权重，因此不将9500分视为S保证。辅助/自动/回放及不兼容条件排除。

短提示音使用既有Windows系统输出并遵守主音量/失焦静音；音乐仍使用选定WASAPI/ASIO设备。自选效果音异步解码并限制时长。检查见候选上级`evidence/VERIFICATION.ko.md`。真实听音/输入、任意文件/皮肤、长时间和其他PC需要另行验证。
