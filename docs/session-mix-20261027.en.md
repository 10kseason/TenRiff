# Session Mix course browser · local follow-up, 2026-10-27

The former settings-row screen now has course actions, a course list, and ordered stages. It reuses Song Select backgrounds and uniform scaling, with dedicated course geometry that does not reinterpret saved song-list skin coordinates.

Import a `.lr2crs`, select a course with a click, arrows or wheel, review its stages, then press Enter, double-click or choose Enter course. PgUp/PgDn moves seven items; Tab cycles courses, actions and stages. Previous/Next buttons page long stage lists. All authored MD5s must match the current indexed library; ordinary song-view filters do not hide imported stages. Missing stages are shown at their original positions. Order and repeated stages are preserved without substitutions. Every chart file is checked before entry. The existing continuous gauge and Enter-to-next-stage result flow remain; completion, failure and Escape at results return to the course browser.

Auto Mix starts the exact previewed list. Remix, a length/library change or re-entry regenerates it. It uses the current filter and selects at most one chart per shared audio path, falling back to folder/title. This is a heuristic, not perfect duplicate detection; authored courses and drafts keep repeats. Reliable 80–100% clears anchor a gradual warm-up/challenge/cooldown route, with overshoot penalties; without records the lower difficulty quartile is used. Seeds diversify comparable candidates. The 15/30/60-minute choices still estimate three minutes per chart (5/10/20 charts), not measured duration. Rule tests do not establish enjoyment or skill gains.

Includes the preceding F1 decrease/F2 increase defaults and accelerated holds. Saved bindings, judgement, grades, replay, course gauge and web-upload boundaries remain. No LR2CRS format, public version or fixed 1.9.6 baseline change. Earlier releases/candidates/installations/profiles are preserved; the local launcher uses a separate session-mix-local profile. See the candidate's evidence/VERIFICATION.ko.md for checks and limitations. Physical input, listening, long courses and arbitrary user imports remain unverified.
