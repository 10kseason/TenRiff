# 本地界面与搜索改进候选

这是基于1.9.5.2的未发布候选。可执行文件版本和固定基线1.9.0不变，保留以前的发布、安装与配置。

- 新配置：音符及轨道60%、按键光束最大高度50%、5K白/蓝/白/蓝/白。保留明确保存的值和各键模式设置，范围仍为10–140%。
- 默认F1速度+0.25、F2速度−0.25，F3判定线上移1%、F4下移1%；保留旧绑定，F5/F6仍为×0.5/×2。共用动作槽对应的菜单操作和提示也遵循绑定。
- 皮肤全屏预览用物理F6开启，F6或Esc关闭，独立于重新绑定，长按不会重复切换。
- 皮肤设置的保存操作生成新的.trskin，并可通过导入恢复。沿用原有格式和外部资源，现有文件另存新名，不覆盖。网页skin.json/ZIP和游戏.trskin是不同格式。
- 搜索中长按Backspace按完整UTF-8字符连续删除，空搜索框仍保持编辑。返回使用Esc，Backspace不再返回。
- 难度表声明的全部等级以数字升序文件夹显示，未持有等级显示0首。Enter/双击只打开该等级曲目，Esc返回。搜索会解除当前等级，搜索所选表的全部曲目。
- `Lv:16`只匹配16，`Lv:16+`只匹配16+，+不再表示下限。区间使用`lv:16to20`，上限使用`lv:20-`。普通文本仅搜索曲名和艺术家，不搜索路径、流派或表名。
- 所有音符和LN结束后，仅Enter跳过剩余音频。轨道键和Esc不跳过通关后奏。保留自然结束、对战/组曲限制和演奏中Esc暂停。
- 网页/离线编辑器同步当前模式、5K颜色、光束高度、简单矩形、350ms FAST/SLOW和700ms标记。预览轨道范围10–140%，默认60%，不写入JSON。Studio HUD、判定线类型、点/条码在游戏配置中调整。浏览器预览仅供外观参考。

沿用原配置与预设格式，将等级选择与曲目选择分开以保留空等级。不改变判定、分数、血条、回放、Guest排除、固定等级、client_submitted和不附带BGA模型政策。

验证记录见候选目录evidence/VERIFICATION.ko.md。网页经用户批准已部署为Sites版本8。游戏公开发布仍需单独批准。物理输入、实际听音、长时间运行、其他电脑和任意外部皮肤尚未验证。
