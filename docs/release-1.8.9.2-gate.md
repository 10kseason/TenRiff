# TenRiff 1.8.9.2: 중복 롱노트 시작점 보정

1.8.9.1의 UI·키 설정·키음/롱노트 변환 수정을 유지하고, BMS에 일반 노트와 롱노트 시작점이 같은 위치에 중복 기록된 경우를 게임 내에서 보정한다. 고정 기준선은 1.8.7이다. 공개 상태와 자산은 [1.8.9.2 릴리스](https://github.com/10kseason/TenRiff/releases/tag/1.8.9.2)를 따른다.

## 원인과 동작

보고된 DELTA 차트는 42마디부터 일반 노트 채널 `11`과 롱노트 채널 `51`에 같은 시작점을 함께 기록한다. 다른 레인에서도 같은 형태가 나타나며 전체 차트에 35개가 있다. 기존 로더는 이를 일반 노트와 롱노트 두 개로 전달했다. Native에서는 한 레인에 겹쳐 판정되고, 키 수 변환에서는 두 개의 독립적인 노트로 재배치될 수 있었다.

새 플레이 준비 단계에서는 같은 레인·같은 샘플 시각에 있는 일반 노트와 유효한 롱노트 시작점을 롱노트 하나로 합친다. 완전한 롱노트의 시작/끝, release 판정 속성, 원본 ID를 유지한다. 다른 레인의 동시 노트, 롱노트 내부/끝의 일반 노트, 가까워도 시각이 다른 노트는 이 보정으로 지우지 않는다. 원본 BMS와 음원 파일은 수정하지 않는다.

중복 시작점의 같은 키음은 한 번만 유지한다. 서로 다른 키음은 롱노트 헤드에 합치며, 헤드 음원 슬롯을 초과하거나 음량이 다른 키음은 원래 시각/음량의 배경음으로 보존한다. 보정은 키 수 변경이나 랜덤 배치보다 먼저 실행되므로 Native와 각 변환 경로가 같은 원본 보정을 사용한다.

## 리플레이 호환성

기존 선택적 `key_conversion_version` 필드를 사용하며 새 필드나 리플레이 포맷 번호를 추가하지 않는다.

| 값 | 동작 |
|---|---|
| 생략/1 | 기존 변환 배치와 중복 시작점 유지 |
| 2 | 1.8.9.1의 LN·키음 보존 변환, 중복 시작점 유지 |
| 3 | 1.8.9.1 변환에 BMS 중복 LN 시작점 보정 추가; 새 플레이 기본값 |

구 리플레이는 당시 배치와 점수로 재생·검증한다. 새 버전 3 리플레이에는 1.8.9.2 이상이 필요하다. 구 고스트 때문에 중복 LN 보정이 필요한 새 플레이가 구 배치로 돌아가지 않도록 해당 고스트 비교를 제외한다. 정상 차트의 기존 고스트 호환 방식은 유지한다. R1–R4 판정 시간과 점수 공식은 변경하지 않는다.

## 검증 기준과 한계

합성 중복 채널 fixture와 제공 차트에서 수정 전 실패를 재현하고, 수정 후 Native의 중복 제거 및 LN 구간/키음 보존, 변환 경로, 구/신 리플레이/결과 직렬화·검증을 확인한다. 제공 파일은 로컬 환경 변수로만 테스트하며 배포 소스에 넣지 않는다. Release/독립 소스 빌드·전체 테스트, 실제 세션 smoke, 패키지 CRC·해시 및 CI/공개 다운로드는 릴리스 증거에 별도로 기록한다.

로컬 Release 빌드와 CTest 3/3(1,121개, 통합 검사 생략 0), 에디터 34/34가 통과했다. 제공 DELTA의 Native 검사에서는 2,572개가 2,537개로 줄고 중복 시작점 35개가 모두 제거됐으며 LN 44개의 시작/끝은 유지됐다. 전 변환기 18개 조합 및 키음 슬롯 초과/다른 음량 보존은 별도의 합성 차트 검사다. 제공 DELTA 전체 변환 행렬이나 실제 음원 청음 결과로 확대해 해석하지 않는다.

실제 앱/세션 smoke는 같은 바이너리 재실행에서 206/206을 통과했다. 첫 실행의 기존 키 설정/카운트다운 검사 9개 실패는 로그를 보존하며 원인을 확정하지 않았다. 신규 DELTA 단일 입력·저장·리플레이 및 영향 차트의 구 고스트 제외는 두 실행 모두 통과했다. 중복 fixture의 호환 버전 1/2 리플레이는 기존 1.8.9.1과 새 검증기에서 동일한 결과로 검증됐다. 정상 차트의 구 고스트 허용 분기는 이번 세션 검사에서 별도로 반복하지 않았다.

물리 키보드·실제 곡 청음·장시간 플레이·다른 PC·실제 온라인 제출은 별도 검증 범위다. 이 변경은 웹사이트 배포나 성능 개선을 포함하지 않는다. 과거 릴리스의 검사 수치를 이번 버전의 검증으로 재사용하지 않는다.
