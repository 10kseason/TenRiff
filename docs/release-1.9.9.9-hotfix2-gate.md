# 1.9.9.9-hotfix2 validation

Acceptance requires Windows x64 Release CTest 4/4 (1,511 unit cases, zero integration skips), the unchanged Windows ASan preset CTest 3/3 (1,495 cases and its 16 existing integration exclusions), all eight focused E+ cases, native menu smoke 664/664, editor 38/38 and native catalog parity. The tests cover 1/4/7/8/10/14/18-lane sources, both target modes, same-key remix, grouped fields, 7+1/14+2 scratch extraction, exact sample/audio/LN preservation, deterministic output, unsupported/unsafe rejection, profile persistence, R13/R14 replay verification and separate submitted identities. Synthetic tests do not establish physical play quality.

Native fixtures cover actual GameSession E+ 8K/10K ghost compatibility with fresh seeds for OFF/Mirror and rejection for seed-dependent S-Random. Mode-screen captures use the actual settings builder and renderer in four languages, small-window and large-font cases. The offline released v24 server contract checks the four emitted 8K/10K R13/R14 payloads and separation from existing E/Remaster boards; this is not a production account upload or live server write.

Publication gates also require independent source-ZIP compilation/CTest/native/editor, exact source Git blobs, ZIP CRC and every-file hashes, default/privacy/license checks, both PR/main CI jobs, and fresh draft/anonymous-public three-asset readbacks. Existing releases/tags/assets and the preceding source are compared before/after. Shipped checksums identify the exact artifacts.

The new engine is KeyWeaver 1.4.0 commit `fb15fb2e44c3c14450e36877d4df96a865bb5553`, adapted only for isolated namespaces/include paths and line endings. File hashes and the MIT license are preserved. Historical NK2/E, default configuration, OGG parser/wrapper, audio timing and judgement implementation remain unchanged. E+ has the stable preset identity `fullfield_taps_eplus_v1`; R13/R14 rules, replay format and fixed baseline 1.9.6 remain.

Limits: phrase spacing and the added-tap repeat guard use TenRiff's representative base BPM, as in its E adapter; no full BPM-change map crosses this boundary. Exact KeyWeaver output equivalence for every variable-BPM chart is not claimed. Sub-millisecond holds that collapse to zero upstream and unsafe outputs retain the source chart. Older clients lacking E+ must not replay E+ records. Physical input/listening/long play, arbitrary charts/skins, other PCs, actual two-PC sessions and real-account uploads remain unverified. No website/database deployment or installation/profile overwrite.

During development, the first import build exposed leftover NK2 include paths, which were localized. A new scratch fixture incorrectly assumed identities removed before conversion were globally reserved; it was corrected to check retained keys, exact scratch autoplay sound times and absence of playable scratch heads. The visual helper's new flag hit MSVC's existing conditional nesting limit and was moved to its early-dispatch section. A sandbox ASan build returned C1902 PDB errors; the unchanged preset was rebuilt with normal host permissions. The first full native run failed one existing filter keyboard-adjustment check while ASan was active; a fresh isolated run of the same binary passed all 664 checks. The initial cause is unconfirmed. Initial failures remain in local evidence; they are not counted as passing checks.
