# TenRiff 1.8.8

결과 분석, 자유 해상도, 긴 LN Mix와 화면·입력·키음 보완을 묶은 릴리스입니다. [배포 파일과 최종 공개 기록](https://github.com/10kseason/TenRiff/releases/tag/1.8.8)을 확인하세요. 사용자 고정 기준은 계속 [1.8.7](baseline-1.8.7.md)이며 기존 태그·배포 파일을 교체하지 않습니다. 새 ZIP은 별도 폴더에 풀고 프로필 가져오기로 설정을 옮길 수 있습니다.

## 바뀐 동작

- 레인별 FAST/SLOW 분포, 시간대별 정확도, 단노트와 LN 시작·해제·유지 실패를 구분합니다. 평균·절대 오차·표본 표준편차·표본 수를 함께 보여주며 측정할 수 없는 미스와 자동 완료는 0ms 표본으로 넣지 않습니다. 판정과 점수 규칙은 유지합니다.
- 창 크기를 자유롭게 바꾸고 그래픽 설정에서 가로·세로를 직접 입력합니다. 결과 하단에 `F9` PNG 저장 위치를 안내합니다.
- LN Mix에 여러 박 길이의 롱노트와 다른 레인의 단타·짧은 롱노트를 섞습니다. 기존 리플레이는 이전 변환을 사용합니다. 새 v2 기록은 로컬 이력·리플레이로만 보관하고 기존 BEST와 Sites 제출에서 제외합니다.
- Studio HUD 글자를 키우고 결과의 판정·정확도·FAST/SLOW를 색 있는 글자로 표시합니다. 게이지 이력은 낮을수록 빨강, 높을수록 초록입니다. 결과와 선곡 등급은 커진 글자와 캐시된 두 단계 Gaussian bloom을 사용합니다.
- 스킨 설정의 `1`~`9`, `0`(10), `Shift+1`~`Shift+6`(11~16)으로 왼쪽부터 대상 레인을 선택합니다. 난이도표 URL에서 Backspace를 누르고 있으면 연속 삭제하며, 활성 표의 최소·최대 필터는 표에 표시된 숫자 레벨을 따릅니다.
- 줄인 키 수 때문에 사라진 키음은 원래 헤드 시각의 BGM으로 보완합니다. 이미 같은 시각의 플레이 노트나 BGM에 있는 소리는 중복 추가하지 않습니다.
- 프로필에 시작 카운트다운 생략(기본 끔)과 즉시 재시작 키(기본 미지정)를 추가합니다. 즉시 재시작은 곡 처음부터 다시 시작하며 기존 시도의 결과를 저장하지 않습니다. 로딩·기존 채보 앞 여백은 유지하고, 멀티·세션 믹스에서는 즉시 재시작을 차단합니다.

세부 동작과 제한: [분석·플러그인/1.9.0 계획](result-analysis-1.8.8.ko.md), [해상도·LN Mix](release-conditions-1.8.8.ko.md), [화면·입력·키음](release-feedback-1.8.8.ko.md), [시작·재시작](gameplay-start-controls.ko.md).

## 검증과 배포 기준

이전 로컬 분석 후보의 검사 횟수를 이번 릴리스 결과로 재사용하지 않습니다. 최종 빌드의 전체 CTest, 실제 MenuApp/GameSession 검사, 네이티브 렌더링·배칭·성능 비교, 에디터 검사와 독립적으로 추출한 소스의 빌드·CTest를 수행합니다. 공개 전에는 PR/main CI, ZIP CRC·파일 해시·개인정보 제외를 검사하고, 공개 후 세 배포 파일을 다시 다운로드해 로컬 해시와 비교합니다. 구체적인 실행 결과는 릴리스 노트에 기록합니다.

검증 도구는 합성 채보·임시 프로필·자체 창을 사용합니다. 키음 검사는 실제 WAV 디코딩과 production 스케줄러·믹서의 출력 PCM을 원본 정시 입력과 비교합니다. 레인 수 감소 이후에도 정시 입력 시 원래 구성의 소리가 유지되는지를 검사하며, 잘못 친 플레이 노트까지 자동으로 재생한다는 뜻은 아닙니다.

상세 작업 증거의 개발 작업 공간 경로는 `1.8.8-release/evidence/VERIFICATION.ko.md`입니다. 이 폴더는 공개 소스 ZIP에 포함하지 않습니다. 공개 검증 기록과 배포 파일은 위 릴리스 링크를 사용합니다.

## 남은 경계

물리 키보드·장치의 청감과 지연, 장시간 플레이, 다른 PC와 실제 온라인 대전은 자동 검사의 범위 밖입니다. 극단적인 해상도·스킨 배치나 아주 긴 제목은 글자가 작아질 수 있습니다. 공개 API/SDK·플러그인 실행 환경은 이번 버전에 구현하지 않으며 1.9.0 안정화와 함께 계획으로만 남깁니다. 기존 일본어 문구 일부의 영어 대체 표시와 선택적 외부 Python 참조 구현 비교의 한계도 유지됩니다.
