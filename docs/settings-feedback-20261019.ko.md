# 설정 UI·매 판 시드 후속 작업

2026-10-19 · [1.9.6](baseline-1.9.6.md)

- 키 설정에 공용 키와 기존 10개 키 배치 탭을 추가했다. 공용 키는 즉시 재시작과 11개 펑션 동작을 편집한다. 프로필과 같은 저장값·충돌 검사·즉시 저장을 사용한다. Tab으로 탭과 키 지정을 전환하고 좌우로 탭을 고른다.

- 스킨의 14개 모드 탭은 높이 52→60, 글자 18→24 디자인 픽셀로 확대했다. 검색 폭을 340→260으로 조정해 한 줄 배치를 유지한다. 키 모드 색은 곡 선택 로비의 같은 팔레트를 사용하며 7+1은 8키 색을 사용한다.

- 스킨 설정 FAST는 파랑, SLOW는 빨강이다. 기존 외곽선·문자 크기 조절·현지화·미리보기를 유지한다. 퍼센트로 표시하는 크기·위치·농도·밝기 항목의 최소 조작 단위는 1%다. px/ms 항목의 단위와 저장된 소수값은 자동 변환하지 않는다.

- 키 모드 설정 화면과 옵션 이름은 게임 모드 설정으로 바뀌었고 판정 범위의 기본 선택은 모든 언어에서 Normal로 표시한다. 판정 수치·R9/R10·점수·고정 등급은 그대로다.

- 새 싱글 플레이와 재시작은 OFF·미러·랜덤·스크래치 고정 랜덤·S랜덤·R랜덤 모두 새 시드를 생성한다. 수동 시드 조절은 읽기 전용 자동 표기로 대체했다. BMS RANDOM도 독립 시드를 사용한다. 시드가 달라도 우연히 같은 배치가 나올 수 있다.

- 리플레이는 저장된 시드로 재생·검증한다. 공유 차트를 사용하는 고스트는 시드가 배치에 영향을 주면 일치 검사를 유지하고, 원본 OFF/미러처럼 시드를 쓰지 않는 경로는 새 시드 때문에 거부하지 않는다. 랜덤 OFF를 강제하는 대전의 공유 설정·peer v7은 그대로다.

- 이 변경은 1.9.7에 포함된다. 기존 릴리스·설치본·프로필을 보존하며 일반 소스 기준선은 1.9.6이다. 물리 입력·청음·장시간 플레이·다른 PC 검증은 별도다.

- 텐리프 자체 배경음(타이틀·메뉴·결과)의 기준 이득을 10%에서 12.5%로 높여 감쇄를 약 1.94dB 줄였다. 저장된 마스터·메뉴 볼륨과 곡 미리듣기·플레이 음량은 유지한다.
