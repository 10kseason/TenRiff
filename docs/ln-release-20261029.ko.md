# 일반 롱노트 조기 해제 수정

일반 롱노트를 끝보다 GOOD 범위(최대 약115ms)만큼 일찍 떼어도 성공하던 동작을 수정합니다. 이제 **현재 PG 범위까지만** 조기 해제를 허용합니다. Normal은 BMS RANK에 따라10/15/19/22ms, Hard는19ms, EX는10ms입니다. 정확히 경계는 성공이며 바로 다음 이른 샘플은 즉시 BAD·콤보 단절·게이지 감소입니다. 끝까지 누르면 자동 PG이며 다시 눌러도 실패는 복구되지 않습니다.

CN처럼 해제 자체를 채점하는 노트는 기존 PG/GR/GD를 유지합니다. `No LN Release`로 일반 LN이 된 노트에는 새 정책이 적용됩니다. 코스 일반 LN의 유지 성공 경계도 PG에 맞추며, 이미 실패한 LN의 OD8 환산은 Miss로 기록해 올콤보/서든데스가 성공으로 간주하지 않게 합니다. 단노트·머리 판정창, 오디오와 입력 보정, 표시 위치는 그대로입니다.

새 실행은 R11/R12 및 custom11/12로 저장하며 리플레이 JSON 필드는 추가하지 않습니다. R1–R10과 이전 custom은 원래 유지/해제 정책으로 재생·검증하고 고스트도 자기 규칙을 사용합니다. BEST는 새 판정 세대를 구분하며 과거 기록 파일을 다시 쓰지 않습니다. 같은 패킷 구조의 peer v8은 v7 상대를 거부합니다. 공개 Sites는 R9/R10 계약을 유지하므로 새 R11/R12 제출은 로컬에서 제외하고, 별도 Ranked의 미지원 차단도 유지합니다. 서버나 웹 배포는 없습니다.

공개1.9.9.6을 계승한 **로컬 수정본**입니다. 버전·태그·일반 기준선1.9.6을 올리지 않으며 이전 설치/프로필/릴리즈를 보존합니다. 물리 키보드의 체감과 장시간 플레이는 별도 확인이 필요합니다.
