# TenRiff 1.9.8 — 스킨 X/Y 위치와 키 구분선 명도

2026-10-19

[한국어](release-1.9.8.ko.md) | [English](release-1.9.8.en.md) | [日本語](release-1.9.8.ja.md) | [简体中文](release-1.9.8.zh-CN.md)

판정·콤보·FAST/SLOW 인디케이터·FAST/SLOW 막대는 이제 스킨 설정에서 X와 Y를 각각 조절할 수 있습니다. 숨겨진 기존 X 설정을 다시 표시하므로 기본값 0과 이전 저장 좌표를 유지하며, X를 바꿔도 Y가 바뀌지 않습니다. 각 X는 −600~600px 범위에서 10px 단위로 조절하고 바로 다음 줄에 대응하는 Y를 표시합니다. Native/TenRiff/LR2에서 설정 검색과 키보드 좌우·마우스 −/+를 지원합니다.

키 구분선 명도는 0~100%에서 1% 단위로 조절합니다. 기본 100%는 기존 색상, 0%는 검정이며 RGB만 바꿉니다. 표시 여부·알파·너비·마디선은 그대로입니다. 선택적 `skin.lane_divider_brightness`는 `0..1`로 저장하고 기본값은 `1`입니다. 저장과 휴대용 스킨, 미리보기·Classic/Studio·고스트에 적용합니다.

기존 X 설정과 렌더링 경로를 재사용해 저장 좌표를 초기화하거나 마이그레이션하지 않습니다. 판정선은 레인에 붙어 있으므로 기존 필드 드래그로 가로 배치를 함께 옮깁니다. 고정 판정·점수·등급·입력·오디오·리플레이 계약, R9/R10과 과거 R1–R8, peer v7 및 Guest/client_submitted 경계를 유지합니다.

1.9.7의 공용 키와 충돌 검사, 커진 색상 탭, FAST 파랑/SLOW 빨강, 1% 조절, 게임 모드 설정·Normal 표기, 매 판/Retry 새 시드와 기록된 리플레이 시드, 배경음 기준 이득 12.5%도 그대로 포함합니다. 일반 고정 기준선은 1.9.6이며 이전 릴리스·후보·설치·프로필을 보존합니다. 웹사이트·데이터베이스·공개 스킨 편집기 변경은 이번 범위에 없습니다.

검증 절차는 완료 결과가 아닙니다. 실제 빌드·테스트·패키지·다운로드 검증은 릴리스 증거로 따로 기록하며, 물리 입력·IME·청음·장시간 플레이·다른 PC·임의 외부 스킨 검증은 별도입니다.
