# オーディオデバイス案内の修正

オーディオ出力を利用できずプレイの初期化に失敗すると、選曲画面の下部に黄色の案内を表示します。**オプション > オーディオ > サウンド出力デバイス**で接続済みのデバイスを選択し、再試行してください。ASIOの場合はインストール済みのドライバーを選択します。

従来のエラーは難易度表URLの編集画面内でしか描画されませんでした。常に見える下部の2行に案内を表示し、セッションの初期化が成功すると消去します。

音声なしのプレイ、自動デバイス切替、オーディオ処理・判定・スコア・リプレイの変更は含みません。保存済みのデバイス選択を維持します。

Included in 1.9.9.8 hot fix 1 (tag: 1.9.9.8-hotfix1). Fixed baseline: 1.9.6.
