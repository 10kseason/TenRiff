# 棱镜等级文字与EX配色（本地候选）

[한국어](rank-prism-20261028.ko.md) · [English](rank-prism-20261028.en.md) · [日本語](rank-prism-20261028.ja.md)

本地候选基于1.9.9.3，为S+、S++、S+++文字加入棱镜效果。Release构建、CTest 3/3（1,445项）、26个最终渲染场景和37项编辑器检查均通过。已发布版本与通用固定基线1.9.6保持不变。

- S+、S++、S+++文字使用EX棱镜渐变、光晕和增加立体感的切面光效。采用现有的字形位图缓存流程，不加载PNG。文字、字体、尺寸或设备变化时缓存效果，无需每帧执行模糊或色相动画。缓存创建失败时回退到原有文字绘制。
- 已制作的等级图片作为概念成果保留在源码之外，游戏不读取，也不随包发布。其他等级以及EZ/NM/HD、E/F的颜色保持不变。
- EX使用选定图片的青色→蓝色→淡紫→粉色→金色→薄荷绿→青色，通过静态sRGB RGB插值显示。此选择取代此前EX仅用金色系及排除紫色的要求。
- 按键叠加层仅移除难度估计显示，保留KPS和按键/音符查看器。谱面与选曲列表中的难度信息也保持不变。
