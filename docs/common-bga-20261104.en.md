# Common BGA

In Graphics Settings, select a local **Common BGA Video**, then enable **Common BGA**. It replaces both background layers for every chart with silent looping video. Pause/restart follows the existing visual clock.

Defaults are OFF and an empty path. Selecting a file does not enable the option; cancelling preserves the selection. BGA OFF takes priority. An empty selection uses chart BGA; a missing or undecodable selected video shows the default background. Changing the file or starting the next game retries it. Back saves the profile.

Existing brightness, playfield blocking and upscaler options apply. Song Select previews, menu/Result backgrounds, judgement, audio, replays and online records are unchanged.
