# スキン設定の改編（ローカル候補）

直前の1.9.5.2フィードバック候補の変更をすべて含む。公開版・既存インストール・プロフィールは変更しない。

- 対象レーンの行を廃止し、プレビューの番号ボタンで編集レーンを選択する。現在の設定行は維持され、色・幅・右側の間隔（最終レーンでは左側）を編集できる。数字キーと7+1のスクラッチ位置にも対応する。
- 単色、ノート枠線、画像比率、全体不透明度、枠線不透明度、レーン色濃度、16K中央間隔、境界線幅をスキン設定から隠す。既存の保存値は維持するが、境界線の実際の幅は100%固定。
- 新規設定のノート形状はシンプルな四角形、16K中央間隔は100%。保存済みの形状と間隔は維持する。
- 元画像ではなく設定後の実際のノート領域の幅と高さを比較する。1:1なら画像の比率を保って領域内に収め、長方形なら引き伸ばす。旧比率トークンは保存互換用に維持するが、プレイヤー・ゴースト・プレビューは自動規則を使う。
- UIフォントとフォントファイル選択はプロフィールの言語・文字サイズの次へ移動。同じ保存項目とTTF/OTF選択・検証を使い、直ちに保存する。
- 判定ライン位置は1～100%。既存の0%は読み込み時に1%へ制限する。ゲーム・プレビュー・スキン解析・エディターの範囲を統一した。

非表示化は保存値のリセットではない。保存済みの単色指定も維持する。判定時刻・スコア・リプレイ・音声処理は変更しない。Webエディターはユーザー承認後に[既存の公開URL](https://tenriff-skin-editor.lastestarcorp.chatgpt.site)へSitesバージョン8として配信した。ゲーム候補はローカルのまま。
