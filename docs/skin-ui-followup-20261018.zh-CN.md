# 窗口模式拖放与皮肤设置更新

2026-10-18更新已纳入1.9.6。保留此前本地候选、已发布1.9.5.3、安装目录及原有配置。当前发布状态参见[发布说明](release-1.9.6.zh-CN.md)。

- 切换到窗口模式时保留文件拖放标志。现有 BMS 文件/文件夹处理及文件对话框生命周期保持不变。
- 在皮肤设置上方用一行横向标签显示支持的键位模式，末尾提供搜索框。搜索当前来源可见的设置，保留按模式保存的方式。
- 点击标签或按 Ctrl+Tab / Ctrl+Shift+Tab 切换模式。Ctrl+F 聚焦搜索，Tab / Shift+Tab 在标签、搜索框和设置列表之间移动。按当前语言的名称、值和分类搜索。
- 隐藏轨道边界线、判定 X、连击 X、FAST/SLOW X 和指示器 X 控件，不删除或重置保存值。 [后续策略：取代隐藏四个X控件的规定](skin-xy-20261019.zh-CN.md).
- 新建皮肤、打开皮肤文件夹和重新加载仅在 TenRiff 来源显示；导入皮肤选择仅在 TenRiff 或 LR2 来源显示。
- 保留 Original 模式的刮盘位置显示条件及隐藏的分隔线宽度 100% 策略。
- 专辑图片的默认判定难度标签从 288×36 缩小为 192×28 设计像素。皮肤明确指定的矩形仍优先。
- 连击文字与判定计数重叠时，移到场地内可容纳的最近一侧，允许越过指示器上方，不再始终向下推。Classic/Studio 和玩家/幽灵共用该规则，不修改保存位置。

保留[固定判定策略](judgement-baseline-20261018.zh-CN.md)、R1–R8录像兼容及对战协议7。1.9.6配合对应Sites支持，允许标准设置的新Online R9/R10提交，旧榜单仅供读取。通用源码基线1.9.0不变。

最终验证记录在1.9.6发布目录的 `evidence/VERIFICATION.ko.md`。此前候选的 `evidence-ui-20261018/VERIFICATION.ko.md` 作为历史证据保留。自动HWND消息及渲染截图与人工Explorer拖放、实际IME/输入及长时间游玩分开报告。
