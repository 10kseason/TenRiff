# 1.9.0 릴리스: 음량·로비·필터·스킨 조작

1.8.9.7 이후 검토한 로컬 후보의 기능을 1.9.0으로 배포한다. 2026-10-14 사용자 요청으로 고정 기준선도 1.9.0으로 올리며 기존 릴리스는 보존한다. [기준선](baseline-1.9.0.md)과 [릴리스 검증](release-1.9.0-gate.md)을 함께 따른다.

## 음량

- 오디오 설정 맨 위에서 마스터, **BMS 인게임 볼륨**, **텐리프 메뉴 배경음 볼륨**을 각각 조절한다.
- BMS 볼륨은 반주와 키음을 함께 조절한다. 기본 100%에서는 기존 곡 믹스를 유지하고, 기존 BMS 반주·키음 세부 볼륨도 보존한다. 곡 미리듣기·BMS 타이틀 재생·편집기 미리듣기는 BMS 볼륨을 따른다.
- 텐리프 자체 메뉴·결과 음악은 별도 볼륨을 따른다. 100%의 기준 출력은 원음의 0.1배다. 1.8.9.7의 0.4배보다 75% 낮아진다. Windows 볼륨 곡선과 청감이 동일하다는 의미는 아니다.
- 게임 내 UI 조작 효과음은 BMS 볼륨으로 줄이지 않는다. 마스터와 창 비활성화 음소거는 기존처럼 전체 출력에 적용한다.

## 로비와 필터

- 플레이를 **싱글 플레이**로 바꾸고 화살표와 멀티플레이 아이콘을 키운다. 옵션·종료는 멀티플레이 바로 아래 같은 줄에 놓는다. 기존 아이콘 색 테두리와 은은한 glow를 유지한다.
- 난이도 최소·최대를 **난이도 범위** 한 줄에서 조절한다. 각 끝점의 −/+를 클릭하거나 Enter로 끝점을 고르고 좌우 키로 조절한다. 저장되는 두 값과 기존 필터는 유지한다.
- 정렬 값 클릭·Enter가 무동작하던 경로를 고친다. 레벨 그룹의 내림차순에서도 난이도 미상 곡은 마지막에 둔다. 그룹 사용 시 정렬은 그룹 안에서 적용한다.
- 곡 선택 창의 내 최고 기록 랭크를 약 2배로 확대한다. 같은 랭크 글꼴·색·glow를 유지하며 아래 점수·정확도·콤보 영역을 보존하도록 재킷과 기록 카드 경계를 조정한다. 스킨이 해당 영역/폰트 크기를 명시한 경우 그 값을 존중한다.

## 스킨과 기본값

- FAST/SLOW 글자와 타이밍 막대 크기를 각각 50–200%로 조절한다. 기존 판정 글자·콤보 크기와 독립적이다.
- 노트 모양에 **사각형(심플)**을 추가한다. 기존 사각형은 유지하며, 심플 모양은 장식 없는 평면 직사각형이다. 가져온 노트 이미지와 스킨의 명시적 이미지 우선순위는 유지한다.
- UI 폰트에서 로컬 TTF/OTF 파일을 선택할 수 있다. 시스템에 설치하지 않고 게임 창이 가진 폰트 컬렉션으로 적용한다. 파일이 없거나 유효하지 않으면 기본 폰트로 표시한다. 고정 숫자 표시용 폰트와 스킨이 명시한 폰트 우선순위는 유지한다. 공유용 스킨/프로필 프리셋에는 사용자 폰트 파일·로컬 경로를 넣지 않는다.
- 새 설정 및 해당 키가 없는 프로필은 게이지 시프트 시작 **EX**, 인덱싱 **빠름(최소)**, 고스트 배틀 **끔**을 사용한다. 기존 저장값은 덮어쓰지 않는다. 게이지 계산·판정·리플레이 형식은 바꾸지 않는다.

## 결과·등급·웹 기록 후속 수정

- 결과와 최고 기록 숫자의 천 단위 콤마를 제거한다. 곡명, 작곡가, `obj: 패터너` 순서로 표시하며 실제 메타데이터가 없는 패터너는 추정하지 않는다.
- BMS `#SUBARTIST`의 일반 크레딧은 작곡가 옆에 함께 표시한다. ARTIST/SUBARTIST에 명시된 `obj:`는 중복 없이 패터너 줄로 분리한다. 원본 BMS와 차트 해시는 바꾸지 않으며, 기존 캐시에 서브아티스트 원문이 없으므로 메타데이터 캐시 v17에서 한 번 다시 읽는다.
- 결과 곡 카드 하단은 BPM과 LV 두 항목으로 정리한다. 변속 곡은 `BPM!`, 레벨은 곡 목록과 같은 난이도표 표기·보라색을 사용한다. Aery 5K 기본 표의 `⑤`만 5K 민트색이며 다른 표에는 적용하지 않는다.
- 등급은 일반 정확도 기준으로 S++ 99%, S+ 98%, S 95%, A+ 93%, A 90%, B 85%, C 80%, D 그 미만의 생존 완주다. 75% 미만 완주도 D다. 사망은 F, 구분 가능한 중단은 `--`, 자동연주는 AUTO다. 기존 결과 파일을 다시 쓰지 않는다. [등급 표시 계약](grade-display.ko.md).
- 웹 업로드 응답 실패를 연결 키 오류로 일괄 처리하지 않고 HTTP 상태에 따른 고정 안내로 구분한다. 원격 응답 본문에 포함될 수 있는 비밀 정보는 출력하지 않는다. 원래 점수 제출 가능 조건과 과거 기록 재전송 정책은 유지한다.
- 결과 하단과 F10 연결 설정에 전송 대기·완료·실패 안내를 표시한다. 이전 곡의 늦은 응답은 현재 곡의 상태를 덮어쓰지 않는다. 기존 누락 기록을 자동으로 다시 제출하지 않는다.

## 검증 범위

- 판정 범위를 상위 키 모드 설정으로 옮기고 기본/Hard/EX를 제공한다. Easy는 새 선택지에서 제외하되 과거 리플레이는 유지한다. [EX 수치와 기록 호환](judge-ex-1.9.0.ko.md).

최종 검증 수치와 패키지 해시는 작업본의 `evidence/VERIFICATION.ko.md`에 기록한다. 실제 소리 청감, 물리 입력 지연, 다른 PC 및 장시간 플레이는 별도 사용자 확인 항목이다. GameSession 구조 분리는 이번 변경에 포함하지 않는다.
