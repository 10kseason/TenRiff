# 시작 카운트다운과 즉시 재시작 (1.8.8)

옵션 → 프로필 설정에서 두 항목을 설정합니다. 기존 프로필은 **시작 카운트다운 생략 끔**, **즉시 재시작 키 미지정**으로 기존 동작을 유지합니다. 변경은 현재 프로필과 전체 설정 내보내기 파일(`.trprofile`)에 저장됩니다.

| 항목 | 동작 |
| --- | --- |
| 시작 카운트다운 생략 | 단독 플레이의 초기 `3 / 2 / 1` 표시를 생략합니다. 일반 곡 시작, 일시정지 메뉴의 재시작, 결과 화면의 재시도에 적용됩니다. |
| 즉시 재시작 키 | Enter를 눌러 사용하지 않는 키 하나를 지정합니다. Esc로 취소하고 Delete로 해제합니다. 진행 중인 단독 곡을 처음부터 다시 불러오며, 새 시도의 초기 카운트다운은 설정과 관계없이 생략합니다. |

**생략하는 것은 로딩 뒤의 `3 / 2 / 1` 표시입니다.** 오디오 준비 시간과 채보의 기존 시작 여백은 유지합니다. 판정 시각, 보정값, 리플레이의 샘플 기준은 바뀌지 않으며 첫 노트를 건너뛰지 않습니다. 즉시 재시작 시 진행 중이던 시도는 결과나 리플레이 파일로 저장하지 않습니다. 새 시도에서는 점수, 입력 상태, 오디오, 리플레이·고스트 위치를 초기화합니다.

편집기의 구간 연습 중에도 즉시 재시작은 곡 처음으로 돌아갑니다. 일반 일시정지 메뉴의 재시작은 선택한 연습 시작 지점을 유지합니다.

일시정지에서 **계속하기**는 설정과 관계없이 기존 3초 재개 카운트다운을 유지합니다. 즉시 재시작 키는 일시정지·시작 카운트다운 중에는 작동하지 않습니다. 키를 누른 채로 새 시도가 시작되어도 반복 재시작하지 않으며, 키를 떼었다가 다시 눌러야 합니다.

멀티플레이는 시작 동기화를 위해 초기 카운트다운을 유지하고 즉시 재시작을 차단합니다. 세션 믹스에서도 즉시 재시작은 차단합니다. 일반 일시정지 재시작과 결과 재시도는 기존 메뉴에 그대로 남아 있습니다.

레인에 지정된 기본·보조 키, 탐색·수정 키와 `F1`~`F11` 등 예약된 키는 지정할 수 없습니다. `F12` 같은 사용하지 않는 키를 사용할 수 있습니다. 이후 키맵 변경으로 충돌이 생기면 해당 차트에서는 즉시 재시작 키를 비활성화합니다. 채팅 등 입력 화면이 열려 있으면 그 화면이 먼저 키를 처리합니다.

내부 설정은 `ui.skip_start_countdown`(boolean), `ui.instant_restart_key`(키 이름 또는 빈 문자열)이며 프로필 버전, 리플레이 형식, 판정 규칙 버전은 바꾸지 않습니다.
