# 皮肤设置改版（本地候选版）

包含上一版1.9.5.2反馈候选版的全部修改，不修改公开版本、安装目录或玩家配置。

- 删除目标轨道行，点击预览编号按钮选择轨道。保留当前设置行，可编辑颜色、宽度及右侧间距（最后一轨使用左侧间距）。保留数字快捷键和7+1搓盘位置映射。
- 从皮肤设置隐藏单色、音符边框、图像比例、整体透明度、轮廓透明度、轨道颜色浓度、16K中央间距及分隔线宽度。保留旧保存值，实际分隔线宽度固定为100%。
- 新配置默认使用简洁矩形音符，16K中央间距默认100%。保留已保存的形状和间距。
- 自动图像比例依据设置后的实际音符区域宽高，而非原图尺寸。1:1区域保持图像比例并完整容纳；矩形区域拉伸。旧比例字段继续读写以保持兼容，但玩家、幽灵和预览使用自动规则。
- UI字体及字体文件选择移至个人配置的语言和文字大小之后，复用原保存字段和TTF/OTF文件验证，并立即保存。
- 判定线位置范围为1～100%，旧0%值在载入时限制为1%。统一游戏、预览、皮肤解析器及编辑器的范围。

隐藏控件不重置保存值，旧单色选择也继续生效。不修改判定时间、分数、回放或音频协议。网页编辑器经用户批准已部署至[原公开地址](https://tenriff-skin-editor.lastestarcorp.chatgpt.site)，Sites版本8。游戏候选仍保留在本地。
