# 选曲、记录和音频选择修复 · 2026-11-03

此本地候选继承UI布局候选。无封面时的TR改为所提供标志中的10/波形透明图案；真实曲图和自定义标志保留。文件夹显示曲目数（空文件夹为0），只隐藏选曲界面的输入后端说明。

文件夹列表右键打开、左键执行原有返回；级别内部左右均返回级别列表。结果中的长标题和相邻详细数值根据DirectWrite实测尺寸缩放，保留完整字符串、原字体和指标，并缓存布局。

MP3/OGG/WAV/FLAC选择器在单次请求的STA线程运行，避开菜单音乐调用线程的MTA冲突。取消不改变设置，错误可见，结束后释放模态输入。判定、计分、记录优先级、回放和槽计算不变。使用独立ui-fixes-local配置，保留旧候选和1.9.6基准。

使用暂停但仍有效的本地BEST也可用于实时比较。当前游玩暂停后不再永久禁用比较。回放按排除暂停时间的曲内采样比较，仅比较值变化也刷新HUD。在线提交规则不变。
