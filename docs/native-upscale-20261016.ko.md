# 원본 해상도에서 먼저 복원하는 BGA 업스케일

2026-10-16

1.9.1.1 출시 커밋 `ea8bdba`와 검증된 UI 후보의 후속 로컬 변경입니다. 고정 등급표·밝기·로딩·언어 설정과 1.9.1.1의 BMS·온라인·입력·볼륨 동작을 유지합니다.

**원본 이미지 → AI x2 복원·잔차 합성 → 표시 영역에 맞춰 크기 조절 → 필요하면 크롭** 순서로 처리합니다. 기존의 16:9 선행 크롭과 960×540 선행 변환을 제거했습니다. 640×480은 1280×960, 300×900은 600×1800으로 복원한 뒤 화면에 맞춥니다.

기존 고정 960×540 입력 / 1920×1080 잔차 출력 모델을 그대로 지원합니다. 원본 픽셀을 크기 변경 없이 넣고 작은 이미지는 가장자리를 반복해 채웁니다. 큰 이미지는 32픽셀 문맥이 겹치는 타일로 나누고, 원본 좌표에 맞춰 2배 결과를 합칩니다. 문맥·패딩 제거로 원본 내용을 잘라내지는 않습니다. 노트·HUD·BGA 밝기 처리 순서는 유지됩니다.

원본은 축당 최대 4096픽셀, 완성 이미지는 최대 8192픽셀입니다. 초과·모델 실패는 일반 배경 표시를 유지하며 AI 입력을 몰래 축소하지 않습니다. 정지 이미지에만 적용하고 영상 AI는 기존처럼 비활성입니다. 캐시는 인스턴스당 최대 3개/96MiB이며 새 이미지가 요청되면 타일 사이에서 이전 작업을 중단합니다.

큰 원본은 추론 횟수와 메모리가 늘어납니다. 32픽셀보다 넓거나 전역 문맥이 필요한 모델은 타일 경계에서 결과가 달라질 수 있습니다. 합성 테스트는 픽셀 처리·크기·알파·FP32/FP16 계약을 검증하며 학습 모델의 품질이나 실시간 FPS를 보증하지 않습니다.
