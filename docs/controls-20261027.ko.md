# 길게 누르기와 기본 속도 키

2026-10-27 · Local follow-up to 1.9.9.1; unpublished, no version bump. General fixed baseline remains 1.9.6.

- 새 기본값은 **F1 노트 속도 −0.25 / F2 +0.25**입니다. F3/F4 판정선 위/아래 1%, F5/F6 속도 ×0.5/×2, F7/F8 시각 레이턴시 −/+1ms는 유지합니다.
- 저장된 단축키(예전 기본값 포함)는 바꾸지 않습니다. 기존 프로필에서 새 방향을 원하면 **키 설정 > 공용 키** 또는 프로필의 해당 속도 감소/증가 키를 다시 지정하세요.
- 선곡 로비의 빠른 설정에서 속도·레이턴시를 선택하고 좌/우를 길게 누르거나, Rate의 −/+ 키를 길게 누르면 가속합니다. 플레이·시작 카운트다운·일시정지 화면의 속도·판정선·시각 레이턴시 키에도 적용합니다.
- 누른 즉시 한 단계 조절하고 기존 첫 반복 대기(로비 250ms, 인게임 180ms)를 유지합니다. 반복 간격은 45ms → 0.6초 이상 25ms → 1.5초 이상 15ms로 바뀝니다. 한 단계 조절량과 상·하한은 그대로입니다. 실제 반복 빈도는 메뉴/오디오 처리 주기에 따라 제한될 수 있습니다.
- 키 해제, 포커스 이탈, 로비 항목·화면 변경, 오버레이 진입, 일시정지 전환 및 재개 카운트다운에서 반복을 초기화합니다. 잠깐 멈췄다가 돌아온 처리 주기에는 누적 단계를 한꺼번에 적용하지 않습니다.
- 게이지/랜덤 선택과 목록 이동·글자 삭제는 기존 반복 속도를 유지합니다. 마우스 버튼 길게 누르기는 이번 범위에 포함하지 않습니다. ×0.5/×2는 누름당 한 번만 적용합니다.
- 판정·점수·리플레이 형식은 변경하지 않았습니다. **레이턴시는 기존 visual offset 조절**이며 입력 판정 오프셋을 바꾸지 않습니다.
