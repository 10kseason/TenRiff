# TenRiff 1.9.5.3 — スキン設定整理と検索・入力の改善

- スキン設定に**フィールド内判定数**（既定値オフ）を追加しました。PG / GR / G / BAD / PRの累計をインジケーター直下に表示し、その位置に追従してノート領域内に収めます。打鍵の間も表示し、プレイヤーとゴーストの集計は別々です。判定名と計算は変更しません。

- プレビューの番号ボタンで編集レーンを選択します。UIフォント、フォントファイル、ゲーム中カーソルはプロフィールで設定します。スクラッチ位置は実行時キーモードが「Original」の場合だけ表示し、7+1配置で調整できます。

- 新規既定値はノート・フィールド60%、キービーム最大高さ50%、5K白/青/白/青/白、シンプルな四角です。F1速度+0.25、F2−0.25、F3判定線を上へ1%、F4下へ1%。F5/F6の×0.5/×2は維持します。

- フィールド背面BGA遮蔽ON、LN終端表示OFF、LN本体幅・不透明度100%、レーン間隔0%、キーラベル下を既定として維持し、該当項目とLN終端縮小をスキン設定から非表示にしました。明示的な保存値は保持します。

- 対象レーン、単色、ノート枠、全体/枠の不透明度、レーン背景濃度、16K中央間隔、区切り線幅の行も削除しました。16K中央間隔の新規既定値は100%、実際の区切り線幅は100%固定です。判定線位置は1～100%です。

- 画像比率は設定後の実際のノート領域で判定し、1:1なら比率維持、それ以外は引き伸ばします。F6全画面スキンプレビューと.trskinプリセット保存を修正しました。

- Backspace長押しはUTF-8文字単位の連続削除となり、戻る操作にはなりません。通常検索は曲名・アーティストのみです。Lv:16とLv:16+は各レベルに完全一致します。

- 難易度表で定義された全レベルを数値順のフォルダーで表示し、空のレベルも残します。フォルダー内はそのレベルのみです。最後のノート/LN後の後奏はEnterのみでスキップします。

- 既存の設定・プリセット形式と入力動作を再利用し、保存値を保持します。判定・スコア・ゲージ・音声・リプレイ規則は変更しません。固定基準1.9.0、Guest除外、固定グレード、client_submitted、BGA重み非同梱を維持します。
