# Local UI and search feedback candidate

Unpublished follow-up to 1.9.5.2. The executable version and fixed baseline 1.9.0 remain unchanged; earlier releases, installations and profiles are preserved.

- Fresh profiles use 60% Note & Field Size, 50% maximum key-beam height and white/blue/white/blue/white for 5K. Explicit saved and per-mode values survive; the size range remains 10–140%.
- Default fine note-speed controls are F1 +0.25 / F2 −0.25; F3 moves the judgement line up 1% and F4 moves it down 1%. Saved bindings survive. F5/F6 still multiply speed by 0.5/2. Existing shared action slots also drive the corresponding menu actions and hints.
- Physical F6 opens skin fullscreen preview independently of profile remapping. F6 or Esc closes it; a held key does not repeatedly toggle it.
- Skin Settings → Save Skin Preset writes a new .trskin using the existing portable format and external assets. Import Skin Preset restores it. Existing files receive a new name instead of being overwritten. Web skin.json/ZIP and game .trskin are different formats.
- Held Backspace deletes complete UTF-8 characters in search and keeps empty search focused. Backspace no longer navigates back; use Esc.
- Selected difficulty tables show every declared level as a folder in ascending numeric order, including unowned levels with zero charts. Enter/double-click opens exactly that level; Esc returns. Searching clears the active folder and searches the selected table.
- `Lv:16` matches 16 only; `Lv:16+` matches the distinct 16+ tier only. Plus is no longer a lower-bound operator. Use `lv:16to20` for a range or `lv:20-` for an upper bound. Ordinary terms match only authored title and artist, excluding paths, genre and table labels.
- After all notes and LN tails finish, only Enter skips pending audio. Lane keys and Esc do not skip a clear outro. Natural completion, peer/course restrictions and in-play Esc pause remain intact.
- The web/offline editor now follows current schema, 5K colors, key-beam height, simple rectangles, 350ms FAST/SLOW and 700ms markers. Preview field size is 10–140%, default 60%, and is not serialized. Studio HUD, judgement-line type and Dot/Barcode remain game-profile settings. Browser preview illustrates appearance, not exact native rendering.

Rationale: reuse existing configuration/preset formats and input/audio paths; separate folder selection from chart selection to preserve empty tiers. Judgement, score, gauge, replay rules, Guest exclusion, fixed grades, client_submitted and the no-BGA-weights delivery policy remain intact.

See the candidate evidence/VERIFICATION.ko.md for measured checks. The web editor was deployed with user approval as Sites version 8. Game publication still requires separate approval. Physical input/listening, long play, other PCs and arbitrary external skins remain unverified.
