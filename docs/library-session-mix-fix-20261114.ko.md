# Library 및 Session Mix 버튼 수정

곡 폴더 추가는 Library 탭의 콘텐츠 머리글에만 표시됩니다. Songs, Records, Session Mix에는 표시되지 않습니다.

Session Mix의 자동 길이·리믹스·저장·가져오기 버튼이 전용 코스 화면의 입력 처리로 연결됩니다. 리믹스 후 생성된 스테이지 수를 표시합니다. 오디오가 실행 중이어도 가져오기·저장 파일 선택 창이 열리며, 취소하면 초안과 기존 코스 경로를 유지합니다.

사용자 코스 만들기: Songs에서 채보를 선택하고 **C**를 눌러 순서대로 초안에 추가한 뒤, Session Mix에서 **초안 저장**을 선택합니다. 같은 채보를 여러 번 추가할 수 있습니다. **코스 가져오기**로 `.lr2crs`를 선택하거나 Session Mix에 파일을 끌어 놓습니다. 비어 있는 초안은 저장 방법 안내를 표시합니다.

LR2CRS 파일 형식, 채보 MD5 매칭, 코스 판정·게이지·리플레이 동작은 변경하지 않습니다.
