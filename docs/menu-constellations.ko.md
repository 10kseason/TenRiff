# 곡 선택 배경의 별자리

[한국어](menu-constellations.ko.md) | [English](menu-constellations.en.md) | [日本語](menu-constellations.ja.md) | [简体中文](menu-constellations.zh-CN.md)

기본 곡 선택 영상의 검은 여백에 양자리·천칭자리·게자리를 본뜬 작은 별자리 세 묶음을 표시합니다. 가는 연결선과 푸른 잔광, 드문 주변 별로 망원경으로 보는 듯한 분위기를 더합니다. 정확한 천문 관측용 성도는 아닙니다.

별자리는 영상 위, 메뉴 글자와 패널 아래에 그립니다. 영상 재압축이나 추가 이미지 로딩 없이 기존 렌더러를 사용합니다. 별의 위치는 고정이며 밝기만 천천히 조금 변합니다. 시스템 또는 앱의 동작 줄이기 설정에서는 정지합니다.

사용자 스킨 배경·영상, 타이틀, 결과 화면과 플레이 화면에는 적용하지 않습니다. 원본 영상 파일, 판정과 기록은 바뀌지 않습니다. 참고 이미지는 로컬 작업 자료로만 보관하며 런타임 자산에 포함하지 않습니다.
