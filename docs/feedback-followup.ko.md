# 1.8.6 이후 로컬 피드백 보완

이 작업은 공개 1.8.6에서 출발한 별도 로컬 수정본이다. 실행 검증 결과와
제보 증상의 재현 범위는 작업 폴더의 evidence/VERIFICATION.ko.md를 따른다.

- LR2 스킨 가져오기 경로에서도 단독 플레이의 스튜디오 덱을 선택할 수 있다.
  왼쪽 밀도 그래프는 스킨 설정의 스튜디오 리프 맵에서 켜고 끈다.
  밝은 BGA 위 제목·점수 열에는 캐시된 어두운 받침을 두며, 일시정지 버튼과
  조절 안내는 불투명한 밝은 글자로 그린다.
- FAST/SLOW는 마지막 유효 비PG 오차를 0.75초 유지한다. 다음 PG가 이 값을
  지우거나 유지 시간을 다시 시작하지 않는다. 판정 글자의 위치·크기·팝
  애니메이션은 FAST/SLOW 글자와 막대의 위치에 영향을 주지 않는다.
- 타이밍 막대는 ON/OFF와 별도로 피그렛 외 판정 후 / 항상 표시 중에서
  선택한다. 항상 표시도 오차 마커는 유효 오차가 있는 동안만 남는다.
- 키를 재할당하면 같은 키 모드의 이전 기본·보조 슬롯에서 제거한 뒤 새
  슬롯에 넣는다. 비워진 기본 슬롯은 저장·재시작 후에도 미할당으로 유지된다.
  키 문자열의 별칭을 실제 키 코드로 비교하며 좌우 Shift는 구별한다.
- Options는 8개 카드의 4×2 배치다. 모드 관리자는 키 모드 설정의 모드 행,
  키 입력 테스트는 키 설정의 NKRO Test로 들어간다. 기존 세부 기능은 같은
  컨트롤러를 사용하므로 별도 설정이나 중복 진입점을 유지할 필요가 없다.

로딩 중 오디오 간섭은 [차트 로딩 설명](chart-loading-audio.ko.md), 노트별
입력 보정 변동의 재현·수정과 리플레이 음원 시각의 경계는
[입력 보정 설명](input-offset-timing.ko.md)에 기록한다.
[WASAPI 시각 결합 설명](audio-callback-timestamp.ko.md)은 재생 위치와 관측 시각의
일치, 기존 샘플 기준 보존과 ASIO fallback 범위를 설명한다.
스튜디오 세부 구현은 [스튜디오 보완 설명](studio-deck-followup.ko.md)을 따른다.
