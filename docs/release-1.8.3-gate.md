# TenRiff 1.8.3 릴리스 검증

기준일: 2026-10-04. MSVC Release 빌드와 CTest 3/3(955개, 통합 검사 제외 0),
스킨 에디터 31개, 웹 계약·마이그레이션 11개와 로컬 D1 업로드 통합 검사가 통과했습니다.
웹 랭킹은 버전 9로 먼저 배포했으며 배포 직전 보드 66개·기록 82개가 모두 보존됐습니다.
패키지·독립 소스·CI·공개 파일의 검증 절차는 아래와 같으며 최종 해시와 공개 결과는 릴리스 노트에 기록합니다.

## 변경 내용

- 스킨 설정의 우측 상단 버튼과 F6으로 전체화면 미리보기를 열고 Esc/F6으로 돌아옵니다.
  실제 게임플레이 렌더러와 화면 비율을 사용하며 저장된 그래픽 모드는 바꾸지 않습니다.
  선택한 키 폭발 모양을 반복 입력 애니메이션으로 보여 줍니다.
- FAST/SLOW 글자와 막대의 표시 여부·X/Y 위치를 각각 저장하며, 이미지가 없는
  `TenRiff_SimpleSquare` 스킨을 추가합니다. 기존 단일 스위치 설정은 처음 편집할 때까지 유지합니다.
- 스크래치 레이아웃을 7+1로 표시하고 좌우 위치를 바꿀 수 있습니다. 모드별 값이 없을 때
  필드·노트 크기의 첫 조절이 50%에서 시작하던 오류를 수정합니다.
- 마름모·화살표·삼각형·오각형·육각형 노트 머리와 꼬리에 검은 테두리를 사용하고,
  롱노트 몸통과 끝 모양을 겹쳐 틈이 생기지 않게 합니다.
- 노트 페이드인·페이드아웃 안개 범위를 각각 설정합니다. 0%는 꺼짐이며 게임플레이·고스트·
  축소 미리보기·전체화면 미리보기에서 같은 마스크를 사용합니다. 프로필과 휴대용 스킨에 저장됩니다.
- Audio의 곡 종료 방식에서 **끝까지 듣기**(기본)와 **후주 스킵**을 선택합니다.
  후주 스킵은 마지막 노트와 롱노트 판정 완료 후 기존 결과 대기 시간을 적용하고 정상 결과를 저장합니다.
- 일시정지 재개 카운트다운에도 정지된 노트를 계속 그립니다. 정지 HUD 시점을 실제 재생 커서에
  고정하고 시간이 뒤로 이동하면 노트 검색 위치를 복구하여 버퍼 지연에 따른 노트 소실을 막습니다.
- Normalize OFF에서는 자동 음량 보정과 숨은 소프트 압축을 건너뛰고 마스터 볼륨을 선형 적용합니다.
  실제 출력 범위 초과만 제한하며 ON의 기존 보정 경로는 유지합니다.
- 일반 LN과 CN을 너무 일찍 놓으면 해제 즉시 BAD·콤보 단절·게이지 감소를 확정하여 재입력으로
  취소할 수 없게 합니다. 정상 꼬리 판정과 일반 LN의 끝까지 누르기 자동 완료는 유지합니다.

자세한 조작과 수정 이유는 [FAST/SLOW와 스킨](timing-feedback-controls.ko.md),
[안개·곡 종료·일시정지](skin-fade-audio-resume.ko.md),
[오디오·롱노트·RANK](audio-ln-rank.ko.md)를 참고하세요.

## BMS RANK와 기록 규칙

새 플레이는 `tenriff-native-score-v2-ruleset-3`을 사용합니다. 기본 설정과 판정 MOD OFF에서
노트 시각의 앞뒤 각각 허용되는 시간은 다음과 같습니다. `#RANK`가 없거나 지원 범위 밖이면 EASY입니다.

| #RANK | 등급 | PG | GR | GD | BAD | EASY 대비 비율 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 3 / 누락 | EASY | 21ms | 65ms | 115ms | 210ms | 1 |
| 2 | NORMAL | 18ms | 55.714286ms | 98.571429ms | 180ms | 18/21 |
| 1 | HARD | 15ms | 46.428571ms | 82.142857ms | 150ms | 15/21 |
| 0 | VERYHARD | 8ms | 24.761905ms | 43.809524ms | 80ms | 8/21 |

EASY는 기존 PG 20ms만 21ms로 바꾸고 GR/GD/BAD를 유지합니다. 다른 RANK는 EASY의
PG/GR/GD/BAD 모두에 위 비율을 적용합니다. 자동 미스 340ms, 홀드 허용 설정과 입력 마스크는
이 비율로 줄이지 않습니다. Judge Easy/Hard MOD는 그 위에 적용하며 Rate로 판정 시간이 이중
변경되지 않습니다. 수동 커스텀 판정은 같은 비율을 사용하지만 비공식으로 구분합니다.

기존 canonical R1/R2 리플레이·고스트·로컬 검증은 PG 20ms, RANK 미적용 및 당시 LN 해제
동작을 복원합니다. 과거 기록에 새 판정을 소급 적용하지 않습니다.
R3은 차트 해시를 얻지 못해 검증 정보가 없는 리플레이도 RANK·LN·Easy 판정 규칙을 유지합니다.
검증 정보 누락은 업로드 자격에만 영향을 주며 재생 판정을 과거 규칙으로 바꾸지 않습니다.

## 웹 호환과 데이터 보존

R3 웹 제출은 `timing_profile`을 필수로 요구하며 `bms-easy`, `bms-normal`, `bms-hard`,
`bms-veryhard`, `osu-fixed`만 허용합니다. 차트 형식에 맞는 프로파일을 사용하고 R3 기록 그룹에
반영합니다. 클라이언트는 BMS 결과에 원본 `bms_rank`도 내보냅니다. `osu-fixed`는 기존 osu
호환 경로를 위한 구분이며 공개 클라이언트의 BMS 전용 입력 범위를 확장하지 않습니다.

기존 R1/R2 기록의 ID·점수·그룹 식별자를 보존합니다. 데이터베이스 마이그레이션은 R3 판정
프로파일을 지원하는 스키마·인덱스 변경이며 기존 점수를 다시 계산하거나 기록을 재작성하지 않습니다.
웹 서버 소스·운영 데이터·계정·키는 클라이언트 공개 소스 패키지에 포함하지 않습니다.

## 릴리스 검증 절차

- Release 빌드와 CTest: 노멀라이즈 OFF의 실제 믹스, LN 해제·재입력, RANK 경계와 한 샘플 초과,
  여러 샘플레이트·Rate, R1/R2/R3 리플레이·고스트·검증, 결과 저장과 후주 선택.
- 스킨 에디터 테스트와 클라이언트 회귀: 새 모양·설정 저장·가져오기, FAST/SLOW 개별 제어,
  F6 진입·복귀·입력 차단, 미리보기 키 폭발과 화면 비율, 일시정지 및 재개 노트 표시.
- 웹 회귀: R3 프로파일 누락·잘못된 값·차트 형식 불일치 거부, BMS RANK 메타데이터,
  프로파일별 그룹 분리, 기존 R1/R2 ID·점수·그룹 유지 및 스키마·인덱스 마이그레이션 전후 비교.
- 웹 배포 후 공개 경로·버전 확인과 기존 기록 읽기. 운영 기록을 변경하는 시험은 별도 허가 없이 수행하지 않습니다.
- 최종 ZIP에서 독립 추출한 공개 소스의 configure·Release 빌드·CTest 및 에디터 확인.
- 바이너리·소스 ZIP CRC, 추출 파일 해시, 소스와 확정 커밋의 일치, 비공개 파일·경로·자격증명 검사.
- PR 및 main의 해당 CI와 AddressSanitizer/OpenVINO 검증 결과 확인.
- 릴리스 태그·첨부 목록 확인 후 공개 첨부 파일을 다시 다운로드하여 로컬/API SHA-256과 비교.

수정 전 오디오 왜곡 경로, 조기 LN 해제 취소, RANK 미적용 및 일시정지 HUD 회귀는
실패 테스트로 확인했습니다. 이전 릴리스의 테스트 수나 패키지 해시는 이번 검증의 증거로 재사용하지 않습니다.

## 확인 범위의 한계

수치·샘플·렌더 회귀와 패키지 검증은 실제 오디오 장치의 청감, 물리 키 입력,
장시간 게임플레이 또는 여러 PC의 네트워크 플레이를 증명하지 않습니다. 해당 실기 검증은
아직 완료로 기록하지 않습니다. 기존 설치·프로필·이전 배포본은 보존합니다.
