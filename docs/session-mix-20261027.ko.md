# 세션 믹스 코스 선택 · 2026-10-27 로컬 후보

기존 설정 행 중심 화면을 코스 메뉴 / 코스 목록 / 수록곡 순서의 세 영역으로 바꿨습니다. 일반 곡 선택의 배경과 화면 배율을 재사용하고, 코스 전용 목록을 그려 기존 곡 선택 스킨 좌표와 충돌하지 않게 했습니다.

1. 세션 믹스에서 **코스 가져오기**로 `.lr2crs`를 엽니다.
2. 가운데 코스를 클릭하거나 ↑↓·마우스 휠로 고릅니다. 오른쪽에서 순서와 누락 채보를 확인합니다. PgUp/PgDn은 7개씩 이동하며, Tab으로 목록 → 메뉴 → 수록곡 영역을 순환합니다. 수록곡은 이전/다음 버튼으로도 넘깁니다.
3. 모든 수록 채보가 현재 색인 라이브러리에 있으면 Enter·더블클릭·코스 입장으로 시작합니다. 일반 곡 목록의 검색/필터는 가져온 코스의 채보 매칭을 제한하지 않습니다.
4. 원본 MD5 순서와 반복 스테이지를 유지합니다. 누락곡을 다른 곡으로 대체하거나 건너뛰지 않습니다. 입장 전 모든 채보 파일의 존재를 확인합니다.
5. 기존 연속 게이지와 결과 화면의 Enter 다음 곡 진행을 유지합니다. 완료·실패·결과 화면 Esc 종료 후 코스 선택으로 돌아갑니다.

자동 믹스는 화면에 표시한 목록을 그대로 시작합니다. **자동 믹스 다시 만들기**, 길이 변경, 라이브러리 변경 또는 화면 재진입 때 새 목록을 만듭니다. 현재 곡 필터를 따르며, 같은 오디오 경로(없으면 폴더+제목)를 공유하는 난이도 변형은 한 곡만 고릅니다. 이 식별은 휴리스틱으로 모든 중복을 알아내지는 못합니다. 수동 초안과 LR2 코스는 중복 제한을 적용하지 않습니다.

확인 가능한 클리어 정확도 80–100%의 레벨을 기준으로 워밍업 → 도전 → 마무리 목표를 잡고, 급격한 난이도 상승에 벌점을 줍니다. 기록이 없으면 보유 레벨의 하위 사분위부터 시작합니다. 유사 후보의 재생성 다양성을 높였습니다. 15/30/60분은 곡당 약 3분으로 추정하는 5/10/20곡 목표이며 실제 곡 길이 보장은 아닙니다. 알고리즘 검증은 규칙·순서 검증이고 체감 재미나 실력 향상을 입증하지 않습니다.

이 후보는 공개 1.9.9.1과 앞선 F1 감소/F2 증가·길게 누르기 가속 변경을 포함합니다. 기존 저장 키 배치, 판정·등급·리플레이·코스 게이지·웹 업로드 경계를 유지합니다. LR2CRS 저장 형식·버전 번호·일반 기준선 1.9.6은 바꾸지 않습니다. 이전 후보·릴리스·설치·프로필은 보존합니다. 별도 실행기는 `session-mix-local` 프로필을 사용합니다.

검증 기록: 후보 상위 `evidence/VERIFICATION.ko.md`. 실제 사용자의 LR2CRS 전체, 물리 입력·오디오 청취·장시간 코스 플레이는 별도 확인이 필요합니다.
