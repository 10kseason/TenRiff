# TenRiff 1.9.9.9-final1

final1はhotfix5の全変更にIR保護と除外表示を追加します。新規スコア提出には本版が必要です。運用リーダーボードv26はSpeed of Linkを公開一覧・順位・集計から除外し、再提出を拒否します。元の保存データは保持します。

hotfix5を基に、単独のプレイ用キー音が原音で45秒以上、または実プレイノートの85%以上が無音ならサーバーが登録を拒否します。合計時間・曲の長さ・BGM専用音声・速度適用後の長さでは判定しません。タップとLN頭を各1個として数え、尾は含めません。キー音なし／PCMがすべて0を無音とします。

リプレイと同じBMS分岐・速度・サンプルレート・ノートモードをバックグラウンドで再構成します。45秒以上はメモリ制限のため45.0に丸めて送信し、拒否対象のままです。音源欠落・解析失敗・情報欠落は登録不可。PCM/float WAV・完全な単一Vorbis OGG・厳格MFのMP3を検査します。MF専用WAV、Opus OGG、現行BMSローダー非対応の過去osu、キー変換はローカル保存です。デジタル0検査であり、不正防止の保証ではありません。

別フォルダーで実行してください。判定・点数・入力・旧リプレイ形式は維持します。新規則適用後、解析情報のない旧クライアントの登録は拒否されます。

除外確定時は選曲一覧の選択行・詳細・結果に `IR EXCLUDED`（韓国語では `IR 제외`）を表示します。選択譜面のみ別スレッドで検査し、全ライブラリーや待機中の定期再解析は行いません。再選択・再訪問・F5・関連設定変更で再検査します。選択中に音源を交換した場合も再選択かF5が必要です。未確認・検査中は登録可能とみなしません。RANDOM分岐は実プレイ後に確認します。ゲストを含む結果は完了リプレイの分岐と条件に紐付け、現在のメニュー設定や通信障害から除外を推定しません。バッジがなくても登録保証ではなく、送信時には再検査します。


Extract into a new folder and run `launch_win.bat`. Fixed baseline: **1.9.6**.
