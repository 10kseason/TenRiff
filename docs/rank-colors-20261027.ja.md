# ランク・開始ゲージ色とEX虹色の修正

以前のローカル変更を含む1.9.9.1候補。ランク閾値・判定・ゲージ計算・スコア・リプレイは変更しません。

- S+/S++/S+++はEX虹色、SはHD #FF3838、A+/AはNM #FFF000、B/C/DはEZ #00ED57、E/Fは薄紫 #C2A0FF。AUTO/--は従来の中立色 #B6C0D0。
- 選曲・記録・結果の共通色です。実際の文字幅にEXの7色を配置し、既存の文字・光彩キャッシュを再利用。毎フレームの再生成はありません。
- 四段階のクリアバッジはEXと同じフォント・太さ・サイズ・ロゴ形状を共有。スキンのフォント指定は維持。開始ゲージも同じ色でEX-HARDは虹色です。
- EXゲージはスキンに単色指定があってもClassic/Studio/ゴーストで虹色になります。前候補の明示的EX色優先の例外を置き換えます。他のゲージ色指定は保持。
- 旧ロビーレンダラーでもクリアバッジを表示。読み込んだロゴはバッジ内でアルファ・形状を保ちクリア色を適用し、バッジ外では元の色を維持。画像や保存スキンを上書きしません。

標準・単色EXスキン・読み込みロゴ・旧ロビーを画面検証。任意スキン・物理入力・長時間プレイは未検証。以前の候補/ZIPと固定基準1.9.6を保持します。
