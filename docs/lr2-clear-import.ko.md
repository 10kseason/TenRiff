# LR2 클리어 램프 가져오기

LR2 점수 DB의 클리어 램프를 TenRiff 프로필로 가져와 선곡 화면에 표시합니다. 표시 전용이며 TenRiff 기록, BEST, 온라인 제출 대상이 되지 않습니다.

EX 확인은 차트의 노트·RANK·TOTAL·LN·지뢰·RANDOM 정보만 읽고 오디오·배경 파일을 탐색하지 않습니다. LR2 식별에 필요한 MD5만 계산하고, 겹치는 곡 폴더는 한 번만 탐색하며, 모든 대상 차트를 찾으면 탐색을 끝냅니다. 램프 변환과 보수적인 EX 인정 조건은 같습니다. 찾지 못한 차트가 있으면 남은 폴더도 계속 확인하므로 큰 라이브러리는 시간이 걸릴 수 있습니다. 원본 RANK가 없거나 0~3 밖일 때 EASY로 보정해 EX를 인정하던 오류도 수정했습니다. 이런 차트는 기본 LR2 램프만 유지합니다.

## 사용법

### 게임에서 가져오기

LR2를 종료한 뒤 **옵션 → 프로필 → LR2 기록 가져오기**를 선택하고 점수 `.db` 파일을 엽니다. 현재 프로필에 저장하며, 등록된 곡 폴더와 현재 곡 폴더에서 EX 판정을 확인합니다. 곡이 없어도 기본 램프는 가져옵니다.

가져오기는 백그라운드에서 진행됩니다. 같은 버튼을 다시 누르면 취소하며, 완료되면 재시작 없이 선곡 램프를 갱신합니다. 재가져오기는 기존 LR2 램프 목록을 교체합니다. 취소·읽기/저장 실패·게임 종료 시 기존 목록을 유지합니다. TenRiff 기록·BEST·온라인 제출에는 영향이 없습니다.

### 명령줄

```
tenriff-lr2-import.exe <LR2 점수 .db> <프로필 폴더> [곡 폴더 ...]
```

예: `tenriff-lr2-import.exe C:\LR2\LR2files\Database\Score\이름.db profiles\default D:\BMS`

- LR2 DB는 읽기만 하고 수정하지 않습니다.
- 결과는 `<프로필 폴더>\lr2_import.json`에 저장되고, 게임이 기록을 읽을 때 함께 읽습니다. 파일을 지우면 가져온 램프도 사라집니다.
- 다시 실행하면 파일을 새로 만듭니다.

## 표시 규칙

| LR2 | TenRiff 램프 |
|---|---|
| EASY | EZ CLEAR |
| NORMAL(GROOVE) | NM CLEAR |
| HARD, FULL COMBO | HD CLEAR |
| 아래 조건을 통과한 기록 | EX CLEAR |

- TenRiff에서 직접 낸 기록이 같거나 더 높으면 그 기록을 그대로 표시합니다.
- 가져온 램프가 표시될 때는 선택 곡의 램프 문구에 `LR2 `가 앞에 붙습니다. LR2 풀콤보는 `(FC)`가 붙습니다.
- 점수, 랭크, 정확도는 가져오지 않습니다.

## EX 인정 조건

곡 폴더를 함께 주면, LR2 `ghost`(최고 점수 플레이의 노트별 판정 순서)를 TenRiff EX-HARD 게이지에 그대로 넣어 봅니다. 이때 각 LR2 판정을 **그 LR2 판정 폭 안에서 TenRiff Normal 판정으로 가능한 가장 나쁜 판정**으로 바꿉니다. 그래도 게이지가 남으면 EX로 인정합니다.

- LR2 판정 폭(ms, RANK VERY HARD/HARD/NORMAL/EASY): PGREAT 8/15/18/21, GREAT 27/32/40/60, GOOD 40/60/100/120, BAD 200. PGREAT와 BAD는 lr2oraja의 LR2 판정 표와 Lunatic Vibes가 일치하고, GREAT/GOOD은 몇 ms 달라 넓은 쪽을 썼습니다.
- 예: RANK NORMAL에서 LR2 GOOD(100ms까지)은 TenRiff GOOD 경계(98.57ms)를 넘을 수 있어 BAD로 계산합니다. LR2 BAD(200ms까지)가 TenRiff BAD 폭을 넘으면 공푸어 + 놓침으로 계산합니다.
- 게이지는 실제 플레이와 같은 `GaugeManager`(BMS TOTAL 기반 EX-HARD)를 씁니다.

다음 경우는 비교할 수 없어 EX를 판정하지 않고 LR2 램프만 가져옵니다: 곡이 곡 폴더에 없음, 롱노트·지뢰·`#RANDOM`이 있는 차트, `#RANK`가 없거나 0~3이 아님, 노트 수가 LR2 기록과 다름, ghost가 없거나 끝까지 가지 않았거나 저장된 판정 개수와 맞지 않음.

## 한계

- ghost 형식은 공개 사양이 아니라 실제 LR2 DB 한 개에서 역으로 맞춘 것입니다(5,285행 중 5,274행의 판정 개수 일치).
- ghost는 최고 **점수** 플레이의 것입니다. LR2에서 램프를 딴 플레이와 다른 판일 수 있습니다.
- 최악 가정이라 실제로는 살았을 기록도 EX로 인정되지 않습니다.
- LR2와 TenRiff는 게이지 규칙이 달라 같은 이름의 램프라도 난이도가 같지 않습니다.
