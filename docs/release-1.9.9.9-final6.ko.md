# TenRiff 1.9.9.9-final6

[한국어](release-1.9.9.9-final6.ko.md) | [English](release-1.9.9.9-final6.en.md) | [日本語](release-1.9.9.9-final6.ja.md) | [简体中文](release-1.9.9.9-final6.zh-CN.md)

7+1·8K 키 설정 분리와 빨간 스크래치, 16레인 간격 수정에 무제한 VSync 처리와 타이밍 마커 캐시를 더했습니다. LR2oraja 기록을 가져오고 BMS 원본 레벨과 고해상도 BGA 원본 프레임을 사용합니다.

- 옵션 → 키 설정과 NKRO 테스트에서 7+1과 8K를 따로 선택합니다. 7+1 스크래치와 건반 1~7에 기본·보조 키를 각각 지정할 수 있습니다.
- 7+1 설정이 없는 프로필은 현재 8K 키 배치로 시작합니다. 구버전에서 키맵을 다시 저장하면 7+1 전용 설정이 빠집니다.
- 기본 스크래치 색은 빨강입니다. 프로필과 스킨에 저장된 색 설정이 우선합니다.
- 14+2 DP와 16K에서 가운데 간격은 노트 표시 영역에서 제외합니다. 일반 노트와 롱노트가 각 블록 안에 그려지며 고스트 필드에도 적용됩니다.
- `Unlimited`는 저장된 VSync 설정에 관계없이 VSync OFF를 적용합니다. 플레이 최대 1,500 FPS, 메뉴 최대 300 FPS를 사용하며 `Match Display`는 저장된 VSync를 적용합니다.
- 점·바코드 타이밍 마커는 같은 이력이 연속 프레임에 유지되면 비트맵을 캐시합니다. 이력이 바뀌는 프레임에는 최신 마커를 바로 그립니다.
- 옵션 → 프로필 → 점수 DB 가져오기에서 LR2oraja의 `player/<profile>/score.db`를 선택합니다. LN/CN/HCN 기록을 따로 저장하고 곡 선택에 출처·클리어·EX·콤보·BP를 표시합니다. 화면은 LN, CN, HCN 순서로 첫 기록을 사용합니다.
- DB ghost는 노트별 판정 범주를 저장합니다. 실제 입력 시각을 쓰는 ms 분포 복원에는 별도 리플레이 입력 로그가 필요합니다. 클리어·콤보·최소 BP는 서로 다른 플레이의 최고값일 수 있습니다.
- 게임 내 기본 난이도는 BMS `#PLAYLEVEL`을 사용하고 내부 계산 옵션을 제거했습니다. 이전 계산 캐시는 다음 인덱싱 때 갱신합니다. 선택한 외부 난이도표는 해당 표의 레벨을 사용합니다.
- 높이 480픽셀을 초과하는 BGA는 원본 프레임 크기를 사용합니다. 이미지 ONNX 처리는 높이 480픽셀 이하에 적용합니다.

외부 제보 PC의 FPS·티어링, 실제 개인 DB, 물리 입력·청음·장시간 플레이는 추가 확인이 필요합니다. [기록 가져오기](lr2-clear-import.ko.md)

- 배포 음악 8개의 계정·개별 곡 식별 태그를 정리했습니다. Suno AI 제작 출처와 압축 오디오·내장 커버를 보존합니다.
