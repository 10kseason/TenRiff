# 简洁长按音符、EX 配色与全连图片（本地候选）

此候选独立于已发布的1.9.9.3。保留版本号、固定基线1.9.6及原有发布包和配置。

- native的simple_rect、square、circle、diamond、arrow、triangle、pentagon、hexagon长按头部、主体和尾部改为轨道纯色。默认rect/Luma Keys、普通音符、导入图片、透明度、宽度和渐缩保持不变。SimpleSquare使用simple_rect。
- 仅EX降低18%饱和度，使用粉→红→黄→绿→青→蓝六色。蓝色末端不接回粉色，避免插值产生紫色。共享EX配色的S+至S+++、通关卡片/徽标、Shift Start和血条同步变化。EZ/NM/HD、E/F淡紫与普通判定色不变。
- 整首曲目全连完成（含最后一个长按尾部）后，在连击数字下用ALL COMBO图片替代COMBO标签。玩家和幽灵独立判断；失败、中止、自动演奏、Auto Scratch、No Fail及局部练习不显示。
- 新完成结果的最大连击栏也显示图片。历史结果不推测新增徽标，旧FULL COMBO判定和存储格式不变。
- 图片按渲染设备缓存，缺失时回退为文字。沿用连击位置、缩放及与判定计数的避让，保持判定、计分、音频、回放与peer v7契约。
