# 评级、起始血条颜色与EX彩虹修正

包含此前本地改动的1.9.9.1候选。评级阈值、判定、血量计算、计分及回放保持不变。

- S+/S++/S+++使用EX彩虹；S使用HD #FF3838；A+/A使用NM #FFF000；B/C/D使用EZ #00ED57；E/F使用淡紫 #C2A0FF。AUTO/--保留中性色 #B6C0D0。
- 选曲、记录和结果共用颜色。EX七色覆盖实际字形宽度，复用字形/光晕缓存，不逐帧重建。
- 四种通关徽章共用EX的字体、字重、字号和标志形状，保留皮肤字体设置。起始血条使用对应颜色，EX-HARD为彩虹。
- 即使皮肤保存了EX单色，Classic/Studio/幽灵EX血条也显示彩虹，取代此前显式EX色优先的例外。其他自定义血条色仍保留。
- 旧版大厅渲染器也显示通关徽章。导入标志在徽章中保留透明度/形状并应用通关色，徽章外保持原色。不覆盖图片和已保存皮肤。

通过标准、EX单色皮肤、导入透明标志及旧大厅画面检查。任意用户皮肤、物理输入和长时间游玩仍未验证。保留此前候选/ZIP和固定基线1.9.6。
