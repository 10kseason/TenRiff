# BGAを元の解像度で復元してから表示領域に合わせる

2026-10-16

1.9.1.1 (`ea8bdba`) と検証済みUI候補を基にしたローカル変更です。固定ランク、明るさ、読み込み、言語設定とBMS・オンライン・入力・音量の動作を維持します。

**元画像 → AIで2倍復元・残差合成 → 表示領域に合わせてサイズ調整 → 必要ならクロップ** の順序です。推論前の16:9クロップと960×540への変換を廃止しました。640×480は1280×960、300×900は600×1800に復元してから表示します。

既存の960×540入力／1920×1080残差出力モデルに対応します。元画素を拡縮せず、余白は端の画素で埋めます。大画像は32画素の周辺領域を重ねたタイルで処理し、元座標の2倍で合成します。余白除去で元画像の内容を失うことはありません。ノート・HUD・BGA明るさの順序は維持します。

元画像は各辺4096画素まで、復元後は8192画素までです。超過や推論失敗時は通常表示を維持し、AI入力を暗黙に縮小しません。静止画のみが対象で、動画AIは無効のままです。キャッシュは各インスタンスで最大3枚／96MiB、古い要求はタイル間で中止します。

大画像では推論回数とメモリ使用量が増えます。32画素より広い範囲や画像全体の文脈を必要とするモデルはタイル境界で差が出る場合があります。合成テストは画素・寸法・アルファ・FP32/FP16契約の検証であり、学習モデルの品質やリアルタイムFPSの保証ではありません。
