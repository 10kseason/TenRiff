# 곡 로비 의미색·기존 리절트 폰트·기본 효과음

2026-11-03 후속 로컬 후보. 앞선 피드백 후보의 NEW RECORD/랭크 연출/전환/누적 게이지 그래프/실시간 비교기는 유지합니다. 기존 설치·프로필·음원과 일반 고정 기준선 1.9.6은 보존합니다.

## 표시

- 곡 로비의 **점수 숫자**는 실제 표시 중인 로컬 BEST/선택 기록/온라인 기록의 클리어 색을 사용합니다. EX는 기존 정적 7색 프리즘, HD는 빨강, NM은 노랑, EZ는 초록입니다. 정의되지 않은 상태/미플레이는 기존 중립 표시를 유지합니다. 점수 비교나 저장 순서는 바뀌지 않습니다.
- 점수의 폰트·위치·크기와 일반 UI의 흰색/회색은 그대로입니다. 첨부 예시의 화면 구조를 새로 만들거나 버튼·패널을 클리어 색으로 칠하지 않습니다.
- 전체 곡과 LN 꼬리까지 완료했음이 검증된 기록만 기존 MAX COMBO 자리에 `FULL COMBO`를 표시합니다. 기존 라임 `#CBEF6B`와 최대 0.25 블룸을 사용합니다. 단순 최대 콤보 숫자, 온라인 요약, 미검증/미완료 기록으로 추정하지 않습니다. 기존 ALL COMBO 이미지의 표시 조건은 유지합니다.
- 리절트는 기존 폰트 객체와 점수 흰색·정확도 청록·NEW 금색·판정/FAST/SLOW 의미색을 유지합니다. 클리어 문구는 기존 게이지 색, FULL COMBO 부분만 약한 색 글로우/블룸입니다. 일반 GRADE 접두어와 UI에는 적용하지 않습니다.

## 기본 효과음

제공한 파일을 바꾸지 않고 `Mainmusic/SFX`에 복사했습니다. 실행 파일 기준으로 찾기 때문에 다른 작업 폴더에서 실행해도 사용할 수 있습니다.

| 파일 | 용도 |
| --- | --- |
| `button click.mp3` | 일반 버튼 클릭 |
| `options edit.mp3` | 옵션 화면의 클릭/조작 |
| `Silder Moving.mp3` | 슬라이더 조작 |
| `Start button click.mp3` | 사용자가 직접 실행한 곡 시작/재도전 |
| `done.mp3` | 성공한 불러오기/가져오기/인덱스/곡 준비 완료 |

한 조작에 시작음·슬라이더음·일반 클릭음이 중복되지 않게 우선순위를 둡니다. 자동 코스 진행/자동 재시작은 수동 시작음을 내지 않습니다. 완료음은 실제 성공·유효한 결과에서 한 번만 울리며 실패/취소에 붙이지 않습니다.

오디오 메뉴에서 각 파일을 바꾸거나 기본값/없음으로 지정할 수 있습니다. 기존에 저장한 사용자 선택은 유지하며, 새 프로필과 기본값 복원은 복사한 파일을 사용합니다. 기존 파일 드롭 알림음은 별도 설정으로 남습니다.

Done은 약 3초인 제공 파일을 자르지 않도록 4초 제한, 나머지는 2초 제한입니다. 효과음은 기존 Windows 시스템 출력과 마스터 음량/비활성 음소거를 사용합니다. BGM의 선택된 WASAPI/ASIO 출력은 유지합니다. 원본 음원이나 설치/프로필을 덮어쓰지 않습니다.

[검증 요약](color-sound-20261103-gate.md). 실제 청취·물리 입력·임의 스킨·장시간·다른 PC 검증은 별도로 필요합니다.
