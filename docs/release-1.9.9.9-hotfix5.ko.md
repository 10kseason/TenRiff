# TenRiff 1.9.9.9-hotfix5

핫픽스4의 타격 모션·키밤 설정·멀티코어 스캔과 캐시 로딩을 모두 이어받았습니다. 이번 런타임 수정은 웹 리더보드로 보내는 원본/변환 키 모드 표시입니다.

원본 키 모드(`auto`/`none`/`native`)의 새 Online 플레이는 설정에 기억된 KRRCREAM/NK2/NK3와 관계없이 변환 없음(`key_conversion: none`)을 보냅니다. 명시한 대상 키 수로 플레이하는 변환 모드는 같은 키 수라도 변환 표시를 유지합니다. 모드가 없거나 알 수 없는 기록도 원본으로 추정하지 않습니다.

운영 웹 v25는 원본 키 기록만 곡 목록·순위·개인 최고 점수·플레이어 수·등록 기록 수에 집계합니다. 이전 클라이언트는 원본 모드에도 컨버터 이름을 보냈으므로 기존 서버 정보만으로 실제 변환 여부를 확정할 수 없습니다. 사용자 선택에 따라 이 분류 불명 기록도 순위에서 제외합니다. 저장 데이터는 보존하고 재분류·삭제·다른 조건으로 재제출하지 않습니다. 이전 클라이언트의 기록은 계속 제외될 수 있으므로 새 원본 집계에는 핫픽스5를 사용하세요.

실행 ZIP을 새 폴더에 풀고 `launch_win.bat`을 실행합니다. 키 컨버터의 대상 키 모드를 원본/None으로 둔 뒤 F10에서 Online 및 웹 연결을 설정하고 새로 플레이하세요. 기존 설치와 프로필은 보관합니다. 키 컨버터 플레이의 로컬 점수와 리플레이 저장은 유지합니다.

Scoring, judgement, replay format and R13/R14 policies remain unchanged. Fixed baseline: 1.9.6.
