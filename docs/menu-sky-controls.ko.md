# 시작 메뉴와 조작 개선

## 화면

이 문서는 당시 메뉴/판정 변경 기록입니다. 아래 판정 표는 R2 기준이며, 현재 RANK·Judge 모드 수치는 [판정 범위](judgement-windows.md)를 참고하세요.

기본 시작 메뉴에 제공된 우주 이미지를 원본 색상 그대로 표시합니다. 이미지 파일은 실행 파일 옆 `assets/menu/title-space.jpg`에서 찾으므로 다른 폴더에서 실행해도 표시됩니다. 기본 메뉴의 바탕·패널·버튼은 검정·회색, 글자는 흰색, 선택 강조는 부드러운 파스텔 하늘색을 사용합니다. 사용자가 가져온 스킨의 명시적인 색상·배경 설정은 유지합니다.

기존 네이티브 팔레트 슬롯 이름을 유지하면서 기본 색상만 바꿨습니다. 스킨 편집기 기본값도 같은 표에서 생성합니다. 메뉴 색상은 인게임에 영향을 주지 않으며, 스킨 설정 미리보기에서도 인게임의 색상을 별도로 복원합니다.

TENRIFF 글자에 4.8초마다 최대 340ms의 짧은 가로 흔들림을 표시합니다. 세 개의 얇은 띠와 더 뚜렷한 하늘색/흰색 잔상을 사용합니다. TI 심볼은 정지해 있고, 모션 줄이기 또는 애니메이션 끄기에서는 지지직 효과가 나오지 않습니다.

## 키 입력 배경

스킨 설정의 키 입력 배경 항목에서 켜기/끄기, 농도, 밝기, 최대 높이를 각각 조절합니다.

- `skin.key_backdrop_brightness`: 0–2, 기본 1. RGB 밝기만 바꾸며 농도와 독립적입니다.
- `skin.key_backdrop_height`: 0–1, 기본 1. 필드 아래쪽을 기준으로 배경색이 올라오는 최대 높이입니다. 0에서는 숨기고 1에서는 기존 전체 높이를 유지합니다.

두 값 모두 초기 100%이므로 이전 스킨이 같은 모습으로 보입니다. 실플레이·고스트·직접 미리보기·웹 편집기는 같은 의미를 사용합니다. 최초 수정 시 스킨의 현재 켜짐·농도·밝기·높이를 함께 계승한 뒤 프로필 값을 우선합니다.

## 방향키 길게 누르기

화면에 `−/+`가 표시되는 설정은 좌우 방향키를 누른 채로 연속 조절합니다. 처음 250ms는 기다리고 이후 45ms 간격으로 조절합니다. 비활성화된 방향에는 적용하지 않습니다. 키를 놓거나 선택·화면·마우스 조작·포커스가 바뀌면 중지하며, 텍스트 입력과 키 할당 중에는 반복 조절하지 않습니다.

표시 순서를 숫자로 가정하던 기존 방식 대신 실제 선택 행의 설정 ID와 버튼 활성 상태를 사용합니다. 이후 옵션을 재정렬해도 반복 대상이 달라지지 않습니다.

## 옵션 카드

옵션 카드는 하늘색·민트·살구·노랑·코랄 등 항목별 파스텔 강조색을 사용합니다. 카드 배경·테두리·값 글자에 같은 색을 적용하고 선택 시 밝기와 안쪽 테두리를 함께 높입니다. 메뉴 기본 검정·흰색은 유지하며 `native.colors`의 `options.key_mode`, `options.keymap`, `options.skin`, `options.graphics`, `options.audio`, `options.input`, `options.latency`, `options.profile`, `options.mode`, `options.key_test` 슬롯으로 개별 편집할 수 있습니다.

## 판정

| 모드 | PG | GR | GOOD | BAD | 무입력 자동 미스 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Normal | 20ms | 65ms | 115ms | 210ms | 340ms 초과 |
| Easy | 27ms | 87.75ms | 155.25ms | 283.5ms | 340ms 초과 |
| Hard | 20ms | 65ms | 115ms | 180ms | 340ms 초과 |

Easy는 기존 1.25배에서 1.35배로 완화했습니다. Hard는 기존 마지막 판정 범위 340ms를 최대 180ms로 좁혔습니다. 자동 미스 시점과 성공 가능한 입력 범위를 분리하므로 BAD 범위 밖에서 340ms 안에 누른 입력을 BAD 성공으로 인정하지 않습니다. 이때 놓친 노트는 미스로 처리하고 다음 노트를 검사하는 기존 복구 규칙을 사용합니다.

새 플레이는 `ruleset-2`, 과거 정식 리플레이는 `ruleset-1`의 정확한 당시 판정을 사용합니다. 과거 리플레이를 새 판정으로 재해석하거나 임의 판정 수치를 정식 기록으로 허용하지 않습니다. 온라인 랭킹 서버가 새 기록을 검증하려면 서버의 리플레이 검증기 역시 이번 버전으로 갱신해야 합니다. ChatGPT Sites 리더보드는 별도 갱신되어 ruleset-1/2 제출을 구분합니다. 이는 커뮤니티 제출 검증이며 C++ 리플레이 재실행 검증과는 별개입니다. 독립적인 공식 검증 서버를 운영한다면 서버의 검증기 교체도 필요합니다.
