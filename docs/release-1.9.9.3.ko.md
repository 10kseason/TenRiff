# TenRiff 1.9.9.3

공개 1.9.9.1에 2026-10-27 로컬 후속 작업을 통합합니다. 일반 고정 기준선은 **1.9.6**입니다. [릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.9.3)의 공개 상태와 첨부 파일을 따릅니다.

## 변경

- 새 기본 노트 속도 키는 F1 감소 / F2 증가입니다. 저장된 사용자 단축키는 유지합니다. 로비와 인게임의 속도·시각 레이턴시 조절은 길게 누르면 가속하며, 키 해제·포커스 전환 때 반복 상태를 초기화합니다.
- 세션 믹스는 곡 선택과 비슷한 코스 목록에서 LR2CRS 코스를 선택하고, 보유한 수록곡을 원래 순서대로 플레이합니다. 반복 수록곡을 보존하며 누락 파일은 입장을 막습니다. 자동 믹스는 음악 변형 중복을 줄이고 준비·도전·마무리 흐름을 선택하며 미리보기와 입장 목록을 일치시킵니다.
- 스킨 설정의 키 오버레이 플러그인은 기본 OFF입니다. 켜짐과 X/Y를 저장하고 4/5/7/8/10K에서만 키 입력·홀드·KPS를 표시합니다. 입력을 짧은 고정 크기 큐로 복사하고 별도 작업 스레드에서 집계합니다. BMS 전체를 로딩 중 분석한 대표 난이도를 크게 고정 표시하며, 입력량·실력·클리어 확률로 해석하지 않습니다. 실제 지연/FPS 개선은 측정하지 않았습니다.
- 선곡 카드의 테두리·앨범 왼쪽 위 로고 배지는 EZ 초록, NM 노랑, HD 빨강, EX 무지개입니다. 배지는 EX의 공통 글꼴·굵기를 사용하고 시프트 시작 값도 같은 색입니다. 가져온 로고의 알파 형상과 구형 로비에도 배지 색을 적용합니다.
- 인게임 EX 게이지는 저장된 `gauge_ex_hard` 단색 지정이 있어도 무지개입니다. 다른 명시적 스킨 색과 원본 스킨·로고 파일은 보존합니다. 기본 텐리프 로고를 확대합니다.
- 랭크 색은 S+/S++/S+++ 무지개, S 빨강, A+/A 노랑, B/C/D 초록, E/F 연보라 `#C2A0FF`입니다. AUTO/--는 중립색입니다.

## 호환과 검증

정확도 기준은 S+++≥99%, S++≥98%, S+≥97%, S≥95%, A+≥93%, A≥90%, B≥85%, C≥80%, D≥70%, 생존 E/게이지 실패 F를 유지합니다. 반올림 전 정확도를 사용합니다. 고정 판정 Normal PG22/19/15/10ms, Hard=Normal NM 전체, EX=Normal VHD 전체와 R1–R10·peer v7·LN Mix v1/v2/v3·NK2 E는 그대로입니다. 기존 온라인 경계·Guest/커스텀 제외·client_submitted를 유지합니다. 웹사이트·DB·공개 스킨 에디터는 배포하지 않습니다.

이전 로컬 검증과 새 버전 검증을 구분합니다. [릴리스 검증 절차](release-1.9.9.3-gate.md)를 따르며 물리 입력·OBS·장시간 플레이·다른 PC·임의 사용자 스킨·실제 두 PC 대전·실계정 업로드는 별도 미검증입니다. 새 폴더에 배포 ZIP을 풀고 `TenRiff.exe`를 실행합니다. 기존 설치와 프로필은 덮어쓰지 않습니다.
