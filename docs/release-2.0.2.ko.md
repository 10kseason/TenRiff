# TenRiff 2.0.2

[한국어](release-2.0.2.ko.md) | [English](release-2.0.2.en.md) | [日本語](release-2.0.2.ja.md) | [简体中文](release-2.0.2.zh-CN.md)

멀티 안정화와 온라인 전체 채팅을 반영했습니다.

- 멀티에서도 현재 선택한 싱글 스킨·HUD 전체를 유지합니다. 상대 정보는 빈 공간에 배치하고, 공간이 없으면 보조 카드만 숨깁니다.
- 로컬 차트와 서버 확인이 일치하면 해시 체크 완료를 표시합니다. 시작·종료 대기 중 조회 간격을 500ms에서 250ms로 줄이고 HTTPS 연결을 재사용합니다.
- 최종 점수 위치가 직전 전송보다 뒤로 가면서 결과 동기화가 멈추던 문제를 수정합니다.
- 온라인 계정 연결 후 F11 전체 채팅을 홈·선곡·옵션·플레이·결과·멀티 어디서나 사용합니다. 새 UI는 전체 채팅만 사용하며, 방 입장과 점수 업로드는 필요하지 않습니다.

2.0.1의 어두운 옵션 배경·15% 작은 카드·한 줄 힌트를 포함합니다. 판정·점수 계산·리플레이·저장 형식과 final4 호환 기준은 유지합니다. 전체 채팅은 사용자가 명시 요청한 2.0.2 범위이며, 2.0.0 이후 유지보수 정책은 계속 적용합니다.
