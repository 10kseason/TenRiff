# 選曲クリアカード

2026-10-27 · Local follow-up to 1.9.9.1. Unpublished; general fixed baseline remains 1.9.6.

- クリア済みの曲を、参考画像に合わせた黒いカード・角丸の色付き枠線・ジャケット左上のロゴ付きバッジで表示します。

- EZ CLEARは緑、NM CLEARは黄、HD CLEARは赤、EX CLEARは静止した虹色グラデーションです。枠・バッジ・標準ベクターロゴに同じ色を使います。

- お気に入りのFAVとクリアバッジを同時に表示します。選択中は枠を太くし、7行と既存のクリック領域を維持します。

- 明示的なスキンのジャケット・状態表示座標と読み込んだロゴ画像を優先します。変更は標準配置に適用し、外部ロゴの元の画素は保持します。

- 保存済みCLEAR・GAUGE SHIFT・ゲージ記録は変更しません。補助プレイ・失敗・未プレイに正式なクリアバッジは付けません。得点・判定・リプレイ・ゲーム中のゲージ色は維持します。
