# FFmpegデブロックと外部ONNX x2

2026-10-16 · TenRiff 1.9.2。[リリース範囲](release-1.9.2.ja.md)

**元画像 → FFmpegデブロック → 外部AI x2復元・残差合成 → 表示領域に合わせる → 必要ならクロップ**

FFmpeg内蔵 `deblock=filter=weak:block=8:planes=7` を元画像全体のRGBに一度適用します。planar RGBでYUV色差の間引きを避け、元のアルファを保持します。AI入力とbilinear x2のベースには同じ処理済み画素を使います。

動的空間軸モデルは元画像のH/W全体を一度に評価します。固定960×540入力/1920×1080残差出力は端の余白補完と32画素の文脈タイルで引き続き対応します。推論前の拡縮・16:9クロップは行わず、実出力が正確に原寸x2かを確認します。入出力名は `rgb_lr` と `rgb_residual_x2`、境界型はfloat32/float16のNCHW RGBです。動的モデルもbatch/channelは1/3が必要です。

**公開実行・ソースパッケージにBGAモデルは含みません。** モデルパスは空が初期値で、既存の空の選択も変更しません。Graphicsで外部ONNXを選択・ドロップするとパスだけを保存します。機能はOFFが初期値で、有効化には別の確認を維持します。保存済みパスと既存のNK3鍵数変換モデルは保持します。

静止BGAと選曲画像が対象で、動画AIは無効です。原寸各軸4096画素、インスタンスごとに3枚/96 MiBまでです。動的モデルは原寸全体を一度に処理するため、この寸法上限でもGPUメモリが足りる保証はありません。FFmpegはworkerで非表示実行し、取消または10秒の期限で終了します。欠落・フィルター・モデル失敗時は通常表示を維持します。開始済みWinML推論自体は中断できませんが、古い結果は表示しません。

FFmpegはゲーム横の `tools/ffmpeg-deblock/ffmpeg.exe`、次にPATHから解決します。依存関係の告知は[THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)を参照してください。元ファイル・旧候補・インストール・プロファイルを保持します。モデル別画質・性能と長時間動作は別途検証が必要です。
