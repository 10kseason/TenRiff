# ホーム・グラフィック・読み込み・固定等級 — 1.9.1.1後続候補

2026-10-16 · `ea8bdba0fb8aa533f0e684b64fc64515e2eb2e41`

ユーザーが指定した **1.9.1.1公開コミット**から作成したローカル候補です。誤って1.9.0を基に作成したUI候補を置き換えます。1.9.1.1のBMS TOTAL、BPM/STOP、RANDOM分岐、オンライン記録、統合音量、入力と言語切り替えを維持します。作業開始点の指定であり、固定基準線や公開タグは変更しません。

- V-Syncの設定行を削除し、リフレッシュレート選択を維持します。保存済みの `graphics.vsync` は互換性のため保持します。
- BGAの明るさを0〜100%、1%刻みで設定できます。初期値は100%。譜面背景だけを暗くし、ノートとHUDは維持します。
- ホーム右下の既存ボタン（English → 한국어 → 日本語 → 中文）と設定保存を維持します。
- LR2/TenRiffの取り込み、譜面読み込み・索引作成、難易度表読み込みは共通の中央パネルを使用します。進捗不明時は動くバーを表示します。
- 等級には丸め前の通常精度を使います。点数・判定・ゲージ・リプレイ・数値順位と原記録を保持します。記録なし・中断は--、自動演奏はAUTOです。
- WebのStableは正式運用表示と固定等級表を意味し、サーバーでのリプレイ再検証を意味しません。
