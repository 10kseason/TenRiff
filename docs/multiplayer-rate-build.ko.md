# 멀티플레이 Rate 지원 빌드

1.7.3 U_E 팩 핫픽스를 기준으로 만든 별도 클라이언트입니다. 기존 배포 파일과 개인 프로필은 보존합니다.

## 사용 방법

1. 모든 참가자가 `TenRiff-1.7.3-multiplayer-rate.zip`을 새 폴더에 풀어 실행합니다.
2. HOST 또는 IP/LAN 방 참가로 연결합니다. 현재 선곡권자가 로비의 **대전 Rate**에서 좌/우 키나 −/+ 버튼으로 **0.50~2.00배**를 **0.05 단위**로 정합니다.
3. 같은 차트와 Rate를 확인한 뒤 모두 READY를 누르고 선곡권자가 시작합니다. Rate를 바꾸면 전원 READY가 해제되므로 다시 준비해야 합니다.

시작한 라운드의 배속은 로딩부터 결과까지 고정합니다. 리더가 교체되거나 나중에 참가한 사람이 있어도 같은 방 값을 공유합니다. 개인 Rate 설정과 `--rate`는 멀티 세션에서 방 값을 덮어쓰지 않으며, 경기 종료 후 개인 설정도 그대로입니다. Hi-Speed·스킨·볼륨·입력 보정은 각자 설정합니다.

## 호환성과 검증 범위

이 빌드는 **peer protocol v6**입니다. 기존 1.7.3 및 U_E 이름 수정 핫픽스의 v5 클라이언트와 함께 접속할 수 없습니다. 방을 여는 PC를 포함해 모든 참가자가 이 빌드를 써야 합니다.

네트워크에는 정수 배속과 설정 세대를 넣어, 배속을 바꾸었다가 원래 값으로 되돌린 경우에도 이전 READY/시작 요청을 거부합니다. 동일 PC의 실제 TCP 소켓을 사용한 다인 테스트로 배속 변경·준비 해제·리더 교대·재접속·라운드 고정·오래된 패킷 거부를 확인합니다. 실제 여러 PC의 연주, 소리의 동시 재생이나 WAN 지연을 측정한 검증은 아닙니다.

기존 경기 규칙 및 접속 안내는 [멀티플레이 안내](multiplayer.md)를 참고하세요.
