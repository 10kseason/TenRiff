# TenRiff 1.7.3 — 2026-09-15

현재 폴더는 이 릴리스를 기반으로 한 **멀티 Rate 지원 빌드**입니다. 설치 파일과 v6 호환성은 [멀티 Rate 빌드 안내](multiplayer-rate-build.ko.md)를 따르세요. 아래 내용은 기존 공개 1.7.3/U_E 이름 수정 릴리스의 기록입니다.

**hotfix-UE:** 4K/6K/8K 프리셋 이름을 **U_E 팩 / U_E Pack**으로 수정했습니다. 단축키와 표 주소는 그대로이며 게임 버전은 1.7.3입니다.

1.7.2 Sites 통합본과 9월 15일 검증한 로컬 핫픽스를 1.7.3으로 배포합니다. 리플레이 형식과 웹 제출 규격은 바꾸지 않습니다.

## 변경 사항

- 마지막 노트 이후 입력하지 않아도 실제 후주와 최소 결과 대기가 끝나면 결과·리플레이를 저장하고 연결된 웹 리더보드에 자동 제출합니다.
- 실제 재생이 끝나도 초기 음원 길이 추정이나 빈 후속 마디 때문에 저장이 늦어지던 경로를 수정했습니다. 실패 음원은 대기에서 제외하고 정상 음원의 마지막 버퍼는 출력 장치에서 재생될 때까지 기다립니다.
- 음원 메모리 추정치로 차트 길이를 바꾸지 않아 리플레이 검증의 원본 차트 길이를 유지합니다. 수동 후주 건너뛰기도 유지합니다.
- 스텔라(F5), 새틀라이트(F6), U_E 팩 4K(F7)·6K(F8)·8K(F9) 난이도표를 추가했습니다. 난이도표 선택 창에서 기존 F1–F3 표와 F4 기본 LV를 포함한 3×3 버튼으로 선택합니다. 선택 창의 F9 입력 충돌도 수정했습니다.
- Sites 계정 연결과 점수·상세 스코어·정확도·상세 정확도 자동 전송을 포함합니다. 네이티브 ASIO, 스킨 파일 내보내기/가져오기, 재개 카운트다운 등 기존 기능도 유지합니다.

## 설치

`TenRiff-1.7.3-hotfix-UE.zip`을 새 폴더에 풀고 `launch_win.bat`으로 시작하세요. 웹 리더보드는 F10에서 계정을 연결합니다. 자세한 안내는 [웹 리더보드](sites-leaderboard.md), [난이도표](library-management.md)를 참고하세요.

최신 핫픽스는 클라이언트 ZIP과 SHA-256 체크섬으로 배포하며 이전 1.7.3 첨부 파일도 보존합니다. 이번 클라이언트의 소스는 공개하지 않습니다. GitHub에서 자동 표시하는 Source code ZIP/TAR는 기존 공개 기준선이며 이번 클라이언트의 빌드 소스가 아닙니다.

## 검증과 한계

1.7.3 Windows x64 Release 새 빌드와 CTest 3/3이 통과했습니다. 무입력 자동 종료·실제 WAV/실패 디코더·출력 버퍼 지연·로컬 저장·해시·웹 제출 데이터 생성 회귀를 포함한 782개 단위 테스트가 통과했고 통합 제외는 0개입니다. 동일한 난이도표 구현은 같은 날 실제 가져오기 8/8을 통과했습니다. 최종 ZIP은 압축 해제 후 모든 파일을 빌드/배포 디렉터리와 대조하며 게시 후 다시 내려받아 SHA-256을 확인합니다.

실제 제보 차트·키보드 연주·실계정 업로드·GUI 화면은 확인하지 않았습니다. ASIO는 이번 릴리스에서 장치 재생을 다시 시험하지 않았으며 기존 Realtek ASIO 장치 실패/가청 재생 미검증 한계는 [1.7.2 장치 확인 기록](release-1.7.2-gate.md)에 있습니다. WASAPI가 기본입니다.
