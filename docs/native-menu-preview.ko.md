# 기본 메뉴 스킨과 스킨 에디터

2026-09-28, TenRiff 1.7.8 릴리스. 기존 배포본과 별도 폴더에 압축을 풀어 사용하세요.

## 바뀐 화면

- 홈: 새 벡터 로고와 프리즘, 궤도 장식, 순서대로 등장하는 버튼, 선택 강조, 빛이 지나가는 시작 버튼.
- 선곡: 목록 등장과 선택 전환, 재킷 확대·등장, 이미지가 없는 곡의 파형·프리즘, 시작 버튼 강조.
- 옵션·설정: 기능별 벡터 아이콘과 부드러운 선택 강조.
- 결과: 점수 패널 강조, 등급 장식과 스펙트럼, 계속하기 버튼 강조.
- 공통: 천천히 움직이는 배경선·입자. 스펙트럼은 장식용이며 음원 분석을 표시하지 않습니다.

12개 벡터 에셋의 편집 가능한 SVG 원본은 `assets/native-menu`에 있습니다. 게임에서는
같은 원본으로 생성한 Direct2D 도형을 한 번 준비해 재사용합니다. 별도 이미지 다운로드나
매 프레임 파일 읽기가 필요하지 않습니다. 배포본에는 에디터의 `vector-assets` 폴더로 동봉합니다.

## 스킨 편집

`launch_skin_editor.bat` 또는 게임의 `Options > Skins > Open Skin Editor`로 엽니다.
에디터는 한국어·영어·일본어를 지원하며 서버나 인터넷 연결이 필요하지 않습니다.
자세한 조작은 [에디터 안내](../tools/skin_editor/README.md)를 참고하세요.

1. `skins/TenRiff_NativeEditable` 폴더를 에디터에서 엽니다. 새 스킨도 같은 기본 메뉴로 시작합니다.
2. 메뉴 배치, 팔레트, 이미지와 Native 세부 설정을 편집합니다.
3. 새 JSON 또는 ZIP으로 저장합니다. ZIP은 새 스킨 폴더에 압축을 풉니다.
4. 게임에서 폴더를 가져와 선택하고 `F5 / Reload Skin`으로 다시 읽습니다.

큰 영역은 캔버스에서 이동·크기 변경하며, 세부 영역은 Native 설정에서 수정합니다.
현재 카탈로그는 수치 35개, 색상 28개, 사각형 290개, 이미지 12개, 모션 4개,
글꼴 18개를 제공합니다. `layout`은 1920×1080의 절대 좌표이고 `native.rects`는
기본 계산 위치에 더하는 `[X 이동, Y 이동, 너비 증감, 높이 증감]`입니다.
이 방식은 곡 목록처럼 반복되는 행의 간격을 보존합니다. 설정하지 않은 값은 기본값을 유지합니다.

`native.motion`에는 `enabled`, `speed`, `intensity`, `entry_seconds`가 있습니다.
`intensity`는 궤도 장식의 강도를 조절합니다. `enabled: 0` 또는 `speed: 0`은 메뉴 모션을 멈춥니다.
Windows의 애니메이션 끄기도 따릅니다. 에디터 캔버스는 큰 배치와 색상 참고용이며
세부 모션·글꼴·모든 사각형을 게임과 똑같이 그리지는 않습니다.

기존 스킨 포맷은 유지하며 `lobby.renderer: "native"`와 선택적 `native` 객체를 추가했습니다.
[포맷과 적용 범위](skin-format.md), [JSON 스키마](tenriff-skin.schema.json)를 참고하세요.

## 인게임과 언어

메뉴 시각 설정은 `native`, 인게임 시각 설정은 `gameplay.native`에 나누어 저장합니다.
기본 NativeEditable 스킨에는 Luma Keys 디지털 건반과 노트의 편집 가능한 도형도 포함합니다.
에디터의 디지털 건반 · 인게임 탭에서 4~16키별 설정을 편집합니다.
판정·오디오·입력 규칙은 변경하지 않습니다. [인게임 스킨 안내](luma-keys-preview.ko.md).

클라이언트 `UI Language`는 `en`, `ko`, `ja`를 지원하고 저장합니다. 일본어는 메뉴·결과·로딩·
BMS 편집 안내와 플레이 중 UI 문구에도 적용합니다. 사용자 곡명·외부 이미지 안의 문구·
서버/파서의 원시 진단은 번역하지 않습니다. [현지화 안내](localization.md).

## 확인 범위

- Windows Release 클라이언트와 시각 검증 도구 빌드.
- 전체 CTest 3/3, 단위 검사 831개 통과. 스킨 로더·모션·설정 저장·일본어 검사를 포함합니다.
- 번역 키 1,043개 검사, 에디터 데이터 테스트 21개, 기본 스킨 11개 왕복 검증.
- 실제 D3D11 장치의 합성 화면: 홈·선곡·옵션·결과 1080p, 일본어 설정 960×540.
- 브라우저에서 세 언어, 숫자 배치·드래그, 실행 취소·다시 실행, 모션 설정과 저장 요청 확인.
- 좁은 창과 1680px 데스크톱 배치, 잘못된 JSON 차단·되돌리기 확인.
- 서로 다른 세 시점의 메뉴 캡처를 비교해 모션 활성화 시 변화, 모션 비활성화 시 픽셀 동일 확인.
- 압축에서 꺼낸 실행 파일의 메뉴 초기화 확인. 합성 화면 검증과 실제 곡 플레이는 구분합니다.
- UI의 JSON 편집값을 다시 읽어 게임 렌더러에 적용. 다운로드 파일 경로는 내장 브라우저에서
  얻지 못했으며, `file://` 직접 실행은 해당 검증 도구의 URL 정책 때문에 확인하지 못했습니다.

장시간 실플레이 FPS, 여러 PC의 글꼴·브라우저와 실제 마우스 플레이 흐름은 별도 확인이 필요합니다.
이 빌드는 공개 업로드하지 않은 로컬 배포용 미리보기입니다.
