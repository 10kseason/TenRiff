# 選曲クリアバッジ・曲情報・背景動画

2026-11-03 のローカル候補です。リザルトを戻した候補を引き継ぎ、その配置を維持します。

曲一覧の点数と未プレイの `--` を既存の EZ/NM/HD/EX CLEAR バッジに置き換えます。ロゴ・書体・意味色とEXプリズムを再利用し、失敗/補助プレイを正式クリアに変換しません。フォルダーの曲数と右側の自己ベスト点数は維持します。

曲情報を BPM / キー数 / Lv / ノート数 / 判定難易度、その下に MIN / AVG / MAX を含む NPS バーとして表示します。実際の選択譜面のノート開始を使用し、AVG は MED の名称変更ではなく平均です。未取得値を推測しません。詳細精度はロビーでのみ非表示とし、詳細点数・通常精度・リザルト・保存値は維持します。

NPS は譜面時刻0から最後のノート開始を含む1秒区間まで、空白区間も0として計算します。TAP/LN開始を各1個とし、終端と地雷は除外します。MIN/算術AVG/MAXは全区間から計算し、描画のみ最大96個の時間区間のピークに集約します。倍率1.0・固定分岐のため実際のランダム分岐と異なる場合があります。未取得・8MB超・6時間以上の譜面は非表示です。既存MEDキャッシュと記録形式は維持します。

先ほど作成した12秒・1080p30・無音の動画を標準選曲背景に使用します。モーション軽減時は静止画を維持し、明示的なユーザー背景を優先します。選曲を離れたら専用デコーダーを解放します。

専用 `lobby-detail-local` プロファイルを使用します。既存候補・インストール・記録は保存し、判定・スコア・リプレイ・保存形式、公開版や固定基準1.9.6は変更しません。計算範囲と未検証項目は検証記録を参照してください。
