# EX Scoreへの移行

[한국어](ex-score.ko.md) | [English](ex-score.en.md) | [日本語](ex-score.ja.md) | [简体中文](ex-score.zh-CN.md)

表示・自己ベスト・順位は **EX Score = P-Great × 2 + Great** を使います。Good・Bad・Poorは0点です。ロングノートの頭・末尾を含む既存の判定イベント数に従います。精度・等級・ゲージ・判定時間は変更しません。

最高クリアランプと最高EX記録は独立して保持します。曲詳細と結果を開く操作は最高EXの実プレイを使い、その精度・等級・判定数を表示します。低いクリアでEXを更新しても既存ランプは下がりません。記録タブは選択した個別プレイを表示します。

従来の正規化点数と5/3/1詳細点数は新しい点数に使いません。過去リプレイの検証とファイル互換性のため旧フィールドと計算を保持します。ローカル記録は保存済み判定数からEXを計算し、情報不足なら`--`としてEXベスト比較から除外します。推定値で元ファイルを上書きしません。

Web DBにはnullableなEXと判定数列を追加します。判定数がない過去の行は保存し、EX順位から除外します。同一アカウントが同じリプレイとメタデータを再送信した場合のみ未算定の行を補完できます。サーバーによるリプレイ検証ではなく、引き続き`client_submitted`です。整数・範囲・判定総数・計算式を検証します。

Web送信は`schema_version=2`・`score_version="ex-v1"`、対戦は`protocol=2`と同じscore_versionを使用し、旧クライアントは更新が必要です。旧部屋は隔離され従来の短い期限で失効します。旧TCPプロトコル・リプレイルールの意味は保持します。

グラデーションはx=800〜1034を維持し、画像全体を短い行へ横長に表示、実行時彩度を1.2倍にします。EXには提供された銀河PNGを使います。元画像・既存インストール・プロファイルは保持します。
