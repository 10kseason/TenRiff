# 設定UIと毎回のシード更新

2026-10-19 · [1.9.6](baseline-1.9.6.ja.md)

- キー設定に共通キーと従来の10配置のタブを追加。即時リスタートと11機能を編集し、プロフィールと保存値・競合検査・即時保存を共有する。Tabでタブと設定を切り替え、左右でタブを選択する。

- スキンの14タブは高さ52→60、文字18→24デザインピクセル。検索幅340→260で1行を維持。選曲ロビーと同じ配置色を使用し、7+1は8キーの色となる。

- スキン設定のFASTは青、SLOWは赤。輪郭・文字縮小・翻訳・プレビューを維持。%表示のサイズ・位置・濃度・明るさは1%刻み。px/msの単位と保存済み小数値は自動変換しない。

- キーモード設定をゲームモード設定へ変更。判定幅の通常選択は全言語でNormal。判定値・R9/R10・スコア・固定ランクは維持する。

- 新規ソロプレイとリトライではOFF・ミラー・ランダム・スクラッチ固定・Sランダム・Rランダムすべてで新シードを生成。手動設定は自動の読み取り専用表示へ変更。BMS RANDOMは独立シード。別シードでも偶然同じ配置になる場合がある。

- リプレイ再生・検証は記録済みシードを使用。共通譜面のゴーストは配置に影響するシードの一致を維持し、原譜面OFF/ミラーの未使用シード差だけでは拒否しない。対戦のランダムOFF共有規則とpeer v7を維持。

- この変更は1.9.7に含まれる。過去のリリース・インストール・プロフィールを保存し、一般ソース基準線は1.9.6を維持する。物理入力・試聴・長時間・別PCは別途検証が必要。

- TenRiff独自の背景音楽（タイトル・メニュー・結果）の基準ゲインを10%から12.5%へ上げ、減衰を約1.94dB緩和。保存済みマスター・メニュー音量と曲プレビュー・プレイ音量は維持する。
