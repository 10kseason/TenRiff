# TenRiff 1.9.4 — メモリ解放のタイミングとプレイ設定

1.9.4 はユーザー指定の 1.9.3 (`bf544e17f22879011a04a7fd157e40b57f6598bb`) が基点です。固定基準 1.9.0、以前の公開ファイル・インストール・プロファイルは保持します。

- デコード済み音源はプレイ・一時停止中にキャッシュ上限で削除せず、セッション終了で音声・デコード処理が停止した後に解放します。開始時の優先読み込みと先読みは維持します。
- 静止 BGA は従来の 256枚/192MiB LRU 制限を超えて保持し、メニュー復帰時に解放します。曲検索の強制ヒープ/ワーキングセット整理は読み込み・プレイ・一時停止中に保留し、メニューの回収地点またはセッション終了後の検索要求で処理します。
- ネイティブ C++ なので管理型 GC はありません。この方針は上記の明示的キャッシュ削除と強制整理が対象です。通常のオブジェクト寿命、動画フレーム再利用、非同期キャンセル、デバイス喪失時の復旧は維持します。全割り当て・解放や OS ページングを停止するものではありません。
- PCM はセッション終了まで、静止 BGA はメニュー復帰まで蓄積します。メニューを挟まないコースでは複数曲の BGA が残る場合があります。非常に大きい譜面ではメモリ負荷が増す可能性があります。カクつきや物理入力遅延の改善値は保証しません。
- 点/バーコードを選択できます。常時表示では目盛りと中心を維持し、各判定マーカーはゲーム時間 0.7秒後に消えます。FAST/SLOW 文字の保持方針は同じです。
- WASAPI 出力指定は演奏と BMS 試聴に適用します。ASIO は専用ドライバー指定、メニュー/結果音楽は Windows 既定 MCI 出力を使います。切断した指定出力から別の出力に無断で切り替えません。
- プロファイルで F1–F11 機能を割り当て/解除し、案内も更新します。F5/F6 −10/+10 は ×0.5/×2 に変更し、1回押すごとに1回適用します。範囲 0.5–50、F3/F4 ±0.25、曲の再生速度、判定は維持します。
- BMS 小節線をノート下端に合わせます。プレイヤー/ゴーストとノート高さ設定に対応し、譜面時刻は変えません。

[互換性の詳細](input-feedback-20261017.ja.md)。BGA 重み非同梱、OFF/空/Auto、Guest 除外、R7/R8・旧リプレイ・固定評価を維持します。Web/DB 変更はありません。
