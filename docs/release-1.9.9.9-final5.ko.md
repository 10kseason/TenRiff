# TenRiff 1.9.9.9-final5

[한국어](release-1.9.9.9-final5.ko.md) | [English](release-1.9.9.9-final5.en.md) | [日本語](release-1.9.9.9-final5.ja.md) | [简体中文](release-1.9.9.9-final5.zh-CN.md)

LR2 기록 가져오기의 해시·차트 탐색 비용을 줄이고, 원본 RANK가 없거나 범위 밖일 때 EX를 잘못 인정하던 오류를 수정했습니다. Andro의 빈 꼬리 마디가 대표 BPM을 1로 만들던 문제를 수정했습니다. 고정 기준선은 final4를 유지합니다.

- LR2에 필요한 MD5만 계산하고, EX 확인 중 오디오·배경 파일 탐색을 생략합니다. 겹치는 폴더는 중복 탐색하지 않으며 모든 대상 차트를 찾으면 종료합니다.
- 합성 기록 512개와 로컬 차트 15,569개를 사용한 같은 PC의 순차 측정에서 91.139초 → 9.852초였습니다. 해당 표본의 램프·EX 결과 JSON은 기존과 동일합니다. 개인 DB나 다른 PC의 속도를 보장하지 않습니다.
- RANK 누락/범위 밖 차트는 EASY로 보정해 EX를 인정하는 대신 기본 LR2 램프만 유지합니다. 원본 DB는 읽기 전용이며 취소·실패 시 기존 가져오기 결과를 보존합니다.
- 마지막 비어 있지 않은 이벤트가 있는 마디 이후의 길이 지정/전부 00인 마디를 대표 BPM 집계에서 제외합니다. 확인한 Andro 20개 차트와 Safe/Fast 인덱스가 모두 165이며 노트 시각·개수·전체 길이는 그대로입니다. 곡 캐시 v22는 이전 파생 메타데이터를 한 번 재구축합니다.
- 가져온 기록은 표시 전용입니다. TenRiff 결과·BEST·업로드 자격, 판정·게이지·기존 R1–R14 리플레이 정책을 바꾸지 않습니다. 개인 DB와 원본 Andro 차트는 배포하지 않습니다. 소스에는 합성 테스트 DB 두 개만 포함합니다.
- 로컬 후보에서 CTest 4/4(1,547개, skip 0), 네이티브 747/747을 확인했습니다. 릴리스 패키지·독립 소스 빌드·CI·공개 다운로드 검증은 릴리스 게이트로 확인합니다. 물리 입력·청음·장시간 플레이·다른 PC·개인 DB 전체의 시간은 미검증입니다.
