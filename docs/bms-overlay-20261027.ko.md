# BMS 대표 난이도·KPS 작업 스레드·게이지 색

1.9.9.1 로컬 후속 후보입니다. 앞선 단축키, 세션 믹스, 로고 확대와 클리어 카드 변경을 포함합니다. 일반 고정 기준선 1.9.6과 기존 릴리스·설치·프로필은 보존합니다.

- **설정 → 스킨 → 판정·HUD → 키 오버레이 플러그인**에서 켭니다. 기본 OFF, X/Y 0~100%와 켜짐 상태 저장, 4·5·7·8·10키만 표시하는 정책은 같습니다. 별도 오버레이 설치가 필요 없습니다.
- 패널 위쪽에 **BMS 대표 난이도**를 크게 표시합니다. 전체 BMS의 현재 키 수·배속·랜덤/변환 적용 결과를 로딩 중 분석하고 가장 어려운 구간의 추정값 하나를 해당 플레이 동안 고정합니다. 실제 입력, 판정, 콤보, 오토플레이 여부로 변하지 않습니다. 연습 시작점과 카운트다운 여백을 넣기 전에 전체 곡을 분석합니다. 새 플레이에서 배속/배치가 바뀌면 값도 달라질 수 있습니다.
- 앞선 실시간 입력 난이도를 대체합니다. 원본 v2.13 계산 코어의 8초 구간(4초 준비 문맥)을 0.5초 간격으로 평가한 최고값입니다. 탭과 LN 길이를 읽으며 BGA·음원·키보드 활동을 분석하지 않습니다. 4K Reform, 5K AERY, 7K Jinjin, 8K Regular, 10K Revive의 원래 단위·단명을 사용합니다. 화살표는 기준 범위 밖입니다. 이는 **채보 구간 부하의 참고 추정**이며 공식 채보 레벨, 플레이어 실력, 클리어 확률이 아닙니다.
- 자료가 부족하거나 지원 한계(25만 노트, 1시간, 계산 코어의 이벤트 한도), 잘못된 노트/같은 레인 중첩이 있으면 `추정 불가`로 표시합니다. 잘린 일부 곡으로 값을 만들지 않습니다. 스킨 미리보기는 `미리보기`만 표시합니다.
- 오른쪽 **KPS**는 최근 1초의 실제 레인 누름 횟수입니다. 계속 누른 키의 반복 입력과 같은 레인 보조키 소유권 이동을 중복 계산하지 않습니다. 오토/리플레이/고스트 입력은 제외합니다. 일시정지·포커스 이탈·카운트다운에서는 키 표시를 비우고 KPS는 `--`, BMS 추정은 그대로 유지합니다.

기존에는 HUD에서 입력 패턴 난이도를 반복 계산했습니다. 이제 입력 경로는 고정 크기 SPSC 큐에 이벤트만 복사하고, 낮은 우선순위의 별도 작업 스레드가 약 8ms마다 키 기록과 KPS를 갱신합니다. 입력 경로에는 할당·뮤텍스·작업 스레드 깨우기가 없습니다. HUD는 대기 없는 try-lock 복사만 수행하며 100ms 이상 오래된 값이나 큐 손실은 초기화합니다. 작업 스레드는 게임 세션 종료 시 정리합니다. 실제 기기에서의 프레임/입력 지연 개선 수치는 측정하지 않았습니다.

기본 Classic/Studio 및 고스트 게이지 색을 선곡 클리어 카드와 통일합니다: **EZ #00ED57, NM #FFF000, HD #FF3838, EX 무지개**. 그라데이션은 전체 게이지 기준으로 고정되어 잔량에 따라 색 위치가 흔들리지 않습니다. 명시적으로 가져온 스킨의 게이지 색은 우선합니다. 게이지 증감량·실패 판정·판정 타이밍·점수·리플레이 형식은 바뀌지 않습니다.
