# TenRiff 1.8.9.1 릴리스 검증 범위

1.8.9 위에 키 설정·키 수 변환·스킨 미리보기 피드백을 반영한다. 고정 기준선 1.8.7과 이전 릴리스/프로필은 보존한다. 공개 상태와 다운로드는 [1.8.9.1 릴리스](https://github.com/10kseason/TenRiff/releases/tag/1.8.9.1)에서 확인한다.

## 동작과 호환성

- 성공한 키 지정 뒤 같은 기본/보조 슬롯의 다음 키를 이어서 지정한다. 마지막 키에서 종료하며 반복 눌림은 다음 키로 넘기지 않는다.
- Krrcream·nK2(세 프리셋)·NK3 공통 경계에서 전체 롱노트를 우선 확보하고, 다른 노트를 빈 레인으로 옮긴다. 수용할 수 없어 빠지는 노트의 키음은 원래 시각의 배경음으로 보존한다. BMS 출력도 서로 다른 동시 키음이 덮이지 않도록 독립 BGM 줄로 보존한다.
- 보고된 LNOBJ 차트는 원본 로딩이 정상(1,631개 노트/21개 LN)이고 변환 후 겹침 정리에서 LN이 잘리던 문제였다. 파서 규칙은 바꾸지 않았다.
- 선택적 `key_conversion_version`: 생략/1은 1.8.9의 원래 변환, 2는 수정된 변환이다. 결과·리플레이·검증기·고스트가 같은 버전을 사용한다. R1–R4 판정 및 리플레이 포맷 번호는 유지한다.
- FAST/SLOW·타이밍 배경은 프로필/프리셋에서 켜고 끌 수 있다. P GREAT·GREAT·GOOD 등의 Studio 판정은 항상 글자만 표시한다.
- Studio rail과 수치 배지, 기본 Classic 게이지를 확대한다. 고스트의 남는 폭을 조정해 게이지 잘림을 피하며 플레이어 노트 크기는 유지한다. 외부 스킨이 직접 지정한 게이지 사각형은 유지한다.
- 작은 스킨 미리보기와 F6 전체화면 장면 모두 기어 핸들을 지원한다. 드래그 거리를 화면 배율로 환산하고 놓으면 프로필에 저장한다. 다른 화면으로 바꾸면 미완료 이동을 취소한다.

[세부 원인·구현 선택·재현 방법](feedback-conversion-20261013.ko.md).

## 검증 기준

기능 후보에서는 CTest 3/3(1,110개 사례, 통합 skip 0), 에디터 34/34, 합성 변환 95조합, 실제 보고 차트 27조합의 21/21 LN 보존, 구/신 변환 리플레이 verifier 6조합, MenuApp/세션 187개, native 화면 17개/510 Present/621 hit checks 및 배율별 preview drag를 통과했다. Studio/Classic GPU sprite 비교는 각 7/7이며, 지원 batch 경로의 최대 색차는 1/255·2/255, fallback은 동일했다. 배경 ON/OFF 4쌍은 인디케이터 영역 밖 픽셀 변경이 없었다.

릴리스 파일에는 버전을 반영한 새 Release 빌드와 CTest/에디터/앱·렌더 검사를 적용한다. 소스 ZIP을 별도로 추출해 독립 빌드/CTest/에디터 검사를 수행하고, 최종 병합 트리와 비교한다. PR/main ASan·OpenVINO CI, ZIP CRC·파일 해시·개인 경로/비밀 패턴 검사와 공개 후 익명 3개 자산 재다운로드가 공개 검증 단계다. 상세 로컬 실행 기록은 릴리스 작업 폴더의 evidence에 보존한다.

## 한계

키 수를 초과하는 동시 LN/겹노트는 모두 플레이 가능한 노트로 남길 수 없다. 완전한 LN과 원래 시각의 키음을 우선 보존한다. 새 변환 리플레이를 정확히 재생하려면 1.8.9.1 이상이 필요하며, 구 파일은 구 변환으로 재생한다.

물리 키보드·실제 곡 청음·장시간 플레이·다른 PC·실제 온라인 제출은 별도 검증 범위다. 합성 WAV/음원 예약 검사는 청음 증거가 아니다. GPU sprite 픽셀 검사는 성능이나 물리 지연 개선의 증거가 아니다. 이번 변경은 웹 스킨 형식이나 랭킹 서버/사이트를 배포하지 않는다. 1.8.9의 기존 ghost p95 한계는 해소되었다고 주장하지 않는다.
