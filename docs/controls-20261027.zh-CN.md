# 长按调节与默认速度键

2026-10-27 · Local follow-up to 1.9.9.1; unpublished, no version bump. General fixed baseline remains 1.9.6.

- 新默认值为 **F1 音符速度 −0.25 / F2 +0.25**。保留F3/F4判定线上下1%、F5/F6速度×0.5/×2以及F7/F8视觉延迟−/+1ms。
- 保留所有已保存的绑定，包括旧默认值。已有配置可在按键设置的公共键或个人配置中重新指定速度减小/增大键。
- 在选曲大厅快捷设置中选择速度或视觉延迟并长按左右键，或长按Rate的−/+键即可加速。游戏、开始倒计时和暂停界面的速度、判定线和视觉延迟键也使用相同规则。
- 首次按下只调节一步。首次重复等待保留大厅250ms、游戏180ms。重复间隔为45ms，按住0.6秒后25ms，1.5秒后15ms。步长和上下限保持不变，实际频率可能受菜单或音频处理周期限制。
- 松键、失去焦点、大厅项目或页面切换、打开浮层、进入暂停以及恢复倒计时会重置重复状态。处理延迟后不会一次补做积压的调节。
- 血条/随机模式选择、列表移动和删除文字保持原重复频率。本次不增加鼠标长按。×0.5/×2仍每次按下只执行一次。
- 判定、得分和回放格式不变。延迟是现有的视觉偏移，不改变输入判定偏移。
