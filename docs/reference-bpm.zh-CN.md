# 参考 BPM

[English](reference-bpm.md) · [한국어](reference-bpm.ko.md) · [日本語](reference-bpm.ja.md)

选曲显示和 Hi-Speed 使用累计行进时间最长的 BPM。同一 BPM 的区间会合并统计，不按音符数或拍数选择。STOP 等待时间不计入，SCROLL 不改变权重；并列时选择最先行进的 BPM。

统计范围从谱面起点到最后一个含非零事件的小节末尾，包括长音符尾部、BGM 和背景事件。之后只有长度定义（`02`）或全为 `00` 的空小节不计入，修复了 Andro 结尾的 0.99 BPM 与空小节使参考 BPM 从 165 显示成 1 的问题。

音符时刻、谱面总时长、滚动区间和既有回放时序保持不变。初始 BPM 仍用于回放与键数/LN 转换。统计在采样取整之前完成，因此 Safe/Fast 索引与不同音频采样率使用相同的参考值。

索引缓存版本 22 会重建一次旧的派生元数据，保留游玩记录。没有有效行进区间时使用初始 BPM；无效时间轴返回 0。
