# TenRiff 1.9.3 游戏、皮肤与模型兼容性

此文描述接续公开1.9.2及先前ONNX兼容工作的1.9.3实现范围，保留已发布文件及固定基线1.9.0。发布状态与最终验证边界见[1.9.3发行说明](release-1.9.3.zh-CN.md)。

- 选曲封面右下显示BMS作者标注的判定难度：RANK 4/3/2/1/0 → VEZ/EZ/NM/HD/VHD。缺失或无效值使用EZ；osu!不显示此标记。缓存20重新读取元数据。
- Classic、Studio及对战HUD在艺术家旁保留独立红色等级区，长名称不会挤掉等级。编辑器练习和直接启动读取实际启动谱面的PLAYLEVEL，不使用无关选中歌曲的等级。
- 在音符后绘制遵循BMS小节长度、BPM、STOP、速度及滚动位置的小节线，不增加判定或音频事件。
- FAST/SLOW常显保留最后一次真实反馈与标记。条件模式仍为750ms，文字和条形开关独立，首次反馈前不虚构FAST，并保留原有PG隐藏规则。
- 新建或缺失的加载设置默认安全。保留已保存的快速选择；原生LV/CR计算仍为独立设置，默认关闭。
- 空POOR仍扣血并计入POOR数量，但不降低普通、详细或分段准确率。实际漏音符仍扣准确率。新普通/Hard记录使用R7，EX使用R8；旧R1–R6回放保持原计算。
- 支持的外部Safetensors先通过本地Python转换为ONNX，再进入现有GPU路径。需要torch/safetensors/onnx/onnxruntime，其他架构需要选装Spandrel；不会自动安装或下载。[模型契约](../tools/onnx_upscaler/README.md)。

RANK 4的VEZ仅表示作者元数据，实际判定窗口仍使用原有Easy回退。小节线目前适用于BMS。Safetensors限于已知LunaSR2 C32 R8/R12/R16 x2或可导出的Spandrel RGB x1–x4架构；失败后保持原图并记录原因。BGA模型权重不随运行包或源码包分发，仍默认关闭、路径为空，视频AI仍禁用。

支持R7/R8的正式排行榜版本19已于2026-10-16经用户批准部署。新规则使用独立榜单，保留旧榜单ID、记录及Stable固定等级。继续永久排除访客记录，保留client_submitted信任边界，未增加服务器端回放验证。
