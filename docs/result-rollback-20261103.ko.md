# 리절트 화면만 이전 구성으로 복원

2026-11-03 로컬 후보입니다. `ui-fixes-local`의 수정 사항을 이어받고, 리절트 표시만 HTML 시안 적용 직전 `color-sound-local`의 구성으로 되돌립니다. 이 문서가 이전 UI 시안 문서의 리절트 배치 설명을 대체합니다.

- 이전 요약 화면, 분석 탭 4개, 배경, 지표와 버튼 위치를 복원합니다.
- 긴 곡 제목은 실제 글자 크기를 측정하여 복원된 제목 영역에 맞춥니다. 사용자 글꼴과 글자 내용을 유지합니다.
- NEW RECORD의 점수 상승 기준/1.2초 연출, 랭크 상승 효과, FULL COMBO 발광, 게이지 전환 그래프 보정은 유지합니다.
- 새 곡 선택 UI, 10 심볼, 폴더 곡 수/방향키, 커스텀 오디오 선택기와 BEST 실시간 비교 수정은 유지합니다.

저장 형식, 기록, 점수·판정·리플레이, 인게임, 멀티플레이는 변경하지 않습니다. 기존 후보와 사용자 설치/프로필은 보존하며 `result-rollback-local` 별도 프로필로 실행합니다. 공개 버전과 고정 기준선 1.9.6은 유지합니다. 별도로 제작한 PPT/배경 영상은 게임에 포함하지 않습니다.
