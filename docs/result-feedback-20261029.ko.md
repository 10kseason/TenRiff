# 인디케이터·리절트 로컬 변경

공개 1.9.9.5의 별도 로컬 후보입니다. 고정 기준선 1.9.6과 공개 버전은 유지합니다.

- 바코드 인디케이터의 이전/최신 입력 막대를 기본 2×18 단위로 통일했습니다. 최신 입력은 밝기로 구분합니다. 점 모양, 색상, 0.7초 수명, 좌표·크기 설정, 플레이어/고스트의 타이밍 계산은 그대로입니다.
- 리절트 요약/분석에서 `GAUGE SHIFT EX CLEAR`는 `EX CLEAR`로 표시합니다. 다른 게이지도 같은 접두어만 제거하며 ASSIST 표시는 유지합니다. 저장 상태와 게이지 색은 바꾸지 않습니다.
- 기존 로컬 공식 BEST가 새로 생기거나 실질적으로 갱신되면 점수 위에 `NEW Record`를 표시합니다. 기존 순서(클리어 등급 → 점수 → 상세 점수/정확도 → 콤보/판정 수)를 그대로 따릅니다. 같은 성적의 최신 저장 시각만으로는 표시하지 않습니다. 새 판정 정책의 첫 유효 기록도 포함합니다.
- 오토플레이·연습·추가 노트·현재 LN Mix 등 기존 BEST 제외 조건을 그대로 따릅니다. 리플레이 재생·과거 결과 열기·저장 실패는 새 기록으로 표시하지 않습니다. 멀티플레이는 자신의 로컬 기록에만 표시하며 상대에게 보내지 않습니다.

세션 표시 플래그만 추가해 파일 형식·점수·판정·리플레이 계약을 유지했습니다. 화면 요약의 점수 제목을 갱신 시 문구로 바꾸어 기존 스킨 배치를 유지합니다. 별도 `result-feedback-local` 프로필을 사용합니다. 물리 입력/실제 두 PC/장시간 플레이/임의 스킨은 미검증입니다.
