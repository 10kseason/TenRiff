# Skin HUD X/Y positioning

Requested on 2026-10-19 and included in 1.9.8, based on published 1.9.7 (`948518d`). The 1.9.7 Common Keys, colored tabs, fresh per-play seeds and scene-music reference gain remain included. The general fixed baseline stays 1.9.6; previous releases, candidates, installations and profiles are preserved.

- Lane Divider Brightness: 0–100%, with a 1% slider and −/+ steps. Default 100% preserves existing color; 0% is black. Only RGB changes, preserving alpha, visibility, width and measure lines. Preview, gameplay and ghost rendering refresh their cache immediately. The optional `skin.lane_divider_brightness` field persists in profiles and portable skins; older files default to 100%.

| Setting | X | Y |
| --- | --- | --- |
| Judgement | −600 to 600px, 10px steps | Existing vertical position ratio |
| Combo | −600 to 600px, 10px steps | Existing vertical position ratio |
| FAST/SLOW Indicator | −600 to 600px, 10px steps | Existing −400 to 400px, 10px steps |
| FAST/SLOW Bar | −600 to 600px, 10px steps | Existing −400 to 400px, 10px steps |

- X/Y controls are adjacent. Native/TenRiff/LR2 support localized search, keyboard left/right and pointer −/+.
- X is an offset from the existing anchor: negative moves left, positive moves right. Each item is independent; changing X preserves stored Y.
- Expose the existing X controls, retaining zero defaults, saved values, profile/portable-skin formats and preview/Classic/Studio/ghost rendering paths. No migration or reset.
- This supersedes hiding these four X controls in the [2026-10-18 policy](skin-ui-followup-20261018.en.md). Gear Boundary and other retired controls remain hidden.
- The judgement line remains attached to the lanes; existing preview field dragging moves its horizontal position with the field.
- Judgement, input, score, replay and audio behavior are unchanged. Automated verification is separate from physical input and extended play.

See the [1.9.8 scope](release-1.9.8.en.md) and [verification gates](release-1.9.8-gate.md). This behavior document does not claim completed verification; publication and downloads follow the [1.9.8 release page](https://github.com/10kseason/TenRiff/releases/tag/1.9.8).

Developer verification: `menu_visual_preview --divider-brightness 0.4` renders a fixed brightness; `--divider-brightness 1 --next-divider-brightness 0 --capture-frames 30,45` checks a same-window update at frame 35. Both flags require finite values in 0..1. The actual static-cache value is emitted in the hit map.
