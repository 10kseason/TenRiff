# TenRiff 1.9.9

1.9.8.5にKeyWeaver 1.3.0のNK2プリセットEと16Kランキング送信を追加します。一般固定ベースラインは1.9.6で、旧リリース・インストール・プロファイルを保持します。

ゲームモード設定で**NK2**と**E - Source LN**を選択します。対象は既存の**4/5/6/7/8/9/10/12/14/16K**のみです。新規設定のNK2プリセットはEですが、保存済みNative/Transform/Remasterと既定アルゴリズムKrrcreamは保持します。増加はEの区間探索と追加タップ/LNを使用し、新規LN全体を一つの原本LN内に収めます。減少は配置と必要な除外のみで、追加や時刻移動は行いません。Fの追加予算は無効です。

原本のサンプル時刻・LN長・キー音・離し判定を保持し、生成ノートはキー音を重複再生しません。独立安全検査や正確なサンプル区間検査の失敗時は警告付きで原本を維持します。内部精度はミリ秒で、実行時の基準BPMを使用します。過去のNK2プリセットは旧エンジンを分離保持し、旧リプレイを再解釈しません。

Eは既存のプリセット項目に`source_ln_e_v1`を保存し、**1.9.9検証器**が必要です。1.9.8.5の補助キー所有権リプレイ検証も含みます。EのOFF/ミラーゴーストは未使用seedの差を許可し、ランダム・ノート追加・LN混合・BMS分岐の検査は保持します。判定・等級・R9/R10・リプレイ形式・peer v7は変更しません。

クライアントとWebで**16K**送信とフィルターを追加します。旧Webの4–14Kと過去11/13Kの読み取りを保持し、15/17Kは拒否します。Eの条件は`nk2:source_ln_e_v1`です。新規送信は正式Online R9/R10のみで、Guest・カスタム・LNMix v2除外と`client_submitted`境界を維持します。DB移行・旧記録の変更・ボードID変更はありません。スキン形式は変更せず、公開Skin Editor v11を維持します。

[検証ゲート](release-1.9.9-gate.md)を参照してください。合成・ローカルAPI検査は物理入力、長時間プレイ、他PC、実アカウントの本番送信の証明ではありません。公開状況と配布は[1.9.9リリース](https://github.com/10kseason/TenRiff/releases/tag/1.9.9)が基準です。
