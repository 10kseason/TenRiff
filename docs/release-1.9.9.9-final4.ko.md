# TenRiff 1.9.9.9-final4

LR2 점수 DB의 클리어 램프를 표시 전용으로 가져오는 `tenriff-lr2-import`를 추가했습니다. LR2 판정 순서를 최악 가정으로 EX-HARD 게이지에 넣어 살아남은 기록만 EX로 표시합니다. 오디오 콜백과 HUD 스레드가 공유하는 잠금에 예방 조치를 넣었습니다. 고정 기준선을 **1.9.9.9-final4**로 올립니다.

## 사용

릴리스 ZIP을 새 폴더에 풀고 `launch_win.bat`을 실행합니다.

### LR2 클리어 램프 가져오기

```
tenriff-lr2-import.exe <LR2 점수 .db> <프로필 폴더> [곡 폴더 ...]
```

LR2 DB는 읽기 전용으로 열고, 결과는 `<프로필 폴더>\lr2_import.json` 하나입니다. 지우면 가져온 램프도 사라집니다. 가져온 램프는 TenRiff 기록보다 높을 때만 선곡 화면에 표시되고, 선택한 곡의 램프 문구에 `LR2 `가 붙습니다. 결과·BEST·온라인 제출 대상이 아니며 점수는 가져오지 않습니다. 릴리스에는 어떤 사용자의 LR2 DB도 포함하지 않습니다. 규칙과 한계: [LR2 클리어 램프 가져오기](lr2-clear-import.ko.md).

### 오디오 콜백 잠금

HUD 스레드가 오디오 콜백과 공유하는 잠금을 쥐는 동안만 우선순위를 올립니다(`TENRIFF_HUD_LOCK_CEILING=0`으로 끔). 오디오 콜백은 창 관리자 조회와 콘솔 출력을 하지 않습니다. 측정에서 수정 전에도 오디오 끊김은 관찰되지 않았으므로 예방 조치이며, 체감·지연 개선은 주장하지 않습니다. `TENRIFF_RT_PROBE=1`로 실행하면 곡이 끝날 때 잠금 대기/보유 시간을 표준 오류에 남깁니다.

## 호환성

판정·점수·게이지 계산, 입력, 리플레이 형식과 R1~R14, peer 프로토콜, 순위 식별자는 final3와 같습니다. 저장된 프로필과 설정은 그대로 읽습니다. 웹 리더보드(v28)와 스킨 에디터(v14)는 변경하지 않았습니다.

## 고정 기준선

일반 소스 기준선은 이 릴리스부터 **1.9.9.9-final4**입니다. [기준선 문서](baseline-1.9.9.9-final4.md).

물리 입력/청취, 장시간, 다른 PC, WASAPI 독점·ASIO에서의 잠금 측정, 임의 사용자의 LR2 DB는 별도 검증입니다. [릴리스 게이트](release-1.9.9.9-final4-gate.md).
