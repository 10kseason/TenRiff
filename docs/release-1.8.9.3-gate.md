# TenRiff 1.8.9.3 변경·검증 범위

1.8.9.2를 출발점으로 한 UI 패치입니다. 고정 문서 기준 1.8.7, 기존 릴리스와 프로필은 유지합니다.

- 리절트: 플레이 점수 116→100, 등급 84→104, 요약 정확도 64→68, 판정 개수 52→46 기본 글자 크기. 스킨 재정의 및 좁은 영역의 텍스트 맞춤은 유지합니다.
- 로비: 플레이 하늘색, 멀티플레이 빨간색, 종료 흰색과 어두운 글자. 옵션 스타일 유지. Bloom은 크기·색이 바뀔 때만 캐시를 생성합니다.
- 키 설정: 편집 키 모드의 스킨 레인 색과 단일 색상을 기본·보조 키에 적용합니다. 색 밝기에 따라 글자 대비를 선택하고 선택 테두리를 별도로 표시합니다.
- 곡 목록: 왼쪽 레벨도 오른쪽 상세 레벨과 같은 보라색입니다.
- 인디케이터: 기존 필드가 true여도 네이티브 판정·FAST/SLOW·타이밍 배경을 그리지 않습니다. 필드는 이전 파일을 읽을 수 있도록 보존하고 기본 false로 둡니다. 외부 스킨 이미지에 직접 그려진 배경은 편집하지 않습니다.
- 스킨 설정: 대상 간격·비주얼 프리셋·인디케이터 배경 행을 제거하고 대상 레인을 노트 색상 바로 위에 배치합니다. 레인 선택이 인접 간격을 같이 선택하므로 기존 간격 편집 데이터는 유지됩니다. 마지막 레인은 마지막 간격을 사용합니다.

1.8.9.2의 BMS 중복 롱노트 시작 보정, 키 변환 버전 3 및 이전 리플레이 경로, R1–R4 판정, 입력·오디오·점수·게이지 계산은 유지합니다. 웹 사이트 배포나 데이터 이전은 포함하지 않습니다.

- 로컬 Release 빌드, CTest 3/3(1121개, integration skip 0), 오프라인 에디터 34/34, 실제 MenuApp·GameSession 합성 입력 검사 220/220을 통과했습니다.

- 초기 창 포커스 검사 실패와 합성 리플레이에 실제 눌린 키가 섞인 실패는 보존했습니다. 검사 도구가 자기 창의 포커스를 기다리고, 독립 세션의 시작 시 직접 키 조회까지 격리하도록 수정한 후 통과했습니다. 제품 입력·리플레이 검증 로직은 변경하지 않았습니다.

패키지 CRC·해시·개인정보 검사, 압축을 푼 소스의 독립 빌드·테스트, PR/main CI와 공개 파일 재다운로드 검증을 릴리스 게이트로 사용합니다. 최종 기록은 릴리스 검증 자료에 남깁니다. 물리 키보드·오디오 지연, 장시간 플레이, 다른 PC와 온라인 실제 제출은 별도 검증 대상이며 이번 패치의 성능 개선이나 엄격한 성능 비퇴행은 주장하지 않습니다.
