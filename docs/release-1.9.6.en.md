# 1.9.6 — Fixed judgement and skin settings

This release continues published 1.9.5.3. The general source baseline **1.9.0**, prior releases, installations and profiles remain preserved. The [1.9.6 release page](https://github.com/10kseason/TenRiff/releases/tag/1.9.6) determines publication and downloads; completed checks belong to the [verification scope](release-1.9.6-gate.md) and separate release evidence.

- Normal PG is fixed at VEZ/EZ 22, NM 19, HD 15 and VHD 10ms. Normal GR/GD/BAD retain their exact existing values. Hard reuses the complete Normal NM row and EX the complete Normal VHD row for every chart RANK. There is no additional scaling or integer-ms rounding. See the [exact table and stored calibration](judgement-baseline-20261018.en.md).
- New Normal/Hard records use R9; EX uses R10. Sites accepts only new standard Online R9/R10 submissions and rejects new submissions under older rules. Existing boards and records remain legacy read-only without recalculation. Guest, unmarked historical, custom and LN Mix v2 exclusions and the `client_submitted` trust boundary remain. The separate Ranked verifier continues to block rules it does not support.
- R1–R8 replays retain their original timing. Peer protocol v7 keeps the packet layout and rejects v6 peers with different windows. Stored `judge.pg=21ms` remains a compatibility calibration; profiles are not automatically migrated.
- Skin Settings places all 14 key modes in one horizontal tab row followed by search. Click a tab or use Ctrl+Tab / Ctrl+Shift+Tab; Ctrl+F focuses search and Tab / Shift+Tab moves between tabs, search and list. Search matches localized labels, values and categories; deletion preserves complete UTF-8 characters.
- Hide Gear Boundary and Judgement, Combo, FAST/SLOW and indicator X controls while preserving stored values. Create Skin, Open Skin Folder and Reload appear only for TenRiff; Imported Skin only for TenRiff/LR2. Original-mode scratch visibility and the 100% divider-width policy remain.
- Keep file drops working after switching to windowed mode. Combo/count overlap moves combo to the nearest fitting side, allowing Combo Y above the indicator in Classic/Studio and player/ghost without changing saved positions. The default album judgement badge is 192×28 design pixels; explicit skin rectangles take precedence. See [detailed behavior](skin-ui-followup-20261018.en.md).

Reusing one Normal timing table and existing settings formats avoids divergent values and loss of hidden settings. Audio, gauge, fixed grades, Empty Poor accuracy policy and BGA-weight exclusion remain. Automated messages/rendering checks are separate from human Explorer dragging, physical IME/input, listening, extended play and other-PC verification.
