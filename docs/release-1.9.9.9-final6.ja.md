# TenRiff 1.9.9.9-final6

[한국어](release-1.9.9.9-final6.ko.md) | [English](release-1.9.9.9-final6.en.md) | [日本語](release-1.9.9.9-final6.ja.md) | [简体中文](release-1.9.9.9-final6.zh-CN.md)

7+1・8Kのキー設定分離、赤いスクラッチ既定色、16レーン間隔の修正に、UnlimitedのVSync処理とタイミングマーカーのキャッシュを加えました。LR2oraja記録、BMS作者指定レベル、高解像度BGAの元フレームに対応します。

- オプション → キー設定と NKRO テストで、7+1 と 8K を個別に選べます。スクラッチと鍵盤 1〜7 には基本キーと補助キーを設定できます。
- 7+1 設定がないプロファイルは現在の 8K 配列を引き継ぎます。旧バージョンでキー設定を保存すると 7+1 専用の設定が失われます。
- スクラッチの既定色は赤です。プロファイルやスキンに保存された色を優先します。
- 14+2 DP と 16K の中央間隔はノートの描画範囲から除きます。通常ノートとロングノートは各ブロック内に描画され、ゴーストにも適用されます。
- `Unlimited`は保存された設定にかかわらずVSyncを無効にし、プレイは最大1500 FPS、メニューは最大300 FPSです。`Match Display`は保存されたVSync設定を適用します。
- 点・バーコードのタイミングマーカーは、履歴が連続フレームで安定するとビットマップをキャッシュします。履歴が変化したフレームは最新内容を直接描画します。
- オプション → プロファイル → スコアDBをインポートからLR2orajaの`player/<profile>/score.db`を選択します。LN/CN/HCNを別々に保存し、選曲で出典・クリア・EX・コンボ・BPを表示します。表示はLN、CN、HCNの順に最初の記録を使います。
- DBのghostはノート別の判定区分を保存します。ms分布の復元には実際の入力時刻を持つ別のリプレイ入力ログが必要です。クリア・コンボ・最小BPは異なるプレイの最高値である場合があります。
- ゲーム内の基本難易度はBMSの`#PLAYLEVEL`を使い、内部計算の設定を削除しました。旧計算キャッシュは次の索引で更新します。外部難易度表を選ぶとその表のレベルを使います。
- 高さ480ピクセルを超えるBGAは元フレームの寸法を使います。画像ONNX処理は高さ480ピクセル以下に適用します。

報告者のPCのFPS・ティアリング、実際の個人DB、物理入力・試聴・長時間プレイは追加確認が必要です。[記録インポート](lr2-clear-import.ja.md)
