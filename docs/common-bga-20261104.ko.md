# 범용 BGA

그래픽 설정에서 **범용 BGA 영상**으로 로컬 동영상을 고르고 **범용 BGA**를 켭니다. 모든 곡의 기본 BGA와 오버레이를 해당 영상으로 대체하며 영상 소리는 재생하지 않습니다. 영상이 끝나면 처음부터 반복합니다. 일시정지와 다시 시작은 게임의 기존 표시 시계를 따릅니다.

기본값은 OFF·빈 경로입니다. 파일 선택만으로 켜지지 않으며 취소하면 기존 선택을 유지합니다. BGA 표시 OFF가 우선합니다. 선택 파일이 없으면 기존 곡 BGA를 사용하며, 선택된 영상이 삭제되거나 디코딩할 수 없으면 기본 배경을 표시합니다. 파일을 바꾸거나 다음 게임을 시작하면 다시 시도합니다. 뒤로 가기로 프로필에 저장됩니다.

기존 BGA 밝기·기어 뒤 BGA·업스케일러 설정을 함께 사용합니다. 선곡 미리보기와 메뉴/리절트 배경은 바뀌지 않습니다. 판정·음원·리플레이·온라인 기록에는 영향을 주지 않습니다.
