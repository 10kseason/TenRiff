# 1.9.6 — 固定判定とスキン設定

公開済み1.9.5.3に続くリリースです。一般ソース基準 **1.9.0** と過去のリリース・インストール・プロファイルを保持します。公開状態とダウンロードは[1.9.6リリースページ](https://github.com/10kseason/TenRiff/releases/tag/1.9.6)、完了した検証は[検証範囲](release-1.9.6-gate.md)と別途保存するリリース証拠で確認します。

- 通常PGはVEZ/EZ 22、NM 19、HD 15、VHD 10msに固定します。通常GR/GD/BADは従来の正確な値を維持します。HardはすべてのファイルRANKで通常NM行全体、EXは通常VHD行全体を再使用します。追加倍率や整数msへの丸めはありません。[正確な表と保存基準](judgement-baseline-20261018.ja.md)を参照してください。
- 新しい通常/Hard記録はR9、EXはR10です。Sitesは標準設定の新規Online R9/R10送信だけを受け付け、旧規則での新規送信を拒否します。既存ボードと記録は再計算せずレガシー読み取り専用で保持します。Guest・出所未記録の過去記録・カスタム・LN Mix v2の除外と`client_submitted`境界は維持します。別のRanked検証サーバーが対応しない規則は引き続き拒否します。
- R1–R8リプレイは当時の判定を維持します。対戦プロトコルv7はパケット配置を保ち、異なる判定幅のv6相手を拒否します。保存`judge.pg=21ms`は互換用の基準値であり、プロファイルを自動移行しません。
- スキン設定の14キーモードを横一列のタブにし、末尾に検索欄を置きます。クリックまたはCtrl+Tab / Ctrl+Shift+Tabで切り替え、Ctrl+Fで検索、Tab / Shift+Tabでタブ・検索・一覧を移動します。現在の言語の項目名・値・分類を検索し、UTF-8文字を途中で切らずに削除します。
- ギア境界線と判定・コンボ・FAST/SLOW・インジケーターのX設定を隠し、保存値を保持します。新規スキン・フォルダーを開く・再読み込みはTenRiffのみ、インポート済みスキン選択はTenRiff/LR2のみ表示します。Originalモードのスクラッチ条件と区切り線幅100%を維持します。
- ウィンドウ切り替え後のファイルドロップを維持します。コンボと判定カウンターが重なる場合は収まる近い側へ避け、コンボYをインジケーターの上にも移動できます。Classic/Studioとプレイヤー/ゴーストで共通とし、保存座標を保ちます。既定のアルバム判定バッジは192×28デザインピクセルで、スキンの明示矩形が優先します。[詳細](skin-ui-followup-20261018.ja.md)。

共通の通常判定表と既存設定形式を再使用し、値の分岐や非表示設定の消失を防ぎます。音声・ゲージ・固定等級・空POOR精度方針とBGAモデル非同梱を維持します。自動メッセージ・描画検査は、人によるExplorerドラッグ、実機IME・入力・試聴・長時間プレイ・別PCの検証とは区別します。
