# 指示条与结算画面的本地修改

此独立候选版本继承已发布的1.9.9.5；固定基线1.9.6及公开版本保持不变。

- 历史和最新条形标记统一为基础2×18尺寸，以亮度区分最新输入。圆点、颜色、0.7秒寿命、位置/缩放以及玩家和影子的时序保持不变。
- 结算摘要及分析将 `GAUGE SHIFT EX CLEAR` 显示为 `EX CLEAR`。其他血条也仅移除相同前缀，保留ASSIST。保存状态和颜色不变。
- 首个有效本地BEST或按现有顺序（通关等级、分数、详细分数/准确度、连击/判定数）实质提升时，在分数上方显示 `NEW Record`。仅保存时间更新的同成绩不触发。新版判定策略的首个有效记录也包括在内。
- 保留自动演奏、练习、增加音符、当前LN Mix等现有排除条件。回放、历史结算和导出失败不显示。多人模式仅标记自己的本地记录，不新增网络数据。

只增加会话显示标志，复用分数标题位置，保持文件格式、计分、判定、回放协议及皮肤布局。使用独立result-feedback-local配置。实体输入、双机对战、长时间及任意皮肤尚未验证。
