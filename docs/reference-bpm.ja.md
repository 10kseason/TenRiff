# 基準 BPM

[English](reference-bpm.md) · [한국어](reference-bpm.ko.md) · [简体中文](reference-bpm.zh-CN.md)

選曲表示と Hi-Speed は、進行時間の合計が最も長い BPM を基準にします。同じ BPM の区間を合計し、ノーツ数や拍数では選びません。STOP の待機時間は除外し、SCROLL は重みに影響しません。同率なら先に進行した BPM を使います。

譜面の先頭から、非ゼロのイベントがある最後の小節の末尾まで集計します。LN 終点や BGM・背景イベントも含みますが、その後の長さ指定（`02`）のみ、または全て `00` の空小節は除外します。これにより Andro の末尾の 0.99 BPM と空小節が基準の 165 BPM を置き換える問題を修正します。

ノーツ時刻、譜面の長さ、スクロール区間、既存リプレイのタイミングは変えません。初期 BPM はリプレイとキー/LN 変換用に保持します。サンプル丸め前に計算するため、Safe/Fast の索引と各音声サンプルレートで基準が一致します。

索引キャッシュのバージョン 22 は以前の派生メタデータを一度再構築します。プレイ記録は保持します。有効な進行区間がなければ初期 BPM、不正なタイムラインでは 0 を返します。
