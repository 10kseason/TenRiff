# 설정 사용성과 오디오·화면 기준 수정

## 오디오와 화면

화면의 노트와 BGA는 오디오 장치의 실제 재생 위치를 기준으로 움직입니다. 이전에는 아직 장치 버퍼에 남아 있는 소리까지 포함한 쓰기 위치를 사용하여, 버퍼 크기에 따라 화면이 소리보다 앞설 수 있었습니다. 콜백 시작 시각과 재생 위치를 함께 전달하며, 판정과 오디오 예약은 기존 쓰기 위치를 유지합니다. 타이밍 전달 자료는 원자적 필드와 시퀀스 검사로 읽어 추가 오디오 콜백 잠금을 만들지 않습니다.

디스코드 방송 수신 화면에서의 최종 싱크는 송출·수신 환경에서 별도로 확인해야 합니다. 이 수정의 자동 검사는 44.1/48kHz 콜백, 버퍼 대기량 변화와 동시 HUD 읽기 범위를 다룹니다.

노멀라이즈를 끄면 노멀라이저와 소프트 리미터를 모두 건너뜁니다. 마스터 볼륨을 선형 적용한 최종 출력이 ±1을 넘을 때만 잘라내며, 유효 범위 안의 파형은 압축하지 않습니다. 노멀라이즈를 켜면 기존 자동 음량·소프트 리미터 경로를 사용합니다. 창 비활성화 음소거는 출력만 막고 곡 위치와 저장 음량을 유지합니다. 최초 음량 기본값은 70%이며 저장된 값은 바꾸지 않습니다. ASIO 화면의 버퍼 사이즈 단위는 채널당 샘플입니다.

## 키와 스킨

키 설정은 가로 건반의 `Key 1`부터 표시하며, 기본 키와 보조 키를 각각 지정합니다. 6K·8K·10K는 중앙에 간격을 둡니다. 5K와 원본 BMS의 실제 키 수를 포함한 각 모드에서 두 키를 사용할 수 있고, 마지막으로 눌린 입력까지 놓아야 해당 건반이 해제됩니다. 따라서 기본 키에서 보조 키로 롱노트를 이어 잡을 수 있습니다. 키·스킨 편집은 옵션에서 처음 열 때 4K이며, 곡에서 키 설정을 열면 해당 차트의 키 수를 사용합니다.

키를 누를 때 깔리는 배경색은 켜기·끄기와 0–100% 밝기를 제공합니다. 타격 효과 밝기와 별도 설정입니다. 처음 변경하기 전에는 가져온 스킨의 기본값을 따르고, 이후에는 프로필 설정이 우선합니다. 판정선 두께는 노트 높이 비율을 따릅니다. 스킨 미리보기는 실제 인게임 그리기 경로를 균일하게 축소하여 크기·위치·비율을 맞춥니다.

콤보와 판정 글자 크기는 `판정·HUD` 그룹에서 각각 50–200%로 조절합니다. 기본값은 100%, 키보드와 `−/+`는 5% 단위이며 마우스 슬라이더도 지원합니다. 각 스킨의 글자 크기에 프로필 배율을 곱하므로 가져온 스킨에도 적용하고, 스킨 파일의 기존 글자 크기는 보존합니다. `비주얼 레이턴시`는 스킨 종류와 관계없이 다섯 번째 설정 항목이며 스킨·파일 그룹에 표시합니다.

홈·곡 선택·옵션·설정·키 설정·결과·도움말·채팅·계정·BMS 편집기와 인게임 HUD에 공통 글자 외곽선을 적용합니다. 성능 표시, 말줄임표 제목과 페이지 도움말의 별도 그리기 경로도 포함합니다. 밝은 글자는 얇은 어두운 테두리, 어두운 버튼 글자는 밝은 테두리를 사용하며 원래 글자 색·투명도·정렬·줄바꿈은 유지합니다. 기본 보조 글자 색은 조금 더 밝게 표시하고 가져온 스킨의 지정 색상은 보존합니다. 로고의 장식용 그림자와 색 번짐에는 테두리를 중복하지 않습니다. 스킨 에디터의 게임 미리보기도 모든 글자에 외곽선을 표시합니다.

글자 레이아웃은 메뉴 최대 384개, 게임과 스킨 미리보기 각각 최대 96개의 캐시에 재사용합니다. 정렬·줄바꿈·말줄임표·줄 간격 변화와 글꼴 교체를 캐시에 반영합니다. 메뉴 글자 크기는 인게임 HUD 크기에 영향을 주지 않습니다.

BMS 편집기의 단축키 안내는 폭이 좁은 오른쪽 영역과 겹치던 한 줄 대신, 화면 전체 폭의 두 줄로 나눠 지나치게 작은 글자와 겹침을 줄입니다.

전체 BGA를 덮던 암막 필터를 제거하여 BMP·JPG·PNG, 투명 레이어와 영상 배경은 원래 밝기로 표시합니다. 검정 필드, 레인 배경과 기어는 기존 설정대로 유지하므로 BGA 밝기 변화가 노트 영역의 가림 설정을 해제하지 않습니다.

해상도 선택은 1600×900·1366×768, 16:10과 울트라와이드를 포함합니다. 명시적인 `가로x세로` 값은 저장되며, 창 모드에서는 작업 영역에 같은 비율로 맞춥니다.

## 마우스와 곡 목록

비슷한 설정은 소제목으로 묶습니다. 소제목은 선택 항목에 포함하지 않습니다. 버튼·슬라이더 입력은 정렬이나 묶음 순서에 의존하지 않는 항목 ID를 사용합니다. 넓은 행 클릭 영역보다 `−/+`와 슬라이더 영역을 우선하여, 버튼을 눌렀는데 행 선택으로 처리되던 문제를 해결합니다. 가져온 메뉴 스킨에서도 스킨 설정 도움말을 페이지로 나눠 긴 안내가 설정 목록을 밀어내지 않게 합니다. 속도 값이 실제로 변경되면 클릭음을 재생합니다.

빠른 설정과 옵션 안내에는 ALL SONG 및 스킨 설정 팁을 표시합니다. ALL SONG에서 난이도표를 선택하면 표에 해당하는 차트만 표시합니다. `Native LV`로 돌아가면 전체 목록을 표시하며, 원본 폴더와 캐시는 변경하지 않습니다.

## 검증 범위

Release 빌드와 CTest, 스킨 에디터 테스트, 실제 렌더러 캡처 및 실제 버튼 좌표 판정 함수를 검사합니다. 활성 창을 얻지 못하는 검증 환경에서는 좌표 판정과 OS 입력 전달 결과를 별도로 기록합니다. 실제 디스코드 방송, 실장치 ASIO 재생과 사람이 마우스로 조작하는 전체 흐름은 자동 검사 결과로 대체하지 않습니다.
