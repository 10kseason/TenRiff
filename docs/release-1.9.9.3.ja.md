# TenRiff 1.9.9.3

実プレイHUDの`EX`と旧プレビューの`EX-HARD`を共に認識します。EXがNM黄に落ちる問題を修正し、プレビューも実際の`EX`表記を使います。

公開済み1.9.9.1に2026-10-27のローカル変更を統合します。一般固定基準は **1.9.6** のままです。公開状態と配布物は[リリースページ](https://github.com/10kseason/TenRiff/releases/tag/1.9.9.3)を参照してください。

## 変更

- 新規ノート速度キーはF1減少 / F2増加。保存済みキー設定は維持します。ロビー・ゲーム内の速度と表示レイテンシーは長押しで調整が加速し、解放・フォーカス変更で反復状態をリセットします。
- セッションミックスは選曲に似たLR2CRSコース一覧を提供します。コースを選び、重複ステージも含めた元の順序で再生します。欠落ファイルは開始を阻止します。自動ミックスは同じ音楽の差分重複を減らし、準備・挑戦・終了の流れを選び、プレビューと開始時の一覧を一致させます。
- スキン設定のキーオーバーレイは初期OFF、ON/OFFとX/Yを保存します。4/5/7/8/10Kのみキー・ホールド・KPSを表示します。入力は容量制限付きキューにコピーし、別ワーカースレッドで集計します。BMS全体をロード中に解析し、代表難易度を大きく固定表示します。実力やクリア確率ではなく、実測遅延/FPS向上も未検証です。
- 選曲カード枠とジャケット左上のロゴバッジはEZ緑、NM黄、HD赤、EX虹色です。全バッジはEXと同じ書体・太さを使い、Shift Startも同色です。読み込んだロゴのアルファ形状と旧ロビーにも配色します。
- EXゲージは保存された`gauge_ex_hard`単色指定より虹色を優先します。他ゲージの明示色と元スキン・画像は維持します。標準TenRiffロゴを拡大します。
- ランク色はS+/S++/S+++虹、S赤、A+/A黄、B/C/D緑、E/F薄紫`#C2A0FF`。AUTO/--は中立色です。

## 互換性と検証

丸め前の精度閾値S+++≥99%、S++≥98%、S+≥97%、S≥95%、A+≥93%、A≥90%、B≥85%、C≥80%、D≥70%、生存E/ゲージ失敗Fは不変です。Normal PG22/19/15/10ms、Hard=Normal NM行全体、EX=Normal VHD行全体、R1–R10、peer v7、LN Mix v1/v2/v3、NK2 Eを維持します。Guest/カスタム除外とclient_submittedも不変。Web・DB・公開スキンエディターは配信しません。

ローカル候補と新バージョンの検証を区別し、[リリース検証](release-1.9.9.3-gate.md)に従います。物理入力、OBS、長時間プレイ、別PC、任意スキン、実際の2台対戦、実アカウント送信は未検証です。新しいフォルダーに展開して`TenRiff.exe`を実行し、既存環境を保全します。
