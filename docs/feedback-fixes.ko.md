# 1.8.4 사용자 피드백 수정

1.8.4에 포함되는 사용자 피드백 수정입니다. 앞서 제공한 로컬 feedback-r1/r2 변경을 함께 포함합니다. [릴리스 검증](release-1.8.4-gate.md)을 참고하세요.

## 마우스와 일시정지

설정의 글자·빈 공간을 클릭하면 해당 행을 선택하고 설명을 표시합니다. 조절 가능한 행은 `−`·`+` 버튼 또는 슬라이더 트랙을 클릭해야 값이 바뀝니다. 실행용 행은 클릭으로 실행하며 키보드 Enter 동작은 유지합니다. 모드 설정·모드 관리자에서 글자를 눌렀을 때 뒤로 가던 경로도 차단합니다.

일시정지 화면의 계속하기·재시작·나가기와 판정선·스크롤 속도·비주얼 레이턴시 `−`·`+`를 클릭할 수 있습니다. 일시정지 중에는 커서를 표시합니다. 버튼은 화면에 그린 사각형과 같은 영역으로 판정하고, 계속하기는 기존 재개 카운트다운을 거칩니다.

| 단축키 | 동작 |
| --- | --- |
| F3 / F4 | Hi-Speed 미세 조절 |
| Shift+F5 / Shift+F6 | Hi-Speed 반감 / 배증 |
| F7 / F8 | 비주얼 레이턴시 감소 / 증가 |
| Shift+F8 | 인게임 채팅 열기 / 닫기 (메뉴에서는 F8) |

F5/F6 단독 입력은 큰 속도 변경을 일으키지 않습니다. 채팅·계정 오버레이가 열려 있을 때 F8은 닫기로 동작하며 레이턴시를 바꾸지 않습니다. 비주얼 레이턴시는 화면 표시 시점이며 판정 범위를 바꾸지 않습니다.

## 페이스메이커와 기록

페이스메이커는 플레이 중 목표 대비 차이를 표시하는 보조 정보가 됩니다. 정확도 모드는 현재 정확도와 목표의 차이를 `%p`로 표시합니다. 점수 모드는 `최종 목표 점수 × 판정된 노트 가중치 / 전체 노트 수`를 현재 목표 페이스로 계산하고, 현재 점수와의 차이를 표시합니다. LN 머리·꼬리는 기존 가중치를 사용하며 곡의 무음·후주 길이는 목표 페이스를 왜곡하지 않습니다.

일반 게이지 실패와 점수 계산은 그대로 적용됩니다. 목표 미달 자체가 정상 클리어를 실패로 바꾸지 않으며, 다른 정식 기록 조건을 충족하면 내 최고 기록·랭킹에 반영됩니다. 기존의 무실패 페이스메이커 기록은 `custom`으로 남겨 새 기록의 자격을 소급 적용하지 않습니다. 웹 랭킹은 기존과 같이 클라이언트 제출 방식이며 서버의 리플레이 재검증을 새로 추가한 것은 아닙니다.

## 오토스크래치

`모드 관리자 > Auto Scratch`를 켜면 BMS에 실제 스크래치로 지정된 레인만 자동으로 누르고 뗍니다. 키음과 롱노트도 처리하고, 일반 키 레인은 직접 입력합니다. 실제 스크래치가 없는 배치의 키를 임의로 자동 처리하지 않습니다.

연습용 보조 기능이므로 **점수 배율 0%, 공식 최고 기록·클리어 램프·랭킹 제외**입니다. 로컬 플레이 이력과 리플레이는 남고 `ASSIST AUTO SCRATCH`로 구분합니다. 자동 입력도 리플레이에 기록하며 물리 스크래치 입력으로 중복 판정하지 않습니다.

`오토스크래치 레인 숨기기`는 오토스크래치가 켜져 있을 때만 조절할 수 있습니다. 스크래치 열을 숨겨도 나머지 키의 폭과 원래 입력 레인 번호를 유지합니다.

## 고스트와 스킨

고스트 배틀에서도 플레이어 필드는 솔로 플레이와 같은 크기 설정을 사용합니다. 고스트 필드는 남는 공간에 맞추며, 플레이어의 레인·노트 크기와 세로 진행 비율을 고스트 때문에 축소하지 않습니다.

1.8.4에 포함한 후속 수정에서는 실제로 적용되지 않던 DXGI 프레임 대기열 제한을 수정하고, 긴 LN 때문에 지난 노트를 매번 다시 검색하던 HUD 경로를 개선합니다. 변경 이유와 측정 범위는 [고스트 배틀 지연 수정](ghost-latency.ko.md)을 참고하세요.

LN 몸통 불투명도는 0–100%를 선형 적용합니다. 기존 렌더러의 중간값 상한과 추가 증폭을 없애 100%, 50%, 45%, 0%가 각각 다른 결과를 냅니다. 게임·스킨 미리보기·오프라인 에디터에서 같은 범위를 사용합니다. 전체 비주얼 불투명도와 원본 이미지 알파도 최종 결과에 함께 반영됩니다.

현재 키 모드에서 지원하지 않는 설정은 회색으로 표시하고 조작 버튼을 비활성화합니다. 행을 선택하면 설명은 볼 수 있습니다. 스크래치 좌우 위치는 7+1에서, 16K 중앙 간격은 16K에서 사용할 수 있습니다. `TenRiff 전용` 폴더 열기·새로고침은 새 스킨을 만들거나 `skin.json` 폴더를 가져온 뒤 스킨 소스와 해당 스킨을 선택하는 방법을 설명합니다.

## 프리셋과 버전 간 설정 이전

- `스킨 > 스킨 프리셋 내보내기`: 스킨 설정과 사용 중인 스킨 에셋을 `.trskin`에 저장합니다. 키 설정·오디오 설정은 이 형식에 포함되지 않습니다.
- `프로필 > 전체 설정 내보내기`: 키 배치(기본·보조 키), 오디오·입력·화면·모드 설정, 현재 스킨과 에셋을 `.trprofile` 하나로 저장합니다.
- 다음 버전에서 `프로필 > 전체 설정 가져오기`로 `.trprofile`을 선택합니다. 가져오기 전에 현재 `config.json`·`keymap.json`을 프로필의 `settings-backups/before-import[-N]`에 백업합니다.

파일 선택 창 오류는 화면에 표시하며, 확장자를 생략한 저장에는 올바른 확장자를 붙입니다. 내보내기에서 같은 이름을 선택하면 번호를 붙인 새 파일로 저장하고 실제 저장 경로를 표시합니다. 기존 내보내기 파일을 덮어쓰지 않습니다. 한글 경로도 UTF-8 경로 변환을 거쳐 읽고 씁니다.

가져오기는 파일 크기·체크섬·JSON·내장 스킨을 임시 폴더에서 검증한 뒤 적용합니다. 계정·인증 파일, 곡 라이브러리·플레이 이력 경로, 프로필 사진과 외부 ONNX 모델 파일은 내보내지 않습니다. 가져오는 버전의 해당 로컬 설정을 유지합니다. 내보내기 파일은 새 버전에서 가져오는 용도이며, `.trprofile` 기능이 없는 이전 버전은 이 파일을 열 수 없습니다.

현재 패키지의 프로필은 여전히 로컬 `profiles/<name>` 폴더에 저장합니다. `.trprofile` 내보내기가 없는 1.8.3에서 처음 옮길 때는 게임을 종료한 뒤 기존 `profiles` 폴더를 새로 압축 해제한 수정본에 복사하면 키 설정과 프로필을 유지할 수 있습니다. 원래 폴더는 백업으로 남겨 둡니다. 자동으로 전역 프로필을 덮어쓰거나 계정을 옮기는 동작은 추가하지 않습니다.

## 검증

회귀 테스트는 설정 행 클릭, 실제 판정 루프의 일시정지·단축키, 페이스메이커의 점수·기록 자격, 스크래치 LN·키음·리플레이, 한글 경로 설정 저장·재로딩·손상 거부를 다룹니다. 렌더 픽스처는 솔로/고스트의 필드 크기와 LN 불투명도, 일시정지 클릭 영역을 확인합니다. 물리 입력·실제 오디오 장치·장시간 플레이와 OS 파일 선택 창의 수동 조작은 별도 확인 대상입니다.
