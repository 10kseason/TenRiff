# 곡 선택·기록·오디오 선택 수정 · 2026-11-03

이 로컬 후보는 앞선 UI 시안 후보를 그대로 이어받아 실제 사용에서 확인된 문제를 수정합니다.

- 곡 커버가 없을 때의 TR 표시는 제공된 10/파형 로고에서 추출한 투명 심볼로 대체합니다. 실제 곡 이미지와 사용자 스킨 로고는 유지하며 심볼은 기존 표시색으로 그립니다.
- 오디오 사용자 파일 선택기는 메뉴 음악이 사용하는 MTA와 분리된 요청별 STA 스레드에서 실행합니다. MP3/OGG/WAV/FLAC 선택·저장 흐름을 유지하고 취소는 설정을 바꾸지 않습니다. 열기 오류는 화면에 안내하며 선택 종료 후 입력 잠금을 해제합니다.
- 난이도 레벨/라이브러리 폴더는 점수 대신 저장된 곡 수를 표시합니다. 빈 폴더는 0이며 실제 곡의 미플레이 -- 표시는 유지합니다. 곡 목록 상단/상세의 입력 백엔드 문구만 제거합니다.
- 폴더 목록에서 오른쪽은 열기, 왼쪽은 기존 뒤로 동작입니다. 레벨 내부는 기존대로 좌우 모두 레벨 목록으로 복귀하고 검색·빠른 설정의 키 동작은 유지합니다.
- 기록/리절트 제목은 실제 DirectWrite 줄 높이와 폭을 측정해 기존 영역에 전체 문자열이 들어갈 때까지만 축소합니다. 기존 글꼴·문자·지표를 유지하며 인접 상세 점수/정확도도 같은 방법으로 겹침을 막습니다. 측정 결과는 캐시해 매 프레임 다시 만들지 않습니다.

판정·점수·기록 저장 우선순위·리플레이·게이지 계산·인게임 오디오 스레드는 변경하지 않습니다. 설치/원본/이전 후보를 보존하며 별도 ui-fixes-local 프로필로 실행합니다. 공개 버전과 고정 기준선 1.9.6은 유지합니다.

일시정지 사용 기록도 로컬 BEST로 인정되는 기존 정책에 맞춰 실시간 비교에서 사용할 수 있도록 합니다. 현재 플레이를 일시정지한 뒤에도 비교기를 영구 비활성화하지 않습니다. 리플레이는 정지 시간을 뺀 곡 시점으로 재생하며, 비교값만 변한 경우도 HUD 갱신에 포함합니다. 온라인 제출 기준은 변경하지 않습니다.
