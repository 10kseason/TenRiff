# TenRiff 1.9.5 — 音乐输出统一与判定指示器

菜单和结果音乐也使用声音选项中选定的设备。FAST为蓝色，最高判定为绿色，LATE为红色；最高判定也会更新FAST/SLOW。选曲循环为OFF → 镜像 → 随机 → S随机 → 固定搓盘随机 → OFF。

- 用现有AudioThread和解码器替换MCI，使菜单/结果音乐使用选定WASAPI设备或ASIO驱动。菜单在相同设备上使用共享模式，游戏的独占设置保持不变。设备缺失时不自动切换；保留音量、场景曲目轮换和失焦静音。
- 在菜单和音频回调外异步解码，空闲菜单也检查完成状态。试听、游戏和编辑器打开前释放原输出；过期编辑器任务不会在练习/结果页开始播放。设置调整点击音仍使用Windows默认路径。
- 蓝/绿/红范围使用玩家和幽灵各自实际的采样级最高判定边界。范围内或获得最高判定的点/竖线（含最新标记）均为绿色。条件显示也显示最高判定；保留每个标记0.7秒到期和常显刻度。
- 最高判定也更新FAST/SLOW；四舍五入到整数毫秒为0时清除旧文字。条件文字持续0.75秒，常显模式保留最新值。不改变分数、判定窗口或回放计算。
- 随机顺序如上，反向也对应。rr只改显示名称，保留算法、保存令牌、种子及回放含义。韩语关闭值统一显示OFF。
- 保留1.9.4缓存延迟回收、速度倍率、按键设置、小节线对齐，以及固定基线1.9.0、旧发布/配置、Guest排除、评级、R7/R8及旧回放、不附带BGA模型和OFF/空/Auto默认值。
