# NK2 E 로컬 이식 후보

1.9.8.5 소스를 바탕으로 KeyWeaver 1.3.0의 E Source LN을 이식했다. 공개 릴리스나 일반 고정 기준선 변경이 아니다. 게임 모드 설정에서 키 컨버터 NK2와 `E - Source LN`을 고른다. 새 설정의 NK2 프리셋 기본값은 E이며, 기존에 저장한 Native/Transform/Remaster 선택은 보존한다. 키 모드 원본과 다른 변환 알고리즘의 선택은 유지한다.

출력은 기존 메뉴의 **4·5·6·7·8·9·10·12·14·16K**다. 11·13·15K 메뉴는 추가하지 않았다. 같은 키 수와 원본 선택은 원본 배치를 유지한다. 키 수 감소는 구간 탐색으로 배치하고 수용할 수 없는 노트를 제외하며 노트를 추가하거나 시각을 이동하지 않는다. 증가는 E의 추가 탭/LN 단계를 사용한다. 생성 LN 전체는 유효한 원본 LN 한 개의 시작~끝 안에 들어가야 하며, 원본 LN이 없는 구간에는 새 LN이 없다. F의 추가 예산은 사용하지 않는다. DP는 E의 전체 필드 탐색을 사용하며 스크래치 제외와 키음 보존 정책은 기존 런타임을 따른다.

남겨진 원본의 샘플 시각, LN 길이, 키음과 릴리스 판정을 보존한다. 생성 노트는 별도 식별자를 갖고 키음을 중복 재생하지 않는다. 제외된 원본의 키음은 기존 보존 경로를 따른다. 독립 충돌/연타/LN 검사와 정확한 샘플 구간 검사를 통과해야 E 결과를 사용한다. 실패하면 경고와 함께 원본 배치를 유지한다. 엔진의 내부 시간 해상도는 밀리초이며 밀리초 반올림 후 길이가 0이 되는 LN은 안전하게 표현할 수 없어 거부한다. 구간 길이에는 런타임이 제공하는 기준 BPM을 사용한다.

E는 기존 리플레이 필드에 `source_ln_e_v1`로 저장한다. 예전 Native/Transform/Remaster 엔진은 별도로 보존하여 과거 리플레이를 재해석하지 않는다. E 리플레이는 이 후보에 포함된 새 검증기를 사용한다. R9/R10, 판정/등급, 리플레이 형식 버전은 변경하지 않았다. Sites 요청은 `nk2:source_ln_e_v1`로 별도 조건을 식별하며 `client_submitted` 경계를 유지한다. Krrcream/NK3에는 E 기본값이 적용되지 않으며 기존 기록 식별자를 유지한다.

검증 결과와 남은 범위는 후보 폴더의 `evidence/VERIFICATION.ko.md`에 기록한다. 합성 입력 검사와 실제 플레이 감각, 물리 입력, 실제 계정 업로드는 서로 다른 검증이다.

Sites는 기존 정책상 14K까지만 허용하므로 16K 기록은 로컬에 보존된다. 16K의 변환과 리플레이 검증은 지원한다.
