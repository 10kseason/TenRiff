# EX香槟金渐变

EX六色调色板改为**静态香槟金渐变**。根据用户追加要求，初始纯色`#D6B77A`改为更浓郁的**基础色`#E7BA68`**，HSV饱和度约从43%提高到55%。色带为`#BA8B43` → 基础色 → `#FFE3A6` → 基础色，保持金色色相，不混入紫色或其他色系。保留已有轮廓、辉光及透明度。

应用于EX/EX-HARD的Classic/Studio、玩家/幽灵血条、EX通关轮廓/标志/徽章、Shift Start及共享EX色板的S+/S++/S+++与旧等级别名。旧Gauge Shift EX结果色和离线编辑器默认值也统一。保留已有EX语义颜色覆盖规则。

EZ/NM/HD、其他等级、轨道颜色及ALL COMBO图片和黄色辉光不变。继承之前的简约长音符、ALL COMBO及BGA恢复更改；判定、输入、音频、分数、回放、FPS均不变。

共享绘制色带使用4个stop，保留缓存、几何、透明度和保存设置。最终候选取代以前六色/彩虹及初始完全纯色描述。最终文件在`dist-final`，初始纯色`dist-local`保留。未发布本地候选，使用独立`ex-gold-local`配置；一般基线1.9.6、已发布1.9.9.3及以前候选/安装保持不变。
