# TenRiff 1.9.9.9-hotfix3

- **NK2 E+**를 7K, 8K, 10K에서 사용할 수 있습니다. 옵션 → 모드에서 대상 키 수와 NK2를 고른 뒤 **E+ - Full-field + taps**를 선택하세요. 지원 키 모드로 돌아오면 E+ 선택을 복구하며, 유지된 롱노트 끝에 추가되는 탭은 원래 샘플 시점을 사용합니다.
- **Safe 인덱싱**은 차트의 파싱과 파일 해시에 같은 읽기 결과를 사용하고, 계산한 타임라인을 NPS와 난이도에 재사용합니다. 합성 12,000차트의 초기 인덱싱 중앙값은 10.898초에서 8.501초, 캐시 재열기는 3.414초에서 3.042초로 줄었습니다.
- **곡 폴더 추가** 버튼을 라이브러리 탭 아래에 배치했습니다. Windows 폴더 선택기는 선곡 화면에서 바로 열립니다. 제목과 아티스트 정렬은 A-Z와 Z-A로 표시합니다.
- **텐리프 리더보드**로 온라인 기록 조회와 제출을 통합했습니다. F10에서 Online을 선택하고 공식 웹사이트의 연결 정보를 붙여넣거나 연결 파일을 불러오세요. 게임에서 R13/R14와 E+ v1·v2 보드를 조회할 수 있습니다. 멀티플레이는 LAN 검색과 직접 피어 접속을 지원합니다.

Windows ZIP을 새 폴더에 풀고 `launch_win.bat`으로 실행하세요. 기존 설치와 프로필은 따로 보관하세요. 고정 기준선은 **1.9.6**입니다.
