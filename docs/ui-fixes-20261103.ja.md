# 選曲・記録・音声選択の修正 · 2026-11-03

UI案候補を継承するローカル修正版です。画像なしのTR表示を提供ロゴの10・波形の透過シンボルに変更し、実際の曲画像とスキンロゴは維持します。フォルダーには曲数（空なら0）を表示し、選曲画面の入力バックエンド表示を除きます。

フォルダー一覧では右で開き、左で既存の戻る動作を実行します。レベル内では左右ともレベル一覧へ戻ります。結果の長い曲名と詳細数値はDirectWrite実測値で全文を領域内に収め、既存フォントと指標を維持します。レイアウトはキャッシュします。

MP3/OGG/WAV/FLACの選択はメニュー音声のMTAから分離した要求ごとのSTAで実行します。取消時は設定を変更せず、エラーを表示し、終了後に入力を解放します。判定・得点・記録優先順位・リプレイ・ゲージ計算は不変です。専用ui-fixes-localプロファイルを使用し、以前の候補と基準1.9.6を保存します。

一時停止を使用した有効なローカルBESTも比較に利用します。現在のプレイを一時停止しても比較を永続的に無効にしません。停止時間を除いた曲内サンプルで比較し、比較値だけの変更もHUD更新に含めます。オンライン提出条件は変更しません。
