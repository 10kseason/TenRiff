# TenRiff 2.0.2

[한국어](release-2.0.2.ko.md) | [English](release-2.0.2.en.md) | [日本語](release-2.0.2.ja.md) | [简体中文](release-2.0.2.zh-CN.md)

修复多人稳定性并接通在线全体聊天。

- 多人模式保留当前选定的完整单人皮肤和HUD。对手信息放入侧边空白处；空间不足时仅隐藏辅助卡片。
- 仅在本地谱面与服务器确认一致后显示哈希检查完成。开始和结束等待期间将轮询间隔从500ms缩短到250ms，并复用HTTPS连接。
- 修复最终成绩位置落后于最近实时更新而导致结果同步停滞的问题。
- 连接在线账号后，可在主页、选曲、选项、游戏、结果和多人界面按F11使用同一全体聊天。新版UI仅使用全体聊天，无需加入房间或上传成绩。

包含2.0.1的较暗选项背景、缩小15%的卡片及单行提示。判定、计分、回放、保存格式和final4兼容基准保持不变。全体聊天属于用户明确要求的2.0.2范围；2.0.0之后的维护政策继续适用。
