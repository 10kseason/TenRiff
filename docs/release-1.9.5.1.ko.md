# TenRiff 1.9.5.1 — 판정선·FAST/SLOW·파일 선택창

판정선 타입 1/2를 스킨 설정에서 선택합니다. 타입 1이 기본이며 타입 2는 정타 노트가 초록색 영역 안에 들어오도록 표시만 정렬합니다. 이미지 비율·회전·노트 모양, 롱노트, 고스트와 마디선을 반영합니다. 판정 시간·점수·게이지·리플레이 규칙은 유지합니다.

FAST/SLOW는 마지막 최대판정 범위 밖 입력부터 0.35초 동안 남습니다. 최대판정을 쳐도 즉시 지우지 않고, 최대판정 연타가 표시 시간을 연장하지도 않습니다. 그 전에 새 범위 밖 판정이 나오면 즉시 새 값으로 바뀝니다. Always 모드의 범위 막대와 0.7초 점/바코드 수명은 그대로입니다.

사진·폴더·모델·프로필 등의 파일 선택창은 매번 새 객체를 만들고, 겹친 명시적 요청은 앱이 연 이전 선택창을 취소합니다. 중첩 교체는 한 번만 허용해 재귀적인 창 생성이 반복되지 않게 합니다. 게임 창만 소유 창으로 사용하며 종료 뒤 활성 상태를 복원합니다. 일부 선택 경로의 COM 객체 해제 순서를 바로잡고, 창 안에서 발생한 오래된 입력을 버립니다. Windows 탐색기 프로세스나 사용자가 따로 연 창을 종료하지 않습니다.

새 마스터 기본 음량은 30%이며 기존 저장값은 유지합니다. 기본 곡 라이브러리를 넓히고 중앙 최고 기록 글자를 약 79%로 줄였으며, 앨범아트 배지는 `판정난이도 : EZ` 형식으로 표시합니다. 사용자 지정 로비 좌표는 유지합니다.

1.9.5의 출력 장치, 랜덤 순서, 프로필 키, 메모리 정리 시점, ONNX/Safetensors, Guest 제외 및 기존 리플레이 호환을 포함합니다. BGA 가중치는 동봉하지 않으며 OFF/빈 경로/Auto와 기존 NK3 모델은 유지합니다. 고정 기준선은 1.9.0입니다. 웹·DB 변경은 없습니다.
