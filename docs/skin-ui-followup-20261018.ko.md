# 창모드 드롭과 스킨 설정 후속 작업

1.9.6에 포함된2026-10-18 후속 변경입니다. 이전 로컬 후보와 공개1.9.5.3, 설치·프로필 원본을 보존합니다. 현재 공개 상태는 [릴리스 안내](release-1.9.6.ko.md)를 따릅니다.

- 창모드로 전환할 때 사라지던 파일 드롭 허용 플래그를 유지한다. 기존 BMS 파일/폴더 드롭 처리와 파일 대화상자 수명은 유지한다.
- 스킨 설정 상단에 지원 키 모드를 가로 한 줄 탭으로 표시한다. 끝의 검색창은 현재 소스에서 보이는 설정을 검색한다. 키 모드별 저장값은 기존 방식을 유지한다.
- 탭 클릭 또는 Ctrl+Tab / Ctrl+Shift+Tab으로 키 모드를 바꾼다. Ctrl+F로 검색창을 선택하고, Tab / Shift+Tab으로 탭·검색창·설정 목록 사이를 이동한다. 검색은 현재 언어의 항목명·값·분류를 사용한다.
- 기어 경계선, 판정 X, 콤보 X, FAST/SLOW X, 인디케이터 X 설정을 숨긴다. 저장값을 삭제하거나 초기화하지 않는다. [후속 정책: 네 X 설정의 숨김을 대체함](skin-xy-20261019.ko.md).
- 새 스킨 만들기·스킨 폴더 열기·다시 불러오기는 TenRiff 소스에서만, 가져온 스킨 선택은 TenRiff 또는 LR2 소스에서만 표시한다.
- 원본 키 모드의 스크래치 위치 조건과 숨겨진 구분선 너비 100% 정책은 유지한다.
- 앨범 아트의 판정 난이도 기본 박스를 288×36에서 192×28 디자인 픽셀로 줄인다. 사용자 스킨에 지정된 박스 좌표는 우선한다.
- 판정 카운터와 콤보가 겹치면 화면 안에서 가까운 위·아래쪽으로 피한다. 항상 아래로 밀던 처리를 없애 콤보 Y를 인디케이터 위로 옮길 수 있다. Classic/Studio와 플레이어/고스트에 공통 적용하며 저장 위치는 변경하지 않는다.

[고정 판정 정책](judgement-baseline-20261018.ko.md), R1–R8 리플레이 호환과 대전 버전7을 유지합니다. 1.9.6은 대응 Sites와 함께 정식 새 Online R9/R10 제출을 허용하고 이전 보드는 읽기 전용으로 보존합니다. 일반 소스 기준선1.9.0은 변경하지 않습니다.

최종 검증은1.9.6 릴리스 루트의 `evidence/VERIFICATION.ko.md`에 기록합니다. 이전 후보의 `evidence-ui-20261018/VERIFICATION.ko.md`는 당시 증거로 보존합니다. 자동 HWND 메시지·렌더 캡처와 실제 탐색기 드래그·물리 IME/입력·장시간 플레이 검증은 구분합니다.
