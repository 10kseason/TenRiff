# TenRiff 2.0.2

[한국어](release-2.0.2.ko.md) | [English](release-2.0.2.en.md) | [日本語](release-2.0.2.ja.md) | [简体中文](release-2.0.2.zh-CN.md)

マルチプレイの安定性とオンライン全体チャットを修正しました。

- マルチでも選択中のソロ用スキン・HUD全体を維持します。相手情報は空き領域に配置し、収まらない場合は補助カードのみ非表示にします。
- ローカル譜面とサーバー確認が一致したときだけハッシュ確認完了を表示します。開始・終了待機中の取得間隔を500msから250msに短縮し、HTTPS接続を再利用します。
- 最終スコア位置が直前の更新より戻り、結果同期が停止する問題を修正しました。
- オンラインアカウント接続後、F11でホーム・選曲・設定・プレイ・結果・マルチから同じ全体チャットを使えます。新UIは全体チャットのみで、ルーム参加やスコア投稿は不要です。

2.0.1の暗い設定背景・15%小さいカード・1行ヒントを含みます。判定・得点計算・リプレイ・保存形式とfinal4互換基準を維持します。全体チャットは明示依頼された2.0.2の範囲であり、2.0.0以降の保守方針は継続します。
