# TenRiff 1.9.0 고정 기준선

[한국어](baseline-1.9.0.md) | [English](baseline-1.9.0.en.md) | [日本語](baseline-1.9.0.ja.md) | [简体中文](baseline-1.9.0.zh-CN.md)

**고정 기준선: [1.9.0](baseline-1.9.0.md)** (2026-10-14 사용자 요청). Git tag `1.9.0`을 기준으로 하며 `main`이나 `latest`를 따라 자동 변경하지 않습니다. 1.8.7 기준선과 기존 릴리스는 이력으로 보존합니다.

## 버전과 보존

- 2026-10-14 사용자 요청으로 1.8.7에서 **1.9.0**으로 기준선을 올린다. 이전 [1.8.7 계약](baseline-1.8.7.md)은 당시 이력으로 보존한다.
- 불변 Git tag `1.9.0`이 가리키는 커밋을 사용한다. `git rev-parse 1.9.0^{commit}`으로 정확한 소스 커밋을 확인한다. 최종 커밋·공개 자산 SHA-256은 버전별 릴리스 본문과 `TenRiff-1.9.0-SHA256SUMS.txt`에 기록한다. 자기 자신을 포함한 ZIP의 해시를 소스 문서 안에 삽입하지 않는다.
- Windows GUI와 BMS 계열을 기준으로 한다. 기존 태그·배포 파일·프로필·원본 차트는 교체하지 않는다.

## 동작·호환 계약

- BMS 전체 음량과 텐리프 메뉴/결과 음악을 독립 조절한다. BMS 100% 상대 게인 1.0, 텐리프 음악 기본 감쇄 0.1, 마스터 기본 70%. 저장된 사용자 값은 유지한다.
- 판정 범위는 기본/Hard/EX이며 실행 중에만 유지한다. EX는 RANK 비례 PG14/GR44.571429/GD78.857143ms(EASY RANK 기준), BAD250ms 고정, 자동 미스340ms와 Hard 홀드·1.10 점수 배율을 유지한다.
- 기본/Hard 새 기록은 R5, EX는 R6. R1–R5 및 과거 Easy·변환 버전의 재생·검증을 유지한다. 이전 클라이언트가 R6를 검증할 수 있다고 보장하지 않는다.
- 살아서 완주한 일반 정확도로 S++99/S+98/S95/A+93/A90/B85/C80/D나머지를 표시하고, 사망은 F다. 표시 등급 변경은 과거 원점수·판정 기록을 다시 쓰지 않는다.
- SUBARTIST/OBJ 표시는 캐시 17로 메타데이터만 다시 읽는다. 원본 차트와 리플레이 바이트를 바꾸지 않는다.
- 새 설정은 EX 게이지, 빠름(최소) 인덱싱, 고스트 끔. 스킨 크기·노트 모양·사용자 폰트는 표현 계층이며 판정·입력·배칭 계약을 바꾸지 않는다.
- 기존 정밀 대기·입력 MMCSS/전원 정책은 유지한다. 전체 CPU 사용률로 물리 지연 개선을 단정하지 않는다.
- Sites는 client_submitted 기록이다. R6 수용과 오류 상태 표시를 지원하지만 서버의 리플레이 재검증을 새로 구현한 것은 아니다. 계정 인증·기존 동의와 멀티플레이 신뢰 경계는 유지한다.

## 패키지·검증 범위

- 공개 패키지는 클라이언트·verifier·빌드 자료와 허용된 NK3 런타임/추론 모델만 포함한다. 서버 구현·계정·프로필·곡·로그·비밀·학습자료·BGA 업스케일 모델·독립 키 변환기 EXE는 제외한다.
- [릴리스 조건](release-1.9.0-gate.md), [소스 범위](../SOURCE_PACKAGE_SCOPE.txt), [현재 상태](current-state.md)를 함께 따른다. 후보 검사 결과와 1.9.0 최종 빌드·독립 추출 빌드·CI·공개 readback은 구분한다.
- 실제 계정 업로드, 원래 기록 누락 원인, 물리 입력/소리 지연, 장시간 플레이, 다른 PC는 미검증이다. 플러그인 runtime/API/SDK 및 대규모 GameSession 분리는 이번 배포에 없다.
- 다음 기준선은 자동으로 올리지 않는다. 사용자 요청, 문서 4개 언어 동기화, 기록·설정·패키지 호환 검증을 필요로 한다.
