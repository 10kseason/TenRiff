# TenRiff 1.9.9.9-hotfix4

Safe와 빠름·최소 모드 모두 첫 폴더 스캔, F5 재스캔과 기존 캐시 읽기에서 사용 가능한 논리 코어에 작업을 나눕니다. 전체 곡 보기의 캐시 경로 확인도 병렬 처리하며, 남은 채보 수와 여유 RAM으로 동시 작업 수를 조절합니다.

성공 타격의 판정·점수와 키밤 모션은 기본 0.5초 동안 재생됩니다. PG·GR·GOOD의 탭과 롱노트 머리는 즉시 사라지고 BAD·POOR·미스 노트는 판정선을 지나 내려갑니다.

옵션 → 스킨 → 배경·키 효과에서 키밤 모양과 밝기를 조절합니다. 크기는 노말 100%, 크게 130%, 더 크게 165%입니다. Prism·Ring·Spark·충격파·파편·픽셀과 이미지 모드가 있습니다. 팔레트는 부드러운 기본·파스텔·유화·단색(밝은 회백색)·사이버펑크입니다.

키밤 이미지 선택에서 PNG 또는 JPEG를 고르면 원본 색과 비율, PNG 투명도를 사용합니다. 경로는 현재 기기의 프로필에 저장되며 파일을 옮기면 Prism이 표시됩니다. 판정·HUD에서 판정선 타입 2를 선택하고 타입 2 판정선 색상에서 초록 테두리 또는 단색 띠를 고를 수 있습니다. 메뉴와 도움말의 표기를 키밤 모양·키밤 밝기로 정리했습니다.

Existing R13/R14 replay and leaderboard identities apply. The fixed baseline is 1.9.6.
