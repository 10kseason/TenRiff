# LR2 クリアランプのインポート

LR2 のスコア DB からクリアランプを TenRiff のプロフィールに取り込み、選曲画面に表示します。表示専用であり、TenRiff のリザルト、BEST、オンライン送信の対象にはなりません。

EX 確認はノーツ、RANK、TOTAL、LN、地雷、RANDOM 情報を読み、音声・背景ファイルを探索しません。LR2 に必要な MD5 だけを計算し、重複するフォルダーの探索を省き、全対象譜面が見つかれば終了します。ランプ変換と保守的な EX 条件は同じです。未発見の譜面がある場合は残りのフォルダーも探索するため、大きなライブラリでは時間がかかります。 元の RANK がない場合や 0～3 の範囲外の場合に EASY とみなして EX を付ける不具合も修正しました。その譜面は元の LR2 ランプのみ保持します。

## 使い方

### ゲーム内でインポート

LR2を終了し、**オプション → プロフィール → LR2記録をインポート**でスコアの `.db` を選択します。現在のプロファイルに保存し、登録済み曲フォルダーと現在のフォルダーでEXを確認します。曲がなくても基本ランプは取り込めます。

処理はバックグラウンドで進み、同じボタンを再度選ぶとキャンセルします。完了後は再起動せず選曲ランプを更新します。再インポートは以前のLR2ランプ一覧を置き換えます。キャンセル、読み書きの失敗、ゲーム終了時は以前の一覧を保持します。TenRiff記録、BEST、オンライン送信資格は変わりません。

### コマンドライン

```
tenriff-lr2-import.exe <LR2 スコア .db> <プロフィールフォルダ> [曲フォルダ ...]
```

- LR2 の DB は読み取り専用で開きます。
- 出力は `<プロフィールフォルダ>\lr2_import.json` です。ファイルを削除するとランプも消えます。再実行すると作り直します。

## 表示ルール

| LR2 | TenRiff ランプ |
|---|---|
| EASY | EZ CLEAR |
| NORMAL (GROOVE) | NM CLEAR |
| HARD、FULL COMBO | HD CLEAR |
| 下記の判定を通過したプレイ | EX CLEAR |

- TenRiff で同等以上のクリアがあれば、そちらを表示します。
- 取り込んだランプを表示するときは、選択曲のランプ表記の先頭に `LR2 ` が付きます。LR2 のフルコンボには `(FC)` が付きます。
- スコア、ランク、精度は取り込みません。

## EX の判定

曲フォルダを指定すると、LR2 の `ghost`(ベストスコアのプレイのノーツごとの判定順)を TenRiff の EX-HARD ゲージで再生します。各 LR2 判定は、**その LR2 判定幅の中で TenRiff Normal 判定としてあり得る最悪の判定**に置き換えます。それでもゲージが残れば EX とします。

- LR2 判定幅(ms、RANK VERY HARD/HARD/NORMAL/EASY):PGREAT 8/15/18/21、GREAT 27/32/40/60、GOOD 40/60/100/120、BAD 200。PGREAT と BAD は lr2oraja の LR2 判定表と Lunatic Vibes で一致し、GREAT/GOOD は数 ms 異なるため広い方を使います。
- ゲージは実際のプレイと同じ `GaugeManager`(BMS TOTAL ベースの EX-HARD)です。

判定しない場合(LR2 のランプのみ):曲フォルダに譜面が無い、ロングノート・地雷・`#RANDOM` を含む譜面、`#RANK` が無いか範囲外、ノーツ数が LR2 の記録と異なる、ghost が無い・途中で終わる・保存された判定数と合わない。

## 制限

- ghost の形式は仕様書ではなく、実際の LR2 DB 1 つから逆算したものです(5,285 行中 5,274 行で判定数が一致)。
- ghost はベスト**スコア**のプレイのものです。ランプを取ったプレイとは別の場合があります。
- 最悪ケースの規則のため、実際には生存したプレイも EX にならないことがあります。
- LR2 と TenRiff はゲージ規則が異なり、同名のランプでも難しさは同じではありません。
