# TenRiff 1.9.9.9-hotfix3

- **NK2 E+** は 7K・8K・10K に対応します。オプション → モードで変換先のキー数と NK2 を指定し、**E+ - Full-field + taps** を選びます。対応するキーモードに戻ると E+ の選択が復元されます。保持されたロングノートの終端に追加するタップは元のサンプル位置を使います。
- **Safe インデックス**は譜面の解析とハッシュ計算で読み込み結果を共有し、NPS と難易度の計算に同じタイムラインを使います。合成譜面 12,000 件では、初回の中央値が 10.898 秒から 8.501 秒に、キャッシュ再読み込みの中央値が 3.414 秒から 3.042 秒に短縮されました。
- ライブラリタブの下に **曲フォルダーを追加** ボタンを配置しました。選曲画面から Windows のフォルダー選択を直接開けます。曲名とアーティストの並び順は A-Z と Z-A で表示します。
- オンライン記録の閲覧と送信には **TenRiff リーダーボード**を使います。F10 で Online を選び、公式サイトの接続情報を貼り付けるか、接続ファイルを読み込んでください。ゲーム内で R13/R14 と E+ v1・v2 の各ランキングを閲覧できます。マルチプレイは LAN 検索とピアへの直接接続に対応します。

Windows ZIP を新しいフォルダーに展開し、`launch_win.bat` を実行してください。既存のインストールとプロファイルは別に保管してください。固定基準バージョンは **1.9.6** です。
