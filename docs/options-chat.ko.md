# 별자리 옵션 화면과 전체 채팅 입력

> **2.0.1** 기본 옵션 은하 배경 밝기를 2.0.0의 40%로 낮췄습니다(원본 RGB 배율 0.392). 8개 카드의 가로·세로와 내부 글자·아이콘을 각각 85%로 줄이고 클릭 영역도 맞췄습니다. 선택한 옵션의 설명을 카드 아래 한 줄로 표시합니다. 한국어·영어·일본어·중국어를 지원합니다. [2.0.1](release-2.0.1.ko.md)


[한국어](options-chat.ko.md) | [English](options-chat.en.md) | [日本語](options-chat.ja.md) | [简体中文](options-chat.zh-CN.md)

옵션 화면은 제공된 `TENRIFF_constellation_options_mockup.png`를 참고해 기본 8개 카테고리를 4×2 카드로 표시합니다. 각 카드에는 서로 다른 별자리, 색상 아이콘, 현재 값과 선택 강조를 배치합니다. 기존 카테고리 순서·설정 값·키보드 탐색·클릭 대상은 유지합니다. 별자리는 정적인 장식이며 실제 천체 지도를 뜻하지 않습니다. F1 도움말은 유지합니다.

배경은 제공된 `TENRIFF_galaxy_background.png`를 수정 없이 `assets/menu/options-galaxy-background.png`로 복사합니다. 표시할 때만 채도 0.92, 밝기 0.392의 색상 행렬을 적용하고 알파는 바꾸지 않습니다. 비율을 유지해 화면을 채우고 넘치는 가장자리를 자릅니다. 기본 옵션·설정 화면에 적용하며 사용자 스킨 배경을 덮어쓰지 않습니다. 자산을 불러오지 못하면 기존 배경 경로로 돌아갑니다. 카드 테두리의 은은한 빛과 별자리 패널은 읽기 쉬운 설정 화면을 위한 표현 변경입니다.

2.0.2에서는 온라인 인증이 완료된 전체 채팅 서비스를 통해 입력·전송합니다. F11로 열고 Enter로 전송합니다. 방 참가 여부와 무관하며 게스트·연결 해제·계정 변경 시 이력과 대기열을 지웁니다.
