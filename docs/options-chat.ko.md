# 별자리 옵션 화면과 방 채팅 입력

[한국어](options-chat.ko.md) | [English](options-chat.en.md) | [日本語](options-chat.ja.md) | [简体中文](options-chat.zh-CN.md)

옵션 화면은 제공된 `TENRIFF_constellation_options_mockup.png`를 참고해 기본 8개 카테고리를 4×2 카드로 표시합니다. 각 카드에는 서로 다른 별자리, 색상 아이콘, 현재 값과 선택 강조를 배치합니다. 기존 카테고리 순서·설정 값·키보드 탐색·클릭 대상은 유지합니다. 별자리는 정적인 장식이며 실제 천체 지도를 뜻하지 않습니다. F1 도움말은 유지합니다.

배경은 제공된 `TENRIFF_galaxy_background.png`를 수정 없이 `assets/menu/options-galaxy-background.png`로 복사합니다. 표시할 때만 채도 0.92, 밝기 0.98의 색상 행렬을 적용하고 알파는 바꾸지 않습니다. 비율을 유지해 화면을 채우고 넘치는 가장자리를 자릅니다. 기본 옵션·설정 화면에 적용하며 사용자 스킨 배경을 덮어쓰지 않습니다. 자산을 불러오지 못하면 기존 배경 경로로 돌아갑니다. 카드 테두리의 은은한 빛과 별자리 패널은 읽기 쉬운 설정 화면을 위한 표현 변경입니다.

방 채팅은 사용하지 않는 전역 채팅 서비스의 설정 여부 때문에 입력이 막히던 조건을 수정합니다. 열린 방 채팅 창은 연결된 `PeerSession`을 기준으로 확정된 텍스트를 받으며 호스팅 방에도 같은 경로를 사용합니다. F11 창 열기·닫기와 Enter 전송, UTF-8 256바이트 제한은 유지합니다. 닫힌 창·연결 해제·계정/URL 경고 창에서는 잘못된 필드로 입력이 흘러가지 않도록 막습니다. 계정 인증, protocol 2, 서버 전송 제한은 바꾸지 않습니다.

검증용 회귀에는 확정된 한글·ASCII 입력 큐와 로컬 양방향 채팅, 호스팅 응답 대역과 두 클라이언트 Worker 채팅 확인이 포함됩니다. 이 문서는 테스트 통과나 성능 수치를 주장하지 않으며 실제 실행 결과는 [2.0.0 검증 게이트](release-2.0.0-gate.md)를 따릅니다. 실제 Windows IME 조합창·확정 키 타이밍, 운영 계정 메시지, 인터넷 지연, 장시간 사용과 다른 PC는 별도 확인이 필요합니다. 기존 [ALL COMBO 표시](menu-starlight.ko.md)·점수·판정 규칙은 이 수정의 대상이 아닙니다.
