# インジケーター・リザルトのローカル変更

公開1.9.9.5を継承する独立候補です。固定基準1.9.6と公開版は変更しません。

- バーコードの過去・最新マーカーを基本2×18に統一し、最新入力は明るさで区別します。点形状・色・0.7秒寿命・位置と倍率・プレイヤーとゴーストの判定時間は維持します。
- リザルトの要約・分析で `GAUGE SHIFT EX CLEAR` を `EX CLEAR` と表示します。他ゲージも同じ接頭辞のみ除去し、ASSISTは維持します。保存状態と色は変更しません。
- 初回の有効なローカルBEST、または既存の比較順（クリア強度、点数、詳細点数・精度、コンボ・判定数）で改善した場合、点数の上に `NEW Record` を表示します。日時だけ新しい同成績は対象外です。新しい判定方針での初記録も含みます。
- オート・練習・追加ノート・現行LN Mix等の既存除外条件を維持します。リプレイ、過去結果、保存失敗では表示しません。対戦では自分のローカル記録だけに表示し、通信形式を変更しません。

セッション内フラグと既存の点数見出し領域を使い、保存形式・点数・判定・リプレイとスキン配置を維持します。専用result-feedback-localプロファイルを使用します。実入力・実機2台対戦・長時間・任意スキンは未検証です。
