# 검색창, 고스트 배틀, 타이틀 음악

## 곡 검색

검색창은 곡 목록 바로 아래에 표시합니다. 클릭하거나 기존 검색 단축키로 입력할 수 있으며, 입력 중에는 커서를 표시합니다. 긴 검색어는 말줄임표로 표시합니다. 일곱 개의 곡 카드가 모두 보이도록 카드 사이 간격을 조절하고 스크롤바도 검색창 위에서 끝냅니다. 정렬·필터와 난이도표는 가운데 패널 하단에 표시합니다.

## 고스트 배틀

실플레이와 고스트의 판정·콤보는 같은 스킨 위치, 가로 이동, 글자 크기, 색상과 애니메이션 설정을 사용합니다. 두 필드가 화면에 들어가도록 배틀 필드 폭을 사용하며, 노트·키·판정선·가져온 스킨 그림도 공통 렌더링 경로를 따릅니다.

상단 정보창은 점수, 콤보, 정확도와 판정 개수를 분리해 표시합니다. 곡 제목·아티스트·속도 정보는 필드 밖 공간을 사용하되, 필드가 넓어 여백이 부족하면 실플레이 정보창 안에 두 열로 나눠 표시합니다. 좁은 정보창은 화면 중앙 쪽으로 확장하여 바깥 게이지를 가리지 않습니다. 기존에는 정보창의 마지막 행 높이가 부족했고 긴 요약 한 줄이 필드 너비를 넘어 잘렸습니다.

## 타이틀 음악

`옵션 → 오디오 설정 → 타이틀 음악`에서 선택합니다. 키보드 좌우, 클릭, `−/+`를 지원하고 프로필에 바로 저장합니다.

| 선택 | 동작 |
| --- | --- |
| 없음 | 타이틀과 빠른 설정에서 음악을 끕니다. |
| 기본 | 기존 기본 타이틀 음악을 재생합니다. 새 프로필의 기본값입니다. |
| 랜덤 BMS 음악 | 타이틀 방문마다 현재 불러온 라이브러리의 BMS 한 곡을 선택합니다. 검색어나 난이도표 필터와는 별개입니다. |
| 마지막 플레이한 음악 | 마지막으로 플레이를 시작한 곡의 음악을 재생합니다. 앱을 다시 열어도 기억합니다. 시작 카운트다운에서 취소하거나 오디오 시작에 실패한 곡, 리플레이와 편집기 연습은 이 곡을 바꾸지 않습니다. |

등록된 곡이 없거나 파일을 읽을 수 없으면 기본 타이틀 음악으로 돌아갑니다. `배경음`을 끄면 타이틀 음악도 꺼집니다. 마스터·BGM 볼륨과 창 비활성화 음소거 설정을 따릅니다. 옵션·곡 선택·결과 화면은 각 화면의 음악과 미리듣기를 사용합니다.

BMS는 배경음과 키음을 합쳐 재생합니다. 합성은 기존 곡 미리듣기의 취소 가능한 작업을 재사용하므로 메뉴 스레드에서 디코드하지 않습니다. 타이틀용 오디오는 스테레오, 최대 5분으로 제한하고 반복합니다. WASAPI에서는 44.1kHz를 사용하며, ASIO에서는 선택한 장치 샘플레이트를 유지합니다. 5분 PCM 버퍼는 44.1kHz에서 약 101MiB이며 샘플레이트에 비례해 증가합니다. 화면이나 선택이 바뀐 뒤 도착한 이전 디코드 결과는 적용하지 않습니다.

저장 항목은 `audio.title_music` (`none`, `default`, `random_bms`, `last_played`)와 `ui.last_played_chart_path`입니다. 마지막 곡 경로는 로컬 프로필 정보이며 배포 기본 설정에는 빈 값만 들어갑니다.

## 검증 범위

설정 저장·선택·타이틀 방문·작업 취소·실패 시 기본 음악 전환 및 BMS 합성을 회귀 테스트로 확인합니다. 합성 장면으로 곡 카드 일곱 개와 검색창의 클릭 좌표, 고스트 표시, 가져온 스킨과 작은 해상도를 검사합니다. 이러한 검사는 실제 디스코드 방송, 장시간 재생과 사람의 청취 평가를 대신하지 않습니다.
