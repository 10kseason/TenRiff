# レンダー待機補正の停滞からの回復

一時的なタイマー遅延で oversleep 推定値が大きくなると、その後のタイマー待機がすべて省略され、新しい実測値も得られず推定値が高いまま残る場合がありました。

補正値だけが待機を妨げ、実際の sleep がなかった場合に限り、最後の測定・回復から100ms以上経過した時点で推定値を7/8に減衰します。フレームごとや yield ごとの減衰は行いません。実測EMA、短い待機、目標FPS、締切計算、VSync、無制限モードは維持します。入力・判定・音声・リプレイのコードと設定は変更しません。以前のゴールド・スキン・BGA修正を継承し、青色ランク画像は比較案のままです。

コード上で再現した待機状態への対策であり、Discord症状の原因特定や解決の証明ではありません。継続して遅いタイマーでは再試行の負担が残ります。フレームごとの減衰案は継続遅延モデルで悪化したため採用せず、100msの間隔で再試行頻度を抑えます。回復時間は残りフレーム予算に依存します。

配信なしのゲーム中にもカーソルが停止する場合は、同じ場面でオーバーレイを一つずつ無効にして比較してください。読み込まれたモジュールだけでは競合を断定できません。[Discord公式ガイド](https://support.discord.com/hc/en-us/articles/217659737-Game-Overlay-101)。
