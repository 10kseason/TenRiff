# 1.8.8 화면·메뉴 입력·키음 보완

이 문서는 1.8.8의 추가 동작과 한계를 설명합니다. 현재 빌드·테스트·패키지·공개 상태는 [릴리스 검증 안내](release-1.8.8-gate.md)에서 확인합니다. 고정 기준 [1.8.7](baseline-1.8.7.md)의 태그와 기존 배포 파일은 유지합니다.

## 난이도표 URL 편집

Backspace를 한 번 누르면 마지막 UTF-8 코드포인트 하나를 지우고, 계속 누르면 250ms 뒤부터 45ms 간격으로 지웁니다. 한글·한자·이모지의 일부 바이트를 남기지 않습니다. 결합 문자 여러 개를 하나의 표시 글자로 묶어 삭제하는 기능은 아닙니다.

키 해제·포커스 상실·화면 전환·모달 표시·입력 교체·적용·취소 시 반복을 중단합니다. 빈 값에서도 더 지우지 않습니다. Delete는 전체 지우기, Esc는 편집 취소, Ctrl+V는 기존 붙여넣기 동작을 유지합니다. 다른 목록의 방향키 반복과 URL 편집의 반복 소유를 구분합니다.

## 선택한 난이도표 기준의 최소·최대 필터

난이도표가 선택된 동안 최소·최대 필터는 **그 표에 표시된 레벨의 숫자**를 사용합니다. 기본 LV로 돌아가면 기존 내장 레벨 필터를 사용합니다. 표의 정렬 순번을 레벨 숫자로 취급하지 않습니다.

| 표 레벨 예 | 숫자 필터의 의미 |
| --- | --- |
| `12`, `st12`, `sl12`, `★12`, `12+` | 12로 비교. 최소 12에는 포함하고 최소 13에는 제외 |
| `0`, `st0` | 숫자 0. 최대만 설정한 범위에는 포함 가능 |
| `?`, `A`, `EX`, 표에 없는 곡 | 숫자 제한이 있으면 제외. 내장 LV로 대신 판정하지 않음 |
| `12-13`, `12/13`, `12.5`, `12A`, 음수, 정수 범위 초과 | 하나의 지원되는 정수 레벨로 해석하지 않아 숫자 제한에서 제외 |
| 최소·최대 모두 제한 없음 | 숫자 해석 없이 기존 소스·표·검색 조건을 따름 |

표 기호는 그대로 표시합니다. 레벨 안에 포함된 접두사와 후행 `+`도 읽지만, `+`를 별도의 반 단계로 계산하지 않습니다. 같은 숫자를 가진 서로 다른 표가 같은 난이도라는 의미는 아닙니다. 현재 선택한 표 안에서만 범위를 적용합니다.

## 스킨의 숫자 레인 선택

스킨 설정과 실제 인게임 비율 미리보기 부근에서 다음 단축키를 안내합니다.

| 입력 | 선택 |
| --- | --- |
| `1`~`9` | 화면 왼쪽부터 1~9번째 레인 |
| `0` | 10번째 레인 |
| `Shift+1`~`Shift+6` | 11~16번째 레인 |

숫자패드도 같은 선택을 지원합니다. 현재 키 모드에 없는 번호는 무시하고 기존 대상 레인 `+/-` 조작은 유지합니다. 현재 편집 행은 그대로여서 폭·색상 등을 조절하던 위치에서 대상만 바꿀 수 있습니다. 대상 선택만으로 스킨 값을 변경하거나 저장하지 않습니다. 7+1에서 스크래치를 오른쪽으로 옮겼다면 `1`은 왼쪽 첫 키, `8`은 오른쪽 스크래치입니다.

이 단축키는 스킨 설정에만 적용합니다. 전체화면 미리보기·도움말·채팅·계정 모달·문자 입력·키맵 캡처가 입력을 소유할 때는 레인을 바꾸지 않으며 Ctrl/Alt/Windows 조합도 제외합니다. 실제 플레이의 레인 키 배치를 바꾸는 기능은 아닙니다.

## 읽기 쉬운 결과와 플레이 표시

스튜디오 덱의 곡 정보·설정값·점수·정확도·판정 개수 글자를 키웁니다. 결과의 PG 노랑, GR 청록, GD 주황, POOR 빨강, FAIL 보라, 정확도 cyan은 검은 메뉴의 흑백 색상 변환과 분리합니다. FAST는 파랑, SLOW는 분홍빛 빨강으로 표시하고 글자 크기를 16px에서 24px로 키우며 분포 그래프에도 같은 색을 사용합니다.

게이지 이력은 실제 게이지 높이에 따라 0% 빨강·50% 노랑·100% 초록의 세로 그라데이션으로 표시합니다. 성공·실패 상태가 이 색을 결정하지 않습니다. 결과와 선곡·기록 카드의 등급은 52px에서 84px로 키우고 등급별 색과 두 단계 Gaussian bloom을 적용합니다. 등급 그림은 작은 비트맵에 한 번 캐시하고 매 프레임 해당 이미지를 그립니다. 표시 변경으로 판정·점수 규칙을 바꾸지 않습니다.

## 키 수를 줄일 때 사라지던 키음 보존

4K처럼 레인 수를 줄이는 변환에서 삭제되거나 같은 시점 충돌로 빠진 노트의 키음을 원래 시작 시각의 BGM으로 보완합니다. Krrcream·NK2·NK3와 이전 변환 경로, 스크래치 제외에 같은 중복 방지 기준을 적용합니다.

- 최종 플레이 노트나 원래 BGM에 같은 시각·같은 오디오가 있으면 새로 겹치지 않습니다.
- 같은 시각의 서로 다른 소리는 각각 유지하며, 원본이 의도적으로 갖고 있던 BGM 중복은 그대로 둡니다.
- LN은 시작 키음만 보완합니다. 끝점에 새 키음을 만들지 않습니다.
- 원본 파일·플레이 노트·판정·점수·리플레이 seed를 바꾸지 않습니다. 이전 리플레이도 같은 노트를 재구성하며 보완된 배경음을 재생합니다.
- 보완한 소리는 BGM 음량·사운드 오프셋과 기존 Rate 믹서 정책을 따릅니다. Rate 1에서 추가 피치 변화를 만들지 않습니다. Rate 변경 시 피치를 유지하는 새로운 time-stretch 기능을 넣은 것은 아닙니다.

실제 장치에서의 청감과 물리 입력·오디오 지연은 구조·자동 검사와 별개입니다. 진행한 검사와 남은 한계는 릴리스 검증 안내에 기록합니다.

## 시작과 즉시 재시작

프로필의 시작 카운트다운 생략은 기본 OFF, 즉시 재시작 키는 기본 미지정입니다. 즉시 재시작은 초기 표시 카운트다운을 생략하지만 오디오 준비와 기존 채보 앞 여백을 제거하지 않습니다. 재개 카운트다운·멀티플레이·Session Mix의 제한, 키 충돌 방지와 프로필 이전은 [시작·재시작 조작](gameplay-start-controls.ko.md)에 별도로 설명합니다.
