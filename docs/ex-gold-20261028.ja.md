# EXのシャンパンゴールド・グラデーション

EXの6色パレットを**静的なシャンパンゴールドのグラデーション**に変更しました。ユーザーの追加指定で初期単色`#D6B77A`から**基本色`#E7BA68`**へ変更し、HSV彩度を約43%から55%へ上げています。`#BA8B43` → 基本色 → `#FFE3A6` → 基本色とし、紫や別の色相を混ぜません。既存の輪郭・グロウ・透明度は維持します。

EX/EX-HARDのClassic/Studio・プレイヤー/ゴーストゲージ、EXクリア輪郭・ロゴ・バッジ、Shift Start、EXを共有するS+/S++/S+++と旧ランク別名に適用します。旧Gauge Shift EX結果色とオフラインエディターのEX初期値も統一します。保存済みEX色による意味色上書きを防ぐ以前の動作は維持します。

EZ/NM/HD、その他のランク、レーン色、ALL COMBO画像と黄色グロウは変更しません。以前のシンプルLN・ALL COMBO・BGA復帰を継承し、判定・入力・音声・スコア・リプレイ・FPSはそのままです。

共通描画ランプの4stopで既存キャッシュ・形状・透明度・保存値を保ちます。以前の6色/虹色と初期完全単色の説明は最終候補で置き換えます。最終は`dist-final`、初期単色の`dist-local`は保存します。未公開ローカル候補・別`ex-gold-local`プロファイルで、一般基準1.9.6と公開1.9.9.3、以前の候補・インストールを維持します。
