# マルチプレイでも選択中のソロスキンを維持

[한국어](multiplayer-skins.ko.md) | [English](multiplayer-skins.en.md) | [日本語](multiplayer-skins.ja.md) | [简体中文](multiplayer-skins.zh-CN.md)

Native・取り込んだLR2はソロとマルチで同じHUD選択を使います。TenRiff画像スキンとメニュー専用スキンも選択中の素材・スタイルを維持します。

Studio Deckをマルチで強制的にClassicへ切り替える条件を削除しました。対戦相手の順位表はフィールド・ゲージ・曲情報・自分の点数・マップ・性能表示の空き領域に配置し、人数に応じて縮小します。

ルームからオプション → スキンで選択して戻ります。オプションを開くと準備が解除されるため、再度準備してください。試合中の変更は禁止のままです。

ゴースト対戦の共有配置、判定、点数、通信、保存形式は維持します。任意の自作スキン座標と実機複数PCでの対戦は別途確認が必要です。

読める大きさで表示できる余白がない場合は補助の相手スコアだけを非表示にします。全順位は結果画面で確認できます。フィールドと選択したHUDの位置は変更しません。

## ハッシュ確認と開始・終了の同期

ロビーの「ハッシュチェック完了」は、このPCで確認したチャートとルームが確認したハッシュ・サイズが一致した場合だけ表示します。選択変更、確認待ち、切断時は完了と表示しません。

ホスト型マルチはワーカースレッドでHTTPS接続を再利用し、ロード・最終結果・ラウンド終了の待機中だけポーリングを500msから250msへ短縮します。通常時の間隔とサーバーの5秒カウントダウンは維持します。全体の同期時間が半分になる保証ではありません。

最終結果のサンプル位置が直前のライブスコアより戻って拒否される問題を修正しました。最終結果の拒否時は長時間待機せず切断し、ロード中に相手が退出した場合は従来どおりロビーへ戻ります。実際のインターネット遅延と長時間の複数PCプレイは別途確認が必要です。
