# 中央服务器多人游戏

本文介绍TenRiff 2.0.0的中央服务器多人游戏。保留final4兼容性基准、判定、回放及旧PeerProtocol v9。在线房间使用hosted protocol v2和`score_version="ex-v1"`。分数和排名统一采用[EX Score](ex-score.zh-CN.md)，不能与旧hosted v1或直接IP客户端混用。

按 F10 选择 Online 并导入现有排行榜连接信息。在多人游戏中创建或加入官方房间。服务器验证账户，不要求排行榜成绩。Guest、过期或撤销的连接无法加入。游戏界面不提供 IP、端口或 LAN 入口。

独立的 TenRiff Multiplayer Site 通过 HTTPS 和 D1 管理最多 8 人的房间。房主离开后，选曲权交给其他玩家。房主选择本地 BMS，各 PC 在本地匹配相同文件。全员匹配并准备后才能开始。不传输完整曲库、谱面或音频。使用所选谱面匹配，替代直接连接模式预先计算的共同曲库列表。

音乐和输入判定仍在各 PC 执行。服务器安排未来的开始时间，所有客户端使用同一时间；迟到的开始通知或过慢的响应会被拒绝。状态与对手成绩每 500ms 交换一次，因此对手显示可能延迟。互联网延迟、8 人负载、长时间游玩及 D1 用量需要单独验证。服务器托管不等于回放验证或反作弊。

F11 打开房间聊天。切换 Guest、解除或更换账户连接会结束多人连接。连接密钥仅通过 HTTPS 交给官方多人 Site 并向排行榜验证，不会保存。后续请求使用仅存储哈希的短期会话，每 20 秒重新验证；撤销最多有 30 秒的会话窗口。
