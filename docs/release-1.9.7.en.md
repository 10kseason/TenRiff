# TenRiff 1.9.7 — Common keys, skin settings and per-play random seeds

2026-10-19

Adds Common Keys, larger mode tabs with lobby colors, colored FAST/SLOW labels, 1% adjustments, Game Mode Settings/Normal labels and a fresh seed for every solo play.

These changes are included in 1.9.7. Preserve prior releases, installations and profiles; the general source baseline remains 1.9.6. Physical input/listening, long sessions and other PCs require separate validation.
