# 인게임 곡 제목 자동 맞춤

플레이필드를 넓히거나 왼쪽으로 옮겼을 때 제목 끝이 잘리거나 필드와 겹치는
현상을 보완한다. 기본 스튜디오 덱과 클래식 단독 HUD에서 제목 영역은 실제
필드 바깥의 여백으로 정한다. 스튜디오 덱에서는 리프 맵과 시간 눈금도 피한다.
왼쪽 여백이 좁고 오른쪽에 더 넓은 공간이 있으면 제목을 오른쪽 점수 아래로
옮긴다. 필드 위치가 돌아오면 제목도 원래 왼쪽 위치로 돌아온다.

DirectWrite로 글꼴의 실제 폭·높이와 글자의 돌출 부분을 측정한 뒤, 제목 전체가
영역 안에 들어가는 비율로 줄인다. 공간이 다시 넓어지면 기본 크기까지 늘어난다.
자동 줄바꿈이나 말줄임표로 끝을 숨기지 않는다. 매우 긴 제목은 그만큼 작아질 수
있다. 제목의 제어 문자·연속 공백은 기존 UI 정규화 규칙을 그대로 따른다. 별도 설정은 없다.

제목 레이아웃은 제목 또는 글꼴이 바뀔 때 한 번 만들고 재사용한다. 필드 이동·크기
변경은 측정한 레이아웃의 좌표와 배율만 바꾸므로 프레임마다 텍스트 레이아웃이나
문자열을 만들지 않는다. 스튜디오 덱의 추가 제목 받침도 정적 커맨드 리스트에
기록한다. LR2 단독 스튜디오 덱과 스킨 설정의 전체 화면 미리보기도 공통 경로를 쓴다.

클래식 외부 스킨에 직접 지정된 제목 위치·글꼴은 유지하며 해당 영역 안에서 전체를
맞춘다. 대전에서는 기존 제목 영역을 유지하고 같은 측정 방식으로 크기만 맞춘다.
다른 HUD 항목의 극단 이동 배치는 이번 제목 수정의 범위에 포함하지 않는다.
판정·입력·오디오·리플레이·점수·게이지와 노트 루프/배칭은 변경하지 않는다.

회귀 확인은 한국어·영어·혼합·공백 없는 긴 제목, 짧은 제목, 필드 50~140%,
좌우 극단 이동, 리프 맵 켜기/끄기, Native/LR2 및 클래식/대전 제목 영역을 대상으로
한다. `menu_visual_preview --song-title-file <UTF-8 파일>`로 실제 렌더러에 제목을
넣을 수 있다. `--field-next <가로 이동> <크기>`는 35번째 프레임에 필드를 바꾸며,
benchmark JSON의 `song_title`은 측정 영역·크기·문자 수·레이아웃 생성 횟수를 기록한다.

배포본을 덮어쓰지 않는 로컬 시험 패키지 이름은 `TenRiff-1.8.6-title-fit-test`이다.
현재 작업 폴더의 `evidence/title-fit/VERIFICATION.ko.md`가 검증 결과다.
