# TenRiff 1.9.3 プレイ・スキン・モデル互換性

公開1.9.2と先行ONNX互換作業を継続する1.9.3の実装範囲です。公開済みファイルと固定基準1.9.0を維持します。公開状態・最終検証は[1.9.3リリース案内](release-1.9.3.ja.md)を参照してください。

- 選曲アルバム画像の右下にBMSの記述上の判定難度を表示：RANK 4/3/2/1/0 → VEZ/EZ/NM/HD/VHD。省略・不正値はEZ、osu!には表示しません。キャッシュ20で情報を再取得します。
- Classic・Studio・対戦HUDでアーティスト名と分離した赤いレベル欄を確保します。長い名前でもレベルを隠しません。エディター練習・直接起動では実際に起動する譜面のPLAYLEVELを使い、無関係な選択曲の値を使いません。
- BMSの小節長・BPM・STOP・速度・スクロールに従う小節線をノートの背後に描きます。判定・音声イベントは追加しません。
- FAST/SLOWの常時表示は最後の実測表示とマーカーを保持します。条件付き表示は750msのまま、文字・バーのスイッチは独立です。最初の入力前の架空表示やPG表示の追加はありません。
- 新規・設定省略時の読み込みは安全が既定です。保存済みの高速選択は維持し、独自LV/CR計算は別設定で既定OFFです。
- 空POORは体力とPOOR数に影響しますが、通常・詳細・区間精度には影響しません。実ノートのミスは精度を下げます。新記録は通常/HardがR7、EXがR8で、R1–R6の再生計算を維持します。
- 対応SafetensorsはローカルPythonでONNXに変換して既存GPU経路へ渡します。torch/safetensors/onnx/onnxruntimeが必要で、一般構造には任意導入のSpandrelが必要です。自動導入・ダウンロードはありません。[モデル契約](../tools/onnx_upscaler/README.md)。

RANK 4のVEZは記述情報で、実際の判定幅は従来のEasy代替を維持します。小節線はBMS向けです。Safetensorsは既知のLunaSR2 C32 R8/R12/R16 x2または変換可能なSpandrel RGB x1–x4構造に限定されます。失敗時は元画像とログ診断を使用します。BGA重みは配布せず、OFF/空パス既定と動画AI無効を維持します。

R7/R8対応の運用リーダーボード版19を2026-10-16にユーザー承認のもと公開しました。新ルールは別ボードで受け付け、従来のボードID・記録・Stable固定等級を維持します。ゲスト記録の永続除外とclient_submitted境界は変えず、サーバーでのリプレイ検証は追加していません。
