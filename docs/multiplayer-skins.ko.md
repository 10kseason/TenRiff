# 멀티플레이에서 싱글 스킨 유지

[한국어](multiplayer-skins.ko.md) | [English](multiplayer-skins.en.md) | [日本語](multiplayer-skins.ja.md) | [简体中文](multiplayer-skins.zh-CN.md)

Native·가져온 LR2의 HUD 선택은 싱글과 멀티에서 동일하게 적용됩니다. TenRiff 이미지 스킨과 메뉴 전용 스킨도 기존 선택·이미지·스타일을 유지합니다.

Studio Deck을 멀티에서 강제로 Classic으로 바꾸던 조건을 제거했습니다. 상대 점수판은 필드·게이지·곡 정보·내 점수·그래프 맵·성능 표시의 빈 공간에 맞춰 배치하고 인원에 따라 축소합니다.

방에서 옵션 → 스킨으로 들어가 현재 스킨과 HUD를 고른 뒤 방으로 돌아오세요. 옵션 진입 시 준비가 해제되므로 다시 준비해야 합니다. 대전 도중 스킨 변경은 허용하지 않습니다.

고스트 대전의 공용 배치, 판정·점수·네트워크 프로토콜·저장 형식은 그대로입니다. 임의 제작 스킨의 모든 좌표와 실제 다중 PC 대전은 별도 확인이 필요합니다.

여백이 부족해 읽을 수 있는 크기로 표시할 수 없으면 보조 상대 점수판만 숨기며, 전체 순위는 결과 화면에서 확인할 수 있습니다. 필드와 선택한 HUD의 위치는 바꾸지 않습니다.

## 해시 확인과 시작·종료 동기화

로비의 `해시 체크 완료`는 이 PC의 선택 차트와 방에서 확인한 해시·크기가 모두 일치할 때 표시됩니다. 선택 변경, 확인 대기, 연결 해제 시 완료로 표시하지 않습니다.

호스팅 멀티는 같은 작업 스레드에서 HTTPS 연결을 재사용하며, 로딩·최종 결과·라운드 종료 대기 중 폴링 간격을 500ms에서 250ms로 줄입니다. 평상시 간격과 서버의 5초 시작 카운트다운은 유지합니다. 이는 클라이언트의 추가 대기를 줄이며 전체 동기화 시간의 절반을 보장하지 않습니다.

최종 결과의 시간값이 직전 실시간 점수보다 과거가 되어 서버에서 거부되던 경우를 수정했습니다. 최종 결과 거부 시 장시간 대기 대신 연결 실패로 종료하며, 로딩 중 다른 참가자가 나간 경우에는 기존처럼 방으로 복귀합니다. 실제 인터넷 지연과 장시간 다중 PC 플레이는 별도 검증이 필요합니다.
