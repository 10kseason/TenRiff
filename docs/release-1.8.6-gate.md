# TenRiff 1.8.6 릴리스 검증

기준일: 2026-10-08. 1.8.5 이후 인게임 표시와 단축키를 개선합니다.

## 변경과 선택 이유

Native 단독 플레이의 기본 HUD는 스튜디오 덱입니다. 곡을 불러올 때 노트 시작점을
64구간으로 집계하고 밀도 막대·레일 바탕은 정적 레이어에 기록합니다. 매 프레임
전체 차트를 순회하지 않으며 1.8.5 GPU 노트 배칭과 노트 그리기 순서를 유지합니다.
숫자·영문은 Bahnschrift, 한글은 기존 UI 글꼴을 사용합니다.

Options > Skins에서 Classic으로 돌아갈 수 있습니다. 이전 프로필에 HUD 설정이
없어도 Studio Deck이 기본이며, 명시한 Classic은 보존됩니다. 외부 이미지 스킨,
고스트와 멀티플레이는 기존 배치를 유지합니다. 기본 EX-HARD 색만 레일·퍼센트 표시에서
밝은 회색으로 보정하며 사용자 지정 색과 실제 게이지 계산은 바꾸지 않습니다.

좌우 Shift를 플레이 키로 사용할 수 있습니다. 기존 단축키 처리기가 Shift 이벤트를
소비하던 문제를 없애고, RawInput의 공통 Shift 코드를 물리 좌우 키로 정규화합니다.
폴링 키 설정에서도 공통 Shift 중복 이벤트 대신 좌우 키를 저장합니다.

| 키 | 기능 |
|---|---|
| F1 / F2 | 판정선 위치 감소 / 증가 |
| F3 / F4 | Hi-Speed −0.25 / +0.25 |
| F5 / F6 | Hi-Speed 절반 / 두 배 |
| F7 / F8 | 화면 표시 시점 −1ms / +1ms |
| F9 | 스크린샷 |
| F10 | 계정 |
| F11 | 채팅 열기 / 닫기 (메뉴에서도 동일) |

단축키는 Shift를 요구하지 않으며 Shift를 누른 상태에서도 같은 기능입니다.
F5/F6은 일시정지 상태에서도 동작합니다. 노트 판정·점수·게이지 계산, 오디오 시계,
R1~R4 리플레이/고스트 및 웹 제출 계약은 그대로입니다. 웹 배포나 DB 변경은 없습니다.

## 공개 전 검증 기준

- Release 빌드, 전체 단위 테스트(통합 생략 0), CTest 3/3, 스킨 에디터 검사.
- Shift 정규화·키 저장·탭/LN·보조 키·일시정지 복귀와 단축키 충돌 회귀 검사.
- Studio/Classic 각각 GPU 배칭 게이트와 캡처 비교, 1.8.5 대비 CPU 렌더 p50 증가 0.03ms 이하.
- 실제 MenuApp smoke, 메뉴 조작 영역과 왕복, 창/독점 전체화면 × VSync OFF/ON Present 및 모드 복원.
- 실행/소스 ZIP CRC·추출 SHA-256·개인정보 검사와 압축 해제한 소스의 독립 빌드·CTest·에디터 검사.
- PR/main ASan 및 OpenVINO CI, 병합 Git blob 일치, 초안/익명 공개 자산 재다운로드 확인.

결과 수치와 해시는 릴리스 노트 및 별도 릴리스 증거에 기록합니다. 이전 릴리스,
설치본과 사용자 프로필은 보존합니다.

## 알려진 한계

스튜디오 덱에서 플레이 필드를 왼쪽 끝으로 크게 옮기면 고정된 왼쪽 정보와 겹칠 수
있습니다. 성능 오버레이를 켜면 게이지 표지가 가려질 수 있습니다. 기본 필드 위치에서
사용하거나 Classic으로 전환할 수 있습니다. 스킨 에디터 미리보기의 완전한 HUD 일치는
보장하지 않습니다. 물리 키보드·오디오 지연, 장시간 실곡 플레이와 다른 PC의 동작은
자동 합성 테스트와 별도의 검증입니다.

Gemini 용어 제안은 이번 릴리스의 게임 문구에 적용하지 않았습니다.
