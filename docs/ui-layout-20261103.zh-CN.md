# 选曲与结算界面设计更新

2026-11-03

此本地原生界面采用所提供HTML的黑色背景、细分隔线、顶部标签、左侧曲目列表与右侧详情，以及结算顶部摘要和宽分析区域。

按确认移除白色遮盖的通关分布、中间难度列、列表分数下的通关/BP附注和右侧通关标题。现有指标保留在详情和结算中。不会将示例数字、推测诊断或装饰图当成真实数据。

原生列表显示10行，搜索位于上方。分数按所显示记录使用EX棱彩、HD红、NM黄和EZ绿。验证过的FULL COMBO使用原有浅绿色发光和少量泛光。沿用现有字体、判定及快慢语义色。

保留摘要、轨道、音符类型和时间段标签，以及现有分数、详细精度、连击、判定、分布、均值、绝对误差、标准差、轨道/类型/区间/血槽指标。重试、回放、继续和NEW RECORD/段位提升效果仍可使用。

继承之前的5种音效、音乐选择器、30帧/1秒转场和可选实时比较。使用独立ui-layout-local配置，保留旧候选、原始资源与固定基线1.9.6；不发布新版本。
