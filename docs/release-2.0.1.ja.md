# TenRiff 2.0.1

[한국어](release-2.0.1.ko.md) | [English](release-2.0.1.en.md) | [日本語](release-2.0.1.ja.md) | [简体中文](release-2.0.1.zh-CN.md)

オプション画面の読みやすさを修正しました。

- 既定の銀河背景を2.0.0の明るさの40%に下げました（元画像のRGB倍率0.392）。
- 8枚のカードの幅・高さと内部の文字・アイコンを85%に縮小し、クリック領域も合わせました。
- 選択中の項目の説明をカードの下に1行で表示します。韓国語・英語・日本語・簡体字中国語に対応します。

判定・スコア・リプレイ・保存形式とfinal4互換基準は維持します。カスタム背景の動作は変わりません。
