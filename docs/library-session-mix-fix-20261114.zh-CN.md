# Library 与 Session Mix 按钮修复

添加文件夹按钮只显示在 Library 页的内容标题栏中；Songs、Records 和 Session Mix 不显示此按钮。

Session Mix 的时长、重新混合、保存和导入按钮现已连接到课程页面的专用输入处理。重新混合会显示生成的阶段数。菜单音频播放时也能打开保存及导入文件窗口；取消后保留草稿和现有课程路径。

创建自定义课程：在歌曲列表中选择谱面，按 **C** 按顺序添加到草稿，然后在 Session Mix 中选择**保存草稿**。可重复添加同一谱面。使用**导入课程**选择`.lr2crs`，或将文件拖入 Session Mix。保存空草稿时会显示创建说明。

LR2CRS 格式、谱面 MD5 匹配、课程判定、血条及回放行为均不变。
