# 실패 노트 가림 / 판정선 색상 명도 로컬 후보

공개 1.9.9.9-final2를 바탕으로 만든 별도 로컬 후보입니다. 기존 공개판, 설치와 프로필은 보존합니다. 고정 기준선1.9.6, 점수·판정·입력·오디오·리플레이·웹 정책은 유지합니다.

실패 노트가 판정선 아래로 내려가면 그 부분은 기어 뒤로 가려집니다. 노트의 이동/수명은 유지하되, 기어를 덮던 픽셀을 판정선에서 잘라냅니다. 플레이어·고스트, 비트맵·도형, 단타·LN 머리/몸통/꼬리에 같은 표시 경계를 적용합니다. 판정선 위에 남은 LN 몸통과 앞으로 오는 노트, 히트 이펙트는 그대로 표시합니다.

스킨 → 판정·HUD → **판정선 색상 명도**에서 0~100%를 1%씩 조절합니다. 기본100%는 기존 색상, 0%는 검정입니다. 타입1·타입2의 색상과 글로우에 적용하며 색조·불투명도·판정 시점은 바꾸지 않습니다. 일반 설정/프로필과 .trskin 프리셋에 저장하며 실시간/전체화면 미리보기에도 적용됩니다.

새 폴더에 실행 ZIP을 풀고 launch_win.bat을 실행합니다. 별도 note-gear-local 프로필을 사용합니다. 기존 스킨 설정은 해당 프로필로 가져올 수 있습니다. 임의 스킨·다른 PC·실제 입력/청취·장시간은 별도 검증입니다.
