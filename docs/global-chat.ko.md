# 전체 채팅

[한국어](global-chat.ko.md) | [English](global-chat.en.md) | [日本語](global-chat.ja.md) | [简体中文](global-chat.zh-CN.md)

온라인 모드에서 F10으로 계정을 연결한 뒤 F11을 누르면 전체 채팅을 엽니다. 홈·곡 선택·옵션·플레이·결과·멀티 방에서 같은 채널을 사용합니다. 방에 참가하거나 점수를 등록할 필요가 없습니다.

Enter로 전송하고 Esc/F11로 닫습니다. 한글 등 UTF-8 입력과 /np 현재 곡 공유를 지원합니다. 입력은 256바이트까지이며, 연속 전송은 1초 간격으로 처리합니다. 방을 나가거나 싱글로 전환해도 전체 채팅과 작성 중인 내용은 유지됩니다.

게스트 모드·계정 연결 해제·계정 변경 시 이전 계정의 대화와 전송 대기열을 지웁니다. 인증 실패나 서버 응답 오류 시 전송이 차단되며, F10에서 다시 연결할 수 있습니다. 이미 서버에 전달된 메시지는 로그아웃으로 삭제되지 않습니다.

서버는 최근 100개 메시지를 보관하고 인증된 계정의 이름으로 표시합니다. 새 클라이언트는 전체 채팅만 노출합니다. 기존 방 채팅 API는 이전 클라이언트와의 호환을 위해 남아 있습니다.

전체 채팅 인증은 멀티 방 인증과 분리되어 서로의 연결을 끊지 않습니다. 새 서버와 추가 채팅 테이블이 필요합니다. 배포 전 구버전 서버에서는 채팅 연결을 거부해 기존 멀티 세션을 보존합니다. 2.0.2와 함께 멀티 서버 v4 및 채팅 테이블 4개가 배포되었습니다. 실제 계정 메시지·인터넷 지연·장시간 사용은 별도 확인이 필요합니다.
