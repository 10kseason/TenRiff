# 星座オプション画面とルームチャット入力

[한국어](options-chat.ko.md) | [English](options-chat.en.md) | [日本語](options-chat.ja.md) | [简体中文](options-chat.zh-CN.md)

提供された`TENRIFF_constellation_options_mockup.png`を参考に、標準オプションの8カテゴリを4×2のカードに配置します。各カードに異なる星座、色付きアイコン、現在値、選択強調を表示します。カテゴリ順・設定値・キーボード操作・クリック対象の意味は維持します。星座は静止した装飾であり、実際の天体図ではありません。F1ヘルプは維持します。

提供された`TENRIFF_galaxy_background.png`を変更せず`assets/menu/options-galaxy-background.png`へコピーします。表示時だけ彩度0.92・明るさ0.98の色行列を適用し、アルファは保持します。縦横比を保って画面を覆い、余分な端を切り取ります。標準オプション・設定画面が対象で、カスタムスキン背景は上書きしません。画像読み込みに失敗した場合は従来の背景へ戻ります。控えめな枠の光と星座パネルは表示上の変更です。

無関係なグローバルチャットの設定状態でルームチャット入力が止まる条件を修正します。開いているチャット欄は接続済み`PeerSession`で確定文字を受け取り、ホスティングルームにも同じ経路を使います。F11開閉・Enter送信・UTF-8の256バイト上限は維持します。非表示・切断状態やアカウント/URL警告では、別の欄への誤入力を防ぎます。認証・protocol 2・サーバー送信制限は変更しません。

回帰確認の対象は確定済み韓国語/ASCIIの入力キュー、ローカル双方向チャット、ホスティング応答の代替、2クライアントのWorkerチャットです。この文書ではテスト合格や性能値を主張せず、実行結果は[2.0.0検証ゲート](release-2.0.0-gate.md)に記録します。実際のWindows IME変換候補・確定キーのタイミング、運用アカウントのメッセージ、通信遅延・長時間・他PCは別途確認が必要です。既存の[ALL COMBO表示](menu-starlight.ja.md)・得点・判定ルールは変更対象ではありません。
