# 星座オプションと全体チャット入力

> **2.0.1** 既定の銀河背景を2.0.0の明るさの40%に下げました（元画像のRGB倍率0.392）。 8枚のカードの幅・高さと内部の文字・アイコンを85%に縮小し、クリック領域も合わせました。 選択中の項目の説明をカードの下に1行で表示します。韓国語・英語・日本語・簡体字中国語に対応します。 [2.0.1](release-2.0.1.ja.md)


[한국어](options-chat.ko.md) | [English](options-chat.en.md) | [日本語](options-chat.ja.md) | [简体中文](options-chat.zh-CN.md)

提供された`TENRIFF_constellation_options_mockup.png`を参考に、標準オプションの8カテゴリを4×2のカードに配置します。各カードに異なる星座、色付きアイコン、現在値、選択強調を表示します。カテゴリ順・設定値・キーボード操作・クリック対象の意味は維持します。星座は静止した装飾であり、実際の天体図ではありません。F1ヘルプは維持します。

提供された`TENRIFF_galaxy_background.png`を変更せず`assets/menu/options-galaxy-background.png`へコピーします。表示時だけ彩度0.92・明るさ0.392の色行列を適用し、アルファは保持します。縦横比を保って画面を覆い、余分な端を切り取ります。標準オプション・設定画面が対象で、カスタムスキン背景は上書きしません。画像読み込みに失敗した場合は従来の背景へ戻ります。控えめな枠の光と星座パネルは表示上の変更です。

2.0.2ではオンライン認証済みの全体チャットサービスで入力・送信します。F11で開き、Enterで送信します。ルーム参加は不要です。ゲスト・切断・アカウント変更時にはローカル履歴と送信待ちを消去します。
