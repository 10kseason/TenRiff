# 대표 BPM

[English](reference-bpm.md) · [日本語](reference-bpm.ja.md) · [简体中文](reference-bpm.zh-CN.md)

선곡 BPM과 플레이 Hi-Speed 기준은 실제 진행 시간의 합이 가장 긴 BPM입니다. 같은 BPM 구간은 합산하며, 노트 수나 박자 수로 고르지 않습니다. STOP 대기 시간은 제외하고 SCROLL 값은 가중치에 영향을 주지 않습니다. 동률은 먼저 진행한 BPM을 선택합니다.

차트 시작부터 마지막 비어 있지 않은 이벤트가 있는 마디 끝까지 집계합니다. 롱노트 끝과 BGM·배경 이벤트도 포함하지만, 이후 길이 지정(`02`)만 있거나 전부 `00`인 빈 마디는 제외합니다. Andro 끝의 0.99 BPM 뒤에 남은 빈 마디 때문에 대표 BPM 165가 1로 표시되던 문제를 이 방식으로 수정합니다.

기존 노트 시각·차트 길이·스크롤 구간·리플레이 타이밍은 바꾸지 않습니다. 초기 헤더 BPM도 리플레이와 키/LN 변환용으로 유지합니다. 샘플 반올림 전에 계산하므로 Safe/Fast 선곡 인덱스와 각 오디오 샘플레이트에서 같은 대표 BPM을 사용합니다.

곡 인덱스 캐시 버전 22에서 이전 메타데이터를 한 번 재구축하므로 기존 폴더도 수정된 BPM을 표시합니다. 플레이 기록은 유지합니다. 유효한 진행 구간이 없으면 초기 BPM을 사용하고, 잘못된 타임라인은 기준 BPM 0을 반환합니다.
