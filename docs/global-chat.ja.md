# 全体チャット

[한국어](global-chat.ko.md) | [English](global-chat.en.md) | [日本語](global-chat.ja.md) | [简体中文](global-chat.zh-CN.md)

オンラインモードでF10からアカウントを連携し、F11で全体チャットを開きます。ホーム・選曲・設定・プレイ・結果・対戦ルームで同じチャンネルを使います。ルーム参加やスコア投稿は不要です。

Enterで送信、Esc/F11で閉じます。UTF-8入力と/npによる現在の曲の共有に対応します。本文は256バイトまで、連続送信は1秒間隔です。ルーム退出やソロへの切り替え後もチャットと下書きを維持します。

ゲストへの切り替え、連携解除、アカウント変更時はローカル履歴と送信待ちを消去します。認証失敗や不正な応答時は送信を停止し、F10から再接続できます。既にサーバーへ届いたメッセージはログアウトで削除されません。

サーバーは最新100件を保持し、認証されたアカウント名を表示します。新クライアントでは全体チャットのみを表示し、旧ルームチャットAPIは旧クライアントとの互換性のため残します。

チャット認証とルーム認証は分離し、更新が互いを切断しないようにします。更新サーバーと追加テーブルが必要です。旧サーバーでは専用エンドポイントが拒否され、対戦セッションを変更しません。2.0.2向けにマルチサーバーv4とチャット用4テーブルを配備しました。実アカウントの送受信・インターネット遅延・長時間使用は別途確認が必要です。
