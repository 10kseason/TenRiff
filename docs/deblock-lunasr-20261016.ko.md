# FFmpeg 디블록과 외부 ONNX x2

2026-10-16 · TenRiff 1.9.2. [릴리스 범위](release-1.9.2.ko.md)

**원본 → FFmpeg 디블록 → 외부 AI x2 복원·잔차 합성 → 표시 영역 맞춤 → 필요한 크롭**

FFmpeg 내장 `deblock=filter=weak:block=8:planes=7`을 전체 원본 RGB에 한 번 적용합니다. planar RGB로 YUV 색차 축소를 피하고 원본 알파를 보존합니다. AI 입력과 bilinear x2 합성 바탕은 같은 디블록 결과를 사용합니다.

동적 공간 축을 받는 모델은 원본 H/W 전체를 한 번에 추론합니다. 기존 고정 960×540 입력·1920×1080 잔차 출력은 가장자리 패딩과 32픽셀 문맥 타일로 호환됩니다. 두 경로 모두 추론 전 크기 조절이나 16:9 크롭을 하지 않으며, 실제 출력이 정확히 원본 x2인지 검사합니다. 입력은 `rgb_lr`, 출력은 `rgb_residual_x2`이고 float32/float16 NCHW RGB를 사용합니다. 동적 모델도 batch/channel은 1/3이어야 합니다.

**공개 실행·소스 패키지에 BGA 업스케일 모델을 포함하지 않습니다.** 모델 경로 기본값은 빈 값이며 이전의 빈 선택도 그대로 둡니다. Graphics의 ONNX Model에서 외부 파일을 선택하거나 드롭하면 경로만 저장합니다. 기능 기본값은 OFF이고 별도로 켤 때 기존 확인 절차를 유지합니다. 저장된 사용자 경로는 보존하고, 기존 키 모드 변환용 NK3 모델만 계속 포함합니다.

정지 BGA와 선곡 이미지에 적용하며 영상 AI는 비활성입니다. 원본은 축당4096픽셀까지, 캐시는 인스턴스당3개/96 MiB입니다. 동적 모델은 전체 원본의 메모리가 한 번에 필요하므로 크기 제한이 GPU 메모리 수용을 보장하지 않습니다. FFmpeg는 worker에서 숨김 실행하며 취소 또는10초 제한 시 종료합니다. 실행 파일 누락·필터·모델 실패는 원본 표시를 유지합니다. WinML의 이미 시작된 추론은 중간 취소할 수 없지만 오래된 결과를 표시하지 않습니다.

FFmpeg는 게임 실행 파일 옆 `tools/ffmpeg-deblock/ffmpeg.exe`, 이후 PATH에서 찾습니다. 의존성 고지는 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)를 따릅니다. 외부 모델 원본·이전 후보·설치·프로필은 보존합니다. 모델별 화질·성능과 실제 장시간 플레이는 별도로 검증해야 합니다.
