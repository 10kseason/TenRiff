# TenRiff 1.9.3 공푸어 정확도 정책

새 플레이에서는 노트가 없는 곳의 이른 입력으로 발생하는 공푸어가 체력을 깎고 POOR 개수에 남지만, 일반 정확도와 상세 정확도 분모에는 들어가지 않는다. 시간 구간 정확도 그래프도 같은 기준을 사용한다. 실제 노트를 놓쳐 생긴 POOR와 BAD는 이전처럼 정확도를 낮춘다.

예를 들어 노트 두 개를 정확히 처리하고 공푸어가 한 번 있으면 새 정확도는 100%다. 이전 정책으로 기록한 같은 입력은 66.666…%를 유지한다. 공푸어의 체력 감소량, POOR 개수, 점수 공식, 콤보 처리, 판정 창은 바뀌지 않는다.

## 호환성

- 새 일반/Easy/Hard 플레이: `tenriff-native-score-v2-ruleset-7`.
- 새 EX 플레이: `tenriff-native-score-v2-ruleset-8`.
- 비표준·코스·연습 보조 등 기존 custom 경로: 대응하는 `custom-ruleset-7` 또는 `custom-ruleset-8`.
- R1–R6와 이전 custom 기록은 기존 공푸어 정확도 정책으로 재생·검증한다. 리플레이 직접 재생과 고스트 엔진 모두 기록의 규칙 ID로 정책을 선택한다.
- 새 기록에 정확도 정책을 나타내는 JSON 필드를 추가하지 않는다. 기존 규칙 ID와 저장된 정확도 누적값을 사용하므로 리플레이 파일 형식 버전은 그대로다. 과거 결과 파일을 다시 쓰거나 등급을 소급 계산하지 않는다.

## 온라인 경계

일반/상세 정확도가 온라인 동점 순위에 쓰이므로 새 정책은 R7/R8의 별도 보드로 전송한다. 기존 R5/R6 보드 ID와 기록은 그대로 유지한다. 클라이언트는 과거 규칙으로 ID를 바꾸어 전송하지 않는다. R7/R8을 지원하는 운영 리더보드 버전 19를 2026-10-16 사용자 승인으로 배포했다. 다른 구 서버에서 새 규칙을 거부하면 업로드 실패로 표시한다. 서버 리플레이 검증과 게스트 업로드 권한은 이 변경으로 추가되지 않는다.

Guest 기록과 출처 표시 없는 과거 기록의 영구 업로드 제외, Online 선택 요건, `client_submitted` 신뢰 경계는 그대로다. 모델이나 판정 난이도 배지 표시는 이 정책을 바꾸지 않는다.
