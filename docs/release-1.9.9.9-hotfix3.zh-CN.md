# TenRiff 1.9.9.9-hotfix3

- **NK2 E+** 支持 7K、8K 和 10K。在选项 → 模式中选择目标键数、NK2 和 **E+ - Full-field + taps**。回到支持的键数时会恢复 E+ 选择，在保留的长音符尾部添加的单键音符使用原始采样位置。
- **Safe 索引**共用一次谱面读取来解析和计算哈希，并复用同一时间轴计算 NPS 和难度。使用 12,000 张合成谱面测试，首次索引的中位数从 10.898 秒降至 8.501 秒，重新打开缓存的中位数从 3.414 秒降至 3.042 秒。
- 曲库标签下方新增 **添加歌曲文件夹** 按钮。选歌界面可以直接打开 Windows 文件夹选择器。曲名和艺术家的排序显示为 A-Z 和 Z-A。
- 在线记录统一通过 **TenRiff 排行榜**查询和提交。按 F10 选择 Online，粘贴官网的连接信息或导入连接文件。游戏内可查看 R13/R14 及分开的 E+ v1 和 v2 榜单。多人模式支持局域网搜索和直接连接其他玩家。

请将 Windows ZIP 解压到新文件夹，再运行 `launch_win.bat`。请单独保留已有安装和个人配置。固定基线版本为 **1.9.6**。
