# 全体聊天

[한국어](global-chat.ko.md) | [English](global-chat.en.md) | [日本語](global-chat.ja.md) | [简体中文](global-chat.zh-CN.md)

选择在线模式，通过F10关联账号，然后按F11打开全体聊天。主页、选曲、设置、游玩、结果及多人房间使用同一频道，无需加入房间或上传成绩。

按Enter发送，Esc/F11关闭。支持UTF-8输入及/np分享当前曲目。正文上限256字节，连续发送间隔1秒。退出房间或切换到单人模式会保留聊天及草稿。

切换访客模式、解除关联或更换账号时会清除本地历史及待发消息。认证失败或响应无效时停止发送，可通过F10重新连接。退出登录不会删除已送达服务器的消息。

服务器保留最新100条消息，显示经过认证的账号名称。新客户端仅提供全体聊天；旧房间聊天API为兼容旧客户端而保留。

聊天认证与房间认证相互独立，续期不会断开另一服务。需要新版服务器及新增聊天表。旧服务器会拒绝专用聊天接口，不替换房间会话。已为2.0.2部署多人服务器v4及四个聊天表。真实账号消息、网络延迟和长时间使用仍需单独验证。
