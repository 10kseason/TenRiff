# 스킨 HUD X/Y 위치 조절

2026-10-19 사용자 요청에 따라 공개 1.9.7 (`948518d`)을 바탕으로 1.9.8에 포함하는 변경입니다. 1.9.7의 공용 키·색상 탭·매 판 새 시드·배경음 기준 이득을 그대로 포함합니다. 일반 고정 기준선 1.9.6과 이전 릴리스·후보·설치본·프로필은 보존합니다.

- 키 구분선 명도: 0~100%, 1% 단위 슬라이더와 −/+. 기본 100%는 기존 색상이며 0%는 검정입니다. RGB만 조절하고 알파·표시 여부·너비·마디선은 유지합니다. 미리보기와 실제 플레이/고스트에 적용하고 즉시 캐시를 갱신합니다. 선택적 설정 `skin.lane_divider_brightness`를 프로필과 휴대용 스킨에 저장하며, 없는 기존 파일은 100%로 읽습니다.

| 스킨 설정 항목 | X | Y |
| --- | --- | --- |
| 판정 | −600~600px, 10px 단위 | 기존 세로 위치 비율 |
| 콤보 | −600~600px, 10px 단위 | 기존 세로 위치 비율 |
| FAST/SLOW 인디케이터 | −600~600px, 10px 단위 | 기존 −400~400px, 10px 단위 |
| FAST/SLOW 막대 | −600~600px, 10px 단위 | 기존 −400~400px, 10px 단위 |

- 각 항목의 X/Y를 나란히 표시합니다. Native/TenRiff/LR2 모두 설정 검색, 키보드 좌우, 마우스 −/+로 조절합니다.
- X는 기존 위치에서의 가로 오프셋입니다. 음수는 왼쪽, 양수는 오른쪽입니다. 각 항목은 독립적이며 X 조절로 Y 저장값이 바뀌지 않습니다.
- 숨겨졌던 기존 X 설정만 다시 노출합니다. 기본값 0, 이전 저장값, 프로필/휴대용 스킨의 형식과 미리보기·Classic/Studio·고스트의 기존 렌더링 경로를 재사용합니다. 좌표를 새로 만들거나 초기화하지 않습니다.
- [2026-10-18 정책](skin-ui-followup-20261018.ko.md)의 네 X 설정 숨김은 이 작업에서 대체합니다. 기어 경계선과 다른 숨김 항목은 유지합니다.
- 판정선은 레인에 붙는 기존 구조입니다. 판정선의 가로 배치는 미리보기의 필드 드래그로 함께 옮기는 기존 기능을 사용합니다.
- 판정·입력·점수·리플레이·오디오 처리는 변경하지 않습니다. 자동 검증과 실제 물리 입력·장시간 플레이 검증은 구분합니다.

[1.9.8 변경 안내](release-1.9.8.ko.md)와 [검증 절차](release-1.9.8-gate.md)를 참조하세요. 이 문서의 기능 설명은 검증 완료 선언이 아니며, 공개 상태와 다운로드는 [1.9.8 릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.8)가 기준입니다.
