# 先以原始分辨率修复BGA，再适配显示区域

2026-10-16

此本地修改基于1.9.1.1 (`ea8bdba`) 和已验证的UI候选版本。保留固定评级、亮度、加载、语言设置，以及BMS、在线记录、输入和音量行为。

处理顺序为：**原始图像 → AI二倍修复与残差合成 → 调整至显示区域 → 必要时裁剪**。取消推理前的16:9裁剪和960×540缩放。640×480先修复为1280×960，300×900先修复为600×1800，再适配画面。

继续兼容960×540输入、1920×1080残差输出的现有模型。直接使用原始像素，较小图像以边缘像素填充，较大图像以带32像素上下文的重叠图块处理，再按原始二倍坐标合成。去除填充和上下文不会丢弃原图内容。音符、HUD和BGA亮度的处理顺序保持不变。

原图每边最大4096像素，修复后最大8192像素。超限或模型失败时保留普通显示，不会隐式缩小AI输入。仅处理静态图像，视频AI仍禁用。每个实例最多缓存3张图像／96MiB，并在图块之间取消过期任务。

大图需要更多推理和内存。需要超过32像素或全局上下文的模型可能出现图块相关差异。合成测试验证像素、尺寸、透明度和FP32/FP16接口，不保证训练模型画质或实时帧率。
