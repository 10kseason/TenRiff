# TenRiff 1.8.9.5 — 판정·표시 시간 일관성

1.8.9.4 소스에서 이어지는 수정입니다. 고정 문서 기준 1.8.7과 이전 태그·배포본·사용자 프로필은 유지합니다.

## 재현한 문제와 처리

- 오디오 write buffer 끝까지 판정을 진행하면 실제 재생 시각보다 먼저 LN 꼬리·지뢰·자동 미스가 확정될 수 있었습니다. R5는 입력과 같은 playback 시간에 입력 보정을 적용한 지점까지만 판정하고, 미리 준비할 키음은 별도로 예약합니다.
- 같은 일반 LN의 늦은 해제도 중간 `advance` 호출 유무에 따라 PG/GR이 달랐습니다. R5는 입력보다 이른 자동 사건을 먼저 처리하여 끝까지 유지한 일반 LN을 꼬리 시각에 완료합니다. 이른 해제와 CN 해제 판정은 유지합니다.
- 서로 다른 레인의 미스·LN 완료를 레인 순서로 처리하면 콤보·게이지·게임 오버 결과가 달랐습니다. R5는 사건 시각을 우선하고 동률은 안정된 순서로 처리합니다. 밀리초 단위 판정 창은 R4와 같습니다.
- 입력의 필터된 시계와 화면의 원시 오디오 관측값이 달랐습니다. 새 플레이는 공통 시계로 입력과 HUD를 계산합니다. 화면 위치는 표시 시각의 실제 BPM/STOP/SCROLL 구간을 조회하여 이전 구간 속도로 경계를 지나친 뒤 되돌리는 현상을 방지합니다.
- 로비 카드와 글자는 어두운 배경/밝은 글자로 복구하고 플레이·멀티플레이·종료 아이콘에만 하늘색·빨강·흰색을 적용합니다. 마스터 음량은 오디오 설정 맨 위, 다음은 BGM·키음입니다. 저장된 음량은 그대로입니다.

## 기록 호환

새 정식 플레이는 기존 `ruleset_id` 필드의 `tenriff-native-score-v2-ruleset-5`를 사용합니다. 커스텀 플레이도 `custom-ruleset-5`로 처리 버전을 구분하며 정식 기록으로 인정하지 않습니다. 리플레이 JSON 구조·변환 버전·기존 점수 파일을 재작성하지 않습니다.

R1~R4는 과거 엔진 순서와 판정 정책을 사용합니다. 예전 기록의 순서 의존성을 새 규칙으로 소급 고치는 것은 호환 정책에 포함되지 않습니다. 웹은 R5를 추가로 받고 기존 보드 식별값과 기록을 보존합니다. R4와 R5 점수는 같은 보드로 합치지 않으며 DB 마이그레이션은 없습니다.

오래 밀린 입력을 점수 없이 상태만 복구하는 경로는 기존 리플레이의 일반 누름/해제 이벤트만으로 정확히 표현할 수 없습니다. 이 복구가 실제 발생한 새 플레이는 경고를 남기고 `custom-ruleset-5`로 저장하여 공식 기록에서 제외합니다. 정상 시작 시의 키 상태 확인에는 이 제한을 적용하지 않습니다. 이는 기록 자격을 보수적으로 제한한 조치이며, 상태 복구가 포함된 리플레이의 완전한 재현을 해결한 것은 아닙니다.

공통 시계는 위상을 즉시 뛰어넘기는 대신 진행 속도를 최대 ±2% 안에서 조정합니다. 500ms 보정 목표는 한 번의 오차가 남아 있지 않도록 따라가는 설계값이며, 큰 시각 단절은 속도 제한 때문에 더 오래 걸립니다. 실제 드라이버마다 최적이라고 측정한 값은 아닙니다. 표시용 비주얼 오프셋과 사용자 입력 보정은 서로 분리합니다.

느려진 새 시계 구간이 늦게 화면에 전달되면 이전 화면이 이미 외삽한 시각보다 작아질 수 있습니다. 렌더러는 이때 표시 시각만 잠시 유지하고 시계가 따라오면 계속 진행합니다. 새 세션·일시정지·시각 되감기에서는 이 캐시를 초기화하며, 비주얼 오프셋 변경과 차트의 역방향 스크롤에는 적용하지 않습니다. 기존 외삽 한계는 `max(24ms, 오디오 버퍼 길이 × 2)`이므로 모든 장치에서 최대 24ms라고 해석하면 안 됩니다.

## 검증 구분

회귀는 36,000개 판정 경계 조합, callback 크기·padding·입력 보정, 일반 LN/CN/지뢰·자동 미스, 낮은 게이지, 입력 그룹과 자동 사건 동률, 리플레이 검증기, BPM/STOP·offset·reverse scroll을 포함합니다. 이 문서의 검사 목록은 실행 결과 자체가 아닙니다. 최종 빌드·CTest·네이티브 화면·패키지 재빌드·CI·공개 다운로드 결과는 해당 릴리스의 검증 보고서 및 공개 릴리스 노트로 확정합니다.

합성 입력과 실제 Windows 렌더/무음 오디오 경로 검사는 사람의 키보드·청취·장시간 플레이 검사와 구분합니다. 이번 수정만으로 사용자가 보고한 물리 장치의 흔들림 원인이 전부 해소됐다고 단정하지 않습니다. 실제 기기의 입력/출력 지연, 다른 PC, 오디오 장치의 장기 drift와 최악 지연은 별도 확인 대상입니다.

수치 창과 동률 처리 규칙은 [판정 범위](judgement-windows.md)를 참고하세요.
