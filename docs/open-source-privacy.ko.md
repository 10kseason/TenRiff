# 공개 소스와 웹 랭킹 정보 경계

1.7.7 공개 소스 번들은 클라이언트 코드만 포함합니다. 웹 랭킹 서버 소스, 배포 설정, 데이터베이스, 계정 연결 파일, 업로드 키, Bearer 토큰, 프로필, 로그, 리플레이/결과 내보내기, 개인 모델 체크포인트는 포함하지 않습니다.

소스에 남아 있는 랭킹 관련 코드는 클라이언트의 공개 프로토콜 처리와 입력 검증을 위한 것입니다. 실제 연결 정보는 실행 중 사용자가 붙여넣고 Windows DPAPI로 로컬 보호하며, 공개 패키지에는 들어가지 않습니다.

공개 전 확인 항목:

- `tr_` 형식 업로드 키와 Bearer 토큰 검색
- API 키·비밀번호·개인키 리터럴 검색
- `profiles/`, `logs/`, `songs/`, `.dpapi`, `.pem`, `.key` 파일 제외 확인
- ZIP 압축 해제 후 위 항목 재검색
- 소스 ZIP과 바이너리 ZIP의 SHA-256 기록

이번 릴리스는 실제 계정 업로드를 실행하지 않았습니다. 로컬 페이로드 생성과 정적 누출 검사는 웹 서버에 기록을 쓰지 않습니다.
