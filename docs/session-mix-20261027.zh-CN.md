# Session Mix 课程选择 · 2026-10-27 本地候选

将原来的设置行改为课程菜单、课程列表、关卡顺序三个区域。复用选曲背景和等比缩放，采用独立课程布局，避免改变已保存的选曲皮肤坐标。

导入`.lr2crs`，用点击、上下键或滚轮选择课程，检查关卡，再用Enter、双击或进入课程开始。PgUp/PgDn移动7项，Tab依次切换列表、菜单、关卡；长关卡列表也有前后翻页按钮。所有原始MD5必须匹配当前已索引曲库，不受普通选曲搜索/显示筛选限制。保留原顺序及重复关卡，按原位置显示缺谱，不替换或跳过缺谱。进入前检查所有谱面文件存在。保留连续血条及结果页Enter进入下一曲的行为；完成、失败或结果页Esc后返回课程列表。

自动混合按预览列表开始。重新生成、时长/曲库变化或重新进入屏幕时更新。遵循当前选曲筛选，同一音频路径（没有则用文件夹+标题）的不同难度只选一次。这是启发式去重，不保证识别全部重复；不限制手写课程或草稿的重复。用准确率80–100%的通关记录作为难度基准，按热身→挑战→放松逐步安排，并惩罚过大难度跳跃。无记录时从等级下四分位开始，种子提高相近候选的多样性。15/30/60分钟仍是每曲约3分钟、5/10/20曲的目标，不保证实测时长。规则测试不证明乐趣或技术提升。

包含此前F1减速/F2加速默认值及长按加速。保留已存按键、判定、等级、回放、课程血条和Web上传边界。不更改LR2CRS格式、公开版本或固定1.9.6基线。保留旧版本、候选、安装及配置；本地启动器使用独立session-mix-local配置。验证见候选上层evidence/VERIFICATION.ko.md。物理输入、试听、长时间课程及任意用户文件仍未验证。
