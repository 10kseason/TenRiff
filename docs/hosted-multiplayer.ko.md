# 중앙 서버 멀티플레이

TenRiff 2.0.0의 중앙 서버 멀티플레이 안내입니다. 호환 기준 final4, 기존 리플레이·판정·PeerProtocol v9는 유지합니다. 새 온라인 방은 별도 hosted protocol v2와 `score_version="ex-v1"`을 사용합니다. 점수와 순위는 [EX Score](ex-score.ko.md) 기준이며 이전 hosted v1 또는 직접-IP 클라이언트와 혼합할 수 없습니다.

F10에서 Online을 선택하고 기존 리더보드 연결 정보를 가져옵니다. 멀티플레이의 서버 방 목록에서 참가하거나 방 만들기를 선택합니다. 계정은 서버에서 검증하며 기록이 없어도 참가할 수 있습니다. Guest, 만료되거나 폐기된 연결 키는 참가할 수 없습니다. 게임 화면은 IP·포트 입력이나 LAN 접속을 제공하지 않습니다.

방은 별도 TenRiff Multiplayer Site가 HTTPS와 D1으로 관리합니다. 최대 8명이고, 방장이 나가면 남은 참가자에게 선곡권을 넘깁니다. 방장은 자기 목록에서 BMS를 고르며 다른 PC는 같은 파일을 로컬에서 찾습니다. 전원 차트 일치 및 준비 후 시작합니다. 전체 곡 보유 목록이나 차트·음원 파일은 전송하지 않습니다. 기존 직접 연결의 사전 공통곡 목록 대신 선택한 곡의 일치 여부를 확인합니다.

음악과 입력 판정은 각 PC가 처리합니다. 서버는 미래 시작 시각을 배포하며 모든 참가자가 그 시각을 사용합니다. 늦게 받은 시작이나 지나치게 느린 응답은 안전하게 거부합니다. 경기 상태와 상대 점수는 500ms 주기로 교환하므로 상대 점수가 늦게 표시될 수 있습니다. 실제 인터넷 지연·8인 부하·장시간 플레이·D1 사용량은 별도 검증이 필요합니다. 서버 호스팅은 점수 리플레이 검증이나 부정행위 방지를 뜻하지 않습니다.

방 채팅은 F11입니다. 계정 연결을 해제하거나 Guest로 전환하면 멀티 연결도 종료합니다. 연결 키는 리더보드 확인을 위해 공식 멀티 Site에 HTTPS로 전달되며 저장하지 않습니다. 이후에는 해시로 저장되는 짧은 세션 키를 사용하고 20초마다 원래 연결 키를 다시 확인합니다. 폐기 반영에는 최대 30초의 세션 수명이 적용됩니다.

2026-11-14: 승인된 새 Site의 D1 테이블 4개와 MULTIPLAYER_ENABLED=1을 반영했습니다. 공개 API 입구에서 계정 세션 인증을 필수로 적용하며 미인증·위조 헤더·무효 키 거절을 운영 환경에서 확인했습니다. 실제 계정의 경기·인터넷 지연·장시간 부하·비용은 아직 검증하지 않았습니다. 새 설치는 기본 Guest이므로 F10에서 직접 계정을 연결해야 합니다.
