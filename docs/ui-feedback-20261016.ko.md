# 홈·그래픽·로딩 및 고정 등급 — 1.9.1.1 후속 후보

2026-10-16 · `ea8bdba0fb8aa533f0e684b64fc64515e2eb2e41`

사용자가 확인한 **1.9.1.1 출시 커밋**을 기반으로 만든 로컬 후속 후보입니다. 앞서 잘못 만든 1.9.0 기반 UI 후보를 대체합니다. 1.9.1.1의 BMS TOTAL·BPM/STOP 타이밍·RANDOM 분기·온라인 기록 지원, 통합 볼륨·입력·언어 전환을 모두 유지합니다. 작업 기반 선택이며 고정 기준선·공개 태그의 승격은 아닙니다.

- 그래픽 옵션의 V-Sync 행을 제거하고 주사율 선택을 유지합니다. 저장된 `graphics.vsync` 값은 호환을 위해 유지합니다.
- BGA 밝기는 0~100%, 1% 단위이며 기본 100%입니다. 차트 BGA만 어둡게 하고 노트/HUD는 유지합니다.
- 기존 홈 오른쪽 아래 English → 한국어 → 日本語 → 中文 버튼과 프로필 저장을 유지합니다.
- LR2/TenRiff 스킨 임포트, 곡 로딩·인덱싱, 난이도표 로딩은 같은 중앙 로딩 패널을 사용합니다. 진행률을 모르면 움직이는 막대를 표시합니다.
- 등급은 반올림 전 일반 정확도 기준입니다. 기존 점수·판정·게이지·리플레이·숫자 순위는 유지하고 기록 파일을 다시 쓰지 않습니다. 기록 없음·중단은 --, 자동연주는 AUTO입니다.
- 웹 Stable은 정식 운영 표시와 이 고정 등급표를 뜻합니다. 서버 리플레이 재검증을 의미하지 않습니다.
