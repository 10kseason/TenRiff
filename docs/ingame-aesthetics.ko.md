# 인게임 화면 다듬기

1.8.5를 기준으로 한 인게임 표시 개선입니다. 판정, 입력, 오디오, 리플레이(R1~R4), 고스트 규칙과 1.8.5의 GPU 노트 배칭 경로는 바꾸지 않습니다. 변경은 HUD와 정적 플레이필드 레이어, Luma Keys 키 라벨에 한정됩니다.

## 바뀐 점

- **헤더 열**: 곡 제목·아티스트·상태줄을 플레이필드 왼쪽 열(필드 32px 앞까지) 안에 둡니다. 이전에는 상태줄이 첫 레인 위까지 넘어갔습니다. 상태줄은 `RATE / HS / BPM`과 `스크롤 / 판정선 / 레이턴시` 두 줄로 나누고, 넘칠 때만 실제 글자 폭을 측정해 축소합니다. 필드를 왼쪽 끝까지 끌어 열이 240px보다 좁아지면 이전 폭을 유지합니다(`gameplay_solo_header_right`). 대전(상대 카드) 화면은 한 줄을 유지합니다.
- **구분자**: UI 문자열 정리 과정에서 연속 공백이 하나로 줄어 `0.00%/ DETAIL`, `PG 3 GR 0 G 0`처럼 붙어 보였습니다. HUD 문자열을 한 번에 조립하고 항목 사이를 `·`로 나눕니다.
- **키 라벨(Native 렌더러)**: 라벨이 키 하단 베젤에 걸려 잘려 보였습니다. 이제 Luma Keys 키 아트의 라벨 창(256px 기준 y 204~238) 중앙에 놓이고 키가 눌리면 함께 내려가며 밝아집니다. 창 속 LED 줄이 글자를 가로지르지 않도록 글자 뒤에 창 색 판을 깝니다. 외부(LR2/TenRiff 이미지) 스킨과 `top` 위치 설정은 이전과 같습니다.
- **눌린 레인 빛**: `키 배경`은 레인 전체를 같은 농도로 칠했습니다. 이제 설정한 불투명도는 키 쪽 최대값이고 위로 갈수록 옅어집니다. 색·밝기·높이 설정은 그대로 적용되며, 레인 색별 그라데이션 브러시는 색이 바뀔 때만 다시 만듭니다.
- **판정선 주변 조명(Native)**: 판정선 위로 옅은 빛이 고이고 필드 양옆 레일이 판정선으로 모입니다. 정적 커맨드 리스트에 한 번만 기록하므로 프레임당 비용이 없습니다. 기존 `판정선 글로우` 설정을 끄면 함께 꺼지고, 스킨의 `judgement_glow`/`judgement_line` 색을 따릅니다.
- **일시정지 메뉴**: 버튼과 조정 행의 글자를 세로 중앙에 두고, 선택 행에 강조 막대를 더합니다. 클릭 영역은 같습니다.
- **재개 카운트다운**: 왼쪽 위 `재개3` 글자 대신 필드 안(콤보 아래, 판정선 위)에 반투명 카드로 크게 표시합니다. 멈춘 노트는 그대로 보입니다.
- **진행 바**: 0% 근처에서 둥근 모서리가 잔선처럼 남던 채움을 그리지 않고, 고스트 화면의 얇은 내장 트랙에서는 잘리던 시간 글자를 생략합니다.
- **필드 이동 핸들**: 플레이 중에는 옅게, 마우스를 올리거나 끄는 동안에는 이전처럼 선명하게 표시합니다. 히트 영역은 같습니다.

## 검증

- `bms_parser_tests` 986개(새 헤더 열 테스트 포함), CTest 3/3, 통합 테스트 생략 0.
- GPU 배칭: 1.8.5 릴리스와 같은 7개 픽스처에서 원래 경로와 기본 경로의 픽셀 차이가 배칭 대상은 최대 2/255이고 배칭 제출이 발생했으며, 대체 경로(롱노트·소수 노트·VSync)는 픽셀이 완전히 같고 제출이 없습니다.
- 렌더 비용: 1.8.5 `menu_visual_preview`와 번갈아 6회씩 측정한 CPU 렌더 호출 시간 중앙값의 p50/p95/p99가 16K·10K 롱노트·고스트에서 같거나 낮았습니다. GPU FPS나 실제 입력 지연 측정이 아닙니다.
- 화면: 4K/7+1/8K/16K, 고스트, 일시정지, 재개, 960×540, 영어, 외부 스킨(LUNAR-FRACTURE) 픽스처를 1.8.5와 나란히 비교했습니다.

## 남은 확인

실제 곡 장시간 플레이, 실기기 입력 체감, 다른 GPU/해상도 배율, 스킨 에디터 미리보기와의 세부 위치 일치(에디터는 근사 배치)는 확인하지 않았습니다.
