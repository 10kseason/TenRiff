# TenRiff 1.9.5 — 출력 장치 통합과 판정 인디케이터

메뉴·결과 음악도 사운드에서 선택한 장치로 재생합니다. 인디케이터는 FAST 파랑 / 최대판정 초록 / LATE 빨강이며 FAST/SLOW도 최대판정 입력으로 갱신합니다. 로비 랜덤 순서는 OFF → 미러 → 랜덤 → S랜덤 → 스크고정 랜덤 → OFF입니다.

- 이전 MCI 경로를 게임과 같은 AudioThread/디코더로 교체해 메뉴·결과 음악에도 WASAPI 장치 또는 ASIO 드라이버를 적용합니다. 메뉴 WASAPI는 같은 장치의 공유 모드이며 게임의 독점 모드 설정은 유지합니다. 선택 장치가 없으면 다른 출력으로 자동 전환하지 않습니다. 음량·장면별 곡 순환·포커스 음소거를 보존합니다.
- 파일은 메뉴/오디오 콜백 밖에서 비동기 디코딩하고, 입력이 없는 메뉴에서도 완료를 확인합니다. 곡 미리듣기·게임·에디터 진입 전에 기존 장치를 해제합니다. 오래된 에디터 디코딩 결과는 연습/결과 화면에서 재생을 시작하지 않습니다. 설정 조절 클릭음은 기존 Windows 기본 경로입니다.
- 파란 왼쪽 범위는 FAST, 초록 중앙 범위는 최대판정, 빨간 오른쪽 범위는 LATE입니다. 중앙 너비는 실제 엔진의 샘플 단위 최대판정 경계이며 플레이어/고스트가 각자 적용된 판정 정책을 따릅니다. 구간 안의 점/바코드 또는 최대판정을 받은 표시는 초록색입니다. 최신 마커도 색을 유지합니다. 최대판정만 이어져도 조건부 인디케이터가 표시되고, 마커별 0.7초 만료와 항상 표시 눈금은 유지합니다.
- FAST/SLOW는 최대판정도 최신 입력 시간차로 갱신합니다. 정수 밀리초로 반올림한 값이 0이면 문구를 지웁니다. 조건부 글자는 0.75초, 항상 모드의 글자는 마지막 값 유지입니다. 판정 점수·윈도·리플레이 수치는 변경하지 않습니다.
- 곡 선택 랜덤 순서: OFF → 미러 → 랜덤 → S랜덤 → 스크고정 랜덤 → OFF. 역방향도 대응합니다. `rr`은 표시만 랜덤으로 바꾸며 변환 알고리즘, 저장 토큰, 시드와 리플레이 의미는 유지합니다. 한국어 끔/꺼짐 값 표시는 OFF로 통일합니다.
- 1.9.4의 플레이 중 캐시 보관·메뉴 정리, ×0.5/×2, 키 지정, 마디선 정렬과 1.9.3 기능을 유지합니다. 고정 기준선 1.9.0, 기존 릴리스·설치·프로필, Guest/등급/R7·R8/옛 리플레이, 외부 BGA 모델 미동봉과 OFF/빈 경로/Auto 기본값은 그대로입니다.
