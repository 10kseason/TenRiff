# TenRiff 1.8.7

1.8.6 이후의 피드백 수정과 곡 제목 자동 맞춤을 포함합니다. 실행용 ZIP은 새 폴더에 풀어 사용하고, 기존 프로필은 게임의 가져오기로 옮길 수 있습니다. 기존 설치 폴더에 덮어쓸 필요가 없습니다.

## 바뀐 동작

- 양수 입력 보정이 오디오 콜백의 진행 위치에 따라 줄어들던 결함을 수정합니다. WASAPI 재생 위치와 그 위치를 관측한 시각을 함께 사용합니다. 키음은 실제 입력에 즉시 반응하며, 판정 창과 R1~R4 리플레이 정책은 유지합니다.
- 차트 분석과 샘플 레이트 선택 후 게임 오디오를 한 번 엽니다. 로딩 화면만 60FPS로 제한하고 플레이가 시작되면 기존 프레임 설정을 복구합니다.
- LR2 가져오기 스킨도 단독 플레이에서 스튜디오 덱을 지원합니다. 왼쪽 리프 맵을 끌 수 있고 밝은 배경 위의 HUD에는 어두운 바탕을 사용합니다.
- FAST/SLOW를 750ms 유지해 뒤따르는 PG가 지우지 않습니다. 글자와 막대의 위치는 판정 위치와 독립적이며, 막대는 비PG 판정 후 또는 항상 표시를 선택할 수 있습니다.
- 키를 다른 기본·보조 슬롯에 할당하면 같은 키 모드의 이전 슬롯에서 제거합니다. 비워진 기본 키는 저장 후에도 미할당으로 유지됩니다.
- 옵션은 여덟 카드입니다. 모드는 키 모드 설정, NKRO 입력 테스트는 키 설정에서 엽니다.
- 곡 제목 전체를 플레이필드 크기·위치에 맞춰 표시합니다. 왼쪽 공간이 좁으면 오른쪽 HUD 아래로 옮기며 필드 변경 시 기존 글자 레이아웃을 재사용합니다.

최종 소스 ZIP의 1,057개 파일은 병합 Git blob과 정확히 같고 독립 빌드한 후보와 같은 트리입니다. 최종 ZIP 자체를 다시 독립 빌드한 것은 아닙니다. 선택적 외부 Python 참조 구현 비교는 실행하지 못했습니다.

작업 공간에 보관한 상세 증거는 `1.8.7-release/evidence/VERIFICATION.ko.md`, `summary.json`, `source-commit-dist.json`, `release-public-readback.json`입니다. 이 경로는 개발 작업 공간의 자료이며 공개 소스 ZIP에 포함된다는 뜻이 아닙니다. 배포 파일 식별자는 [기준선 자산 표](baseline-1.8.7.md#release-identity)를 사용합니다.

## 남은 경계

확인된 입력 보정·콜백 결함은 이전 버전에도 있었습니다. 제보자의 기기에서 보고된 노트별 싱크 흔들림 전체가 해결됐다고 단정하지 않습니다. 물리 입력·음성채팅·긴 연주·다른 PC·온라인 대전은 별도 확인이 필요합니다. WASAPI 독점 출력은 다른 앱과의 동시 출력을 보장하지 않습니다.

라이브 입력 키음과 보정 시각만 저장한 리플레이 키음은 같지 않을 수 있습니다. [입력 보정](input-offset-timing.ko.md), [콜백 관측 시각](audio-callback-timestamp.ko.md), [로딩](chart-loading-audio.ko.md)을 참고하세요.

아주 긴 제목은 전체 표시를 위해 작은 글자로 줄어들 수 있습니다. 모든 LR2 스킨과 극단적 HUD 위치를 확인한 것은 아닙니다. 노트 배칭 코드와 노트 그리기 루프는 그대로 유지합니다. 이전 추가 동적 렌더 시험에서는 클래식의 CPU p50이 1.8.5보다 +0.1939ms였으며, 고정 캡처 시험의 통과가 이 차이를 해소했다는 뜻은 아닙니다.
