# BMS固定难度估计、KPS线程和血条颜色

基于1.9.9.1的本地候选，保留此前快捷键、Session Mix、加大标志和通关卡片。固定基线1.9.6及既有发布、安装、配置不变。

在**皮肤 → 判定/HUD → 按键叠加插件**启用，默认关闭，保存开关及X/Y，仅显示4/5/7/8/10键，无须独立安装。大号**BMS难度估计**在加载时读取整曲并计算一次，游玩期间固定，不受输入、判定或自动演奏影响。分析当前键数、速度、随机/转换后的BMS，先于练习截取和倒计时添加；新一局配置改变可能改变估计。

此功能取代实时输入难度。沿用v2.13核心，每0.5秒评估8秒区间及4秒预热上下文，选取峰值。只分析BMS的单键和长按时序，不分析音视频或键盘活动。保留4K Reform、5K AERY、7K Jinjin、8K Regular、10K Revive单位，箭头表示超出校准范围。这是谱面区间负荷参考，非官方等级、玩家实力或通过概率。数据稀少、无效/同轨重叠或超出限制（25万音符、一小时、核心事件容量）显示“无法估计”，不会给截断谱面估值。皮肤预览仅显示模拟内容。

**KPS**为最近一秒的实际轨道按下次数，不重复计算按键重复、持续按住轨道的辅助键接管，不统计自动/回放/幽灵输入。暂停、失焦、倒计时清空按键并显示KPS `--`，BMS估计保持不变。输入路径只复制到固定SPSC队列，无分配、互斥等待或唤醒。低优先级独立线程约每8ms更新，HUD采用不等待的快照，100ms过期或队列溢出清空显示。线程随会话结束。尚未测量真实硬件延迟/FPS提升。

Classic/Studio/幽灵默认血条统一为 **EZ #00ED57、NM #FFF000、HD #FF3838、EX彩虹**。渐变固定在整条范围，明确指定的皮肤颜色优先。血量规则、判定、计分及回放不变。

原有评级按未四舍五入的普通准确率：S+++/S++/S+ ≥99/98/97% **#FFD66B**，S ≥95% **#70ECFF**，A+/A ≥93/90% **#9DB3FF**，B ≥85% **#78E3A9**，C ≥80% **#FFAD70**，D ≥70%及失败F **#FF7386**，存活且低于70%的E **#B6C0D0**。自动`AUTO`，无记录/中止`--`。等级规则不变。MIT来源位于`third_party/key_note_overlay/`。自动测试不等于实机、OBS和长时间游玩验证。
