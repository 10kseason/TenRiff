# TenRiff 1.9.9.9-final1

final1包含hotfix5的全部更改，并加入IR保护与排除标记。提交新分数需要使用此版本。运营排行榜v26将Speed of Link从公开列表、排名及统计中移除，并阻止重新提交，保留原始存储记录。

基于hotfix5。任一可操作音符的独立键音原始时长达到45秒，或实际可操作音符中无键音比例达到85%，服务器拒绝新成绩。不是累计时长、整曲时长、仅BGM音频或变速后的时长。普通音符与长条头各计一次，不计尾部。没有关联键音或解码PCM全为0视为无键音。

后台提交线程按回放的BMS分支、速度、采样率和音符模式重新分析。45秒以上以45.0饱和值传输来限制内存，仍被拒绝。文件缺失、解码失败、谱面变化、缺少分析信息均无法提交。支持原生PCM/float WAV、完整单流Vorbis OGG及严格MF的MP3。MF专用WAV、Opus OGG、当前BMS加载器无法分析的历史osu及键数转换保留本地。这是数字零检测与客户端声明，不是服务端反作弊保证。

请解压到独立目录。输入、判定、计分和历史回放格式不变。启用服务器规则后旧客户端因无分析信息无法提交。

确认不可提交时，在列表的选中行、详情和结果显示 `IR EXCLUDED`（韩语为 `IR 제외`）。仅在独立线程检查选中谱面，不扫描整个曲库，也不定时重复解码。重新选择、重新进入、F5及相关设置变化会重新检查。保持选中时替换音源后，请重新选择或按F5。未知或检查中不代表可提交；RANDOM分支需实际游玩后确认。包括访客的结果均按完成回放的实际分支与条件检查，与当前菜单设置和网络状态无关。没有标记不保证可提交，提交时仍重新分析。


Extract into a new folder and run `launch_win.bat`. Fixed baseline: **1.9.6**.
