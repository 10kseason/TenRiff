# 음악·전환·기록 피드백 · 2026-11-03 로컬 후보

공개 1.9.9.8 hot fix 1 기반입니다. 이전 설치/프로필/릴리스와 고정 기준선 1.9.6을 보존합니다.

1. **오디오 → 파일 선택**: 메인/클리어/실패 BGM, 버튼 클릭음, 슬라이더 드래그음, 파일 드롭 알림음을 각각 선택합니다. MP3/OGG/WAV/FLAC를 지원합니다. Enter 또는 파일명 클릭으로 선택하고, 좌우 키로 기본값/없음을 고릅니다. 취소하면 기존 선택을 유지합니다. 사용자 음원은 해당 위치에 남으므로 이동/삭제하면 사용할 수 없습니다. 메인 사용자 음원은 기존 타이틀 음악의 기본 음악 모드에 적용합니다.
2. **기본 음원**: `Main Menu 5.mp3`를 새 `Clear.mp3`로, `Options.mp3`의 내용을 원래 `Main Menu 3.mp3` 음악으로 교체하고 `Main Menu 4.mp3`를 후보에서 제외했습니다. 대체/제외된 원본은 후보 상위 `original-assets`에 보존합니다. 메인 메뉴용 `Main Menu 3.mp3`는 유지하고, 옵션 화면에서는 같은 음악의 `Options.mp3`를 재생합니다.
3. **전환**: 생성한 프리즘 이미지를 싱글 플레이 진입과 곡 로딩에서 30단계/1초로 표시합니다. 로딩과 동시에 진행하며, 빠른 로딩은 전환 종료 후 카운트다운/오디오 시간을 시작합니다. 긴 로딩은 추가 1초를 기다리지 않습니다. 즉시 재시작/피어 대전의 시작 동기화는 변경하지 않습니다. 모션 감소 설정에서는 정적인 이미지를 사용합니다.
4. **NEW RECORD**: 같은 판정/차트 정책에서 순수 최고 점수가 1점 이상 오를 때만 표시하며 점수 디지털 변조를 1.2초 동안 함께 재생합니다. 첫 기록은 이전 점수 0을 기준으로 합니다. 클리어 등급 상승만으로는 신기록 문구를 띄우지 않습니다. 공식 BEST 저장은 클리어 우선, 같은 클리어에서는 점수 우선입니다. 순수 최고 점수와 최고 랭크는 기존 기록으로부터 별도 재구성하므로 기록 파일 마이그레이션은 없습니다.
5. **랭크 상승**: 이전 최고 랭크가 밝아지고 조각으로 흩어진 뒤 현재 랭크를 은은한 빛으로 표시합니다. 랭크가 오르지 않은 결과에는 적용하지 않습니다. 연출 건너뛰기와 모션 감소를 존중합니다.
6. **레벨 폴더**: 레벨 안의 곡 목록에서 좌우 방향키도 Esc처럼 상위 레벨 폴더 목록으로 돌아갑니다. 빠른 설정·기록 보기의 좌우 기능은 유지합니다.
7. **리절트 게이지 그래프**: Gauge Shift 결과는 EASY 0%에서 EX 100%까지 고정된 네 구간을 사용합니다. EX 0%와 HARD 100%처럼 게이지 소진/전환 지점은 같은 높이로 연결하여 리필이 회복처럼 튀어 보이지 않습니다. 실제 게이지·판정·저장된 원시 이력은 바꾸지 않습니다.
8. **스킨 → HUD → 점수 비교기**: 기본 OFF이며 켜기와 X/Y 위치를 저장합니다. BEST는 호환 리플레이의 같은 곡 시점 점수와 비교하여 위면 `+`, 아래면 `-`, 같으면 `0`을 표시합니다. 호환 리플레이가 없으면 `--`입니다. S/S+/S++/S+++는 정확도 95/97/98/99% 기준의 현재 차이(%p)를 표시합니다. 총점과 랭크 정확도의 가중치가 달라 9,500점 등을 S 확정 점수로 안내하지 않습니다. 연습·오토·리플레이와 호환되지 않는 정책은 비교 대상에서 제외합니다.

효과음은 기존 설정 클릭과 같은 Windows 시스템 출력 경로를 사용하며 마스터 음량/비활성 음소거를 따릅니다. BGM은 선택한 WASAPI/ASIO 장치를 유지합니다. 사용자 효과음 디코딩은 비동기로 수행하고 짧은 길이로 제한합니다.
