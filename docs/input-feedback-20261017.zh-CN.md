# 指示器、输出设备与配置快捷键

2026-10-17在用户选定的1.9.3 (`bf544e17f22879011a04a7fd157e40b57f6598bb`)上进行修改，并包含于1.9.4。保留固定基准1.9.0、公开资源和原有安装。
