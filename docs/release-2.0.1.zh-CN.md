# TenRiff 2.0.1

[한국어](release-2.0.1.ko.md) | [English](release-2.0.1.en.md) | [日本語](release-2.0.1.ja.md) | [简体中文](release-2.0.1.zh-CN.md)

修复选项界面的可读性。

- 将默认银河背景的亮度降至2.0.0的40%（原图RGB倍率为0.392）。
- 将8张卡片的宽高及内部文字和图标缩小至85%，并同步调整点击区域。
- 在卡片下方以单行显示所选选项的说明，支持韩语、英语、日语和简体中文。

判定、分数、回放、保存格式及final4兼容基准保持不变。自定义背景维持原有行为。
