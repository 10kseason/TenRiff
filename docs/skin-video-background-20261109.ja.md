# 動くスキン背景動画と TenRiff Code / CLI スキン（2026-11-09 ローカル候補）

[한국어](skin-video-background-20261109.ko.md) · [English](skin-video-background-20261109.en.md) · [简体中文](skin-video-background-20261109.zh-CN.md)

ユーザー要望：Claude Code CLI をプレイしているような雰囲気のスキンと、動く背景。Modern Common 候補をそのまま引き継いだ別のローカル候補です。

## スキン背景動画

- `lobby.background_video`：全メニュー画面共通のループ動画。内蔵の選曲／リザルトのループ動画とスキンの静止背景を置き換えます。
- `lobby.screen_videos.<画面 ID>`：画面別のループ。画面 → 代替画面 → 共通動画の順に選びます。空文字列はその画面を静止背景のままにします。
- `gameplay.background_video`：プレイ中のループ。譜面に基本 BGA レイヤーがないときだけデコード・表示し、BGA と同じ譜面時計（一時停止・速度・リスタート）に従います。モード別の上書きに対応します。
- 形式は MP4/M4V/MPG/MPEG/WMV/AVI/MOV/WEBM/MKV で、画像と同じ相対パス規則です。自動検索はせず、音声は再生しません。
- 動画は同じ画面の背景不透明度で静止背景の位置に描きます。最初のフレーム前、システム／メニューのモーション低減時、デコード失敗時は静止背景を使います。スキンを再読み込みすると失敗記録を消して開き直します。
- フォルダー取り込みと `.trskin` 書き出しは参照動画もコピーします。スキーマと同梱オフラインエディター（検証・フォルダーを開く・ZIP 書き出し）も新しいフィールドに対応し、プレビューキャンバスは静止背景を表示します。

## 動画デコーダーの修正

H.264 1080p は内部で 1088 行にデコードされます。Media Foundation 経路が表示領域（1080 行）で切り取らなかったため、画面最下部に緑の行が 4 本見えていました。内蔵の選曲／リザルトのループでも再現しました。デコーダーが `MF_MT_MINIMUM_DISPLAY_APERTURE`（なければ geometric aperture）を読んで切り取るよう修正しました。情報がない、または不正な場合は従来どおりバッファ全体を使います。

## TenRiff Code / CLI スキン

内蔵 `TenRiff_Code_CLI`：Cascadia Mono、コーラルのアクセント、暖かい黒のパネル、ブロックカーソルのノート、選択範囲風の LN、カーソル下線のキー、`pixels` ヒット効果。メニューはスピナー記号が漂う 16 秒ループ、タイトルは入力欄にコマンドが打ち込まれるループ、プレイ中はセッションログが打ち出される 24 秒ループです。1K～16K と 7+1 に対応します。Claude Code CLI の雰囲気を参考にした非公式ファンスキンで、Anthropic のロゴ・マスコット・商標画像は使っていません。画像と動画はすべて同梱の Pillow 生成スクリプトで描いています。

## 変わらないもの

判定・スコア・ゲージ・入力・音声・リプレイ・ランキング方針、`version: 1`、既存スキンとプロフィール設定は変わりません。動画フィールドのないスキンの動作も同じです。ただし 1080p H.264 メニュー動画の下端 4 行の切り取りは内蔵動画にも適用されます。実機入力、長時間プレイ、他の PC のコーデック環境は別途検証が必要です。
