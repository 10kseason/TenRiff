# シンプルLN・EX配色・オールコンボ画像（ローカル候補）

公開1.9.9.3から分離した候補です。バージョン、固定基準1.9.6、既存リリース・設定は保持します。

- nativeのsimple_rect、square、circle、diamond、arrow、triangle、pentagon、hexagonのLN頭・胴・尾をレーン単色にします。標準rect/Luma Keys、通常ノート、インポート画像、透過率・幅・テーパーは保持します。SimpleSquareはsimple_rectを使います。
- EXだけ彩度を18%下げ、紫を除いたピンク→赤→黄→緑→シアン→青の6色にします。青からピンクへ戻さず、補間による紫も避けます。EX共通のS+～S+++・クリア表示・Shift Start・ゲージに適用し、EZ/NM/HD、E/Fの薄紫、通常判定色は保持します。
- 最後のLN尾まで全曲をコンボ切れなく完了すると、数値下のCOMBOの代わりにALL COMBO画像を表示します。プレイヤーとゴーストは独立判定。失敗・中断・自動演奏・Auto Scratch・No Fail・部分練習は対象外です。
- 新しい完了結果の最大コンボ欄にも表示します。過去結果から達成を推測せず、既存FULL COMBO判定や保存形式は変更しません。
- 画像は一度読み込み、欠落時は文字へフォールバックします。コンボ位置・サイズ・判定数との重なり回避を使い、判定・スコア・音声・リプレイ・peer v7を保持します。

[画像記録](../assets/menu/achievements/README.md)。実入力・長時間・他PC・任意スキンは未確認です。


オールコンボ画像には丸い枠と控えめな黄色グローを付けています。
