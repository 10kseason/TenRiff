# TenRiff 1.9.2 변경·호환성

2026-10-16 · 1.9.1.1 릴리스 `ea8bdba0fb8aa533f0e684b64fc64515e2eb2e41` 기반. 고정 기준선은 계속 1.9.0이며 기존 태그·배포물·설치·프로필을 보존합니다. 공개 여부와 다운로드는 [1.9.2 릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.2)를 기준으로 확인합니다. 이 문서는 동작 범위이며 검증 완료 보고서가 아닙니다.

## 게스트·온라인 선택

게임을 실행할 때마다 F10 계정 창을 자동으로 열고 **게스트 모드** 또는 **온라인 모드**를 선택합니다. 시작 기본값은 항상 게스트이며, 시작 선택을 Esc로 닫아도 게스트로 남습니다. F10으로 다시 열어 전환할 수 있습니다. 온라인 선택은 실행 중에만 유효하며 다음 실행으로 저장하지 않습니다.

온라인 모드에서 새로 시작한 플레이만 기존 연결·지원 조건을 통과하면 리더보드 제출 대상이 됩니다. 게스트 플레이는 로컬 기록으로 남고, 나중에 온라인으로 바꾸거나 계정을 연결해도 제출 대상으로 바뀌지 않습니다. 출처 표시가 없는 과거 기록도 업로드하지 않으며, 기존 기록 보기·로컬 리플레이 재생은 유지합니다.

게스트로 한 번이라도 전환하면 현재 플레이의 업로드 권한을 영구히 취소합니다. 같은 플레이 중 다시 온라인으로 바꿔도 복구하지 않고 다음 새 플레이부터 적용합니다. Sites와 별도 Ranked 제출 경로 모두 이 제한을 확인합니다. 게스트 전환은 대기 중인 업로드를 무효화하며, 이미 전송을 시작한 POST가 있으면 끝날 때까지 기다린 뒤 완료됩니다. 이미 서버가 받은 기록을 취소하거나 삭제하는 기능은 아닙니다.

서버·DB 형식과 숫자 순위 계산은 바꾸지 않습니다. Sites는 계속 `client_submitted` 커뮤니티 기록이며, 이 클라이언트의 게스트 차단은 서버 리플레이 검증이나 부정행위 방지 인증을 뜻하지 않습니다. LN Mix v2·자동연주·지원되지 않는 규칙 등 기존 제출 제한도 유지합니다.

## 그래픽·스킨·메뉴

- V-Sync 옵션 행을 없애고 주사율 선택을 유지합니다. 기존 `graphics.vsync` 저장값은 호환용으로 유지합니다.
- BGA 밝기는 0–100%, 1% 단위, 기본 100%입니다. 배경 합성 후 노트·HUD보다 먼저 적용합니다.
- LR2/TenRiff 스킨 가져오기, 곡 불러오기·인덱싱, 난이도표 불러오기에 공통 로딩 바를 사용합니다.
- 홈 오른쪽 아래 언어 버튼은 영어 → 한국어 → 일본어 → 중국어를 순환하며 선택을 저장합니다.
- 스킨 화면의 **스킨 프리셋 내보내기**만 제거합니다. 가져오기·파일 드롭·전체 프로필 내보내기와 내부 스킨 패키징은 유지합니다.

등급은 반올림 전 일반 정확도를 사용하며 고정합니다: 99% S+++ / 98% S++ / 97% S+ / 95% S / 93% A+ / 90% A / 85% B / 80% C / 70% D / 70% 미만 생존 E / 게이지 실패 F. 기록 없음·중단은 `--`, 자동연주는 `AUTO`입니다. 점수·판정·게이지·숫자 순위 규칙은 바꾸지 않습니다. 웹 Stable은 정식 운영 표시와 같은 고정 등급표를 뜻합니다.

## 외부 AI 업스케일

**원본 → FFmpeg 내장 디블록 → AI x2 복원·잔차 합성 → 표시 영역에 맞춤 → 필요한 크롭** 순서입니다. 디블록은 전체 원본 RGB에 `weak/block=8`로 한 번 적용하며 알파를 보존합니다. AI 입력과 bilinear x2 바탕은 같은 디블록 결과를 사용합니다.

동적 공간 축 모델에는 원본 H/W 전체를 한 번에 넣습니다. 고정 960×540 입력 모델은 원본 픽셀 패딩·32픽셀 문맥 타일로 계속 지원합니다. 선행 확대·축소나 16:9 크롭은 없습니다. 출력은 원본의 정확히 x2 잔차여야 하며, 원본 축당 4096픽셀 제한과 인스턴스당 3장/96 MiB 캐시는 유지합니다. 정지 BGA·선곡 이미지에 적용하고 영상 AI는 비활성입니다.

**공개 실행·소스 패키지에 BGA 업스케일 모델을 포함하지 않습니다.** 모델 경로 기본값은 빈 값, 업스케일 기본값은 OFF입니다. Graphics에서 외부 ONNX 파일을 선택하거나 드롭한 뒤 별도로 켭니다. 기존 사용자 경로와 저장값은 유지하며, 키 모드 변환용 기존 NK3 모델은 계속 포함합니다. FFmpeg 실행 경로는 게임 옆 `tools/ffmpeg-deblock/ffmpeg.exe`, 이후 PATH입니다. 누락·필터 실패·모델 실패는 원본 표시를 유지합니다.
