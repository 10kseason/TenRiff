# 메뉴 가독성, 프로필과 ALL SONG

TenRiff 1.7.9에 포함된 메뉴·프로필·곡 소스 개선 안내입니다.

## 사용

- **옵션 → 프로필**과 첫 실행의 **빠른 설정** 첫 두 행에서 언어와 글자 크기를 선택합니다.
  글자 크기는 **보통 / 크게 / 더 크게**(100% / 115% / 130%)이며 선택 즉시 프로필에 저장됩니다.
  게임플레이 스킨의 글꼴 크기는 이 메뉴 설정으로 바뀌지 않습니다.
- **프로필 사진**에서 로컬 이미지를 고르면 같은 화면에 미리 표시합니다.
  시작 메뉴와 선곡 화면도 같은 사진 경로를 사용합니다. 파일을 옮기거나 삭제하면 다시 선택해야 합니다.
  같은 경로의 사진을 수정한 뒤 다시 선택해도 갱신됩니다. 미리보기는 원본 파일을 잠그지 않습니다.
- **소스 → ALL SONG**을 열면 등록한 모든 폴더의 곡을 한 목록에서 검색·정렬·선택할 수 있습니다.
  겹치는 폴더에 들어 있는 같은 차트 경로는 중복 표시하지 않습니다. 다른 경로의 별도 복사본은 유지합니다.
  이 선택은 다음 실행에도 복원됩니다. `ALL SONG` 자체는 폴더가 아니므로 삭제할 수 없습니다.
- 사용 가능한 폴더 캐시를 먼저 읽습니다. 캐시가 없는 폴더만 순서대로 스캔하며,
  **F5**는 등록 폴더 전체를 다시 스캔합니다. 없는 폴더는 건너뛰고 기존 파일을 삭제하지 않습니다.
  캐시에 남은 삭제된 하위 폴더·차트도 통합 목록에서 제외하고 나머지 곡을 계속 불러옵니다.
  캐시를 통합하는 중에도 처리한 차트 수와 진행률을 표시합니다. 원래 폴더 캐시는 유지합니다.
  통합 중에는 이전 목록을 유지하고 완료된 결과를 한 번에 적용합니다.
  목록과 로딩 완료 상태를 함께 전달하므로 완료된 결과를 받은 화면에 이전 로딩 상태가 남지 않습니다.

## 표시

옵션 카드의 색상과 테두리, 선곡 상단 버튼, 최고 기록 및 차트 정보 영역의 경계를 강화합니다.
최고 기록의 점수·정확도·최대 콤보는 흰색으로 표시합니다.
선곡 화면의 긴 곡명은 글자를 과하게 줄이지 않고 줄임표로 표시합니다.
TENRIFF 글자는 약한 홀로그램·빛 번짐·짧은 글리치 효과를 사용하며 옆 TI 마크는 정적으로 유지합니다.
기존 모션 감소 설정을 따릅니다.

### 숫자 정렬과 스킨 범위

- BPM·레벨·노트 수·NPS 값은 한 행에서 같은 글자 배율을 사용합니다. 값마다 따로 축소되어 레벨만 높거나 커 보이던 현상을 줄입니다.
- 난이도 카드 하단의 레벨과 차트 이름도 같은 글꼴 크기·높이로 맞춥니다.
- 최고 기록과 결과의 최대 콤보는 `742 COMBO`처럼 단위를 붙입니다.
- 키 수 표시는 모드별로 구분합니다: 4K 민트, 5K 노랑, 6K 파랑, 7K 보라, 8K 분홍, 9K 연두, 10K 청록, 12K 주황, 16K 코랄. 11K·13K·14K·15K도 각자 색을 가집니다.
- 노트 높이 조절은 50~400%입니다. 200%를 넘는 값을 계속 200%로 표시하던 문제를 수정합니다. 웹 에디터와 `.trskin`의 `note_height_ratio`도 0.5~4.0으로 맞춥니다. 프로필 기본값과 LR2 스킨의 고유 종횡비는 유지합니다.

## 구현 선택

기존 프로필 JSON에 `ui.menu_font_size`, `ui.all_song_sources`만 선택 항목으로 추가합니다.
원래 값이 없는 프로필은 보통 글자와 개별 소스를 유지합니다.
통합 인덱스만 절대 차트 경로를 사용하고 각 폴더 캐시는 원래 상대 경로를 유지하므로,
개별 소스와 통합 소스를 오가도 차트·미리보기·기록의 경로를 보존합니다.
폰트와 로고의 렌더 자원은 재사용하며 UI를 위해 새 백그라운드 서비스를 추가하지 않습니다.
