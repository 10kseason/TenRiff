# TenRiff 1.9.7 — 공용 키·스킨 설정과 매 판 랜덤 시드

2026-10-19

공용 키 탭, 커진 키 모드 탭과 로비 색상, FAST/SLOW 색상, 1% 조절, 게임 모드 설정·Normal 표기와 매 판 새 시드를 포함한다.

이 변경은 1.9.7에 포함된다. 기존 릴리스·설치본·프로필을 보존하며 일반 소스 기준선은 1.9.6이다. 물리 입력·청음·장시간 플레이·다른 PC 검증은 별도다.

[Settings](settings-feedback-20261019.ko.md) · [Baseline](baseline-1.9.6.md) · [Normal / Hard / EX](judgement-baseline-20261018.ko.md) · [Verification](release-1.9.7-gate.md)

공개 여부와 다운로드는 버전별 릴리스 페이지를 따른다. 이전 날짜의 안내는 당시 이력이다.

[1.9.7](https://github.com/10kseason/TenRiff/releases/tag/1.9.7)

- 텐리프 자체 배경음(타이틀·메뉴·결과)의 기준 이득을 10%에서 12.5%로 높여 감쇄를 약 1.94dB 줄였다. 저장된 마스터·메뉴 볼륨과 곡 미리듣기·플레이 음량은 유지한다.
