# セッションミックスのコース選択 · 2026-10-27 ローカル候補

従来の設定行を、コースメニュー・コース一覧・ステージ順の3領域に変更しました。選曲画面の背景と均一な拡大縮小を再利用し、保存済み選曲スキン座標とは別のコース専用配置を使います。

`.lr2crs`を読み込み、クリック・上下キー・ホイールでコースを選択し、ステージを確認してEnter・ダブルクリック・コース開始で入場します。PgUp/PgDnは7項目移動、Tabは一覧→メニュー→ステージを循環します。長いステージ一覧には前後ボタンもあります。元のMD5順と繰り返しを保持し、不足位置を表示します。全譜面が現在の索引ライブラリに必要で、選曲の検索・表示フィルターには制限されません。不足譜面の代替や省略はせず、入場前に全ファイルの存在を確認します。従来のゲージ引き継ぎと結果画面Enterで次曲へ進む操作を維持し、終了・失敗・結果画面Esc後はコース選択へ戻ります。

自動ミックスは表示した順番で開始します。再生成・長さ/ライブラリ変更・画面再入場で更新します。現在の選曲フィルターに従い、同じ音声パス（なければフォルダー+曲名）の難易度違いを重複選択しません。完全な重複検出ではなく、手動コースには適用しません。精度80–100%のクリアを基準に段階的なウォームアップ→挑戦→クールダウンを選び、急な上昇を避けます。記録がなければレベルの下位四分位を使います。15/30/60分は1曲約3分による5/10/20曲の目標で実測時間ではありません。規則の検証は楽しさや上達の証明ではありません。

先行候補のF1減速/F2加速の初期値と長押し加速を含みます。保存キー、判定、等級、リプレイ、コースゲージ、Web投稿境界を維持。LR2CRS形式・公開バージョン・固定基準1.9.6は変更しません。既存リリース・候補・インストール・プロファイルを保全し、専用session-mix-localプロファイルで実行します。検証記録は候補上位evidence/VERIFICATION.ko.md。実機入力・試聴・長時間コース・任意のユーザーファイルは未検証です。
