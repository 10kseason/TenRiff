# 音楽・画面切替・記録表示 · 2026-11-03 ローカル候補

公開版1.9.9.8 hot fix 1を基にした別フォルダーです。既存リリース・インストール・プロフィールと固定基準1.9.6を保全し、アップロードや配布は行いません。

- オーディオにメイン/クリア/失敗BGM、ボタンクリック、スライダードラッグ、ファイルドロップ音の個別選択を追加。MP3/OGG/WAV/FLAC対応。Enter/ファイル名クリックで選択、左右で既定/なし、キャンセルは変更なし。外部ファイルは移動しないでください。メインの指定は既定タイトル音楽モードに適用します。
- Main Menu 5をClear、Optionsの内容を元のMain Menu 3音楽に変更し、Main Menu 4を候補から除外。旧ファイルはパッケージ外の`original-assets`に保存。メニュー用Main Menu 3は保全し、オプション画面では置き換えたOptionsを再生します。
- 生成したプリズム画像をシングルプレイ移行と曲ロード時に30段階・1秒で表示。ロードと同時進行し、速いロードでは終了後にカウントダウン/音声時間を開始。長いロードに追加1秒はありません。即時再開/対戦同期は維持し、モーション軽減時は静止画です。
- NEW RECORDは互換性のある最高点から1点以上の向上時だけ表示し、1.2秒のデジタル変調を同時再生。初回は0点と比較。クリア状態だけの向上では表示しません。公式BESTはクリア優先、同じクリアなら点数優先。過去最高点/ランクは既存履歴から再構成し、ファイル移行はありません。
- ランク向上時は旧ランクが明るくなって砕け、新ランクが穏やかに発光。スキップ/モーション軽減に対応。
- レベル内の曲一覧で左右キーでも上位レベルフォルダーへ戻れます。クイック設定/記録表示の左右操作は維持。
- Gauge Shiftの結果グラフはEASY 0%～EX 100%の固定4区間。EX 0%とHARD 100%を同じ高さで接続し、補充を回復として描きません。原データ/実際のゲージは変更しません。
- スキンHUDに既定OFFの点数比較器とX/Y保存を追加。BESTは同じ曲時刻の互換リプレイとの差を符号付きで表示、利用不可は`--`。S/S+/S++/S+++は正確度95/97/98/99%との差(%p)です。総点とランクの重みは異なるため9500点をS保証とは扱いません。アシスト/オート/再生/非互換条件は除外します。

効果音は既存のWindowsシステム出力経路とマスター/非アクティブ消音を使用。音楽は選択したWASAPI/ASIO装置を維持します。効果音は非同期・短時間制限付きでデコード。検証は候補上位の`evidence/VERIFICATION.ko.md`参照。実機入力/聴取、任意ファイル/スキン、長時間、別PCは別途確認が必要です。
