# 고밀도 노트 프레임 페이싱 수정

TenRiff 1.8.42의 렌더 페이싱 최적화입니다. FHD에서 노트가 많아지면 간헐적으로 움직임이 끊긴다는 제보를 조사했습니다. 제보 PC의 RTX 4070에서 직접 재현한 결과는 아닙니다.

## 변경 이유와 범위

- 이전 제한기는 그리기 완료 후 **기존 시간 격자의 다음 칸**까지 기다렸습니다. 1050 FPS의 약 0.952ms 예산을 조금만 넘겨도 프레임 간격이 약 1.905ms로 뛰었습니다. 노트 밀도에 따른 비용 변화가 인위적인 추가 대기로 확대될 수 있었습니다.
- 이제 **실제 프레임 시작 시각 + 설정 간격**까지만 기다립니다. 이미 예산을 넘긴 경우 바로 다음 프레임을 시작합니다. 늦게 깨어나거나 긴 정지가 발생해도 밀린 프레임을 몰아서 그리지 않습니다. FPS 설정과 VSync의 Present 정책은 유지합니다.
- 성능 오버레이가 꺼져 있을 때도 실행되던 프레임 이력 수집과 주기적인 정렬을 생략합니다. 다시 켜면 새 이력을 시작하므로 꺼져 있던 시간이 긴 프레임으로 기록되지 않습니다.
- 노트·롱노트 모양, 표시 수, 스크롤/음악 속도, 판정, 입력, R1/R2/R3/R4 리플레이와 고스트 규칙은 변경하지 않습니다. 표시 품질을 낮추거나 GPU 드라이버 설정을 변경하지 않습니다.

## 재현과 검증 도구

`menu_visual_preview`의 기존 렌더 측정에 다음 옵션을 추가했습니다.

```text
menu_visual_preview --gameplay --keys 10 --1080p --no-vsync --fixture-time 1.25 --dense-notes 128 --benchmark-frames 600 --benchmark-json benchmark.json
```

- `--dense-notes 1..128`: 현재 HUD의 표시 상한 내에서 노트 수를 고정합니다.
- `--dense-holds`: 위 노트를 모두 롱노트로 만듭니다.
- `--tapered-holds`: 끝이 좁아지는 롱노트 경로를 사용합니다.
- `--ghost`: 같은 부하의 고스트 필드를 함께 그립니다.
- `--fixture-time`은 비교할 때 동일한 노트 배치를 유지합니다. 이 도구는 판정/오디오 없이 합성 화면을 그리며, 성공한 Present 수를 따로 기록합니다. 측정 중 캡처를 요청하면 디스크 기록 비용이 섞이므로 성능 측정과 캡처는 별도로 실행합니다.

`TENRIFF_BENCH_RENDER_PACING=1` 환경변수를 지정하고 `bms_parser_tests`를 실행하면 실제 `RenderThread`에서 1050 FPS와 700/980/1100µs 합성 CPU 부하를 각각 측정합니다. 60회 준비 후 1,000개 프레임 간격의 중앙값·p95·p99를 출력합니다. 성능 수치는 자동 통과 기준으로 삼지 않습니다. 일반 테스트에서는 이 선택적 측정이 실행되지 않습니다.

항상 실행하는 회귀 테스트는 60/144/240/300/600/1050/1500 FPS에서 예산 초과·정확한 경계·긴 정지 이후의 대기 규칙과 오버레이 재활성화를 확인합니다. 합성 CPU 측정, D3D 렌더/Present, 실제 사용자의 게임 체감은 서로 다른 검증 범위입니다.

## 남은 확인

제보 PC의 곡·스킨·FPS 제한·VSync·오디오 설정을 재현한 장시간 플레이는 별도 확인이 필요합니다. 도형 노트의 상태 변경과 tapered LN의 도형 생성은 추가 최적화 후보이지만, 이번 변경에는 포함하지 않았습니다. 기존 설치와 프로필은 보존합니다. 공개 전 검증 항목은 [1.8.42 릴리스 안내](release-1.8.42-gate.md)에 기록합니다.
