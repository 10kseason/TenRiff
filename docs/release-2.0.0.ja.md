# TenRiff 2.0.0

[한국어](release-2.0.0.ko.md) | [English](release-2.0.0.en.md) | [日本語](release-2.0.0.ja.md) | [简体中文](release-2.0.0.zh-CN.md)

EX Score（PG×2 + GR）、アカウント連携の中央サーバー対戦、星座ホーム・選曲・設定、検証済みALL COMBO表示、チャット・ライブラリ・Session Mix修正を統合します。

- **得点:** EX ScoreはP-Great×2 + Great、Good・Bad・Poorは0点です。表示・自己ベスト・ゴースト・Session Mix・対戦・Web順位を統一し、モード/Rate倍率は適用しません。精度・等級・ゲージ・判定ルールは別指標です。旧リプレイ検証用の得点を保持し、判定数不足を推測で補いません。該当Web記録は保持しますがEX順位から除外します。
- **オンライン:** F10で既存ランキングアカウントを連携し、公式ルームを作成・参加します。投稿済みスコアは不要です。最大8人で選曲・準備・開始予約・得点・チャットを共有し、リーダー退出時は権限を引き継ぎます。同じ譜面を各PCで用意し、譜面・音声・全曲一覧は転送しません。
- **画面:** 星座ホーム・選曲・設定と静止銀河背景を統合します。ホーム文句は正確に**Tenriff BMS Rhythm Game Client**で、ヒーロー直下のサブタイトルだけを削除し、ガイドは維持します。設定は既存8カテゴリの4×2カードと操作を維持します。設定用銀河画像は変更せず、表示時の彩度0.92・明るさ0.98でアルファを保持します。
- **記録表示:** 検証済みフルコンボだけを**ALL COMBO**と表示します。最高クリアランプと最高EX記録を分離し、長い曲名・作者名、静止サムネイル、ポインター照明、動きを減らす経路を整えます。EX銀河バッジとクリアグラデーションは設定背景とは別の素材です。
- **修正:** チャット入力は未設定の全体チャットではなく接続済みPeerSessionを確認します。F11・Enter・256バイト上限は維持します。フォルダー追加をLibraryだけにし、Session Mix生成・再編成・保存・取り込み・キャンセルを修正します。

新ルームはhosted protocol 2と`ex-v1`、Web投稿はschema 2が必要です。旧ルールセット/リプレイと直接TCP PeerProtocol v9実装は保持しますが、旧クライアントとの混在はできません。記録は引き続き**client_submitted**で、サーバーのリプレイ検証や不正対策を保証しません。ゲスト・出所不明の旧記録を投稿可能に変更しません。

最終2.0.0ビルド、ソースZIP独立ビルド、パッケージ、CI、公開資産の実際の検証結果は検証ゲートに記録します。旧候補の合格数を今回の証拠に流用しません。実IME・物理入力・試聴・実アカウント対戦・長時間・他PC・性能/費用は別途確認が必要です。

互換基準は**1.9.9.9-final4**を維持します。**2.0.0以降は不具合修正のみとし、新機能は追加しません。** 検証・公開状態は[検証ゲート](release-2.0.0-gate.md)を参照してください。以下の旧版案内は当時の履歴です。
