# 長押し調整と既定の速度キー

2026-10-27 · Local follow-up to 1.9.9.1; unpublished, no version bump. General fixed baseline remains 1.9.6.

- 新規既定値は **F1 ノート速度 −0.25 / F2 +0.25** です。F3/F4 判定線の上下1%、F5/F6 速度×0.5/×2、F7/F8 表示遅延−/+1msは維持します。
- 旧既定値を含む保存済みキー割当は変更しません。既存プロファイルではキー設定の共通キー、またはプロファイルで速度の減少・増加を再割当できます。
- 選曲ロビーの簡易設定で速度・表示遅延を選び左右キーを長押し、またはRateの−/+を長押しすると加速します。プレイ中・開始カウントダウン・一時停止画面の速度・判定線・表示遅延にも適用します。
- 最初の押下は1段階です。最初のリピート待機はロビー250ms、プレイ180ms。間隔は45ms、長押し0.6秒以降25ms、1.5秒以降15msです。刻み幅と上下限は維持し、実際の頻度はメニュー・音声処理周期に制限される場合があります。
- キーを離す、フォーカス喪失、ロビーの項目・画面変更、オーバーレイ、一時停止への移行、再開カウントダウンでリピートを初期化します。処理が遅れても蓄積した調整を一度に適用しません。
- ゲージ・ランダム選択、一覧移動、文字削除の頻度は維持します。マウスボタン長押しは対象外です。×0.5/×2は押下ごとに1回です。
- 判定・スコア・リプレイ形式は変更しません。遅延調整は既存のvisual offsetであり、入力判定オフセットは変更しません。
