# TenRiff 1.9.5.3 — 스킨 설정 정리와 검색·입력 개선

- 스킨 설정의 **필드 내 판정 개수**를 켜면 인디케이터 바로 아래에 PG / GR / G / BAD / PR 누적 개수를 표시합니다. 기본값은 OFF이며, 인디케이터 위치를 따라 이동하고 노트 필드 안으로 맞춥니다. 타격 사이에도 표시하며 플레이어·고스트 집계는 각각 유지합니다. 표기와 판정 계산은 기존대로입니다.

- 스킨 미리보기의 번호 버튼으로 편집 레인을 선택합니다. UI 폰트·폰트 파일과 인게임 커서는 프로필에서 설정합니다. 스크래치 위치는 런타임 키 모드가 원본일 때만 표시하며, 7+1 배치에서 조절할 수 있습니다.

- 새 설정은 노트·필드 60%, 키빔 최대 높이 50%, 5K 흰/파/흰/파/흰, 심플 사각형입니다. F1 속도 +0.25 / F2 −0.25, F3 판정선 위로 1% / F4 아래로 1%이며 F5/F6 ×0.5/×2는 유지합니다.

- 기어 뒤 BGA 가림 ON, LN 끝 표시 OFF, LN 몸통 너비·투명도 100%, 레인 간격 0%, 키 표시 아래를 기본으로 유지하면서 해당 항목을 스킨 설정에서 숨겼습니다. LN 끝 줄임도 숨겼습니다. 기존에 명시적으로 저장한 값은 보존합니다.

- 대상 레인·단일 색상·노트 테두리·전체/외곽선 투명도·레인 색상 농도·16K 중앙 간격·구분선 너비 행도 제거했습니다. 16K 중앙 간격의 새 기본값은 100%, 구분선의 실제 너비는 100% 고정입니다. 판정선 위치는 1~100%입니다.

- 이미지 비율은 설정된 노트 영역의 실제 너비·높이로 자동 결정합니다. 1:1이면 비율을 유지해 맞추고 직사각형이면 늘입니다. F6 스킨 전체화면 미리보기와 파일로 저장하는 .trskin 프리셋을 수정했습니다.

- 검색 Backspace는 길게 누르면 UTF-8 문자 단위로 반복 삭제하고 뒤로가기로 동작하지 않습니다. 일반 검색은 곡명·아티스트만 사용합니다. Lv:16과 Lv:16+는 각각 정확한 레벨만 찾습니다.

- 난이도표가 정의한 모든 레벨 폴더를 숫자 오름차순으로 표시하며 빈 폴더도 보존합니다. 폴더를 열면 그 레벨만 표시합니다. 마지막 노트/LN 종료 후 후주를 넘기는 키는 Enter로 제한합니다.

- 기존 설정·프리셋 형식과 입력 동작 슬롯을 재사용해 저장값을 보존했습니다. 판정·점수·게이지·오디오·리플레이 규칙은 변경하지 않습니다. 고정 기준선 1.9.0, Guest 제외, 고정 등급, client_submitted, BGA 가중치 미동봉 정책을 유지합니다.
