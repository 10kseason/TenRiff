# TenRiff 1.9.3 플레이·스킨·모델 호환 변경

공개 1.9.2와 앞선 ONNX 호환 작업을 잇는 1.9.3의 구현 범위다. 고정 기준선 1.9.0과 이전 배포 파일은 유지한다. 공개 상태·최종 검증은 [1.9.3 릴리스 안내](release-1.9.3.ko.md)를 따른다.

- 선곡 앨범 아트 오른쪽 아래에 BMS 저작 판정 난이도를 표시한다: `#RANK 4=VEZ`, `3=EZ`, `2=NM`, `1=HD`, `0=VHD`. 누락·잘못된 값은 기존 Easy 기본값에 맞춰 EZ로 표시한다. osu!에는 이 배지를 표시하지 않는다. 인덱스 캐시 20으로 새 메타데이터를 다시 읽는다.
- 인게임 Classic·Studio·대전 헤더에서 아티스트와 분리된 공간에 빨간 레벨을 표시한다. 긴 아티스트 이름이 레벨 공간을 차지하지 않는다. 편집기 연습·직접 실행은 실제 실행 채보의 PLAYLEVEL을 사용하며 관계없는 선택 곡의 레벨을 가져오지 않는다.
- BMS 노트 필드에 마디선을 표시한다. 작성된 마디 길이, BPM·STOP, 배속과 스크롤 좌표를 따르며 노트 뒤에서 그린다. 마디선은 판정·오디오 이벤트를 추가하지 않는다.
- 스킨의 FAST/SLOW 표시를 상시로 설정하면 마지막 실제 FAST/SLOW 글자와 위치를 유지한다. 조건부 모드는 기존 750ms를 사용한다. 글자/막대 스위치는 독립적이고 첫 유효 피드백 전에는 임의의 FAST를 만들지 않는다. 기존 PG 피드백 생략 정책은 유지한다.
- 새 프로필 또는 설정 누락 시 불러오기는 안전(`safe`)이 기본이다. 저장된 빠름 선택은 유지한다. 자체 LV/CR 계산은 별도 설정이며 여전히 기본 OFF다.
- 공푸어는 체력·POOR 수에 남지만 일반/상세/구간 정확도에서 제외한다. 실제 노트 미스는 계속 감점한다. 새 R7/R8과 과거 R1–R6를 분리한다. [계산·리플레이·온라인 호환](empty-poor-accuracy.ko.md).
- 외부 Safetensors 모델은 지원 구조를 로컬 Python에서 ONNX로 변환한 뒤 기존 GPU 경로로 처리한다. Python의 torch/safetensors/onnx/onnxruntime가 필요하고, 일반 구조에는 선택 설치한 Spandrel이 필요하다. 자동 설치나 다운로드는 없다. [지원 모델·설정·변환 제한](../tools/onnx_upscaler/README.md).

## 경계

`#RANK 4`의 VEZ는 저작 메타데이터 표시다. 실제 판정창은 기존 Easy 대체 동작을 유지하며 이번 변경으로 판정 폭을 늘리지 않는다. 마디선은 BMS에 적용하며 osu! 마디 생성은 포함하지 않는다.

Safetensors는 모든 아키텍처를 보장하지 않는다. 내장 LunaSR2 C32 R8/R12/R16 x2 또는 변환 가능한 Spandrel RGB x1~x4 구조를 지원한다. 실패 시 원본 이미지를 표시하고 로그에 원인을 남긴다. 동적 LunaSR2와 고정 타일 일반 모델 모두 최종 표시 영역 맞춤·크롭은 추론 이후에 한다. BGA 모델 가중치는 실행/소스 패키지에서 제외하며 OFF/빈 경로 기본값을 유지한다. 영상 AI는 기존처럼 비활성이다.

R7/R8을 지원하는 운영 리더보드 버전 19를 2026-10-16 사용자 승인으로 배포했다. 기존 기록·보드 ID·Stable 고정 등급표는 유지하며 새 규칙은 별도 보드로 받는다. 게스트 기록은 계속 업로드 대상에서 영구 제외한다. 서버의 신뢰 수준은 기존 `client_submitted`이며 서버 리플레이 검증을 추가한 것은 아니다.
