# BMS固定推定・KPSワーカー・ゲージ色

1.9.9.1のローカル候補。前回の操作キー、Session Mix、ロゴ拡大、クリアカードを含みます。固定基準1.9.6と既存の配布物・設定を保持します。

**スキン → 判定・HUD → キーオーバーレイ**で有効化。初期値OFF、保存したON/OFFとX/Yを保持し、4/5/7/8/10Kだけ表示します。別アプリは不要です。大きな**BMS推定難易度**はロード時に全曲から一度計算し、プレイ中は固定。入力・判定・オートで変化しません。キー数・速度・配置変換後、練習開始点での切り取りとカウントダウン追加前に解析します。次のプレイの設定が変われば推定も変わる場合があります。

従来の入力による難易度推定を置き換えます。元のv2.13コアで8秒区間と4秒の準備文脈を0.5秒ごとに評価し、最大値を選択。BMSのタップ・LNを使い、映像・音声・実入力は使いません。4K Reform、5K AERY、7K Jinjin、8K Regular、10K Reviveの単位を維持。矢印は基準範囲外です。公式レベル・実力・クリア確率ではありません。少なすぎるノート、不正/同レーン重複、上限（25万ノート・1時間・コアイベント容量）では「推定不可」。一部分だけの推定を表示しません。スキンプレビューは仮表示です。

**KPS**は直近1秒の実レーン押下数。キーリピート、保持中の補助キー移譲、オート・リプレイ・ゴーストを重複計上しません。停止・フォーカス喪失・カウントダウン中は入力表示を消してKPSを`--`にし、BMS推定は保持。入力経路は固定長SPSCキューへのコピーだけで、メモリ確保・ロック・ワーカー起床はありません。低優先度ワーカーが約8msで集計、HUDは待機しないコピーを使用。100ms以上古い値やキュー損失を初期化し、セッション終了でワーカーも終了します。実機の遅延/FPS改善値は未測定です。

Classic/Studio/ゴーストの標準ゲージは **EZ #00ED57、NM #FFF000、HD #FF3838、EX虹色**。全ゲージ基準のグラデーションで、明示的なスキン色を優先。ゲージ計算・判定・スコア・リプレイは変更しません。

既存ランクは丸め前の通常精度：S+++/S++/S+ ≥99/98/97% **#FFD66B**、S ≥95% **#70ECFF**、A+/A ≥93/90% **#9DB3FF**、B ≥85% **#78E3A9**、C ≥80% **#FFAD70**、D ≥70%と失敗F **#FF7386**、生存かつ70%未満E **#B6C0D0**。オート`AUTO`、記録なし/中断`--`。基準は変更なし。MIT出典は`third_party/key_note_overlay/`。自動検証と実機・OBS・長時間プレイは区別します。
