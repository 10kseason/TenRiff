# TenRiff 1.9.2 変更と互換性

2026-10-16 · 1.9.1.1 リリース `ea8bdba0fb8aa533f0e684b64fc64515e2eb2e41` を基にします。固定基準は1.9.0のまま、旧タグ・配布物・インストール・プロファイルを保持します。公開状況とダウンロードは[1.9.2 リリースページ](https://github.com/10kseason/TenRiff/releases/tag/1.9.2)を参照してください。この文書は動作範囲を示し、検証完了の報告ではありません。

## ゲスト・オンラインモード

起動するたびにF10のアカウント画面を開き、**ゲストモード**または**オンラインモード**を選びます。毎回の初期状態はゲストで、起動時の選択をEscで閉じてもゲストのままです。F10で再び開いて変更できます。オンラインの選択は現在の実行中のみ有効で、次回起動には保存しません。

オンラインで新しく開始したプレイだけが、既存の接続・対応条件を満たす場合に送信対象になります。ゲストの記録は永久にローカル専用で、後からオンラインに切り替えたりアカウントを接続したりしても送信しません。由来情報のない過去の記録も送信不可ですが、履歴表示とローカルリプレイ再生は維持します。

一度でもゲストに切り替えると、進行中のプレイの送信権限を取り消します。同じプレイでオンラインに戻しても復活せず、次の新しいプレイから適用します。Sitesと独立したRanked送信経路の両方で確認します。ゲストへの移行は待機中の送信を無効にし、既に開始したPOSTがあれば、その終了を待ってから完了します。サーバーが既に受信した記録を取り消す機能ではありません。

サーバー・DB形式と数値順位計算は変更しません。Sitesは引き続き `client_submitted` のコミュニティ記録です。このクライアント側の権限制御はサーバーのリプレイ再検証や不正対策の認証を意味しません。LN Mix v2、自動演奏、未対応ルールなどの既存制限も維持します。

## グラフィック・スキン・メニュー

- V-Syncの設定行を削除し、リフレッシュレート選択と既存の `graphics.vsync` 保存値を維持します。
- BGA明るさは0～100%、1%刻み、初期値100%。背景合成後、ノート・HUDより前に適用します。
- LR2/TenRiffスキンの読み込み、曲の読み込み・索引作成、難易度表の読み込みで共通バーを使います。
- ホーム右下の言語ボタンは英語 → 韓国語 → 日本語 → 中国語を循環し、選択を保存します。
- スキン画面の**スキンプリセット書き出し**を削除します。読み込み・ファイルドロップ・プロファイル全体の書き出しと内部スキン梱包は維持します。

丸め前の通常精度による固定等級は99% S+++ / 98% S++ / 97% S+ / 95% S / 93% A+ / 90% A / 85% B / 80% C / 70% D / 70%未満で生存 E / ゲージ失敗 Fです。記録なし・中断は `--`、自動演奏は `AUTO`。スコア・判定・ゲージ・数値順位の計算は変更しません。WebのStableは正式運用表示と同じ固定等級表を指します。

## 外部AIアップスケール

**元画像 → FFmpegデブロック → AI x2復元・残差合成 → 表示領域に合わせる → 必要ならクロップ**の順です。内蔵weak/block-8フィルターを原寸RGB全体に一度適用し、アルファを保持します。AI入力とbilinear x2のベースは同じ処理済み画素です。

動的空間軸のモデルには原寸H/W全体を一度に渡します。固定960×540入力は元画素の余白補完と32画素の文脈タイルで引き続き対応します。推論前の拡縮や16:9クロップはありません。評価後の残差出力は正確にx2である必要があり、原寸各軸4096画素、インスタンスごとに3枚/96 MiBのキャッシュ上限を維持します。静止BGA・選曲画像が対象で、動画AIは無効です。

**公開実行・ソースパッケージにBGAアップスケールモデルは含みません。** モデルパスは空、機能はOFFが初期値です。Graphicsで外部ONNXを選択・ドロップし、別途有効にします。保存済みのパス・設定と既存NK3鍵数変換モデルは維持します。FFmpegはゲーム横の `tools/ffmpeg-deblock/ffmpeg.exe`、次にPATHから解決します。実行ファイルの欠落・フィルター・モデルの失敗時は通常表示を維持します。
