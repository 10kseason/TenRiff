# TenRiff 1.8.4 릴리스 검증

기준일: 2026-10-05. Release CTest 3/3(973개, runner 통합 검사 제외 0)과
스킨 에디터 32개가 통과했습니다. 선택적인 외부 `10k-calc` Python 비교 원본은
이 환경에 없어 해당 참조 비교는 수행하지 않았습니다.

## 변경 내용과 이유

- 일시정지 화면의 계속·재시작·나가기와 설정 조절 버튼을 마우스로 사용할 수 있습니다.
  F7/F8은 시각 레이턴시, Shift+F5/F6은 HS 절반/두 배, 게임 중 Shift+F8은 채팅입니다.
- 페이스메이커는 플레이 중 목표 대비 차이를 표시하고 일반 판정·게이지를 유지합니다.
  다른 비공식 조건이 없다면 내 최고기록과 온라인 기록을 저장합니다.
- 연습용 오토스크래치를 추가합니다. 실제 BMS 스크래치 레인만 자동 처리하고,
  선택적으로 해당 레인을 숨깁니다. 점수 배율은 0%이며 공식 기록에서는 제외합니다.
- 고스트 배틀의 플레이어 필드는 솔로와 같은 사용자 설정 크기를 유지합니다.
  고스트가 남은 공간을 사용하며 플레이어 판정·스크롤 시각은 변경하지 않습니다.
- 설정 행의 글자·빈 공간 클릭은 선택만 합니다. 값 변경은 명시적인 −/+ 버튼에서만
  수행하며 적용할 수 없는 스킨 옵션은 회색과 설명으로 구분합니다.
- LN 몸통 불투명도는 0~100%를 선형 적용합니다. 게임·미리보기·에디터를 일치시키고,
  Tengear에 동봉된 스키마도 최신 모양과 설정을 허용하도록 동기화합니다.
- `.trskin` 내보내기의 확장자·파일 대화상자 오류 처리를 보강합니다. 프로필의
  `.trprofile` 내보내기/가져오기로 키맵·설정·프로필 스킨을 이전할 수 있습니다.
  가져오기 전 백업하고 파일 경로·크기·CRC를 검증합니다.
- DXGI 최대 프레임 대기열 설정에서 지원하지 않는 API 호출 뒤 빠져나가던 경로를
  수정하여 장치 설정으로 대체합니다. 실제 장치의 설정값 3 → 1을 확인했습니다.
- 오래 남은 LN 꼬리가 HUD 노트 검색 시작점을 붙잡지 않도록 머리와 꼬리의 수명을
  분리했습니다. 입력 처리와 공유하는 잠금 안에서 과거 노트를 반복 검색하지 않습니다.
  미스·활성 LN 표시와 플레이어 입력의 샘플 시각은 유지합니다.

조작·호환성은 [피드백 수정](feedback-fixes.ko.md), 지연 수정의 상세 근거는
[고스트 HUD와 표시 대기열](ghost-latency.ko.md)을 참고하세요.
[판정 범위](judgement-windows.md)는 1.8.3의 R3 규칙을 유지하며 기존 R1/R2 재생도 보존합니다.
1.8.3에서 배포한 랭킹 스키마와 호환되므로 이번 릴리스에 추가 DB 마이그레이션은 없습니다.

## 자동 화면 표시 검사

최종 Release 렌더 검사 실행본으로 실제 데스크톱에서 다음을 확인했습니다.
60 준비 프레임 후 측정한 30프레임을 기준으로 하며, 모든 실행이 정상 종료했습니다.

| 화면 | VSync | 성공 Present | 실제 독점 전체화면 Present | 종료 후 표시 모드 복귀 |
| --- | --- | ---: | ---: | --- |
| 창 모드 | ON | 30/30 | 해당 없음 | 정상 |
| 창 모드 | OFF | 30/30 | 해당 없음 | 정상 |
| 독점 전체화면 | ON | 30/30 | 30/30 | 정상 |
| 독점 전체화면 | OFF | 30/30 | 30/30 | 정상 |

모든 조건에서 DXGI 최대 대기열 readback은 1입니다. 추가 960×540 솔로/고스트
비교 6회에서도 각각 30/30 성공 Present를 확인했습니다. 같은 고정 시각의 플레이어
LN 폭은 5K 60%에서 52px, 8K 60%에서 30px, 8K 140%에서 69px로 솔로와 고스트가
일치했고 몸통의 세로 범위도 y246~383으로 같았습니다. 캡처 10장의 디코드·해상도·
빈 화면 여부·SHA-256 검사를 통과했습니다.

이전 로컬 r2의 Present 실패는 같은 실행본으로 제한 환경에서는 재현되고 실제
데스크톱에서는 통과하는 것을 대조했습니다. 이전 실패 기록은 보존하며, 이번 결과를
최종 1.8.4 실행본에서도 다시 검증했습니다. 검사 조건을 완화하지 않았습니다.

## 배포 게이트

공개 전에 다음을 완료하고 최종 결과와 해시는 릴리스 노트 및 배포 증거에 기록합니다.

- 최종 바이너리의 위 화면 표시 검사와 Release 회귀 검사.
- 배포 ZIP에서 독립 추출한 소스의 configure·Release 빌드·CTest 및 에디터 검사.
- ZIP CRC·추출 파일 해시·Git 커밋의 소스 일치·비공개 경로와 자격증명 검사.
- PR과 병합 후 main의 해당 AddressSanitizer/OpenVINO CI.
- 초안 첨부 파일 다운로드 검증 후 공개, 공개 첨부 파일의 로컬/API SHA-256 재검증.

짧은 합성 화면의 표시 성공과 비율 검사는 물리 키 입력부터 화면·오디오까지의 지연,
실제 차트 장시간 플레이 또는 여러 PC의 동작을 증명하지 않습니다.
이전 릴리스·설치본·사용자 프로필은 그대로 보존합니다.
