# 皮肤 HUD X/Y 位置调整

根据2026-10-19用户要求，基于已发布的1.9.7 (`948518d`)，将本次改动纳入1.9.8。保留1.9.7的通用按键、彩色标签、每局新种子和场景音乐基准增益。通用固定基线仍为1.9.6，并保留之前的发行版、候选、安装目录及配置。

- 键位分隔线亮度：0～100%，滑块与−/+均以1%调整。默认100%保持原色，0%为黑色。只调整RGB，保留透明度、显示开关、宽度及小节线。预览、游戏和幽灵会立即更新缓存。可选字段 `skin.lane_divider_brightness` 保存在配置与便携皮肤中，旧文件默认为100%。

| 设置 | X | Y |
| --- | --- | --- |
| 判定 | −600～600px，步长10px | 现有纵向位置比例 |
| 连击 | −600～600px，步长10px | 现有纵向位置比例 |
| FAST/SLOW 指示器 | −600～600px，步长10px | 现有−400～400px，步长10px |
| FAST/SLOW 条 | −600～600px，步长10px | 现有−400～400px，步长10px |

- 相邻显示X/Y。Native/TenRiff/LR2均支持本地化搜索、键盘左右和鼠标−/+。
- X是相对现有位置的偏移，负值向左，正值向右。每项独立，调整X不会修改保存的Y值。
- 重新显示已有X控件，保留默认值0、保存值、配置及便携皮肤格式，以及预览、Classic/Studio和幽灵的绘制路径。不迁移或重置数据。
- 本更新取代[2026-10-18策略](skin-ui-followup-20261018.zh-CN.md)中隐藏这四个X控件的规定。轨道边界线及其他已隐藏控件保持原状。
- 判定线仍附着于轨道，横向位置使用现有预览场地拖动功能一起移动。
- 不改变判定、输入、分数、录像或音频处理。自动验证与实际输入、长时间游玩验证分开报告。

请参阅[1.9.8变更范围](release-1.9.8.zh-CN.md)和[验证流程](release-1.9.8-gate.md)。功能说明不代表验证已经完成；发布状态和下载以[1.9.8发布页面](https://github.com/10kseason/TenRiff/releases/tag/1.9.8)为准。
