# Library and Session Mix button fixes

Add Folder appears only in the Library content header. It is hidden in Songs, Records and Session Mix.

Session Mix length, remix, save and import buttons now reach the course screen input handler. Remix reports its generated stage count. Import and save file dialogs open while menu audio is active; cancelling preserves the draft and existing course path.

To create a custom course, select charts in Songs and press **C** to append them in order, then choose **Save draft** in Session Mix. Repeated stages are allowed. Choose **Import courses** to select a `.lr2crs`, or drop it into Session Mix. Saving an empty draft displays these creation instructions.

The LR2CRS format, chart MD5 matching, course judgement, gauge and replay behavior are unchanged.
