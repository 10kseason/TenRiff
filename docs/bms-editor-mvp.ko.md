# 내부 BMS Editor MVP

선곡 화면에서 BMS 차트를 선택한 뒤 `I`를 누르면 내부 편집기가 열립니다.

- 방향키: 세로 타임라인에서 좌우는 레인, 위아래는 시간 이동
- 키를 누르고 있으면 커서가 연속 이동합니다. `M`은 시간축을 잠그고 X(레인)만 움직이는 모드입니다.
- `Tab`: 시간 스냅 간격 변경, `F6` / `F7`: 보이는 마디 수 축소·확대
- `PageUp` / `PageDown`: BPM/STOP을 반영해 5초씩 앞·뒤로 이동
- 마우스 휠: 타임라인을 1초씩 이동
- `Ctrl`+클릭: 노트/BGM 다중 선택, BGM을 선택한 뒤 `Ctrl`+`↑/↓`: 스냅 단위로 배경음 위치 이동
- `T`: 마우스 도구를 `무키음 노트 배치 → 노트 이동 → 노트 제거` 순서로 전환합니다. 현재 도구는 상단 상태에 표시됩니다.
- 기존 노트는 마우스로 끌어 레인과 시간 위치를 옮길 수 있습니다.
- `Enter` / `Space`: 탭 노트 추가·삭제
- `H`: 현재 노트를 약 1/4마디 롱노트로 변환
- `Delete`: 현재 노트 삭제
- `-` / `+`: 선택 키음 변경
- `K`: 무키음 노트 입력 모드 전환, `Ctrl+K`: 무키음 노트를 선택 키음으로 일괄 변환
- 노트 색은 레인별로 다르게 표시되며, BMS 키음 토큰과 롱노트/마디선을 함께 표시합니다.
- `O`: 현재 커서부터 10초 재생, `Ctrl+O`: 처음부터 차트 끝까지 재생
- `P`: 현재 커서 구간부터 실제 판정 플레이를 시작합니다. 편집 버퍼를 임시 BMS로 실행하며, 해당 세션은 연습 모드·노페일로 동작합니다.
- `Ctrl+Z`: 실행 취소, `Ctrl+R`: 다시 실행
- `Ctrl+Y`: 노트 클릭 시 같은 Y의 BGM을 해당 레인 키음으로 옮기는 기능 켜기·끄기
- `Ctrl+S`: Save As
- `Esc`: 편집기 닫기

Save As는 원본 파일을 덮어쓰지 않고 같은 차트 폴더에 새 BMS를 저장합니다. 기존 키음·BGM·BPM/STOP·미지 헤더와 기존 롱노트 정보를 보존하며, 조건부 `RANDOM/SWITCH` 차트와 `LNTYPE 2` 차트는 MVP에서 편집을 거부합니다. `O`/`Ctrl+O` 프리뷰는 시작점부터 10초간 제한된 오프라인 믹스를 사용합니다.

왼쪽 `BGM/배경음` 트랙에는 BMS 채널 01 이벤트가 표시됩니다. 마우스로 세로 그리드를 클릭하면 레인과 시간 위치를 선택해 노트를 넣을 수 있고, 노트나 배경음 위에 커서를 두면 해당 키음을 짧게 미리 듣습니다. 자동 정렬이 켜져 있을 때 노트를 클릭하면 같은 시간의 BGM이 그 노트의 키음으로 이동하며 기존 키음은 BGM으로 보존합니다. 프리뷰는 `O`에서 10초, `Ctrl+O`에서 시작점부터 차트 끝까지 모든 BGM과 노트 키음을 함께 재생합니다. 저장 결과는 항상 새 `.bms` 파일입니다. 실제 Windows 창에서의 마우스 감각, 장시간 편집, 장치별 키음 출력은 별도 수동 확인 범위입니다.

컬럼 폭과 노트 폭·높이는 현재 선택한 스킨 포맷의 레인 폭/노트 크기 설정을 사용합니다.
