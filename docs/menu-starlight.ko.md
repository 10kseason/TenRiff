# 별빛 클리어 표시와 마우스 조명

[한국어](menu-starlight.ko.md) | [English](menu-starlight.en.md) | [日本語](menu-starlight.ja.md) | [简体中文](menu-starlight.zh-CN.md)

기본 곡 목록·라이브러리·기록 화면은 사용자가 제공한 원본 정적 이미지를 `assets/menu/song-select-constellation-background.png`로 그대로 사용합니다. 가로세로 비율을 유지해 화면을 채우고 넘치는 가장자리를 잘라 표시합니다. 이미지 로딩에 성공하면 기존 배경 영상과 절차적으로 그리던 배경 별자리를 건너뜁니다. 자산이 없거나 로딩에 실패하면 기존 배경으로 돌아갑니다. 사용자 스킨의 정적·영상 배경과 다른 화면의 동작은 유지합니다.

기본 곡 목록에서 제공된 v2 PNG의 별빛 그라데이션을 표시합니다. EZ는 초록, NM은 파랑, HD는 빨강, EX는 새로 제공된 투명한 은하, 검증된 풀콤보는 금색입니다. 모든 행은 1920 기준 x=800부터 x=1034까지 표시합니다. 원본 PNG는 수정하지 않고 가로·세로 전체를 짧은 행에 늘려 담아 무늬가 가로로 길게 보이게 합니다. 캐시된 Direct2D 색상 행렬로 채도를 1.2배 적용하며 원본 알파는 보존합니다. EX 자산은 `TENRIFF_RESULT_EX_galaxy.png`로 원본 그대로 복사했습니다. 풀콤보는 기존 검증 기록으로만 표시하며 폴더·미플레이·실패·보조 플레이를 일반 클리어로 꾸미지 않습니다.

현재 화면 구성은 왼쪽 위에 큰 TenRiff 마크와 워드마크를 놓고, 상단의 텍스트·밑줄 탐색 탭은 그룹 전체를 가운데 정렬합니다. 테두리가 있는 조작 버튼의 별자리 장식은 유지합니다. 선택곡 패널 가운데에는 실제 정확도 등급을 표시합니다. 등급은 기존 정확도 기준을 유지하며 EX Score로 계산하지 않습니다. 클리어 배지 아래에는 차트에 작성된 난이도 또는 선택한 외부 난이도표의 레벨을 표시하고, 목록 행의 제목 아래에는 작곡가 정보를 유지합니다.

내 최고 기록 영역에는 최고 EX 기록의 **EX Score**, 정확도, 최대 콤보를 표시합니다. 상세 등급과 판정 개수도 같은 기록을 사용합니다. 최고 클리어 램프는 별도로 보존하므로 낮은 클리어에서 EX Score를 갱신해도 획득한 램프가 낮아지지 않습니다. 기록 화면은 선택한 기록을 그대로 표시합니다. 세션 설정 명칭은 **노트 속도**, **게이지 시프트**입니다. 과거 판정 데이터는 보존하며 현재 점수는 [EX Score 전환](ex-score.ko.md)을 따릅니다.

목록의 보이는 행과 선택곡 패널에서 긴 제목·작곡가 이름은 논리 좌표 기준 초당 14픽셀로 왕복하며 양 끝에서 2초씩 멈춥니다. 영역에 들어가는 글자는 움직이지 않습니다. 동작 줄이기에서는 자동 이동 없이 고정된 말줄임표 표시를 사용하고, 각 텍스트는 자기 영역 밖으로 그리지 않습니다. 작은 곡 썸네일은 인덱스의 정적 BGI 이미지를 사용합니다. BMS `STAGEFILE`, `BACKBMP`, 참조된 정적 BMP 이미지 순서이며 영상은 재생하지 않습니다. 이미지가 없거나 해독할 수 없으면 TenRiff 마크를 표시합니다.

버튼이나 옵션 위에 포인터를 올리면 따뜻한 원형 빛이 포인터 주변과 해당 표면에 번집니다. 기존 클릭 영역을 사용하며 선택이나 클릭을 추가로 발생시키지 않습니다. 창 밖·포커스 이탈·일반 배경·비활성 버튼에서는 빛을 표시하지 않습니다. 플레이 도중에는 숨기고 일시정지 메뉴에서만 허용합니다. 동작 줄이기에서도 맥동 없이 포인터를 따라 정적으로 표시합니다.

앞선 [배경 별자리](menu-constellations.ko.md)는 정적 배경을 불러올 수 없을 때의 기존 대체 경로에 남습니다. 라이브러리 전용 폴더 추가 버튼 수정은 병행 작업과 조율하여 보존했습니다. TenRiff 2.0.0은 계정 연동 멀티플레이와 세션 믹스 생성·저장·가져오기 수정도 함께 포함합니다.

검증된 올콤보 기록은 선택곡의 클리어 배지 글자를 **ALL COMBO**로 표시합니다. 기존 로고와 테두리는 유지하며 배지 안에 은은한 블룸과 작은 렌즈 플레어를 더합니다. 느린 반짝임은 동작 줄이기에서 고정됩니다. 곡 목록은 배지에 해당하는 최고 클리어 기록, 기록 화면은 선택한 기록의 검증된 풀콤보 정보를 사용합니다. 노트 수와 최대 콤보의 단순 비교로 올콤보를 추정하지 않습니다. 점수 계산·판정·DB·서버는 바뀌지 않습니다.

옵션 카드 개편과 방 채팅 입력 수정은 [별자리 옵션 화면과 방 채팅](options-chat.ko.md)을 참고하세요.
