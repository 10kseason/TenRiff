# TenRiff 1.9.1.1 온라인 BMS 기록

1.9.1.1은 새 BMS 게이지·타이밍·RANDOM 분기 기록을 **Sites 커뮤니티 리더보드**에 제출하도록 클라이언트와 웹의 조건 처리를 함께 확장하는 후속 버전입니다. 공개 여부, 다운로드와 최종 검증 결과는 [릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.1.1)를 기준으로 확인하세요. 배포 전에는 아래 항목을 지원 범위로 읽어야 하며, 실제 공개 서버 검증 완료를 뜻하지 않습니다.

## 바뀌는 동작

- 1.9.1에서 로컬 전용이던 BMS 게이지 v2, BPM/STOP 타이밍 v2, 제어 흐름 v2 기록을 지원 조건에 맞으면 웹 업로드 대상으로 처리합니다. **1.9.1.1 클라이언트와 대응 웹 배포가 모두 필요합니다.** 기존 1.9.1 실행 파일은 업로드 차단을 유지하며 교체하거나 덮어쓰지 않습니다.
- 규칙 버전과 실제 선택된 분기 내용을 순위 조건에 넣습니다. 같은 곡이어도 게이지·타이밍·분기 규칙이나 분기 내용이 다르면 다른 조건으로 비교합니다. 원래 파일의 차트 식별자는 유지합니다.
- 분기는 제어문을 처리한 뒤 활성화된 내용의 SHA-256으로 식별합니다. 서로 다른 시드가 같은 분기 내용을 선택하면 같은 조건에 속합니다. 시드는 각 점수의 재현용 정보로 보관하며 시드 숫자 자체로 순위를 나누지 않습니다.
- 기존 버전 정보가 없는 제출은 옛 규칙으로 처리하여 기존 보드와 기록을 유지합니다. 새 정보는 웹 제출에 선택적으로 추가하며 기존 리플레이 파일과 리플레이 형식은 바꾸지 않습니다.

F10 → 웹 리더보드에서 기존 연결을 사용하고 평소처럼 플레이하세요. 지원 조건을 만족하는 결과가 저장되면 제출을 시도하고 결과 화면과 F10에 상태를 표시합니다. 옛 로컬 기록을 일괄 재전송하거나 실패한 대기열을 다음 실행에 자동 복구하는 기능은 추가하지 않습니다.

## 유지되는 제한

Sites는 인증·형식·중복과 지원 조건을 검사하는 **`client_submitted` 커뮤니티 기록**입니다. 서버에서 C++ 리플레이를 다시 실행하거나 부정행위를 검증한다는 뜻이 아닙니다. 별도의 Ranked 경로는 해당 검증 서버가 지원하기 전까지 새 BMS 규칙 기록을 계속 제외합니다. LN Mix v2, 자동 플레이, 연습, 중단, 일시정지, 코스 등 기존 제외 조건도 유지합니다.

마스터 10%·BMS 연주 20%·디바운스 0ms 기본값과 저장한 설정, 1.9.1의 게임플레이·리플레이 동작, 이전 공개 자산 및 고정 기준 1.9.0을 유지합니다. 이번 변경으로 이전 기록의 점수나 게이지를 다시 계산하지 않습니다.

검증은 클라이언트 제출 계약, 웹 수용·거부 조건, 분기/규칙별 순위 분리, 기존 보드·기록 보존과 공개 배포 후 조회를 포함합니다. 실제 계정의 점수 제출, 리플레이 재실행 검증, 물리 장치·장시간 플레이는 각각 별도의 증거가 필요합니다. 최종 통과 여부와 미검증 항목은 릴리스 검증 결과에 기록합니다.
