# 1.9.6 — 고정 판정과 스킨 설정

공개 1.9.5.3에서 이어지는 릴리스입니다. 일반 소스 기준선 **1.9.0**과 이전 릴리스·설치·프로필을 유지합니다. 공개 여부와 다운로드는 [1.9.6 릴리스 페이지](https://github.com/10kseason/TenRiff/releases/tag/1.9.6)가 기준이며, 최종 검증 결과는 [검증 범위](release-1.9.6-gate.md)와 별도 릴리스 증거에 기록합니다.

- 기본 PG는 VEZ/EZ 22, NM 19, HD 15, VHD 10ms로 고정합니다. 기본 GR/GD/BAD는 기존 정확값을 유지합니다. Hard는 모든 파일 RANK에서 기본 NM의 PG/GR/GD/BAD 전체를, EX는 기본 VHD 전체를 그대로 사용합니다. 별도 배율이나 정수 ms 반올림은 없습니다. [정확한 표와 저장값 호환](judgement-baseline-20261018.ko.md).
- 새 기본/Hard 기록은 R9, EX는 R10입니다. Sites는 정식 설정의 새 Online R9/R10 제출만 받으며, 이전 규칙의 새 제출은 차단합니다. 기존 보드와 기록은 레거시 읽기 전용으로 보존하며 재계산하지 않습니다. Guest·미표시 과거 기록·커스텀·LN Mix v2의 업로드 제외와 `client_submitted` 경계는 유지합니다. 별도 Ranked 검증 서버가 지원하지 않는 규칙은 계속 차단합니다.
- R1–R8 리플레이는 당시 판정을 유지합니다. 대전은 패킷 배치를 유지한 프로토콜 v7을 사용하며, 다른 판정창의 v6 상대를 거부합니다. 저장 `judge.pg=21ms`는 호환용 기준값으로 유지하고 프로필을 자동 이관하지 않습니다.
- 스킨 설정에 14개 키 모드 탭을 가로 한 줄로 놓고 끝에 검색창을 추가합니다. 탭 클릭 또는 Ctrl+Tab / Ctrl+Shift+Tab으로 모드를 바꾸고, Ctrl+F로 검색합니다. Tab / Shift+Tab은 탭·검색·목록을 이동합니다. 현재 언어의 항목명·값·분류를 검색하고 UTF-8 문자를 완전한 단위로 지웁니다.
- 기어 경계선과 판정·콤보·FAST/SLOW·인디케이터의 X 조절을 숨기되 저장값은 보존합니다. 새 스킨·폴더 열기·다시 불러오기는 TenRiff에서만, 가져온 스킨 선택은 TenRiff/LR2에서만 표시합니다. 원본 모드의 스크래치 조건과 구분선 너비 100%를 유지합니다.
- 창모드 전환 후 파일 드롭을 유지합니다. 콤보와 판정 카운터가 겹치면 가까운 위·아래쪽으로 피하므로 콤보 Y를 인디케이터 위로 옮길 수 있습니다. Classic/Studio와 플레이어/고스트에 적용하며 저장 위치는 유지합니다. 기본 앨범 판정 배지는 192×28 디자인 픽셀이고 사용자 지정 박스가 우선합니다. [세부 동작](skin-ui-followup-20261018.ko.md).

단일 기본 판정표와 기존 설정 형식을 재사용해 수치가 따로 어긋나거나 숨긴 값이 지워지는 것을 막았습니다. 기존 오디오·게이지·고정 등급·공푸어 정확도 정책과 BGA 모델 미동봉을 유지합니다. 자동 메시지·렌더 검사와 실제 탐색기 드래그, IME, 물리 입력·청음·장시간 플레이·다른 PC 검증은 구분합니다.
