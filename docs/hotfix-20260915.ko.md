# 1.7.2 핫픽스 — 2026-09-15

9월 13일 Sites 통합 클라이언트를 기준으로 만들었습니다. 기존 설치와 배포 파일은 보존하며 새 폴더에 압축을 풀어 실행하세요. 새 설치의 웹 리더보드는 F10에서 한 번 연결합니다. 게임 버전 1.7.2와 리플레이/웹 제출 형식은 유지합니다.

## 곡 종료와 기록 등록

이전에는 마지막 노트 이후 시작 시 계산한 음원 길이 또는 차트의 뒤쪽 빈 마디까지 기다린 후 결과를 저장했습니다. 실제 후주가 끝나도 대기가 남을 수 있었으며, 레인 키로 후주를 건너뛰면 바로 저장됐습니다.

이제 마지막 판정과 최소 결과 대기가 끝나고, 예약된 BGM·재생 중인 음원·장치 출력 버퍼가 모두 끝나면 추가 키 입력 없이 저장합니다. 연결된 리더보드에는 기존 업로드 작업 스레드가 자동 제출합니다. 디코딩 실패 자산은 후주 대기에서 제외하며 수동 후주 건너뛰기도 유지합니다. 차트 길이는 음원 메모리 추정치로 바꾸지 않아 리플레이 검증의 원본 길이와 일치합니다.

이 변경은 종료 지연 경로를 재현한 수정입니다. 사용자가 제보한 실제 차트나 실제 계정 업로드를 재현한 것은 아닙니다. 네트워크 실패·연결 해제·지원하지 않는 플레이의 제출 제한은 [웹 리더보드 안내](sites-leaderboard.md)를 참고하세요.

## 난이도표 선택

곡 선택의 난이도표 선택 창에서 버튼 또는 단축키로 적용합니다. F9는 이 창 안에서 U_E 팩 8K 선택에 사용하고, 창 밖의 스크린샷 동작은 유지합니다.

| 단축키 | 선택 |
| --- | --- |
| F1 / F2 / F3 | 5키 에리 / 7키 에리 / 10키 리바이브 |
| F4 | 기본 LV |
| F5 / F6 | 스텔라 / 새틀라이트 |
| F7 / F8 / F9 | U_E 팩 4K / 6K / 8K |

주소와 개별 표 설명은 [라이브러리 관리](library-management.md)에 있습니다.

## 검증 범위

- Windows x64 Release 클라이언트 및 검증기 빌드 성공.
- 수정 전: 무입력 자동 종료 2개 회귀 테스트 실패, 수동 후주 건너뛰기 통과.
- 수정 후: 전체 단위 테스트 782개 통과, 통합 제외 0개. 무음·후주·지연된 BGM·장치 버퍼 지연·실패 음원·수동 건너뛰기에서 실제 콜백, 결과/리플레이 저장, 해시, 웹 제출 데이터 생성을 검사했습니다.
- 실제 WAV/실패 디코더로 차트 길이 보존과 실패 음원 제거 확인.
- 표 관련 13개 테스트와 실제 네트워크 가져오기 8표 모두 통과. 신규 표 항목 수는 스텔라 2311, 새틀라이트 2460, U_E 팩 4K 1117 / 6K 1544 / 8K 199였습니다(검증 시점 기준).
- 독립 코드 리뷰에서 종료 변경의 구체적인 회귀를 찾지 못했습니다.
- 실제 키보드 연주·GUI 화면 확인·실계정 업로드·ASIO 장치 재생은 이번 핫픽스에서 실행하지 않았습니다. ASIO의 기존 장치 확인 한계는 [1.7.2 릴리스 게이트](release-1.7.2-gate.md)를 참고하세요.
