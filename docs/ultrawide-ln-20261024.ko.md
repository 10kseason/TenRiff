# 1.9.9 로컬 후속: 21:9 화면과 롱노트

공개 1.9.9(`79433ba`)에서 시작한 미공개 후보다. 일반 고정 기준선은 1.9.6이며 기존 릴리스·패키지·프로필·차트를 보존한다. [English](ultrawide-ln-20261024.md) · [日本語](ultrawide-ln-20261024.ja.md) · [简体中文](ultrawide-ln-20261024.zh-CN.md)

- **21:9:** 기존 2560×1080·3440×1440 지원을 유지하고 5120×2160 프리셋을 추가했다. 전체 화면 배경·BGA·어두운 덮개가 좌우 공간까지 채운다. UI·노트 비율·마우스 좌표·저장된 스킨 위치는 1920×1080 설계 기준으로 중앙에 균일 확대한다. 배경은 기존 비율 유지 cover crop을 사용하며 명시된 작은 스킨 영역은 보존한다.
- **롱노트 중간 해제:** 처리 중 손을 떼도 남은 몸통이 즉시 사라지지 않고 원래 꼬리가 지나갈 때까지 스크롤한다. 이미 처리한 머리·활성 발광·판정을 되살리지 않는다. 플레이어와 고스트에 함께 적용하며 해제 판정·타이밍·게이지·콤보·리플레이 입력은 유지한다.
- **지뢰 회피 LN Mix:** 새로 만드는 LN은 같은 레인 지뢰 앞뒤로 최소 50ms를 비운다. 공간이 부족하면 단타로 남기고, 뒤에 있는 지뢰는 꼬리의 최대 길이를 제한한다. 다른 레인의 지뢰는 독립된 LN을 막지 않는다. 원본 노트·LN·키음·지뢰는 유지하며 기존 seed와 음악적 길이 선택을 사용한다. 지뢰가 없는 차트의 결과는 v2와 같다.

새 플레이는 기존 `long_note_mix_version` 필드에 **3**을 기록한다. 과거 v1/v2 리플레이는 원래 배치를 재현하며 다른 버전 고스트가 새 플레이의 배치를 바꾸지 못하게 한다. v3 리플레이는 이 후보의 검증기가 필요하며 공개 1.9.9 검증기는 거부한다. 리플레이 필드·판정 ruleset ID·peer 프로토콜은 바꾸지 않는다. LN Mix v2/v3의 기존 온라인·BEST 제외도 유지한다. 웹 배포·DB 변경은 없다.

자동 기하·HUD·지뢰 경계·저장 리플레이·네이티브 검사는 후보 옆 `evidence` 폴더에 기록한다. 실제 21:9 모니터·사람의 입력·장시간 플레이·모든 외부 스킨의 검증과는 구분한다.

마지막 LN을 놓친 경우에도 자동 결과 전환은 꼬리가 화면을 벗어날 때까지 기다리며 음수 시각 오프셋도 반영한다. 명시적 건너뛰기·중단·게임 오버는 유지한다.
