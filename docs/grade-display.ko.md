# 정확도 등급 표시

2026-10-16 사용자가 고정한 Stable 등급 규칙이다. 후속 버전에서 임의 변경하지 않는다. 등급은 점수 배율이나 상세 정확도와 별개로 **일반 정확도**에서 계산한다.

| 등급 | 완주한 플레이의 정확도 |
|---|---|
| S+++ | 99% 이상 |
| S++ | 98% 이상, 99% 미만 |
| S+ | 97% 이상, 98% 미만 |
| S | 95% 이상, 97% 미만 |
| A+ | 93% 이상, 95% 미만 |
| A | 90% 이상, 93% 미만 |
| B | 85% 이상, 90% 미만 |
| C | 80% 이상, 85% 미만 |
| D | 70% 이상, 80% 미만 |
| E | 70% 미만의 생존 완주 |
| F | 실패 |

일반 정확도 계산과 판정/점수/게이지 규칙은 바꾸지 않는다. 정확도는 저장된 가중 정확도 값이 있으면 그 비율을 사용하고, 오래된 기록은 기존 로더가 판정 개수에서 계산한다. 등급 경계에는 표시용 소수점 반올림을 적용하지 않는다. 예를 들어 실제 정확도가 98.999999%이면 화면에 99.00%로 표시되더라도 등급은 S++다.

새 결과, 저장 기록 보기, 곡 선택의 기록 및 최고기록은 같은 등급 함수를 사용한다. 이전 SSS/SS/AA 등의 문자값을 새 등급으로 치환해서 저장하지 않고, 통계에서 표시 등급을 다시 계산한다. 원시 결과/리플레이 파일과 최고기록 선택 순서는 그대로 둔다. 멀티플레이 및 온라인의 숫자 순위는 등급과 다른 값이며 변경하지 않는다. 멀티플레이 결과 목록은 기존대로 점수 순위를 표시한다.

기록 없음은 `--`, 자동연주는 `AUTO`다. `ABORTED` 상태나 명시적인 `aborted` 정보가 있는 수동 중단은 `--`로 표시한다. 기존 `game_over` 필드는 사망뿐 아니라 미완주/중단도 포함하므로 원시 값을 바꾸지 않는다. 사망과 중단을 구별하는 정보가 없는 구형 실패 기록은 기존 `game_over` 값을 따라 F로 남는다.

S+++·S++·S+에는 기존 최상위 등급의 금색과 캐시된 glow를 사용한다. 글자 전체를 한 줄로 측정하고 영역에 맞춰 표시하며, glow 생성 실패 시에도 같은 측정 크기로 일반 글자를 표시한다. 이전 스킨에서 지정한 글꼴과 등급 영역은 유지한다.
