# 1.8.8 초기 결과 분석 후보 로컬 검증

아래 내용은 2026-10-12의 초기 결과 분석 후보 `8fd7071`에서 수행한 기록입니다. 후속 [추가 릴리스 조건](release-conditions-1.8.8.ko.md)의 자유 해상도·결과 스크린샷 안내·긴 LN Mix를 포함한 최종 검증으로 대체 해석하지 않습니다. 이전 통과 수치와 한계는 당시 증거로 보존합니다.

미배포 후보 검증이며 현재 고정 기준 [1.8.7](baseline-1.8.7.md)을 바꾸지 않습니다. [분석 기능·조작·향후 계획](result-analysis-1.8.8.ko.md)을 함께 읽으세요.

## 확인한 범위

- MSVC Windows x64 Release 전체 대상 빌드 통과.
- CTest 3/3 통과. 내부 테스트 1,064개, 통합 검사 건너뜀 0. 선택적 외부 Python 기준 구현과의 비교는 별도입니다.
- 오프라인 스킨 편집기 회귀 검사 33/33 통과.
- 실제 MenuApp와 GameSession의 분리된 테스트 프로필에서 92/92 검사 통과. 곡 시작·결과·키보드/마우스 분석 탭·돌아가기·32레인 자료 전환·멀티 상태의 분석 접근 차단을 확인했습니다. 물리 키보드 타건이나 실제 온라인 멀티 검증을 뜻하지 않습니다.
- 결과 화면 11가지에서 성공한 Present 330/330, 클릭 영역/해당 테스트 창의 입력 전달 68/68 통과. 한국어·영어·일본어, 16레인, 측정 표본 없는 결과, 구형 기록, 1920×1080 및 960×540 화면을 포함합니다. 작은 창의 숫자 가독성을 확인한 후 분석 글자를 키웠습니다.
- 저장·복원 검사는 유효한 분석의 왕복, 큰 정수/실수 정밀도, 구형·미지원 버전·잘못된 배열/집계·비유한 수치의 분석 없음 처리를 확인했습니다. 기존 점수와 리플레이 버전은 그대로입니다.

## 기존 판정과의 비교

1.8.7과 후보를 같은 컴파일러로 빌드하고 324개 고정 입력 시나리오, 25,596개 연산, 25,920개 상태를 비교했습니다. 기존 점수·상세 점수·정확도·콤보·게이지·리플레이 입력·피드백 및 판정 관련 상태는 비트 단위로 같았습니다. 샘플레이트·Rate·R1~R4·판정 모드와 LN·미스·중도 종료 조건을 포함합니다. 새 분석 자료는 비교 대상에서 제외합니다.

오디오·입력·GameSession·플레이 렌더링·스프라이트 배칭의 보호 파일 31개는 1.8.7과 SHA-256이 같습니다. 기존 ResultStats의 점수/통계 계약을 바꾸는 대신 별도 고정 크기 분석을 관찰자로 추가했습니다. 새 화면은 그 분석을 사용하며 일반 LN 자동 완료의 합성 0ms를 타이밍 표본으로 사용하지 않습니다.

## 비용과 검증 한계

빌드 종료 후 순서를 번갈아 수행한 6쌍의 고정 엔진 연산 측정에서, 25,596연산 묶음의 p50 중앙값은 793.10µs에서 917.10µs였습니다. 쌍별 증가 중앙값은 128.95µs/묶음(+16.35%)으로 분석 집계의 비용이 있습니다. 연산에는 advance·동기화·실패 후 무시된 입력도 포함됩니다. 이는 실제 입력 지연, 오디오 콜백 지연, 전체 게임 CPU나 GPU 성능의 측정이 아니며 성능이 완전히 같다는 주장을 하지 않습니다.

전체 분석은 고정 크기이며 관찰 시 가변 배열 확장, 플러그인 실행, 외부 대기를 하지 않습니다. 물리 입력/오디오 동기, 다른 PC, 장시간 실곡 플레이, 온라인 멀티, 이번 후보의 ASan/호스팅 CI와 추출 소스의 독립 재빌드는 아직 확인하지 않았습니다. 플러그인 런타임/API/SDK와 1.9.0 안정화는 문서상의 후속 계획입니다.

초기 빌드 도구의 제한 환경 대기, 검증 도구의 MSVC 분기 중첩 한계는 최종 빌드 전에 해소했습니다. 기존 설치·프로필·1.8.7 태그와 배포 파일을 덮어쓰지 않았습니다. 공개 PR·병합·릴리스·사이트 배포는 이 로컬 검증 범위에 포함하지 않습니다.
