# Music, transitions and record feedback · local candidate 2026-11-03

Based on released 1.9.9.8 hot fix 1. Existing releases, installations, profiles and fixed baseline 1.9.6 are preserved. No upload or deployment.

- Audio settings add independent main/clear/fail music, button click, slider drag and file-drop sound pickers (MP3/OGG/WAV/FLAC). Enter/click opens the picker; Left/Right chooses default/none. Cancel preserves the selection. Custom paths remain external; keep the chosen files available. Custom main music applies to the default title-music mode.
- Main Menu 5 becomes Clear; Options uses the original Main Menu 3 music (Main Menu 3 itself is preserved); Main Menu 4 is excluded from this candidate. Displaced originals remain outside the source/package in `original-assets`. The options screen plays the replaced Options.mp3.
- Generated prism artwork appears on single-player entry and song loading in 30 time samples over one second. Loading overlaps the transition; fast loads wait before countdown/audio starts, slow loads add no extra second. Instant restart and peer synchronization stay unchanged. Reduced motion uses a still image.
- NEW RECORD requires at least +1 against the compatible score high-water mark (first record compares against zero), with simultaneous 1.2-second digital score distortion. A clear-only improvement does not trigger it. Official BEST storage remains clear-first, score-first within equal clear. Prior score and rank are rebuilt from existing history without a file migration.
- Rank upgrades brighten and shatter the previous rank, then reveal a gently glowing new rank. Skip/reduced-motion settings are respected.
- Left/Right inside a level's song list return to the level folder list, preserving quick-setting and record-view arrows.
- Gauge Shift result graphs use four fixed bands from EASY 0% to EX 100%. EX 0% and HARD 100% meet at the same height; gauge refill never looks like recovery. Raw gauge history and gameplay are unchanged.
- Skin HUD adds an opt-in score comparator with saved X/Y. BEST shows the signed score difference against a compatible replay at the same song time (`--` if unavailable). S/S+/S++/S+++ track exact categorical-accuracy targets 95/97/98/99%, in percentage points. Native score uses different weights, so a score of 9500 is not presented as an S guarantee. Assisted, autoplay, playback and incompatible comparisons are excluded.

Short effects use the existing Windows system-output path and obey master/focus mute; music retains the selected WASAPI/ASIO endpoint. Custom effects decode asynchronously with a short duration bound. Consult the candidate's `evidence/VERIFICATION.ko.md` for checks and limits. Physical listening/input, arbitrary user files/skins, long sessions and other PCs require separate testing.
