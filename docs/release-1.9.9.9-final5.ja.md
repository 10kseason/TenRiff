# TenRiff 1.9.9.9-final5

[한국어](release-1.9.9.9-final5.ko.md) | [English](release-1.9.9.9-final5.en.md) | [日本語](release-1.9.9.9-final5.ja.md) | [简体中文](release-1.9.9.9-final5.zh-CN.md)

LR2 記録の取り込みでハッシュ計算と譜面探索を軽量化し、元の RANK がない場合や範囲外の場合の誤った EX 認定を修正しました。Andro の空の末尾小節により BPM が 1 になる問題も修正しました。固定ベースラインは final4 のままです。

- LR2 に必要な MD5 のみ計算し、EX 確認時の音声・背景ファイル探索を省きます。重複するフォルダーの探索を避け、全対象譜面が見つかると終了します。
- 合成記録 512 件とローカル譜面 15,569 件による同一 PC の順次測定で、91.139 秒から 9.852 秒に短縮しました。この標本のランプ・EX の JSON は完全一致しました。個人 DB や他の PC での速度保証ではありません。
- 元の RANK がない場合や範囲外の場合は、ゲーム側の EASY 補正で EX を認めず、元の LR2 ランプのみ保持します。DB は読み取り専用で、キャンセル・失敗時は以前の取り込みを保持します。
- 最後の非ゼロイベントの小節より後にある長さ指定のみ・全て 00 の空小節を基準 BPM の集計から除外します。確認した Andro 20 譜面と Safe/Fast 索引は全て 165。ノーツ時刻・数・譜面全体の長さは維持します。キャッシュ v22 は派生メタデータを一度再構築します。
- 取り込みは表示専用です。TenRiff の記録・BEST・アップロード資格、判定・ゲージ、既存 R1–R14 リプレイ方針は変えません。個人 DB や元の Andro 譜面は配布せず、ソースには合成テスト DB を二つだけ含めます。
- ローカル候補は CTest 4/4（1,547 件、skip 0）とネイティブ 747/747 を通過しました。配布 ZIP・独立再ビルド・CI・公開ダウンロードをリリースゲートで確認します。物理入力・試聴・長時間プレイ・他の PC・個人 DB 全体の所要時間は未検証です。
