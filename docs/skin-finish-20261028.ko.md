# 심플 롱노트 · EX 팔레트 · 올콤보 이미지 (로컬 후보)

1.9.9.3 릴리스 소스에서 분리한 로컬 후보입니다. 버전과 일반 기준선 1.9.6, 이전 릴리스/설치/프로필을 유지합니다.

- 기본 rect(Luma Keys)는 유지하고, native의 simple_rect·square·circle·diamond·arrow·triangle·pentagon·hexagon 롱노트 머리/몸통/꼬리를 레인 단색으로 표시합니다. 일반 탭, 가져온 스킨의 이미지/명시적 스프라이트, 투명도·너비·테이퍼 설정은 유지합니다. 동봉 SimpleSquare는 simple_rect를 선택합니다.
- EX 전용 무지개는 채도를 18% 낮추고 보라/자홍을 제외한 분홍→빨강→노랑→초록→청록→파랑 6색으로 표시합니다. 끝을 분홍으로 연결하지 않아 보간으로 생기는 보라도 막습니다. EX를 공유하는 S+~S+++와 클리어 카드/배지/Shift Start/게이지에 적용됩니다. EZ/NM/HD·E/F 연보라·일반 판정색은 유지합니다.
- 곡 전체를 올콤보로 완료하면 숫자 아래 COMBO 라벨 대신 ALL COMBO 이미지를 표시합니다. 마지막 LN 꼬리까지 엔진이 완료해야 하며, 플레이어와 고스트를 독립적으로 확인합니다. 실패/중단/자동 연주/Auto Scratch/No Fail/부분 연습에는 표시하지 않습니다. 기존 콤보 규칙을 보존하므로 빈 POOR는 자체적으로 콤보를 끊지 않습니다.
- 새 완료 결과의 최대 콤보 칸에도 이미지를 표시하여 종료 대기가 0인 경우에도 확인할 수 있습니다. 과거 결과에는 전체 완료 근거를 추정해 이미지를 붙이지 않습니다. 결과의 기존 FULL COMBO 판정과 저장 형식은 바꾸지 않습니다.
- 이미지는 장치 초기화 후 첫 화면에서 한 번 읽고 투명 여백을 제외해 표시합니다. 파일 누락 시 텍스트로 대체합니다. 기존 콤보 위치·크기·판정 카운트와의 겹침 회피를 사용하며 판정/점수/오디오/리플레이/peer v7 계약은 유지합니다.

[이미지 제작 기록](../assets/menu/achievements/README.md). 이 문서의 검증은 역사적 후보 기록이며, 새 릴리스 검증은 [1.9.9.5 검증표](release-1.9.9.5-gate.md)를 따릅니다. 실제 키 입력/장시간 플레이/다른 PC/임의의 스킨은 별도 확인이 필요합니다.


올콤보 이미지는 둥근 테두리와 은은한 노란 글로우를 사용합니다.
