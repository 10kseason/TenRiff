# TenRiff 1.9.4 — 内存回收时机与游玩设置

1.9.4 基于用户选择的 1.9.3 (`bf544e17f22879011a04a7fd157e40b57f6598bb`)。固定基线仍为 1.9.0，保留以前的发布文件、安装与配置档。

- 已解码音源在游玩及暂停时保留，不再根据运行时预算逐出。会话结束、音频及解码工作停止后才释放。保留开局优先加载及后续预读。
- 静态 BGA 超过原来的 256张/192MiB LRU 上限后仍保留，返回菜单时清空。曲库索引的强制堆/工作集整理在加载、游玩、暂停期间合并延期，随后由菜单回收点或会话结束后的索引请求执行。
- TenRiff 使用原生 C++，没有托管 GC。本策略针对上述显式缓存逐出及强制整理；普通对象生命周期、视频帧复用、异步取消与设备丢失恢复保持不变，并非阻止所有分配、释放或操作系统换页。
- PCM 累积至会话结束，静态 BGA 累积至返回菜单。不中途返回菜单的组曲可能同时保留多首曲目的 BGA，超大谱面可能增加内存压力。不承诺已测得的卡顿或物理输入延迟改善。
- 可选圆点/条码形状。始终显示保留刻度和中心，各判定标记在游戏时间 0.7秒后消失，FAST/SLOW 文字保留策略不变。
- WASAPI 输出设备用于演奏和 BMS 试听。ASIO 保留专用驱动选择，菜单/结果音乐保留 Windows 默认 MCI 输出。指定设备断开后不会悄悄改用其他输出。
- 配置档可指定/清除 F1–F11 功能键，提示随之更新。F5/F6 −10/+10 改为 ×0.5/×2，每次按下仅应用一次。保留 0.5–50 范围、F3/F4 ±0.25、歌曲播放速度及判定。
- BMS 小节线对齐音符下缘，支持玩家、幽灵与音符高度设置，不改变谱面时刻。

[兼容性详情](input-feedback-20261017.zh-CN.md)。不打包 BGA 权重，保留 OFF/空路径/Auto、Guest 排除、R7/R8、旧回放和固定评级。无网站或数据库改动。
