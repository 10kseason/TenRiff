# Champagne gold gradient for EX

EX now uses a **static champagne-gold gradient**, replacing the six-color palette. Following the user's refinement, the base changes from the initial solid `#D6B77A` to richer **`#E7BA68`**, raising base HSV saturation from about43% to55%. The ramp is `#BA8B43` → base → `#FFE3A6` → base, staying in one gold hue family without purple or color cycling. Existing outlines, bloom and alpha remain.

Applies to EX/EX-HARD Classic/Studio/player/ghost gauges, EX clear outlines/logos/badges, Shift Start and the S+/S++/S+++ grades and legacy aliases sharing the EX palette. Legacy Gauge Shift EX result text and the offline editor default agree. The existing semantic EX override policy remains.

EZ/NM/HD, other grades, lane colors and the ALL COMBO image/glow are unchanged. All previous simple-LN, full-combo and BGA recovery changes are inherited. Judgement, input, audio, score, replay and FPS settings are unchanged.

Four shared paint stops preserve render caches, geometry, alpha and saved settings. Earlier six-color/rainbow and initial fully-solid descriptions are superseded. `dist-final` is final; `dist-local` preserves the initial solid package. Local/unpublished, separate `ex-gold-local` profile; general1.9.6 baseline and published1.9.9.3 remain unchanged.
